# Workspace 利用ガイド（運用ポリシー）

このファイルは agent-fleet の Workspace コンテナに自動配置される共通ルールです。
Claude / Codex / OpenCode いずれのセッションも、開始時にこれを読み込みます。
編集はリポジトリの `workspace/workspace-notes.md` で行い、イメージ再ビルドで反映されます。

## この環境について
- ここはユーザー専用のコンテナです。ブラウザの Console から複数のセッションを動かします。
- 作業ディレクトリは `~/repos/<repo>` です。リポジトリの clone は Console から行います。
- コンテナは「設定 > 環境」から作り直せます。最新イメージで再生成されます。

## やってはいけないこと
- **未コミット変更を放置しない。** コンテナを作り直すと clone 済みリポジトリは削除されます。こまめに commit / push してください。
- **認証情報を平文で残さない。** API キーやトークンをリポジトリやファイルに書かないでください。接続は「設定 > 接続」で管理し、暗号化して保存されます。
- **エージェントの内部状態を触らない・覗かない。** `~/.config/agent-fleet`・`~/.claude`・`~/.codex`・`~/.local/share/opencode` は認証情報や暗号ストアを含みます。読み書きしないでください。
- **ホストを巻き込む破壊的操作をしない。** `rm -rf` の暴発・フォークボム・暗号採掘・ポートスキャン等は禁止です。
- **リソースを独占しない。** ホストは共有です。重いビルドや大量の並列実行はメモリを枯渇させ、フリート全体へ波及します。並列度を抑えてください。

## 注意点
- 外部ネットワークは制限される場合があります。到達できない宛先があっても異常ではありません。
- 長時間動くサーバを起動するときは WS バーの「プレビュー」でポートを開いて確認してください。
- 他テナント・他ユーザーのデータにアクセスしようとしないでください。コンテナ間は分離されています。
