# Agent Fleet を使う

[English](README.md) | 日本語

このセクションは、実際に作業する人の「**どうやるの？**」に答えます。セッションの起こし方、
エージェントの追い方と操縦、リポジトリとファイルの扱い、使いたいエージェントの接続、
そして詰まったときの対処を扱います。

チームのメンバーや上限を管理する立場なら [テナントの管理](../admin/README.ja.md)、
配備を建てて維持する立場なら [配備の運用](../operate/README.ja.md) が、それぞれの入口です。

## 章立て

**必要になる順**、初日から並べています。上から読めば「初日 → 日々の作業 → その先」の
順に進めます。詰まったときは [21 困ったとき](21-troubleshooting.ja.md) から開いて構いません。
