## エージェントメモリ

メモリビュー・変更・設定の使い方は [エージェントのメモリを見る・直す](../user/memory/overview.ja.md) から始まるページに移りました。

### 取り込み・書き出し

Claude Code・muse・バンドルからの取り込み、Claude Code への書き戻し、なくなったプロジェクトのメモリの移動は、
[メモリを取り込む・書き出す](../user/memory/import-export.ja.md) にあります。

## メモリのスナップショット

エージェントが自分のファイルに溜めるメモリの履歴は、[スナップショットでメモリを戻す](../user/memory/snapshots.ja.md) にあります。

## 外部のエージェントから Agent Fleet のメモリを使う

手元の Claude Code・Claude Desktop・claude.ai から Agent Fleet のメモリを使う方法と、手元の Claude Code のメモリを持ち込む方法は、
[外部のエージェントからメモリを使う](../user/memory/external.ja.md) にあります。
