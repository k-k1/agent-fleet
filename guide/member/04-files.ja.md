# 04. ファイル — ツリー・ビュアー・Markdown/スライド

[English](04-files.md) | 日本語

## ファイルツリー

左ペインの **ファイル** に、ワークスペース内のファイルがツリー表示されます。リポジトリのノードは
折りたためます（三角の「折りたたむ」／「展開」）。1 つの作業コピーに集中したいときに、
他を畳んでおくと見通しが良くなります。

- **compact folders** — 中身が 1 つのサブフォルダだけ、という階層は `a/b/c` のように 1 行に畳んで表示されます（深い単一階層で行を無駄にしない、VS Code と同じ流儀）。
- **ツリー / 変更** — リポジトリノードでは表示を「ツリー」と「変更」（変更ファイルのみ）で切り替えられます。変更ファイルには「未追跡」「追加」「変更」「改名」「削除」のバッジが付きます。

ファイルやフォルダを右クリックすると、「新規ファイル」「新規フォルダ」「名前をコピー」
「相対パスをコピー」「名前を変更」「削除」ができます。ファイルには「朗読で開く」と
「ダウンロード」も表示されます。フォルダを削除すると中身ごと消えるので確認が出ます。
項目ごとの表示条件は [アイコン・バッジ・メニュー](badges-and-menus.ja.md) を参照してください。

ファイルの追加は**ドラッグ＆ドロップでアップロード**するか、右クリックの「新規ファイル」
から作れます。同名ファイルがあると上書き確認が出ます。ファイルを **Ctrl+クリック**（または
中クリック）すると、今の表示を保ったまま**新しいペインで開け**ます（[03](05-terminal.ja.md)）。

ツリーは**自動で最新化**されます。手で更新する必要はふだんありません。

- **セッションがターンを終えて入力待ちに戻ったとき** — そのセッションの作業コピーで作られた・
  名前が変わった・消されたファイルが、そこで反映されます。
- **セッションが作業している間も** — 走っているセッションの作業コピーは、ターンの途中でも
  20 秒ごとに追いつきます。長い作業を眺めながら「今なにが出来たか」を見に行けます。
- **タブやウィンドウに戻ったとき** — 離席している間に終わった作業や、端末で自分が動かした
  コマンドの結果もここで拾えます。
- **フォルダを開き直したとき** — 畳んでいる間の増減も出てきます。
- クローン直後、ワークスペースの起動・停止後。

自動更新で**増えたファイルの行は、数秒だけ淡く色が付きます**（何が増えたのか目で追える
ようにするためで、消えても行の中身は変わりません）。見出しの ⟳ は、上のどれにも当てはまら
ないときのために残してあります。

### 見えないフォルダがある理由

ツリーには**わざと表示されないフォルダ**があります。エージェントのログイン情報や
暗号化された保管領域（claude / codex / opencode の資格ファイル、SSH 鍵、Agent Fleet の
内部状態など）を収めたディレクトリです。あなたの秘密を守るため、一覧に出さず直接の
閲覧もできないようになっています。見当たらなくても異常ではありません。

## ファイルビュアー

ファイルをクリックすると、メイン領域の**ビュアー**に中身が出ます。上部にファイル名・
形式・サイズ・行数が表示されます。

- **構文ハイライト・行番号・ミニマップ** — コードは言語を判定してハイライトされます。行番号やミニマップの有無は ⚙設定 → 「表示」タブの「ファイルビュアー」で切り替えます。
- **巨大ファイル** — 極端に大きい／長い行のファイルは、「プレーン表示」（ハイライト・行番号なし）に自動で切り替わります。
- **LFS ポインタ** — Git LFS の実体がまだ無いファイルには「LFS ポインタ」バッジが出ます。端末でそのリポジトリに入り `git lfs pull` すると実体を取得できます（[04](03-code.ja.md)）。

### Markdown と Mermaid

`.md` ファイルは、上部の切り替えで **「プレビュー」** と **「ソース」** を行き来できます。
プレビューでは Mermaid のコードブロックが図として描画されます。コードブロックごとに
「このコードをコピー」ボタンが付きます。

リンクの挙動は次のとおりです。

- **外部 URL** — 新しいタブで開きます。
- **リポジトリ内の相対リンク** — そのファイルをビュアーで開く／フォルダを **ファイル** で表示します。
- **`#見出し` アンカー** — ページ内をスクロールします。

### Marp スライド

先頭に `marp: true` を書いた `.md` は、**スライド**として表示できます。上部の切り替えに
**「スライド」「プレビュー」「ソース」** が並び、既定でスライド表示になります。

- **◀ / ▶**（または ← → / PageUp・PageDown / Space / Home・End）で 1 枚ずつ送れます。
- **⤢** で全画面表示にできます。

### 図（`.drawio`）

`.drawio` / `.dio` ファイル（および `mxfile` を収めた `.xml`）は、**図**として表示されます。
上部の切り替えで **「図」** と **「編集」**（読み取り専用のときは **「ソース」**）を行き来
できるので、いつでも XML に降りられます。

- **複数ページ** — ヘッダに `1 / 2 ページ` のように出ます。左上の矢印でページを送れます。
- **拡大・移動** — Ctrl（⌘）＋ホイール、または 2 本指ピンチで、指した点を軸に拡大縮小します。素のホイールやドラッグで移動します。ダブルクリック／ダブルタップで「収まり」と等倍を行き来します。
- **テーマは Console に追従します** — 明暗の切り替えに合わせて描き直され、見ていたページ・倍率・位置はそのまま引き継がれます。
- **図が外部に出ることはありません。** ビューアを同梱しているので、図面が第三者のサービスへ送られることはなく、外部ネットワークが一切無くても描画できます。
- **ベンダーアイコン**（AWS・GCP・Azure・Kubernetes・ラック機器…）は、セット単位で Control Plane が 1 回だけ取得して全員分をキャッシュします。通信が制限された環境では取得できないことがあり、その場合は図形の大きさ・色・枠・ラベルは残り、中のアイコンの図案だけが空になります（図そのものは開きます）。運用者が事前に投入しておくこともできます（[運用 02](../operate/03-run.ja.md)）。

このリポジトリに試せるサンプルがあります: **[`docs/assets/architecture.drawio`](../assets/architecture.drawio)**
（Agent Fleet 自身の構成 —— AWS 上と、Docker Compose の 1 ホスト上）。

図そのものの編集にはまだ対応していません。ソース表示か、外部のエディタを使ってください。

### PDF と Office 文書

**PDF** は見た目そのままページとして表示されます（ヘッダに `1 / 12 ページ`）。矢印でページを送り、
**拡大 / 縮小**と**幅に合わせる**が使えます。フォントを埋め込んでいない**日本語の PDF でも文字が
出ます**。

**Word / Excel / PowerPoint**（`.docx` `.xlsx` `.pptx` と、`.odt` `.rtf` `.epub` など）は
**簡易プレビュー**です。中身を読める形に変換して表示するもので、面にもそう書いてあります
——**書式・図形・画像は再現されません**。体裁ごと必要なときは、情報バーの**ダウンロード**から
原本を開いてください。

- **変換も描画もブラウザの中だけ**で行われます。文書が外部のサービスへ送られることはありません
  （`.drawio` と同じ規律です）。
- 初めてその形式を開いたときだけ、読み込みに少し時間がかかります（開かない限り読み込みません）。
- 開けないときは**理由が出ます** — パスワードで保護されている、壊れている、**画像だけのページ**
  （文字を読み取るには OCR が必要で、ここでは行えません）、大きすぎる（40 MB 超）。

## 画像ギャラリー

フォルダの中の画像をカードで並べて見比べるペインです。1 枚ずつ開かなくても、そのフォルダに
何が入っているかが一目で分かります。

**開き方は 5 つ**。どれも既にあるメニューの中の 1 項目です。

- ファイルツリーで**フォルダを右クリック** →「ギャラリーで開く」
- ファイルツリーで**画像ファイルを右クリック** →「ギャラリーで開く」（親フォルダが、その画像を
  開いた状態で出ます。画像以外のファイルには出ません）
- **画像ビュアーのヘッダ**の「ギャラリー」
- ミラーの共有ファイルのカードを拡大した先の**「フォルダを開く」**
- セッションの右クリックメニューの**「生成した画像 (N)」**（下記）

通常クリックは今のペイン、Ctrl／⌘＋クリックと中クリックは別のペインに開きます。スマホは隣が
無いので同じペインに開きます。

**見え方と操作**

- **並び** — 「新しい順」と「名前順」を切り替えられます。並びはペインごとに覚えるので、タブを
  行き来しても元に戻りません。ワークスペースの Agent が古くて更新時刻を返さないときは自動的に
  名前順になり、「3 分前」のような相対時刻も出しません。
- **枚数と容量** — ヘッダにフォルダ全体の合計が出ます。多いフォルダは **300 枚で打ち切り**、
  「さらに表示」で続きを出します（カード 1 枚ごとに縮小版を取りに行くためです）。
- **フォルダ** — サブフォルダも**カードとして並び**、押すとそのペインがそこへ移動します。
  先頭の「上へ」で親に戻れ、ヘッダの**パンくず**（`.cache / agent-fleet / generated`）はどの段からでも
  飛べます。Ctrl／⌘＋クリックと中クリックは別のペインに開きます。
- **カード** — 本体をクリックすると**拡大**（← / → で送り、「3 / 12」で位置が出ます。
  **スマホでは左右のスワイプでも送れます** — 拡大しているあいだはドラッグが画像の移動になるので、
  等倍のときだけです）、右上のボタンで**ファイルペインに開きます**。見るだけならペインを消費しません。
- **更新** — 開いたとき、タブに戻ったとき、稼働中のセッションがある間は 20 秒ごとに読み直します。
  新しく増えた画像にはツリーと同じハイライトが付くので、生成が着地した瞬間が分かります。
  ヘッダの「最新に更新」でいつでも読み直せます。
- カードに出るのは**縮小版**で、原寸を取りに行くのは拡大したときだけです。

**セッションが生成した画像**

`generate_image` で作った画像は、セッションごとのフォルダに 30 日残ります。フォルダ名が
セッションの内部 ID なので、ファイルツリーからはたどれません。**セッションの右クリックメニューの
「生成した画像 (N)」**がその入口で、**生成した画像があるセッションにだけ**出ます（N は枚数）。
ワークスペースが停止しているあいだは出ません — 画像を読むのはワークスペースの中の Agent だからです。

**全部まとめて見る**なら、生成物の親フォルダを一発で開く**「生成した画像」**ボタンが 4 か所に
あります: **ミニマップのボタン列**、**リーダーキー `g g`**（コマンドパレットからも）、
**左ペインの「ファイル」見出し**、**画像生成ペインのヘッダ**。開くと、セッションごとのフォルダと
画像生成ペインの出力先（`console`）がカードで並びます。セッションのフォルダは内部 ID でなく
**セッション名と枚数**で出ます。

## 画像生成

組織が自前で持つ ComfyUI に、**エージェント（LLM）を介さずに**絵を作らせるペインです。
セッションに頼むやり方は「この文書に挿絵を 1 枚」には向いていますが、「1 つのプロンプトを
CFG 3 通りで 40 枚」には向きません。往復のたびにモデルのターンを 1 回使いますし、効かせたい
つまみ（steps・sampler・seed・LoRA の重み）に手が届かないからです。

**開き方は 2 つ**。ワークスペース操作バーの**画像生成**と、リーダーキー **`g i`** です。
ワークスペースにつき 1 枚で、もう一度開くと今あるペインに合わせます。

**作る前に**

- **モデル** — 管理者が有効にしたチェックポイントが並びます。点が付いているものはエンジンに
  読み込み済みで、そうでなければ最初の 1 枚はエンジンの起動待ちになります。ヘッダは
  **すぐ描けます** / **エンジンは停止中**（最初の 1 枚におよそ何分かかるか）/
  **エンジンを起動しています** / **エンジンを使えません** の 4 つのどれかを言います。
- **族カード** — モデルの下に、その系統が期待することが 1 行ずつ出ます。単語を並べるのか
  文章で書くのか、その書き方が定番にしている頭（チップとして出るだけで、勝手にプロンプトへは
  入りません）、ネガティブが届く系統かどうか、推奨の steps と cfg。
- **その系統が読まない欄は、理由つきで無効**になります。`flux1` と `flux2-klein` は cfg を、
  蒸留系の 3 族はネガティブを読みません。この判断はワークスペース側から来るので、実際に走る
  ものと食い違いません。
- **管理者のネガティブ**は外せないチップとして出ます（配備全体のものも同様）。利用者の文章に
  混ぜるのではなく、上に重ねて適用されます。
- **LoRA** — モデルの系統に合うものだけが並びます。選ぶと**トリガー語**がプロンプト欄の上に
  チップで出て、外すとその LoRA が持ってきた分だけ消えます。「LoRA が効かない」のいちばん多い
  原因はトリガー語の書き忘れです。重みの既定は 1 です。

**まず試走、それから本番**

- **試走（`Ctrl+Enter`）**は **1 枚だけ**を待ち行列の**先頭**に、少ない steps で、
  `generated/console/trial/` に入れます。フォームの隣の「直近の試走」に seed と所要時間つきで
  出ます。**「この seed を使う」**で固定にできて、これが本番の前に試す理由そのものです。
  試走そのものを本番にしたいときは **「steps を減らさない」** に印を付けます。試走の絵は
  7 日で消えます。
- **N 枚を投入（`Ctrl+Shift+Enter`）**は N 個のジョブ（1 個 = 1 枚）を末尾に 1 グループとして
  並べます。seed は選んだ方針どおり——**毎回ランダム**、**固定**（「同じ絵で cfg だけ振る」ための
  つまみ）、**連番**。
- 上級欄の `batch_size` は別物で、1 つのジョブの中で同時に描く枚数です。余裕のあるカードでは
  速く、無いカードでは 5 分待った末に OOM になり、1 枚ずつの取消もできません。カードの素性が
  分かっていないうちは 1 のままにしてください。

**走っているあいだ**

グループは 1 行です。「12 / 40」、バー（完了・失敗と、いま描いている 1 枚が普段の所要時間に
対して時間で満ちていきます。見ていない完了を主張しないよう、最後まで届かせずに止まります）、
そして残りのおおよその時間。**一時停止**・**再開**・**今の 1 枚を飛ばす**・**中断**は
どれもグループへの操作で、行の ✕ だけが 1 枚の取消です。行列全体を止めても試走は走ります——
それが止める理由だからです。止めたまま置くとエンジンは眠るので、行がそう言います。

ペインが通信するのは未完了のものがある間だけで、タブが裏にいるあいだは止まります。

**絵の置き場所と、数値の取り戻し方**

既定の出力先は `generated/console/` で、ギャラリーから普通のフォルダとして見られます。ここは
**掃除されません**——1 枚ごとに人がボタンを押したものだからです。上級欄の**出力先**で、自分で
名前を付けたフォルダに入れることもできます。絵の隣には作り方の記録が一緒に書かれるので、
Console のどこで拡大しても（このペイン・ギャラリー・ミラーの共有ファイル）**プロパティ**を
押せば、モデル・seed・大きさ・steps・cfg・sampler・scheduler・LoRA と重み・正負のプロンプトが
行ごとにコピーボタンつきで出ます。**すべて JSON でコピー**と、フォームに読み戻す
**画像生成で開く**もあります。この仕組みができる前にエージェントが作った絵も読めます——
ComfyUI が PNG に埋めたグラフが同じ数値を持っているからです。外部サービス経由（codex・agy）の
絵は何も持っていないので、空欄を並べる代わりに「復元できない」と言います。

**プロンプトを書いてもらう**

**「プロンプトを書いて」**は、その系統の書き方・モデルの説明・選んだ LoRA のトリガー語を
質問に含めた上で、アシスタントに**1 回だけ**尋ねます。返事は**提案**として出るだけで、
「使う」「プロンプトだけ使う」「捨てる」を押すまでフォームには入りません。ボタンを押さない
かぎりモデルは呼ばれません。どの CLI にもログインしたことがない人にはアシスタントがいないので
この機能だけ使えませんが、上に書いたことは全部そのまま動きます。

## ファイルを編集する

ビュアー上部の **「表示 / 編集 / 分割」** で編集に切り替えると、その場でファイルを直せます。
ちょっとした修正のためにセッションを起こす必要はありません（`.md` では「分割」で
編集とプレビューを並べられます）。

- **保存は Ctrl/⌘+S**（または「保存」ボタン）。状態は上部に「未保存の変更」「保存中」
  「保存しました」と出ます。
- **未保存のまま離れようとすると止めます。** ペイン移動・再読み込み・ログアウト・別タブへの
  切り離しなどの前に確認が出て、**「保存して続行」** か **「破棄して続行」** を選びます
  （未保存のファイルは別タブへ切り離せません）。
- **外部で変更されたとき** — エージェントや別のセッションが同じファイルを書き換えると
  **「ファイルが外部で変更されました」** と出ます。**「差分を確認」** で見比べてから取り込めます。
- **競合したとき** — 保存しようとしたリビジョンが古い場合は **「リモートの変更と競合しました」** と
  なり、あなたの内容（mine）は保持されたまま、**remote を採用 / mine を破棄 / remote を base に
  手動マージ**から選べます。保存できたか判定できないときも、mine と送信内容を抱えたまま
  「再取得」「明示的に再保存」で決着させられます。**編集内容が黙って消えることはありません。**
- **保存できない内容** — 2 MiB を超える変更、NUL を含むもの、CR/CRLF 改行（LF のみ対応）、
  不正な Unicode は弾かれます。

### AI に書き換えを提案させる

エディタの **「AI提案」** から、選択範囲（未選択なら全文）に対する変更を AI に作らせられます。
指示を書いて **Ctrl+Enter** で生成し、差分を見て **「適用」** か **「却下」** を選びます。
勝手に書き換わることはありません（生成後に本文が変わった場合は「再生成してください」と出ます）。
この生成に使ったトークンは、⚙設定 →「エージェント使用量」タブに **「変更提案（エディタ）」** として
記録されます（[12](12-settings.ja.md#エージェント使用量)）。

## ファイルをセッション／チャットに送る

エージェントに「このファイルを扱ってほしい」ときは、ファイルを開き、ビュアーで
**テキストを選択**すると出る **「送る」** から送信できます（範囲を選ばず、ファイル全体を
送ることもできます）。この操作はファイルの右クリックメニューにはありません。

- **送信先** — 稼働中のセッション（直接送信）か、アシスタント（チャットで開く）を選びます。停止中のセッションには送れません。

- ファイルは**パスで渡され**、セッションが自分で読み書きします。大きなファイルの翻訳など、ファイル出力を伴う作業に向きます。
