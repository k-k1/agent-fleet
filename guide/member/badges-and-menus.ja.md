# アイコン・バッジ・メニュー — Console 共通リファレンス

[English](badges-and-menus.md) | 日本語

メニュー項目は対象の種類、状態、権限、ワークスペースの状態によって変わります。

## セッションの表示

行の先頭にある色付きアイコンは、`claude`、`codex`、`cursor`、`copilot`、`kiro`、`agy`、`opencode`、`lcpp`、`muse`、`shell`、`ssm` の種類を
表します。行末の状態アイコンにマウスを重ねると状態名を確認できます。利用者の操作が必要な
状態は、アイコンだけでなく文字も表示されます。

| 状態 | 意味 |
|---|---|
| 進行中… | エージェントが処理中 |
| 質問あり | 質問への回答待ち |
| プランあり | プランの承認または却下待ち |
| 許可待ち | コマンド実行や編集などの許可待ち |
| 制限解除待ち · 19:50 | 利用上限に達してターンが止まった。時刻は自動再開の予定（無いときは時刻なし） |
| 残高上限 — 増枠が必要 | 残高・支出の上限に達した。待っても解けないので、増枠かクレジットの追加が要る |
| 入力待ち | 次の指示を受けられる状態 |
| 入力待ち · BG 実行中 | 入力は受けられるがバックグラウンド処理が継続中 |
| 入力待ち・引継あり | セッションが**最後に**提案した次のセッションの最初の指示が、まだ起動されていない。会話を開いて引き継ぎカードから起動する（または破棄する）（[05](05-stopping-and-tidying.ja.md)）。より新しい提案を起動すると、それに置き換えられた古い提案では出ない |
| 起動中 | 詳細な進行状態を持たないshell／ssmが稼働中 |
| 停止中 | プロセスが停止している |
| 停止中・引継あり | 停止しているが、最後に提案した引き継ぎが未起動のまま |
| フォルダ無し — 再開不可 | 作業フォルダがなく、同じ会話を再開できない |
| メモリ不足で終了 | メモリ上限などにより強制終了した可能性がある |
| 強制終了／異常終了 | SIGKILL、シグナル、非ゼロ終了などを検出した |

スピーカーアイコンは回答の読み上げ中、警告とブランチ名は起動時とは別のブランチへ
作業コピーが切り替わったことを示します。**種別アイコンの角の赤いドット**（セッションのタブにも出ます）は、
そのセッションのまだ読んでいない通知です。畳んだプロジェクトの行やセクションには、中に畳まれた分が
出ます。左ペインでは、未読のあるセッションの名前が太字にもなります。どれかのペインにそのセッションが
表示されると消え（報告だけは、報告先のオペレーター会話が表示されたとき、または通知センターから開いたとき）、
通知センターの **「すべて既読にする」** でも消えます。ベルを開いただけでは既読になりません。
赤いドットの説明はここだけです（どの通知で付くかは [設定 › 通知](20-settings.ja.md#通知)）。

行にはこのほか、**「共有中」**（他のメンバーへ公開している。[12](12-collaboration.ja.md#会話を共有する共有セッション)）と
**「削除ロック中」**（削除・自動整理の対象外。[05](05-stopping-and-tidying.ja.md#まとめて片付ける掃除)）が付くことがあります。

行には**2 行目**としてリンクが付くことがあります。1 つ目はセッションが作業しているブランチの GitHub か
Bitbucket のプルリクエストで、アイコンがオープン・下書き・マージ済み・クローズを表し、オープン中なら CI の結果
（成功／失敗／実行中。チェックが 1 つも走っていなければ何も出ません）も付きます。クリックするとそのサービスで
PR を開きます。origin が github.com か bitbucket.org の作業コピーで、そのサービスを接続しているとき
（設定 > 接続）だけ出ます。リポジトリの既定ブランチには出ません。更新は数分おきなので、マージが反映されるまで
少し掛かることがあります。Bitbucket では、接続にプルリクエストの読み取り権限（`pullrequest`。API トークンなら
`read:pullrequest:bitbucket`）が要ります。クローン用だけの接続では PR は出ません。
セッションが起動元にした・作業した・作ったプルリクエストがすべてマージ済み（開いているものがない）で、
セッションが作業中でなければ、この行に **マージ済み** も出ます。押すと確認のあとセッションをアーカイブします
（会話は残り、復元できます）。勝手にアーカイブされることはありません。
残りはセッション自身のプロセスが待ち受けているポート（`:5173`）で、クリックすると既定の開き方で開きます。
プレビュー用サブドメインが発行されていればそれ、なければブラウザペイン、ブラウザペインの無い配備
（Kubernetes。プレビューのランタイム）では軽量プレビューです。Ctrl／中クリックは常にペインを新しいタブで開き
（[ブラウザペイン](../ref/browser-pane.ja.md)）、ポート横の `⋯`（右クリック・長押しでも）から 3 つの開き方・URL のコピー・
「このポートを公開設定に追加…」（設定 › プレビュー用サブドメイン。プレビューが発行される環境のみ）を選べます。対象は `127.0.0.1` か
全インターフェースで待ち受けているサーバだけで（ペインは `http://127.0.0.1:{port}` を開くため）、
他のセッションのサーバは出ません。共有の codex／opencode マネージドサーバが実行したコマンドは、どのセッションにも
結び付けられません。

## リポジトリの状態表示

| 表示 | 意味 |
|---|---|
| 未コミット | コミットしていない変更がある |
| 親= | 親と同じコミット（ここでの「親」は親の作業コピーのブランチの upstream、たとえば `origin/develop`。upstream が無いときは親の作業コピーの HEAD。比較先はバッジのツールチップに出ます。親の作業コピーにある未 push のコミットは比較に入りません） |
| 未取込 N | 親に含まれないworktree固有のコミットがN件ある |
| 親+N・FF可 | worktreeのHEADは親に含まれており、親が N コミット先行している。メニューの **「origin/develop を Fast-Forward で取り込む」**（upstream が無いときは「親を Fast-Forward で取り込む」）で取り込めます（[06](06-code.ja.md)） |
| 分岐 N↕M・FF不可 | worktreeと親の双方に固有コミットがあり、マージかリベースが必要 |
| 比較不可 | detached HEADなどで親との関係を判定できない |
| ↑N | originよりNコミット先行している |
| ↓N FF可 | originがNコミット先行し、fast-forwardできる |
| ↑N ↓M 要マージ | originと分岐し、マージかリベースが必要 |

`●N` はその作業コピーで稼働中のセッション数、数字だけの場合は停止中のセッション数です。
折りたたんだ親リポジトリでは、配下のworktreeのセッションも集計します。
折りたたんだ行のフォルダ自身にセッションがあると、2 行目に稼働中のうち最も新しいセッション（エージェントの
アイコン・タイトル・状態）が出ます。稼働中が無ければ、停止中のうち最も新しいものが薄く出ます。`●N` の
ツールチップには、ほかの稼働中のセッションの名前が出ます。配下の worktree のセッションは数えるだけで、
名前は出しません。行をクリックしたときの動きは変わらず、展開するだけです。

## 画面最上部のエンジンのピル

配備が推論エンジンを動かしている、または借りているとき、画面最上部のバーに**役ごとのピル**（**チャット**と**画像**）が出ます。全メンバーに見えます。ピルはその役の状態（**使用中**・
**準備済み**・**稼働中**・**起動中…**・**停止処理中**・**停止中**、外部管理や借用のエンジンなら
**利用可**）を言い、同じ役を複数のエンジンが受け持つときは **×N**、自動停止までの秒読み中は
**「あと 12 分」**、待っているものがあれば **「待ち N」** が並びます。

**使用中**は、いま誰かの要求をこの配備が受け持っている状態で、誰かのセッションが答えを待っている最中
です。**準備済み**はモデルが VRAM にあって即答できる状態で、いま使っている人はいません。
**稼働中**はその手前の状態で、インスタンスは起動していますが、モデルはまだ読み込み中で、要求を出せば待たされます。

押すとポップオーバーが開きます。エンジンが 1 つの役では、状態はポップオーバーの見出しの右に
出て、下は詳しい行だけになります。同じ役を複数のエンジンが受け持つときだけ、エンジンの名前と
状態が行ごとに並びます。名前はそこでしか行を見分けられないからです。出る行は次のとおりです。状態、
該当すれば **外部管理** / **借用**
（ホバーで意味が出ます。どちらもこの配備からは起動も停止もできません）、いま VRAM にある
**「モデル: Qwen3.8 27B IQ4_XS」**（目録に読める名前が無いときは id）、誰も使っていなければ
**「最後の利用 2 分前」**、停止が予約されていれば **「自動停止 19:50 · あと 12 分」**、アイドルの
規則 **「誰も使わなくなってから 15 分で自動停止します」**、眠っているエンジンには **「最初の要求で
エンジンが起動します。数分かかることがあります。」**。秒読みの行が無いのは予約が無いという意味で、
数が分からないという意味ではありません。モデルの行が無いのは、そのエンジンが何も載せていない
（眠っている）という意味です。同じ役に 2 つのモデルがあるとき、載っているのは 1 つだけで、
もう一方を頼んだ人は読み込みを待ちます。ポップオーバーはそれを先に教えます。画像生成ペインのヘッダは、これから使うエンジンについて
同じ 4 つの状態を言います（[13](13-images.ja.md#画像生成)）。

⚙設定 → エージェントで**自分の llama.cpp 接続先**を設定していると（[09](09-agents.ja.md#lcpp)）、
**チャット**のピルは配備のエンジンではなくその接続先を報告します。状態は**接続中**・**届いていません**・
**確認中**のどれかで、ポップオーバーには **「自分の接続先です。この配備のエンジンではありません。」** と、
直近の確認で見つかったモデル（**「モデル: …」**）が出ます。

## その他のバッジ

- WS バーの **AWS バッジと Google Cloud バッジ**（AWS のマーク、Google のマーク）：設定のプロファイルのログイン状態です。
  名前・数・色の意味と、押すと出る一覧の中身は [16](16-cloud-accounts.ja.md#ws-バーの-aws-バッジ)（AWS）と
  [16](16-cloud-accounts.ja.md#ws-バーの-google-cloud-バッジ)（Google Cloud）にあります。
- **要再起動**（WS バーの電源ボタンの隣）：ワークスペースがまだ更新前のバックエンドで動いています。押すと
  **今すぐ再起動**が出て、実行中のセッションは停止します（あとで再開できます）。ワークスペースが最新になると
  消えます（[01](01-first-day.ja.md)）。
- **応答なし**（電源ボタンの隣）：ワークスペースは起動中ですが、Agent が数分間 Control Plane に応答していません。
  **ワークスペースを停止**してもう一度起動するまで、Console では何も動きません
  （[21](21-troubleshooting.ja.md#電源ボタンの横に-応答なし-バッジが出ている)）。
- 色付きの `1`、`2`…：表示中のペイン番号。押すとそのペインへ移動します。
- 「未追跡」「追加」「変更」「改名」「削除」：ファイルのGit変更種別です。
- アシスタント行の数字：会話のメッセージ数です。
- アシスタント行の回転アイコン／チェック：回答を生成中／待機中です。
- プランカードの「承認待ち」「承認済み」「却下」：プランに対する判断です。
- 会話の中のカードの **「停止時に未回答だった質問」「停止時に承認待ちだった計画」「停止時に許可を求めていた操作」**：セッションが
  止まったときに画面に出ていたものです。答えるとセッションを再開して届けます。カードは 14 日間残ります
  （[04](04-conversation.ja.md#停止したセッションに残った質問とプラン)）。
- 画面上部の **受信箱ボタンの数字**：受信箱の新着と、あなたが受け取るのを待っている引き継ぎの合計です
  （[12](12-collaboration.ja.md#メンバーに頼む-受信箱)）。受信箱の **「14 日以上未完了」** は、誰も終えていない依頼の印です。
  受信箱の依頼から起動したセッションには受信箱の印（**「受信箱の依頼から起動（送信者: …）」**）が付き、受信箱から
  取り込んだメモには **「受信箱: …」** と出ます。あなた宛ての引き継ぎがある共有セッションには、ブランチの印
  **「引き継ぎが届いています」** が付きます。
- 「LFS ポインタ」：Git LFSの実体ではなくポインタだけがあるファイルです。
- チャット表示の **「オペレーターから」「定時実行」「手動発火」「自動再開」「◯◯ から（別のセッションから）」** —
  あなたが入力したのではないプロンプトの出所です。フリート・オペレーター、スケジュール、
  中断からの自動再開、[セッション間メッセージ](11-many-sessions.ja.md#セッション同士でメッセージを送る)の順に対応します。**「MCP 経由: ◯◯」**（プラグのアイコン。名前が分からないときは「MCP 経由」だけ）は、外部のアシスタントやクライアントが
MCP 接続から送った入力の印で、あなたの入力ではなく、エージェントにも「あなたの指示ではない」と伝えてあるため、
承認の代わりにはなりません。**「◯◯ が起動」** は別のセッションが起動したセッションの
  最初のプロンプト、**「停滞通知」** は子がすべて静かになった親へ Agent Fleet が送るプロンプトの印です
  （[11](11-many-sessions.ja.md#セッションから別のセッションを起こす子セッション)）。
- スケジュール行の **「停止中」**：一時停止したスケジュールです（[11](11-many-sessions.ja.md)）。
- 共有セッションの **「承認待ち ◯件」**：共有先からの提案が承認を待っています（[12](12-collaboration.ja.md#会話を共有する共有セッション)）。
- 掃除モーダルの **「安全」「要確認」「保持」**：片付けてよいかの判定です（[05](05-stopping-and-tidying.ja.md#まとめて片付ける掃除)）。
- 停止したセッションの**予算の印**（脈拍のアイコン）：推定の費用が予算に達して止まったことを示します。
  メニューの「**予算を上げて再開…**」で続けられます（[05](05-stopping-and-tidying.ja.md#予算-使いすぎたセッションを止める)）。

## 右クリックメニュー

### セッション

状態や種類に応じて、再開、SSMへの再ログイン、停止、リモートセッションを開く、IDのコピー、
タイトル変更、ブランチ名変更、会話の引き継ぎ（別のエージェントへ、または **メンバーへ引き継ぐ…**）、**別のエージェントへ移す**
（[05](05-stopping-and-tidying.ja.md#別のエージェントへ移すmove)）、**共有する…**、**削除ロックの設定／解除**、
「**Markdown で書き出す**」（3 通り。[04](04-conversation.ja.md#会話を-markdown-で保存する)）、
アーカイブ／削除、作り直しが表示されます。**「レポ {name} のメニュー」** は、左ペインへ移って、そのセッションが属する
リポジトリのメニューを開きます（リポジトリを持たないセッション、スマホ、ワークスペース停止中には出ません。
左ペインがそのリポジトリを隠しているときは、理由を通知します）。作業コピー（worktree）が削除された停止中のセッションには、
「**作業コピー（worktree）を作り直す…**」が出て、元のパスに worktree を作り直して再開できるようにします
（[05](05-stopping-and-tidying.ja.md#再開できるできない)）。エージェントメモリでセッションからの提案をオンにしている間は、
「**メモリを提案させる（今すぐ）**」でこの会話から提案を出させられます。ツールを使わずに動かせるエージェントが
無いときは押せません（[18](18-agent-memory.ja.md#設定)）。別のエージェントへ移したセッションの行の下には
「**… へ移動済み**」（クリックで移動先を開く）か「**… への移動が未完了**」（クリックでやり直すか取り消す）の行が出て、
メニューには再開の代わりに「**移動先のセッションを開く**」と「**それでもここで再開する…**」、または
「**移動をやり直す／取り消す…**」が出ます。リポジトリに属さないセッションでは、
**作業グループへの割り当て**もここに出ます（チェック済みで押せない項目は、リポジトリや会話に
付いて自動で入っているものです）。
そのセッションが `generate_image` で画像を作っていれば、「**生成した画像 (N)**」も出ます
（N は枚数。作っていないセッションと、ワークスペース停止中は出ません —
[13](13-images.ja.md#画像ギャラリー)）。
「**予算…**」はセッションの予算を設定します。予算で止まったセッションでは「**予算を上げて再開…**」に
なります（[05](05-stopping-and-tidying.ja.md#予算-使いすぎたセッションを止める)）。
アーカイブは会話を保持して一覧から隠し、作り直しは現在の会話をアーカイブして同じ場所で
新しい会話を始めます。作業フォルダがない場合、再開、引き継ぎ、作り直しは表示されません。

### リポジトリ／worktree

コミットグラフを開く、フォルダを開く、変更をコミット、ブランチ切替、ブランチ名をコピー、
Fast-Forward（worktree では **「origin/develop を Fast-Forward で取り込む」** など）、プロジェクト設定、**共有する…**、
**作業グループへの割り当て**、**スキル…**（この作業コピーが各エージェントに与えるスキル。読み取り専用）、種類別のセッション起動、**配下のセッションを停止**、ワーキングコピーの削除が
できます。**「この作業コピーのアーカイブ済みセッション」** は、その作業コピーに絞ったアーカイブを開きます。
Subversion の作業コピーでは、Git の項目の代わりに **「更新（svn）」**・**「ロックを解除（svn）」**・
**「再認証（svn）」**・**「ログを表示」**・**「ローカルの変更」** が出ます
（[06](06-code.ja.md#subversionsvnリポジトリ)）。停止は、その行とその下にぶら下がっている作業コピーで動いているセッションを並べたモーダルを
開きます（[05](05-stopping-and-tidying.ja.md#セッションを止める片付ける)）。削除は、
その行の下にぶら下がっている作業コピーも一覧で出る確認画面を開きます（[05](05-stopping-and-tidying.ja.md#ひと仕事ぶんをまとめて消す作業コピーの削除)）。通常クリックは
行を展開／折りたたみます。Ctrl／⌘+クリックまたは中クリックはコミットグラフを新しいペインで開きます。

### ファイル／フォルダ

新規ファイル、新規フォルダ、名前をコピー、相対パスをコピー、名前を変更、削除ができます。
フォルダには **「ここでシェルを開く」** も出て、そのフォルダでシェルセッションを始めます（[07](07-files.ja.md#フォルダからシェルを開く)）。
ファイルにはさらに「朗読で開く」「ダウンロード」「アシスタントで翻訳」「アシスタントで要約」が表示され、**フォルダには「zip でダウンロード」**が
出ます（同じ項目がギャラリーのフォルダのメニューにもあります。フォルダ行をタッチで長押しするとメニューが開きます。
[07](07-files.ja.md#フォルダを-zip-でダウンロードする)）。フォルダと**画像ファイル**には
「**ギャラリーで開く**」も出ます（画像から開くと、その画像を
開いた状態で親フォルダのギャラリーが出ます。詳細は [13](13-images.ja.md#画像ギャラリー)）。フォルダの中にあるファイル
（ホーム直下は除く）には「**フォルダを開く**」（親フォルダをファイル一覧で表示）と、画像以外なら
「**フォルダをギャラリーで開く**」も出ます。ファイルをセッションや
アシスタントへ渡す操作は、ファイルを開き、ビュアーの「送る」から行います。

### 返信やドキュメントの中のファイルとフォルダのリンク

エージェントの返信、アシスタントのチャット、ドキュメントビュアー、Markdown のプレビュー
（[07](07-files.ja.md#表示した-markdown-の中のリンク)）にあるファイルやフォルダのリンクには、専用のメニューが
あります。右クリック、長押し、またはリンク上でメニューキーか Shift+F10 で開きます。ファイルには
**「ペインで開く」** と **「新しいペインで開く」**、どちらにも **「ファイル一覧で表示」** があり、そのあとに
上の項目のうち何も変更しないものが並びます（新規作成・名前の変更・削除はありません）。ホームの外のパス
（`/…`）では、開く項目のあとに並ぶのは **「パスをコピー」** と、ファイルなら **「ダウンロード」** だけです。
対象はメニューを開いたときに改めて調べるので、返信を書いたあとに消えたファイルは、消えていると表示されます。

### 画像ギャラリーのカード

画像のカードでは「**セッション/アシスタントに送る…**」（ファイルビュアーの送ると同じで、セッションには
ファイルのパスを、アシスタントにはファイルを添付したチャットをコメントの下書き付きで開きます）・**パスをコピー**・**ファイル名をコピー**・**ファイル名を変更**（同じフォルダの中だけ。
/ は使えません）・**ファイルを削除**（確認を経て）ができます。フォルダのカードにはフォルダ向けの同じ
項目に加えて「**別のペインで開く**」（素のクリックはこのペインをそのフォルダへ移します）と
「**フォルダを zip でダウンロード**」があり（カードのタッチ長押しでもメニューが開きます）、
フォルダの削除は中身ごとです。セッションが生成した画像のフォルダでは「**生成したセッション「…」を開く**」
でその会話へ飛べ、同じ名前がパンくずの行にもボタンとして出ます。どちらも、そのセッションがもう無い
ときは出ません。メニューは右クリック・Menu キー・Shift+F10 で開きます（[13](13-images.ja.md#画像ギャラリー)）。

### アシスタント

新規チャット、新しいペインで開くが表示されます。利用者が作成したアシスタントには編集と
削除も表示されます。常設アシスタントは編集・削除できません。会話の行には、タイトル変更、
削除ロック、**作業グループへの割り当て**が表示されます。

### コミットグラフ

コミットの詳細表示、参照しているブランチへの切替、detached HEADでのチェックアウト、
そのコミットを基点とした新規ブランチ作成ができます。submodule表示中はブランチ変更項目が
表示されません。

## ペインのボタン

ペイン右上には、内容に応じて **折り返しの切替**、**別タブへ切り離す**（そのペインがブラウザの
別タブへ移ります）、**閉じる**（中クリック／Ctrl+クリックで確認なし）が並びます。切り離せない
種類のペインでは、切り離しボタンは出ません（[02](02-console-basics.ja.md#複数を並べるペイン)）。

### タブ（タブ付きグリッド）

**セッションのタブ**を右クリックすると、左ペインのそのセッションの行と**同じメニュー**が出ます
（[02](02-console-basics.ja.md#複数を並べるペイン)）。セッション以外のタブと、ワークスペース停止中は、
ブラウザ本来のメニューがそのまま出ます。

### セッション一覧のカード

セッション一覧ペイン（[11](11-many-sessions.ja.md#稼働中のセッションを一望するセッション一覧)）の
カードでも、右クリック、カードの ⋯ ボタン、カードにフォーカスがある
ときの Menu キーのいずれからでも、同じメニューが出ます。

## メニューが表示されないとき

- ワークスペース停止中は、ワークスペース内で処理するメニューが無効または非表示になります。
- 種類が対応していない操作や、状態に合わない操作は表示されません。
- 右クリックメニューは、外側のクリック、Escape、ウィンドウからフォーカスが外れたときに閉じ、
  フォーカスは**開いた元の項目に戻ります**。
- これらのメニューは、項目にフォーカスがある状態の**メニューキー**（または **Shift+F10**）でも
  開けます。
