# 08. ターミナル — コピー＆ペースト・往復時間・フォント

[English](08-terminal.md) | 日本語

CLI に慣れていても、ブラウザ端末ならではのクセ（特にコピペ）があるので、
ここを一度読んでおくと詰まりません。

この章は、ターミナル（CLI）実行のセッションと shell / SSM を扱います。セッションを開くと、
メイン領域に**端末**（黒い画面）が出ます。Codex / opencode をマネージド実行で始めた場合は
会話画面だけが開き、端末はありません（実行方式の違いは [03 セッションを始める](03-starting-sessions.ja.md)）。
停止中のセッションを開いたときは「再開中…」のあと **「再開」** ボタンが出るので、押すと再開します。

## コピー＆ペースト

端末にフォーカスがあると、Cloud Shell と同じく**文字を選択中は Ctrl+C でコピー、Ctrl+V で貼り付け**
になります。何も選択していないときの Ctrl+C は、従来どおり **割り込み**（SIGINT）のままなので、実行中の
コマンドはいつでも止められます。Ctrl+C でコピーすると選択は解除され、ドラッグ離しで自動コピー済みの選択もコピー対象にならないため、その直後の Ctrl+C は割り込みになります。
両方のキーをプログラム側へ渡したい（Ctrl+V を文字入力として使う）場合は、設定 > 表示 > ターミナルの
**Ctrl+C / Ctrl+V でコピー・貼り付け**をオフにしてください。ほかの[ショートカット](02-console-basics.ja.md#ショートカット)はオフでも使えます。

- **コピー**：マウスで**左ドラッグして選択すると、離した時点で自動コピー**されます。キーボードなら `Ctrl+Shift+C`（macOS は `⌘+Shift+C`、選択があるときは `⌘C` でも可）、`Ctrl+Insert`。キーボードでコピーすると「コピーしました」と短く表示され、ブラウザがクリップボードを拒否したときも通知が出ます。
- **ペースト**：**右クリック**または**中クリック**で貼り付け。キーボードなら `Ctrl+Shift+V`（macOS は `⌘+Shift+V` / `⌘V`）、`Shift+Insert`。

端末内に出た URL（claude のログインリンクなど）は、折り返して表示されていても
**クリックで新しいタブ**に開けます。長い URL をコピーして貼り直す手間が要りません。

## 端末の遠さを見る（往復時間）

ターミナルのペインの上部に、**往復時間（ミリ秒）** が小さく出ます。1 バイトがワークスペースまで
行って戻るのにかかる時間で、**打鍵と同じソケット・同じフレームで測っています**。つまり別に行う
通信テストではなく、**打鍵のエコーが実際にどれだけ遅れるか**そのものです。

- 出ている数字は直近の実測の**中央値**です。カーソルを合わせると、中央値・最大・何回分かが読めます。
- おおむね **120ms** 未満なら手元の端末と変わらない感覚で、**300ms** を超えると打鍵が目に見えて
  遅れます。色がどちら側かを示します。
- ワークスペースの中の端末（PTY / tmux）自体は 1ms 未満なので、**この数字は経路の遅さ**であって
  マシンの遅さではありません。数字が小さいのにエージェントが遅く感じるなら、待っているのは
  通信ではなく**エージェントの思考**です。

## フォント・サイズを変える

端末の見た目は **⚙設定 → 「表示」タブ**で調整します。「ターミナル」の
**フォント**と**文字サイズ**（9〜28px）を変え、**Ctrl+C / Ctrl+V でコピー・貼り付け** のオン・オフを
切り替えられます（[コピー＆ペースト](#コピーペースト)）。

この設定は**サーバーに保存**され、ユーザーごとに管理されます。会社の PC と自宅の PC、
別のブラウザからサインインしても、同じフォントとサイズが**使われます**。

（テーマや配色、ファイルビュアーの表示設定も同じ「表示」タブにあります。詳しくは
[07 ファイル](07-files.ja.md)。なお端末の背景色は、ライトテーマにしても暗いままです。）
