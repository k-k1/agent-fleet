# 05. ターミナル — 黒い画面の操作・コピペ・ショートカット・スマホ

[English](05-terminal.md) | 日本語

CLI に慣れていても、ブラウザ端末ならではのクセ（特にコピペ）があるので、
ここを一度読んでおくと詰まりません。

この章は、ターミナル（CLI）実行のセッションと shell / SSM を扱います。セッションを開くと、
メイン領域に**端末**（黒い画面）が出ます。Codex / opencode をマネージド実行で始めた場合は
会話画面だけが開き、端末はありません（実行方式の違いは [02 セッション](02-sessions.ja.md)）。
停止中のセッションを開いたときは「再開中…」のあと **「再開」** ボタンが出るので、押すと再開します。

## コピー＆ペースト

端末にフォーカスがあると **Ctrl+C / Ctrl+V はプログラム側に素通し**します（Ctrl+C は
割り込み＝SIGINT、Ctrl+V は文字入力）。そのため、クリップボードのコピペは別のキーに
割り当てられています。ここが普通のエディタと違うので注意してください。

- **コピー** — マウスで**左ドラッグして選択すると、離した時点で自動コピー**されます。キーボードなら `Ctrl+Shift+C`（macOS は `⌘+Shift+C`、選択があるときは `⌘C` でも可）、`Ctrl+Insert`。
- **ペースト** — **右クリック**または**中クリック**で貼り付け。キーボードなら `Ctrl+Shift+V`（macOS は `⌘+Shift+V` / `⌘V`）、`Shift+Insert`。

端末内に出た URL（claude のサインインリンクなど）は、折り返して表示されていても
**クリックで新しいタブ**に開けます。長い URL をコピーして貼り直す手間が要りません。

## ショートカット

- **Ctrl+PgUp / Ctrl+PgDn** — セッションを前後に切り替え。
- **日常操作は Alt でひと押し**: **Alt+N** はじめる、**Alt+W** このタブ / ペインを閉じる、
  **Alt+Shift+W** 全部閉じる、**Alt+1〜8** 番号でペインへ、**Alt+[ / Alt+]** 前後のペイン、
  **Alt+PgUp / Alt+PgDn** 前後のタブ、**Alt+A** メモを追加、**Alt+G** 作業グループを巡回、
  **Alt+/** レールの絞り込みへ、**Alt+Q** 読み上げを止める、**Alt+,** 設定。
  いずれも設定 →「キー操作」で変更できます。
- **Alt+= / Alt+- / Alt+0** — いま見ているものの**文字を大きく / 小さく / 既定へ**。
  端末・ファイルビュー・会話（ミラー）・朗読ビューはそれぞれ別の文字サイズを持っていて、
  フォーカスしているペインに応じた方が動きます（設定 →「表示」の数値がそのまま動きます）。
  ブラウザ全体の拡大は従来どおり **Ctrl+= / Ctrl+-** です。
- ファイルツリーにフォーカスがあるとき: **↑ ↓ ← → / Enter** で移動・開閉、**Ctrl+↑ ↓** でフォルダ間移動、**Shift+↑ ↓** でビュアーをスクロール（[04 ファイル](04-files.ja.md)）。

### コマンドパレット

**Ctrl+P**（macOS は **⌘P**）で **コマンドパレット**を開けます。画面内の操作、セッション、
リポジトリを名前で検索して、キーボードだけで実行・移動できる入口です。設定 →
**キー操作**で、このキーは変更できます。

- **↑ ↓ / Enter** — 候補を選んで実行・開く。ファイルや変更ファイルでは **Ctrl+Enter**（macOS は **⌘Enter**）で別ペインに開けます。
- **Tab** またはもう一度 **Ctrl+P / ⌘P** — 「コマンド」「変更ファイル」「ファイル」の検索対象を切り替えます。
- **Esc** — 閉じて、開く前に操作していた場所へ戻ります。

端末にフォーカスがあり、設定で **「端末入力を優先」** をオンにしていると、Ctrl+P は端末へ渡されます。
その場合は既定の **Ctrl+K → ;**（macOS は **⌘K → ;**）で開けます。**?** では、ほかの
ショートカットも一覧で確認できます。

全画面表示中は、ブラウザが本来横取りするキー（Ctrl+W で閉じる、など）も端末に届くよう
自動でロックされます。Esc はロックしないので、全画面はいつでも Esc で抜けられます。

## 複数を並べる（ペイン）

メイン領域は**複数のペインに分割**できます。1 つのタスクを進めながら別のタスクを横目で
見る、という並行作業に向きます。

- **新しいペインで開く** — セッション・リポジトリ・ファイルの項目を **Ctrl+クリック**（または**中クリック**）すると、今のペインを置き換えず**新しいペインに開き**ます。アシスタントの右クリックにも「新しいペインで開く」があります。項目による違いは [アイコン・バッジ・メニュー](badges-and-menus.ja.md) を参照してください。
- **並べ替える** — ペイン上部のつまみをドラッグすると、他のペインと入れ替えられます。境界をドラッグすれば幅・高さも変えられます。
- **閉じる** — ペインの閉じるボタン（中クリック / Ctrl+クリックで確認なしに直接閉じる）。
- **別タブへ切り離す** — ペイン右上の切り離しボタンで、そのペインを**ブラウザの別タブへ移します**
  （元の画面からは無くなります）。別タブ側では上部に細いタイトルバーが出て、
  **「フルConsoleに展開」**で通常の Console に広げられます。切り離せないペインもあります。
  サブディスプレイにセッションを 1 本だけ出しておく、といった使い方に向きます。

**並べ方は 2 種類**あり、画面最上部のバーの**外観**（ペンキ缶）か、⚙設定 →「表示」の
**メイン領域の配置**で切り替えます。

- **分割ペイン**（既定）— 境界をドラッグして大きさを変えながら並べます。
- **タブ付きグリッド** — 各マスをタブで切り替えます。開くものが多いときに、マスの数を増やさず扱えます。
  表示中のタブを閉じると、**その前に表示していたタブ**に戻ります（並びの隣ではありません）。
  チャットからファイルを開いて閉じれば、元のチャットに戻ります。
  **セッションのタブを右クリック**すると（フォーカスがある状態の**メニューキー** / **Shift+F10**
  でも同じです）、左ペインのそのセッションの行と**同じメニュー**が出ます。名前の変更・引き継ぎ・
  アーカイブなどを、左ペインへ戻らずに行えます。セッション以外のタブでは、ブラウザ本来のメニューが
  そのまま出ます。

この設定は**この端末だけ**に保存され、2 つの配置はそれぞれの並びを別に覚えているので、
行き来しても崩れません。デスクトップでは最大 4 列×2 段まで並べられます。スマホは 1 列・最大 2 枚までです。

各ペインの内容は独立しています。ターミナル（CLI）実行の claude / codex / cursor / copilot / kiro / agy / opencode なら上部の
**チャット ⇄ ターミナル**で会話の Markdown 表示と端末表示を切り替えられます。マネージド実行の
セッションはチャット表示だけを使います（[07 チャットとメモ](07-chat-memo.ja.md)）。

## 端末の遠さを見る（往復時間）

ターミナルのペインの上部に、**往復時間（ミリ秒）**が小さく出ます。1 バイトがワークスペースまで
行って戻るのにかかる時間で、**打鍵と同じソケット・同じフレームで測っています**。つまり別途の
通信テストではなく、**打鍵のエコーが実際にどれだけ遅れるか**そのものです。

- 出ている数字は直近の実測の**中央値**です。カーソルを合わせると、中央値・最大・何回分かが読めます。
- おおむね **120ms** 未満なら手元の端末と変わらない感覚で、**300ms** を超えると打鍵が目に見えて
  遅れます。色がどちら側かを示します。
- ワークスペースの中の端末（PTY / tmux）自体は 1ms 未満なので、**この数字は経路の遅さ**であって
  マシンの遅さではありません。数字が小さいのにエージェントが遅く感じるなら、待っているのは
  通信ではなく**エージェントの思考**です。

## スマホでの操作

スマホでは画面を広く使うため、左ペインは隠れています。

- **左ペインを出す** — 画面左上の **≡（メニュー）**で引き出します。項目を選ぶと自動で閉じます。戻る操作でまた開きます。
- **コントロールキー列** — 端末の下に、ソフトキーボードでは押しづらいキーが並びます: **`Esc` `Tab` `←` `↑` `↓` `→` `^C` `⏎`**。これらはキーボードを呼び出さずに送れます。
- **過去の出力を遡る** — 端末上を **1 本指で縦にスワイプ**すると過去の出力に戻れます（下へドラッグで古い行、上へで新しい行）。vim など端末全体を使うアプリでは、そのアプリ自身のスクロールになります。
- **稼働中のセッションを順に見る** — 画面を **← 方向にスワイプ**すると次のセッション、**→ 方向**で 1 つ前のセッションへ切り替わります（端まで来ると反対の端へ回ります）。切り替わると「2/3 セッション名」のように、何件中の何番目かが一瞬表示されます。作業グループを選んでいるときは、そのグループの中だけを回ります。**画面の左端から始めた →** は、これまでどおり左ペインを引き出す操作です（前のセッションへ戻すときは、左端を避けて振ってください）。左ペインが開いている間の ← も、これまでどおり左ペインを閉じます。文字入力欄・ブラウザペイン・横スクロールする場所（コードブロックなど）の上では、そちらの操作が優先され切り替わりません。

（スマホは「進捗確認・軽い返信」向けです。込み入った編集は PC で行うのがおすすめです。）

## フォント・サイズを変える

端末の見た目は **⚙設定 → 「表示」タブ**で調整します。「ターミナル」の
**フォント**と**文字サイズ**（9〜28px）が変えられます。

この設定は**サーバーに保存**され、per-user で管理されます。会社の PC と自宅の PC、
別のブラウザからログインしても、同じフォント・サイズが**追従**します。

（テーマや配色、ファイルビュアーの表示設定も同じ「表示」タブにあります。詳しくは
[04 ファイル](04-files.ja.md)。なお端末の背景色は、ライトテーマにしても暗いままです。）
