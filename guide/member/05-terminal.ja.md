# 05. ターミナル — 黒い画面の操作・コピペ・ショートカット・スマホ

[English](05-terminal.md) | 日本語

CLI に慣れていても、ブラウザ端末ならではのクセ（特にコピペ）があるので、
ここを一度読んでおくと詰まりません。

この章は、ターミナル（CLI）実行のセッションと shell / SSM を扱います。セッションを開くと、
メイン領域に**端末**（黒い画面）が出ます。Codex / opencode をマネージド実行で始めた場合は
会話画面だけが開き、端末はありません（実行方式の違いは [02 セッション](02-sessions.ja.md)）。
停止中のセッションを開いたときは「再開中…」のあと **「再開」** ボタンが出るので、押すと再開します。

## コピー＆ペースト

端末にフォーカスがあると、Cloud Shell と同じく**文字を選択中は Ctrl+C でコピー、Ctrl+V で貼り付け**
になります。何も選択していないときの Ctrl+C は、従来どおり **割り込み**（SIGINT）のままなので、実行中の
コマンドはいつでも止められます。Ctrl+C でコピーすると選択は解除され、ドラッグ離しで自動コピー済みの選択もコピー対象にならないため、その直後の Ctrl+C は割り込みになります。
両方のキーをプログラム側へ渡したい（Ctrl+V を文字入力として使う）場合は、設定 > 表示 > ターミナルの
**Ctrl+C / Ctrl+V でコピー・貼り付け**をオフにしてください。以下のショートカットはオフでも使えます。

- **コピー**：マウスで**左ドラッグして選択すると、離した時点で自動コピー**されます。キーボードなら `Ctrl+Shift+C`（macOS は `⌘+Shift+C`、選択があるときは `⌘C` でも可）、`Ctrl+Insert`。キーボードでコピーすると「コピーしました」と短く表示され、ブラウザがクリップボードを拒否したときも通知が出ます。
- **ペースト**：**右クリック**または**中クリック**で貼り付け。キーボードなら `Ctrl+Shift+V`（macOS は `⌘+Shift+V` / `⌘V`）、`Shift+Insert`。

端末内に出た URL（claude のログインリンクなど）は、折り返して表示されていても
**クリックで新しいタブ**に開けます。長い URL をコピーして貼り直す手間が要りません。

## ショートカット

- **Ctrl+PgUp / Ctrl+PgDn**：セッションを前後に切り替え。
- **日常操作は Alt でひと押し**: **Alt+N** はじめる、**Alt+W** このタブ / ペインを閉じる、
  **Alt+Shift+W** 全部閉じる、**Alt+1〜8** 番号でペインへ、**Alt+[ / Alt+]** 前後のペイン、
  **Alt+PgUp / Alt+PgDn** 前後のタブ、**Alt+A** メモを追加、**Alt+G** 作業グループを巡回、
  **Alt+/** レールの絞り込みへ、**Alt+Q** 読み上げを止める、**Alt+,** 設定。
  いずれも設定 →「キー操作」で変更できます。
- **Alt+U**：次の**要対応**セッションへ移動。まず回答を待っているもの（質問・計画の承認・
  権限の確認）を新しい順に、続いて未読の通知があるもの（ターン完了・報告）を巡ります。
  続けて押すと残りを順にたどります。左レールでは回答待ちのセッションが枠で囲まれ、
  未読のあるセッションは名前が太字になり赤い点が付きます。回答待ちのセッションを
  映しているペインも枠で囲まれます。未読の印はセッションを開くと消え、枠は回答すると消えます。
- **Alt+= / Alt+- / Alt+0**：いま見ているものの**文字を大きく / 小さく / 既定へ**。
  端末・ファイルビュー・会話（ミラー）・朗読ビューはそれぞれ別の文字サイズを持っていて、
  フォーカスしているペインに応じた方が動きます（設定 →「表示」の数値がそのまま動きます）。
  ブラウザ全体の拡大は従来どおり **Ctrl+= / Ctrl+-** です。
- ファイルツリーにフォーカスがあるとき: **↑ ↓ ← → / Enter** で移動・開閉、**Ctrl+↑ ↓** でフォルダ間移動、**Shift+↑ ↓** でビュアーをスクロール（[04 ファイル](04-files.ja.md)）。

全画面表示中は、ブラウザが本来横取りするキー（Ctrl+W で閉じる、など）も端末に届くよう
自動でロックされます。Esc はロックしないので、全画面はいつでも Esc で抜けられます。

## コマンドパレット

**Ctrl+P**（macOS は **⌘P**）で **コマンドパレット**を開けます。セッション、画面内の操作、
リポジトリを名前で検索して、キーボードだけで実行・移動できる入口です。設定 →
**キー操作**で、このキーは変更できます。

### セッション

開くと最初に出るのは **「セッション」** の一覧で、各行にレポ名・ワークツリー名・状態バッジが
並びます（ワークスペースにセッションが 1 つも無いときは **「コマンド」** で開きます）。並び順は「たいてい見たい順」です。

1. **あなたの答えを待っている**セッション（質問・計画の承認・許可の確認）。最後に待ちに
   入ったものが一番上。
2. そのほかの稼働中のセッション。
3. 停止中のセッションは一番下（未回答の対話を抱えたまま停止されたものが先頭）。アーカイブ済み
   のセッションは出ません。

並び順はパレットを開いた瞬間に固定されます。読んでいる間に状態が変わったセッションが
カーソルの下で入れ替わることはなく、バッジだけが追随します。

何も入力していないとき、別のセッションが起動したセッションはその下に字下げして並び、家族全体は
そのうち最も急ぐセッションの位置に置かれます。そのため、停止中の親も、あなたの答えを待っている子と
一緒に上へ来ます。子は起動した順に並びます。パレットを開いている間に起動したセッションは、もう一度
開くまで一番下に残ります。入力を始めると一覧は平らに戻り、子の行には親の名前が出ます（**↳** と親の
タイトル）。親のタイトルを入力すると、その子も見つかります。

### パレットの中のキー

- **↑ ↓ / Enter**：候補を選んで実行・開く。**PageUp / PageDown** で、見えている行数ぶん（1 画面）ずつ選択を動かせます（先頭・末尾で止まります）。セッションやファイル・変更ファイルでは **Ctrl+Enter**（macOS は **⌘Enter**）で別ペインに開けます。
- **Tab** またはもう一度 **Ctrl+P / ⌘P**：「セッション」「コマンド」「変更ファイル」「ファイル」「会話」「メモリ」（エージェントメモリがオンのとき）「このセッションの変更」（アクティブなペインのセッションが変更したファイル。Console が会話を読めるエージェントのとき）の検索対象を切り替えます。**Shift+Tab**、または **Ctrl+Shift+P / ⌘⇧P** で逆順に 1 つ戻り、先頭から末尾へ回り込みます。逆順のキーはパレットのキーに Shift を足したものです（パレットのキーを Alt+O に変えたなら Alt+Shift+O）。パレットのキーがすでに Shift を含む場合、逆順のキーはなく、戻るには Shift+Tab を使います。表示されていない対象（アクティブなセッションがないときの「このセッションの変更」など）はどちらの方向でも飛ばされます。ブラウザによっては Ctrl+Shift+P を自身で使い（例: Firefox のプライベートウィンドウ）、ページ側から取り消せません。その場合パレットにキーが届かないため、Shift+Tab を使ってください。
- **Esc**：閉じて、開く前に操作していた場所へ戻ります。

端末にフォーカスがあり、設定で **「端末入力の優先」** をオンにしていると、Ctrl+P は端末へ渡されます。
その場合は既定の **Ctrl+K → ;**（macOS は **⌘K → ;**）で開けます。**?** では、ほかの
ショートカットも一覧で確認できます。

### 会話

**「会話」** では、このワークスペースのすべてのセッション（エージェントの種類を問わず、稼働中・
停止中・アーカイブ済みを含む）で交わされた会話を検索できます。語をいくつか入力すると（すべての語を
含むものが出ます。日本語は 2 文字から）、各結果にセッション名、誰がいつ言ったか、一致した文が
並びます。**Enter** でそのセッションを該当のターンまでスクロールした状態で開きます。検索の対象は
会話そのものだけで、ツールの出力やエージェントの思考は含みません。アーカイブ済みのセッションの
結果ではアーカイブが開きます。そこで復元してから一覧で開くと、同じターンで開きます。更新後の最初の検索では、全セッションを
読み終えるまで 1〜2 分かかることがあり、その間パレットに「索引を作成中」と出ます。
ミラーが読み込んだ範囲より古いターンは、先に読み込みます。ミラーはそのターンに届くまで以前の会話を
読み込み、遡れるのは 8,000 位置まで、要求は 4 回までです。それより古いときは、遠すぎて直接移動できない
という通知が出ます。上へスクロールすれば読み込めます。読み込みの間にセッションを切り替えるか自分で
スクロールすると、移動は取りやめになります。検索そのものに失敗したときは、
「一致なし」とは出さずに理由を表示し、再試行できます。

### メモリ

**「メモリ」** では、エージェントが Agent Fleet 独自のエージェントメモリ
（[設定 → エージェントメモリ](14-agent-memory.ja.md#メモリ)）に保存したメモリを検索できます。このスイッチがオンのときだけ
現れます。名前・説明・種類・作成者は入力に合わせて即座に、メモリの本文は少し待ってから検索され、本文で一致したものは
一致した行も表示されます。**Enter** で、そのメモリを選んだ状態の 設定 → エージェントメモリ → メモリ を開きます。
メモリはワークスペースの中にあるため、起動中のみ検索できます。シークレットスキャンで除外されたメモリは
件数だけが表示され、一覧には出ません。検索そのものに失敗したときは、「一致なし」とは出さずに理由を表示し、
再試行できます。

## 複数を並べる（ペイン）

メイン領域は**複数のペインに分割**できます。1 つのタスクを進めながら別のタスクを横目で
見る、という並行作業に向きます。

- **新しいペインで開く**：セッション・リポジトリ・ファイルの項目を **Ctrl+クリック**（または**中クリック**）すると、今のペインを置き換えず**新しいペインに開き**ます。アシスタントの右クリックにも「新しいペインで開く」があります。項目による違いは [アイコン・バッジ・メニュー](badges-and-menus.ja.md) を参照してください。
- **並べ替える**：ペイン上部のつまみをドラッグすると、他のペインと入れ替えられます。境界をドラッグすれば幅・高さも変えられます。
- **閉じる**：ペインの閉じるボタン（中クリック / Ctrl+クリックで確認なしに直接閉じる）。
- **別タブへ切り離す**：ペイン右上の切り離しボタンで、そのペインを**ブラウザの別タブへ移します**
  （元の画面からは無くなります）。別タブ側では上部に細いタイトルバーが出て、
  「**フル Console に展開**」で通常の Console に広げられます。切り離せないペインもあります。
  サブディスプレイにセッションを 1 本だけ出しておく、といった使い方に向きます。

**並べ方は 2 種類**あり、画面最上部のバーの**外観**（ペンキ缶）か、⚙設定 →「表示」の
**メイン領域の配置**で切り替えます。

- **分割ペイン**：境界をドラッグして大きさを変えながら並べます。
- **タブ付きグリッド**（既定）— 各マスをタブで切り替えます。開くものが多いときに、マスの数を増やさず扱えます。
  表示中のタブを閉じると、**その前に表示していたタブ**に戻ります（並びの隣ではありません）。
  チャットからファイルを開いて閉じれば、元のチャットに戻ります。
  **セッションのタブを右クリック**すると（フォーカスがある状態の**メニューキー** / **Shift+F10**
  でも同じです）、左ペインのそのセッションの行と**同じメニュー**が出ます。名前の変更・引き継ぎ・
  アーカイブなどを、左ペインへ戻らずに行えます。セッション以外のタブでは、ブラウザ本来のメニューが
  そのまま出ます。

この設定は**このブラウザだけ**に保存され、2 つの配置はそれぞれの並びを別に覚えているので、
行き来しても崩れません。デスクトップでは最大 4 列×2 段まで並べられます。スマホは 1 列・最大 2 枚までです。

各ペインの内容は独立しています。ターミナル（CLI）実行の claude / codex / cursor / copilot / kiro / agy / opencode なら上部の
**チャット ⇄ ターミナル**で会話の Markdown 表示と端末表示を切り替えられます。マネージド実行の
セッションはチャット表示だけを使います（[07 チャットとメモ](07-chat-memo.ja.md)）。

## 端末の遠さを見る（往復時間）

ターミナルのペインの上部に、**往復時間（ミリ秒）** が小さく出ます。1 バイトがワークスペースまで
行って戻るのにかかる時間で、**打鍵と同じソケット・同じフレームで測っています**。つまり別に行う
通信テストではなく、**打鍵のエコーが実際にどれだけ遅れるか**そのものです。

- 出ている数字は直近の実測の**中央値**です。カーソルを合わせると、中央値・最大・何回分かが読めます。
- おおむね **120ms** 未満なら手元の端末と変わらない感覚で、**300ms** を超えると打鍵が目に見えて
  遅れます。色がどちら側かを示します。
- ワークスペースの中の端末（PTY / tmux）自体は 1ms 未満なので、**この数字は経路の遅さ**であって
  マシンの遅さではありません。数字が小さいのにエージェントが遅く感じるなら、待っているのは
  通信ではなく**エージェントの思考**です。

## スマホでの操作

スマホでは画面を広く使うため、左ペインは隠れています。

- **左ペインを出す**：画面左上の **≡（メニュー）** で引き出します。項目を選ぶと自動で閉じます。戻る操作でまた開きます。
- **コントロールキー列**：端末の下に、ソフトキーボードでは押しづらいキーが並びます: **`Esc` `Tab` `←` `↑` `↓` `→` `^C` `⏎`**。これらはキーボードを呼び出さずに送れます。
- **過去の出力を遡る**：端末上を **1 本指で縦にスワイプ**すると過去の出力に戻れます（下へドラッグで古い行、上へで新しい行）。vim など端末全体を使うアプリでは、そのアプリ自身のスクロールになります。
- **稼働中のセッションを順に見る**：画面を **→ 方向にスワイプ**すると左ペインの一覧で 1 つ下のセッション、**← 方向**で 1 つ上のセッションへ切り替わります（端まで来ると反対の端へ回ります）。順番は左ペインの並び（起動元のセッションの下に入れ子になった worktree も含む）どおりで、shell と SSM のセッションは飛ばします。切り替わると「2/3 セッション名」のように、何件中の何番目かが一瞬表示されます。作業グループを選んでいるときは、そのグループの中だけを回ります。**画面の左端から始めた →** は、これまでどおり左ペインを引き出す操作です（1 つ下へ進むときは、左端を避けて振ってください）。左ペインが開いている間の ← も、これまでどおり左ペインを閉じます。文字入力欄・ブラウザペイン・横スクロールする場所（コードブロックなど）の上では、そちらの操作が優先され切り替わりません。

- **ワークスペース操作バー**：画面が狭いと、収まらないボタンは操作バーの **⋯** メニューへ移り、そこでは
  ラベル付きで並びます。最初に **ホーム**・**セッション一覧**・**画像生成**、次に **下に分割** と **全て閉じる** も移ります。
- **通知（トースト）**：スマホでは上のバーのすぐ下に出て、入力欄には重なりません。外側をタップすると消えます。**更新**や AWS のログインのようにボタンがあるものは、× でだけ閉じます。

（スマホは「進捗確認・軽い返信」向けです。込み入った編集は PC で行うのがおすすめです。）

## フォント・サイズを変える

端末の見た目は **⚙設定 → 「表示」タブ**で調整します。「ターミナル」の
**フォント**と**文字サイズ**（9〜28px）を変え、**Ctrl+C / Ctrl+V でコピー・貼り付け** のオン・オフを
切り替えられます（[コピー＆ペースト](#コピーペースト)）。

この設定は**サーバーに保存**され、ユーザーごとに管理されます。会社の PC と自宅の PC、
別のブラウザからサインインしても、同じフォントとサイズが**使われます**。

（テーマや配色、ファイルビュアーの表示設定も同じ「表示」タブにあります。詳しくは
[04 ファイル](04-files.ja.md)。なお端末の背景色は、ライトテーマにしても暗いままです。）
