# 01. 初日 — サインインから最初のセッションまで

[English](01-first-day.md) | 日本語

## サインインする

Console の URL をブラウザで開くと、まずサインインを求められます。出てくるボタンは会社の
設定次第で、Google や Microsoft、そのほかのサインイン方法になります。
複数並んでいる場合は、会社のアカウントで、管理者に案内された方法を使ってサインインして
ください（許可されたアカウントだけが入れます）。

テナントは部署などのグループで、あなたのワークスペースはテナントごとに分かれています。多くの場合は
1 つだけなので、そのまま進んで構いません。複数に所属している人には、右上のアカウントメニューに
**テナント**の選択が出るので、作業したいテナントをそこで選んでください
（画面の名前は [README](README.ja.md) を参照）。

## ホームとようこそカード — 2 ステップ＋目的の選択

サインインすると、メイン領域に **ホーム** が表示されます。あなたの返事を待っているものと、
続きの作業がここに並びます。初回はホームの最上部に **「Agent Fleet へようこそ」** という
カード（「まず2ステップ。そのあとは目的を選ぶだけです」）が出ます。これはチェックリストで、済んだ項目には
自動でチェックが付きます。全員に必要なのは上の 2 つだけです。

1. **ワークスペースを起動**：「起動」ボタンで、あなた専用の作業環境を立ち上げます。起動中は「起動中…」、完了すると「稼働中」と表示され、チェックが付きます。これを済ませないと、以降の操作（接続を含む）はできません。
2. **エージェントを接続**：「接続」から、使いたいエージェントにログインします。少なくとも 1 つ接続すればチェックが付きます（接続の詳細は [09 エージェント](09-agents.ja.md)）。管理者がチームのエージェントを決めていれば、この手順にその名前が出ます（「このチームの既定は Claude です」）。まずそれを接続してください。ほかのエージェントでも完了になります。

続いて **「どちらから始めますか？」** の 2 択が出ます（あとから両方使えます）。

- **AI に質問・翻訳を頼む**：「チャットをはじめる」で、そのままアシスタントとの
  チャットが開きます。git もターミナルも不要です（[10 チャットとメモ](10-chat-memo.ja.md)）。
- **リポジトリで開発する**：「開発のセットアップへ」で続きの手順が展開されます。
  1. **git プロバイダを接続**（任意）：GitHub／Bitbucket にログインします。private リポジトリをクローン／push するなら必要です（[06 リポジトリと git](06-code.ja.md)）。
  2. **リポジトリをクローンしてセッション開始**：ワークスペース操作バーの **「はじめる」** からクローンと起動をまとめて行えます（[03 セッションを始める](03-starting-sessions.ja.md)）。

カードは、最初のセッションを作るか、最初のチャットを始めるとホームから消えます。それ以降の
ホームには次の 3 つが並びます。

- **あなたの返事を待っています**：質問・許可・プランの承認を待っているセッション。
- **続きから**：再開できるセッション。新しいものから並びます。
- **新しく始める**：「はじめる」（クローンと起動）と「チャットをはじめる」。

ホームは画面が空のときに表示されるので、ペインをすべて閉じる（「全て閉じる」）と
ホームに戻ります。どこからでも開きたいときは、ワークスペース操作バーの **「ホーム」**（スマートフォンではバーの **⋯** の中にあることがあります）か、
リーダーキー `g h` を使います。

### カードを閉じても大丈夫

右下の **「あとで」** を押すとカードは消えます。これはこのテナントでのあなたの所属ごとに記録されるので、
別の端末からサインインしてもカードは再び出ません。所属しているほかのテナントでは、もう一度出ます。同じチェックリストは、右上の
アカウントメニューの **「はじめかたガイド」** からいつでも開き直せます。操作を調べる
通常のガイドは、同じメニューの **「利用ガイド」** から開けます。ようこそカードの
各項目に対応する、通常の画面での操作は次のとおりです。

| ようこそカードの項目 | 通常の画面での同じ操作 |
|--------------------------|--------------------|
| ワークスペースを起動 | ワークスペース操作バーの起動 / 停止ボタン |
| エージェントを接続 | ⚙設定 → 「エージェント」タブ |
| チャットをはじめる | 左ペインのアシスタントにある「＋（新規チャット）」 |
| git プロバイダを接続 | ⚙設定 → 「Git ホスティング」タブ |
| リポジトリをクローンしてセッション開始 | ワークスペース操作バーの「はじめる」（左ペイン「リポジトリ」の「追加」からは、取り込みだけできます） |

## 最初のリポジトリをクローンする

エージェントに仕事をさせるには、まず作業対象のリポジトリをワークスペースに持ってきます。
左ペインの **リポジトリ** から **「追加」** を開き、種類は **Git** のままにして、リポジトリを選ぶ
（またはクローン URL を貼る）と **「クローン」** を押します。終わると **リポジトリ** の一覧に並び、
その行の **「起動」** から最初のセッションを起動できます。private リポジトリには上の「git プロバイダを接続」が
前提です。ブランチやフォルダ名などのオプション、つまずきどころ、内蔵 git プロバイダは
[06 リポジトリと git](06-code.ja.md#リポジトリをクローンする) にあります。

まだどこにも無いものを作り始める場合は、クローンするものがありません。**「はじめる」→
「新しいフォルダで始める…」** で、すでに git リポジトリになっている空のフォルダを作れます
（[06](06-code.ja.md#取り込み元が無いところから始める新規フォルダ)）。

## 一日の終わりに — ワークスペースを止めていい？

**停止して構いません。** ワークスペース操作バーでワークスペースを止めても、次のものは残ります。

- クローンしたリポジトリと、その中の変更（コミット前の作業も含む）。
- 実行していたセッションの一覧。**停止中**として残り、次にワークスペースを起動したときにクリックで再開できます（再開できないケースは [05 止める・片付ける](05-stopping-and-tidying.ja.md) を参照）。
- git やエージェントの接続（ログイン）。ワークスペースを停止・起動しても保持されます。

停止中のワークスペースでも、左ペインのセッション一覧は見えます（中身の操作はできません）。
つまり、通勤中にスマホで「どのセッションがあったか」を眺める程度なら、止めたままでもできます。

止め忘れても心配は要りません。しばらく操作がないと自動で停止します（アイドル自動停止）。
資源の節約にもなるので、自分で止めるのが面倒なら放っておいても大丈夫です。

ただし、**コミットしていない変更はワークスペースの中だけにあります**。長期の作業は
こまめにコミット・push しておくと安心です（[06](06-code.ja.md)）。

### 「新しいバージョンがあります」と **要再起動** バッジ

Console が更新されると、**更新** ボタン付きのトーストが出ます。このボタンはブラウザを
読み込み直すだけで、**実行中のセッションは止まりません**。

その更新にバックエンドの更新も含まれていた場合、いま動いているワークスペースは古いままなので、
ワークスペース操作バーの電源ボタンの横に **要再起動** バッジが出ます。押すと影響の説明と
**今すぐ再起動**（停止→起動）が出ます。こちらは読み込み直しと違って**実行中のセッションが
停止します**（**停止中**として残り、あとで再開できます）。リポジトリやファイルはそのままです。
急ぐ必要はないので、都合の良いタイミングで構いません。ワークスペースが新しい版で起動すると
バッジは自動的に消えます。

その版で何が変わったかは [更新履歴](../../deploy/release/notes/SUMMARY.ja.md) にあります。

### 初日の終わりのチェック

- 大事な変更はコミット・push したか（ワークスペースの外に残るのは push した分だけ）。
- 走らせっぱなしにしたいセッションは、止めなくてもそのまま残ります。区切りが良ければ ⋯ メニューの「停止する（あとで再開できる）」で止めておくと、次回クリックで再開できます（[05](05-stopping-and-tidying.ja.md)）。
- ワークスペースは自分で停止しても、放っておいて自動停止に任せても構いません。

初日に「あれ？」となりやすい点（claude がログイン画面を出す、セッションが再開できない、
クローンに失敗するなど）は [21 困ったとき](21-troubleshooting.ja.md) にまとめてあります。
