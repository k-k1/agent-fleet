# 07. ファイル — ツリー・ビュアー・Markdown/スライド

[English](07-files.md) | 日本語

## ファイルツリー

左ペインの **ファイル** に、ワークスペース内のファイルがツリー表示されます。リポジトリのノードは
折りたためます（三角の「折りたたむ」／「展開」）。1 つの作業コピーに集中したいときに、
他を畳んでおくと見通しが良くなります。

- **compact folders**：中身が 1 つのサブフォルダだけ、という階層は `a/b/c` のように 1 行に畳んで表示されます（深い単一階層で行を無駄にしない、VS Code と同じ流儀）。
- **ツリー / 変更**：リポジトリノードでは表示を「ツリー」と「変更」（変更ファイルのみ）で切り替えられます。変更ファイルには「未追跡」「追加」「変更」「改名」「削除」のバッジが付きます。

ファイルやフォルダを右クリックするとメニューが開きます。「新規ファイル」「新規フォルダ」、名前やパスの
コピー、「名前を変更」「削除」のほか、朗読やギャラリーで開く、「ダウンロード」（フォルダなら
「**zip でダウンロード**」、下記）、ファイルをアシスタントに渡して翻訳・要約させる項目があります。フォルダを
削除すると中身ごと消えるので確認が出ます。
すべての項目と表示条件は [アイコン・バッジ・メニュー](badges-and-menus.ja.md#ファイルフォルダ) にあります。

### フォルダからシェルを開く

フォルダを右クリック →「**ここでシェルを開く**」で、そのフォルダを作業場所にした shell セッション（名前は
`shell · <フォルダ名>`）が起動します。リポジトリの作業コピーの中のフォルダなら、その作業コピーの下のフォルダで開き、
セッションもその作業コピーのものになります。ホームの外のパスでも使えます。

### フォルダを zip でダウンロードする

フォルダを右クリック（またはそのフォルダで Menu キー、**タッチ画面では長押し**）→
「**zip でダウンロード**」。同じ項目が画像ギャラリーのフォルダのメニューにもあります。Console はまずフォルダを
確かめ、トーストでファイル名・ファイル数・大きさ・含めなかったものを知らせます。続いてブラウザが
`<フォルダ>.zip` を保存します。中身は最上位の `<フォルダ>/` の下にそのままのフォルダ構成（空のフォルダも）で
入り、日本語などの名前も保たれます。

- **含めないもの（意図的）:** 選んだフォルダの*下*にある `.git` と `node_modules`（自分でそのフォルダを
  選んだときは丸ごと書き出します）、ファイルブラウザが元々見せないフォルダ（認証情報やエージェントの
  状態）、シンボリックリンク・ハードリンクされたファイル（同じファイルに名前が複数あるもの）・特殊ファイル
  （トーストが件数を言います）。押す前に、メニュー項目のツールチップが最初の 2 つを教えます。
- **大きすぎれば、途中で切らずに断ります。** 20,000 ファイル・4,000 フォルダ・32 階層・512 MiB・読み込み
  45 秒（[上限](../ref/limits.ja.md#製品として固定のもの)）を超えると、ふつうは上限の名前を挙げたメッセージが出て
  ダウンロードは始まりません。もっと小さいフォルダを選んでください。Console の確認は、読んで初めて分かること
  （ディスクの空き不足・I/O エラー・大きくなるファイル・遅いボリュームでの時間切れ）を見られません。
  その場合はダウンロード自体が失敗し、**ブラウザのダウンロード一覧にだけ**表示され、Console にメッセージは
  出ません。途中までの zip を受け取ることはありません。
- **zip に入れられない名前**（バックスラッシュ、制御文字、UTF-8 として不正なバイト列）があると、そのファイル名を
  挙げてダウンロード全体を止めます。黙って名前を変えたり、落としたりはしません。
- **スナップショットではありません。** アーカイブを作る間にファイルを 1 つずつ読むので、書き込み中の
  ファイルは途中の状態で入ることがあります。Console の確認の後にファイルが消えたりリンクに差し替わったり
  すると、ダウンロードが失敗します（サーバーは「zip の作成中にフォルダが変わりました。もう一度お試しください」と
  答え、ブラウザは失敗したダウンロードとして表示します）。
- **zip の作成は Workspace ごとに同時に 1 つ**です。作成中にもう一度押すと、混み合っていると出ます。
  ホームフォルダそのもの（ツリーの根）はこの方法ではダウンロードできません。
- すべてのブラウザで確かめたわけではありません。タッチの長押しとダウンロード自体は、実機の iPhone や
  Android ではなく、テストでだけ確かめています。

ファイルの追加は**ドラッグ＆ドロップでアップロード**するか、右クリックの「新規ファイル」
から作れます。同名ファイルがあると上書き確認が出ます。ファイルを **Ctrl+クリック**（または
中クリック）すると、今の表示を保ったまま**新しいペインで開け**ます（[02](02-console-basics.ja.md#複数を並べるペイン)）。

ツリーは**自動で最新化**されます。手で更新する必要はふだんありません。

- **セッションがターンを終えて入力待ちに戻ったとき**：そのセッションの作業コピーで作られた・
  名前が変わった・消されたファイルが、そこで反映されます。
- **セッションが作業している間も**：走っているセッションの作業コピーは、ターンの途中でも
  20 秒ごとに追いつきます。長い作業を眺めながら「今なにが出来たか」を見に行けます。
- **タブやウィンドウに戻ったとき**：離席している間に終わった作業や、端末で自分が動かした
  コマンドの結果もここで拾えます。
- **フォルダを開き直したとき**：畳んでいる間の増減も出てきます。
- クローン直後、ワークスペースの起動・停止後。

自動更新で**増えたファイルの行は、数秒だけ淡く色が付きます**（何が増えたのか目で追える
ようにするためで、消えても行の中身は変わりません）。見出しの ⟳ は、上のどれにも当てはまら
ないときのために残してあります。

### 見えないフォルダがある理由

ツリーには**わざと表示されないフォルダ**があります。エージェントのログイン情報や
暗号化された保管領域（claude / codex / opencode の資格ファイル、SSH 鍵、Agent Fleet の
内部状態など）を収めたディレクトリです。あなたの秘密を守るため、一覧に出さず直接の
閲覧もできないようになっています。見当たらなくても異常ではありません。

## ファイルビュアー

ファイルをクリックすると、メイン領域の**ビュアー**に中身が出ます。上部にファイル名・
形式・サイズ・行数が表示されます。

- **構文ハイライト・行番号・ミニマップ**：コードは言語を判定してハイライトされます。行番号やミニマップの有無は ⚙設定 → 「表示」タブの「ファイルビュアー」で切り替えます。
- **巨大ファイル**：極端に大きい／長い行のファイルは、「プレーン表示」（ハイライト・行番号なし）に自動で切り替わります。
- **LFS ポインタ**：Git LFS の実体がまだ無いファイルには「LFS ポインタ」バッジが出ます。端末でそのリポジトリに入り `git lfs pull` すると実体を取得できます（[06](06-code.ja.md)）。

### Markdown と Mermaid

`.md` ファイルは、上部の切り替えで **「プレビュー」** と **「ソース」** を行き来できます。
プレビューでは Mermaid のコードブロックが図として描画されます。コードブロックごとに
「このコードをコピー」ボタンが付きます。

リンクは [表示した Markdown の中のリンク](#表示した-markdown-の中のリンク) のとおりに動きます。プレビューでは、
相対リンクはそのファイル自身のフォルダから読み、`#見出し` アンカーはページ内をスクロールします。

### 表示した Markdown の中のリンク

Console が Markdown を表示する場所（ファイルのプレビュー、会話の中のエージェントの返信、アシスタントの
チャット、ドキュメントビュアー）では、次のものがリンクになります。

- **外部 URL** は新しいタブで開きます。
- **ワークスペース内のファイルやフォルダへのパス**は、Markdown のリンク（`[text](src/app.ts)`）でも
  バッククォート（`` `src/app.ts` ``）でもリンクになります。ファイルはビュアーで開き、フォルダは
  **ファイル** に表示します。
- セッション（ターミナル（CLI）でもマネージドでも）の返信の **`$AF_WORK_DIR/…`** は、そのセッションの
  作業用一時領域（`~/.af-work/<セッション>`）を指し、そこにファイルやフォルダがあればリンクになります。
  チャットとドキュメントビュアーではただの文字のままです。
- **課題番号**（`#956`、`owner/name#956`、Jira のキー、`#573-#598` のような範囲の両端）は課題の詳細を
  開きます。規則は [03 セッションを始める](03-starting-sessions.ja.md#会話の中の課題番号から) のとおりです。ファイルの
  プレビューでは、`#956` はそのファイルがある作業コピーの番号として読みます。対象は `~/repos/<名前>/` の
  下にあり、origin が github.com か bitbucket.org にあるファイルだけです。作業コピーの中に入れ子になった
  Git リポジトリ（サブモジュールや取り込んだクローン）のファイルや `~/repos` の外のファイルでは課題番号は
  一切リンクにならず、ドキュメントビュアーも課題番号をリンクにしません。
- **ループバックの URL**（`http://127.0.0.1:<ポート>/…`・`http://localhost:…`・`http://0.0.0.0:…`）は
  手元のマシンではなくワークスペースのサーバを指すので、クリックするとセッション行のポートチップと同じように
  そのポートを開きます（[チップ](badges-and-menus.ja.md#セッションの表示)）。Ctrl／⌘／中クリックは
  新しいタブで開きます。配備にブラウザペインがあればブラウザペインで、無ければ既定の開き方で開きます。右クリックや
  長押しでチップと同じメニューが開きます。そのポートで待ち受けて
  いる稼働中のセッションが無いとリンクは薄く表示されますが、それでも開けます。バッククォートの中の URL は、
  待ち受けているセッションがある間だけリンクになります。`https:` のループバック URL はふつうのリンクのまま
  で、ASCII 以外の句読点や記号（省略の `…` など）を含むバッククォートの中の URL も同じです。ワークスペースが
  止まっているときは、クリックするとそのポートを開けないと表示されます。
- ファイルやフォルダのリンクを**右クリック**（長押し、メニューキーでも）すると、「ペインで開く」
  「新しいペインで開く」「ファイル一覧で表示」と、ファイルのメニューのうち何も変更しない項目が並ぶメニューが
  開きます（[メニュー](badges-and-menus.ja.md#返信やドキュメントの中のファイルとフォルダのリンク)）。

共有セッションを読んでいる人には、これらは働きません。パスと課題番号はただの文字で、URL はふつうの
リンクです。

### Marp スライド

先頭に `marp: true` を書いた `.md` は、**スライド**として表示できます。上部の切り替えに
**「スライド」「プレビュー」「ソース」** が並び、既定でスライド表示になります。

- **◀ / ▶**（または ← → / PageUp・PageDown / Space / Home・End）で 1 枚ずつ送れます。
- **⤢** で全画面表示にできます。

### 図（`.drawio`）

`.drawio` / `.dio` ファイル（および `mxfile` を収めた `.xml`）は、**図**として表示されます。
上部の切り替えで **「図」** と **「編集」**（読み取り専用のときは **「ソース」**）を行き来
します。「編集」「ソース」はファイルの XML をテキストのまま表示するので、いつでもそこに降りられます
（図そのものを画面上で編集できるわけではありません。下記）。

- **複数ページ**：ヘッダに `1 / 2 ページ` のように出ます。左上の矢印でページを送れます。
- **拡大・移動**：Ctrl（⌘）＋ホイール、または 2 本指ピンチで、指した点を軸に拡大縮小します。素のホイールやドラッグで移動します。ダブルクリック／ダブルタップで「収まり」と等倍を行き来します。
- **テーマは Console に追従します**：明暗の切り替えに合わせて描き直され、見ていたページ・倍率・位置はそのまま引き継がれます。
- **図が外部に出ることはありません。** ビューアを同梱しているので、図面が第三者のサービスへ送られることはなく、外部ネットワークが一切無くても描画できます。
- **ベンダーアイコン**（AWS・GCP・Azure・Kubernetes・ラック機器…）は、セット単位で Control Plane が 1 回だけ取得して全員分をキャッシュします。通信が制限された環境では取得できないことがあり、その場合は図形の大きさ・色・枠・ラベルは残り、中のアイコンの図案だけが空になります（図そのものは開きます）。運用者が事前に投入しておくこともできます（[運用 03](../operate/03-run.ja.md)）。

このリポジトリに試せるサンプルがあります: **[`docs/assets/architecture.drawio`](../assets/architecture.drawio)**
（Agent Fleet 自身の構成：AWS 上と、Docker Compose の 1 ホスト上）。

図を画面上で編集すること（図形を動かす、線を引く）にはまだ対応していません。「編集」で変えられるのは
XML のテキストだけで、ほかのファイルと同じ扱いです（[ファイルを編集する](#ファイルを編集する)）。作図には外部のエディタを使ってください。

### PDF と Office 文書

**PDF** は見た目そのままページとして表示されます（ヘッダに `1 / 12 ページ`）。矢印でページを送り、
**拡大 / 縮小**と**幅に合わせる**が使えます。フォントを埋め込んでいない**日本語の PDF でも文字が
出ます**。

**Word / Excel / PowerPoint**（`.docx` `.xlsx` `.pptx` と、`.odt` `.rtf` `.epub` など）は
**簡易プレビュー**です。中身を読める形に変換して表示するもので、画面にもそう書いてあります。
**書式・図形・画像は再現されません**。体裁ごと必要なときは、情報バーの**ダウンロード**から
原本を開いてください。

- **変換も描画もブラウザの中だけ**で行われます。文書が外部のサービスへ送られることはありません
  （`.drawio` と同じ方針です）。
- 初めてその形式を開いたときだけ、読み込みに少し時間がかかります（開かない限り読み込みません）。
- 開けないときは**理由が出ます**：パスワードで保護されている、壊れている、**画像だけのページ**
  （文字を読み取るには OCR が必要で、ここでは行えません）、大きすぎる（40 MB 超）。

## ファイルを編集する

ビュアー上部の **「表示 / 編集 / 分割」** で編集に切り替えると、その場でファイルを直せます。
ちょっとした修正のためにセッションを起こす必要はありません（`.md` では「分割」で
編集とプレビューを並べられます）。

- **保存は Ctrl/⌘+S**（または「保存」ボタン）。状態は上部に「未保存の変更」「保存中…」
  「保存しました」と出ます。
- **未保存のまま離れようとすると止めます。** ペイン移動・再読み込み・ログアウト・別タブへの
  切り離しなどの前に確認が出て、**「保存して続行」** か **「破棄して続行」** を選びます
  （未保存のファイルは別タブへ切り離せません）。
- **外部で変更されたとき**：エージェントや別のセッションが同じファイルを書き換えると
  **「ファイルが外部で変更されました」** と出ます。**「差分を確認」** で見比べてから取り込めます。
- **競合したとき**：保存しようとしたリビジョンが古い場合は **「リモートの変更と競合しました」** と
  なり、あなたの内容（mine）は保持されたまま、**remote を採用 / mine を破棄 / remote を base に
  手動マージ**から選べます。保存できたか判定できないときも、mine と送信内容を抱えたまま
  「再取得」「明示的に再保存」で決着させられます。**編集内容が黙って消えることはありません。**
- **保存できない内容**：2 MiB を超える変更、NUL を含むもの、CR/CRLF 改行（LF のみ対応）、
  不正な Unicode は弾かれます。

### AI に書き換えを提案させる

エディタの **「AI 提案」** から、選択範囲（未選択なら全文）に対する変更を AI に作らせられます。
指示を書いて **Ctrl+Enter** で生成し、差分を見て **「適用」** か **「却下」** を選びます。
勝手に書き換わることはありません（生成後に本文が変わった場合は「再生成してください」と出ます）。
この生成に使ったトークンは、⚙設定 →「エージェント使用量」タブに **「変更提案（エディタ）」** として
記録されます（[20](20-settings.ja.md#エージェント使用量)）。

## ファイルをセッション／チャットに送る

エージェントに「このファイルを扱ってほしい」ときは、ファイルを開き、ビュアーで
**テキストを選択**すると出る **「送る」** から送信できます（範囲を選ばず、ファイル全体を
送ることもできます）。この操作はファイルの右クリックメニューにはありません。

- **送信先**：稼働中のセッション（直接送信）か、アシスタント（チャットで開く）を選びます。停止中のセッションには送れません。
- **コメント（指示）**：「日本語に翻訳して保存して」などの指示を添えます。
- ファイルは**パスで渡され**、セッションが自分で読み書きします。大きなファイルの翻訳など、ファイル出力を伴う作業に向きます。

「カテゴリ」を付けて**メモキュー**に溜めておき、あとでまとめて送ることもできます
（[10 チャットとメモ](10-chat-memo.ja.md)）。
