# 20. 設定 — ⚙設定モーダルの全タブ

[English](20-settings.md) | 日本語

個々の設定の**使いどころ**は各章に書いてあるので、この章は**地図**として使ってください。
深い説明がある項目はその章へのリンクを置いています。

## 開き方と構成

画面最上部のバーのアカウントメニューにある **⚙設定** で開きます。左レールが 4 つのグループに分かれています。

| グループ | 何が入るか |
|---|---|
| **個人設定** | 表示 / アカウント / キー操作 / 読み上げ / 通知 / 利用枠ボード / アシスタント / AI 補助 / エージェントへの指示 / エージェントメモリ / メモリのスナップショット |
| **接続** | エージェント / Git ホスティング / 運用・監視 / 課題管理 / チャット連携 / MCP サーバー（セッションで使う） / AWS プロファイル/SSM / Google Cloud |
| **外部からのアクセス** | MCP トークン・接続アプリ（外部からこのワークスペースを操作するためのトークンと接続アプリ） |
| **ワークスペース** | エージェント使用量 / クラウド費用 / 稼働時間 / マシン / ツールチェーン / データベース / プレビュー用サブドメイン / 内部リポジトリ / 書き出し / 取り込み / 危険な操作 |

- 最後に開いたタブを覚えているので、次に開くとそこから始まります。
- **スマホでは一覧 → 詳細のドリルダウン**です。戻る操作で一覧に戻り、もう一度で閉じます。
- チームの**メンバー・上限・監査**の管理は、権限のある人にだけ出る**別のモーダル**、同じメニューの
  **テナント設定**です（[admin/](../admin/README.ja.md)）。**管理**（盾のアイコン）は配備全体のものです。
- 一部のタブは**ワークスペースの起動が必要**です（設定の実体がワークスペース内にあるため）。
  停止中はその旨と「ワークスペースを起動」ボタンが出ます。

### いつ反映されるか

これを取り違えると「設定したのに変わらない」になります。

| タイミング | 対象 |
|---|---|
| **即時** | 表示・キー操作・読み上げ・通知、接続の追加と削除、停止中セッションのアーカイブ期間（次の一覧更新から） |
| **次に起動するセッションから** | エージェントの動作設定、エージェントへの指示、セッション間メッセージ、セッションからのセッション起動、過去セッションの検索（オフにすると起動中のセッションの検索もその場で断る）、Agent Fleet のメモリ（同じく）、画像生成、MCP サーバー |
| **次のチャット送信から** | アシスタントの設定、運用・監視の接続（アシスタントで使う場合） |
| **ワークスペースの停止 → 起動** | ツールチェーン（タイムゾーン・言語のバージョン）、マシン（管理者が変えたサイズ・種類） |

**保存先も 2 種類**あります。テーマ・背景色・メイン領域の配置は**このブラウザだけ**に保存され、
それ以外（フォント・文字サイズなど）はサーバーに保存されて別の PC やブラウザでも追従します。
サーバーへの保存に失敗すると、設定画面の上部に「設定をサーバーに保存できていません」と出ます。
その間、エージェントは前の設定のまま動くので、「再送」を押してください。

## 個人設定

### 表示

言語・タイムゾーン・テーマ・フォント・メイン領域の配置です。[表示とアカウントを変える](../user/settings/display.ja.md) にあります。

### アカウント

サインイン方法の追加と解除です。[表示とアカウントを変える](../user/settings/display.ja.md#サインイン方法を追加する) にあります。

### キー操作

ショートカットの割り当て・端末入力の優先・送信キー・返信サジェストは [キーボードとコマンドパレットで操作する](../user/start/shortcuts.ja.md#キーを変える) にあります。

### 読み上げ

回答を声で読み上げます。[読み上げを使う](../user/settings/read-aloud.ja.md) にあります。

### 通知

通知の種類ごとに、未読ドット・OS の通知・読み上げを選びます。[通知を受け取る](../user/settings/notifications.ja.md) にあります。

### 利用枠ボード

利用上限に対する自分の状況を、このテナントの誰に・どこまで見せるかを選びます。[使用量の上限の状況を見せ合う](../user/team/usage-limits.ja.md) にあります。

### アシスタント

回答言語・エージェント優先順位・アシスタントのモデル・自動圧縮などです。[アシスタントに質問する](../user/chat/assistant.ja.md#回答の言語とモデルを決める) にあります。セッション報告への自動応答と自動走行は [フリート・オペレーターに任せる](../user/fleet/operator.ja.md#自動応答を調整する) にあります。

### AI 補助

タイトルや返信候補などの 1 回きりの AI 生成に使うエージェントとモデル、機能ごとのオン・オフです。[翻訳や専用のアシスタントを使う](../user/chat/purpose-assistants.ja.md#ai-補助を設定する) にあります。

### エージェントへの指示

自分専用の指示を、新しく起動するエージェントに足します。[作業のしかたを一度だけ書いておく](../user/agents/instructions.ja.md) にあります。

### スキル

各エージェントの個人スキルを読み取り専用で一覧します。[手元の Claude Code の設定を持ち込む](../user/agents/bring-claude-setup.ja.md#スキルを確かめる) にあります。

### エージェントメモリ

どの種類のエージェントも読み書きする Agent Fleet 自身の共有メモリです。セッション向けのスイッチは**設定**の表示にあります。
画面の説明は [エージェントのメモリを見る・直す](../user/memory/overview.ja.md) にあります。

### メモリのスナップショット

エージェントが自前のファイルに貯めるメモリの版管理です。画面の説明は
[スナップショットでメモリを戻す](../user/memory/snapshots.ja.md)にあります。

## 接続

### エージェント

エージェントごとのカードで、接続と動作設定を行います。[エージェントを選ぶ](../user/agents/choose.ja.md) と、各エージェントのページにあります。

**セッション**グループには、**停止中セッションのアーカイブ**（既定＝配備の期間で、配備で変えていなければ 7 日／1・3・7・14・30 日／しない）、**セッション間メッセージ**、**セッションからのセッション起動**（と
**子セッションの同時本数**）、**過去セッションの検索**（既定オン。セッションが
`search_sessions` ツールでこのワークスペースの過去の会話を検索できます。コマンドパレットの「会話」はこの設定に
関係なく使えます。[02](../user/start/shortcuts.ja.md#コマンドパレットで探して開く) を参照）、**画像生成**と**画像生成の優先順位**（配備のエンジンがそれぞれの名前で先、CLI の経路が後）があります。→
[セッション同士でやりとりさせる](../user/fleet/messages.ja.md)・
[セッションから子セッションを起動する](../user/fleet/child-sessions.ja.md)・
[セッションに画像を作らせる](../user/images/from-session.ja.md)

### Git ホスティング

GitHub・Bitbucket の接続、コミットの作者、保存した Subversion の認証情報です。GitHub の接続は GitHub Copilot の接続も兼ねます。
[Git のサービスを接続する](../user/code/connect-git.ja.md) にあります。

### 運用・監視

PagerDuty・Grafana・CloudWatch・AWS を **SRE アシスタント**につなぐ設定です。接続のしかたと、アシスタントがそれで何をするかは
[監視ツールとつなぐ](../user/integrations/ops-monitoring.ja.md) にあります。

### 課題管理

左ペインの**課題管理**に課題やプルリクエストを出すための、Jira の接続です。接続と保存クエリは
[課題管理サービスを接続する](../user/integrations/issue-tracker.ja.md) にあります。

### チャット連携

Discord・Slack の Bot の接続と、届く通知の設定です。接続の手順と、返信で答える方法は
[Discord・Slack とつなぐ](../user/integrations/chat-bridge.ja.md) にあります。

### MCP サーバー（セッションで使う）

セッションとアシスタントが使う MCP サーバーの登録、3 つの出自、接続テスト、OAuth のサインインは
[セッションに MCP サーバーを追加する](../user/integrations/mcp-servers.ja.md) にあります。外部のアプリからこのワークスペースを
操作させるには、**外部からのアクセス**の [MCP トークン・接続アプリ](#mcp-トークン接続アプリ) を開いてください。

### AWS プロファイル/SSM

`af-aws-exec` と SSM セッションがログインに使う AWS プロファイル（共通設定）と、社内の別ホストへ SSM でログインするための
SSM ホスト（個別）の登録です。プロファイルは **IAM Identity Center（SSO）** か **別のプロファイルからロールを引き受ける** かの 2 種類で、SSO の行には
**ログイン**と、ログイン中なら**ログアウト**があり、ロールを引き受ける行の**ログアウト**は元のプロファイルのログインを終わらせます（確認の画面で元を示します）。ログイン・ログアウトの動きと 2 つの種類は
[AWS SSO を使う](../user/integrations/aws-sso.ja.md) に、SSM ホストは [SSM で EC2 にログインする](../user/integrations/aws-ssm.ja.md) にあります。

### Google Cloud

`af-gcloud-exec` がコマンドを実行するときに使う Google Cloud のプロファイルです。登録・取り込み・ログインと、WS バーの
Google Cloud バッジは [Google Cloud を使う](../user/integrations/gcloud.ja.md) にあります。

## 外部からのアクセス

### MCP トークン・接続アプリ

このワークスペースを外から使うための個人アクセストークンと接続アプリを扱います。トークンは [外部の Claude からワークスペースを動かす](../user/outside/external-claude.ja.md)、接続アプリは [リモートの MCP クライアントをサインインでつなぐ](../user/outside/oauth-client.ja.md) にあります。セッションが呼ぶサーバーを登録するのは [セッションに MCP サーバーを追加する](../user/integrations/mcp-servers.ja.md) です。

## ワークスペース

### エージェント使用量

何にトークンを使ったかの台帳です。見かたは [料金と使用量を確かめる](../user/agents/usage.ja.md#何にトークンを使ったかを見る) にあります。

### クラウド費用

自分のワークスペースに直接ひも付くクラウドの費用です（AWS で動く配備だけ）。見かたは
[稼働時間とクラウド費用を見る](../user/workspace/cost.ja.md#クラウド費用を見る) にあります。

### 稼働時間

ワークスペースがいつ動いていたかを、1 時間ごとのマス目で見ます。見かたは
[稼働時間とクラウド費用を見る](../user/workspace/cost.ja.md#稼働時間を見る) にあります。

### マシン

ワークスペースが動いているマシンの大きさと、メモリ・ディスクの使用状況、ディスクの空けかたです。
[マシンと使用状況を見る](../user/workspace/machine.ja.md) にあります。

### ツールチェーン

タイムゾーンと Node.js / Java / Go のバージョン、ツールのバージョン、エージェント CLI の更新です。
[ツールチェーンを選ぶ](../user/workspace/toolchains.ja.md) にあります。

### データベース

このワークスペースの PostgreSQL と MySQL です。
[データベースを使うテストを動かす](../user/workspace/databases.ja.md#console-から管理する) にあります。

### プレビュー用サブドメイン

作っているアプリを専用の URL で開くためのタブで、プレビュー用サブドメインを発行する配備にだけ出ます。公開するポート、共有、URL の再発行は
[プレビュー用のサブドメインを使う](../user/preview/subdomains.ja.md) に、開発用 OIDC IdP の欄（issuer、client id、アプリの設定例、テスト用ペルソナ）は
[プレビューで Google ログインを試す](../user/preview/dev-signin.ja.md) にあります。

### 内部リポジトリ

外部のサービスを使わずに、テナントの中に Git のリポジトリを作ります。[内蔵の Git を使う](../user/code/internal-git.ja.md) にあります。

### 書き出し / 取り込み

自分の設定をファイル 1 つにまとめて持ち出し、別の環境で読み戻します。
[設定を書き出す・取り込む](../user/workspace/export-import.ja.md) にあります。

### 危険な操作

ワークスペースの作り直しとホームの掃除です（実行できる配備だけ）。何が残り何が消えるかは
[ワークスペースを作り直す](../user/workspace/recreate.ja.md) にあります。

## やりたいこと → どのタブか

| やりたいこと | タブ |
|---|---|
| 文字が小さい / 配色を変えたい | 表示 |
| 別のサインイン方法でも入れるようにしたい | アカウント |
| Enter で送信したい | キー操作（送信キー） |
| ペインをタブで切り替えたい | 表示（メイン領域の配置） |
| ショートカットを変えたい / 端末にキーを渡したい | キー操作 |
| 回答を読み上げてほしい | 読み上げ |
| Slack への通知だけ止めたい | 通知（サービス通知） |
| アシスタントを英語で答えさせたい | アシスタント（回答言語） |
| オペレーターに勝手に進めさせたい / 止めたい | アシスタント（自動走行・自動応答） |
| タイトルや返信候補を AI に作らせたくない | AI 補助（機能ごとのオン・オフ） |
| 補助生成だけ安いモデルで回したい | AI 補助（優先順位・モデル） |
| 毎回同じ前置きをプロンプトに書いている | エージェントへの指示 |
| Claude / Codex にログインしたい | エージェント |
| 課金されるモデルを選ばせたくない | エージェント（使わないモデル） |
| 停止したセッションを一覧に長く残したい・早く片付けたい | エージェント（停止中セッションのアーカイブ） |
| セッション同士で連絡させたい | エージェント（セッション間メッセージ） |
| セッションに過去の会話を検索させたくない | エージェント（過去セッションの検索） |
| エージェントが学んだことを種類をまたいで共有したい | エージェントメモリ（設定） |
| セッションに他のセッションの状況を見せたい | 設定は不要。どのセッションでもできます（[セッションに全体を見せる](../user/fleet/fleet-visibility.ja.md)） |
| 作業中に気づいたことをメモに残させたい | 設定は不要。どのセッションでもできます（[セッションに全体を見せる](../user/fleet/fleet-visibility.ja.md)） |
| private リポジトリを clone したい | Git ホスティング |
| インシデントの調査を手伝わせたい | 運用・監視 |
| チケットや Issue から作業を始めたい | 課題管理 |
| 席を外しても進捗を受け取りたい | チャット連携 |
| 社内ツールを AI から使わせたい | MCP サーバー（セッションで使う） |
| 手元の Claude から操作したい | 外部からのアクセス → MCP トークン・接続アプリ |
| トークンを何に使ったか知りたい | エージェント使用量 |
| 自分のワークスペースにいくらかかっているか知りたい | クラウド費用 |
| ワークスペースがいつ動いていたか知りたい | 稼働時間 |
| 変なことを覚えさせてしまった | エージェントメモリ（メモリ・変更）、メモリのスナップショット（履歴） |
| Java / Node のバージョンを変えたい | ツールチェーン |
| DB が要るテストを回したい | データベース |
| 作っているアプリを人に見せたい | プレビュー用サブドメイン |
| 別のサーバーに入りたい | AWS プロファイル/SSM |
| 自分の Google Cloud プロジェクトでコマンドを実行したい | Google Cloud |
| 外部に出せないコードを置きたい | 内部リポジトリ |
| 別の環境へ設定を持っていきたい | 書き出し / 取り込み |
| 環境が壊れた | 危険な操作 |
