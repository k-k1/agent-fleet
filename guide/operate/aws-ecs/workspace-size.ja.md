# ワークスペースの大きさを決める

[English](workspace-size.md) | 日本語

ECS の配備で、すべてのワークスペースが既定で受け取る CPU・メモリ・作業ディスクを決めます。
メンバーごとの大きさは、テナント管理者が Console で変えます（[ワークスペースの大きさを決める](../../admin/resources/workspace-size.ja.md)）。その値はテナントの上限で切り詰められます。

## 全体像

| あなたがやること | 起きること |
|---|---|
| `30-ingress` の 3 つのパラメータを決める | Control Plane が、その値をワークスペースの既定として使う |
| 作業ディスクを 30 GiB 以上にする | ビルドのキャッシュと生成物が、EFS から作業ディスクに移る |
| 半端な CPU とメモリの組を指定する | Control Plane が、ECS で使える組に寄せる |

## パラメータ

| パラメータ | Control Plane の環境変数 | 既定 | 中身 |
|---|---|---|---|
| `WsTaskCpu` | `AF_ECS_TASK_CPU` | `1024` | Fargate の単位。1024 が 1 vCPU |
| `WsTaskMemory` | `AF_ECS_TASK_MEMORY` | `2048` | MiB |
| `WsDiskGiB` | `AF_ECS_WS_DISK_GB` | `50` | 21〜200 で作業ディスク（エフェメラルストレージ）の大きさ。0 で Fargate の無料の 20 GiB（キャッシュの移動もオフ） |

## CPU とメモリの組

ECS で使える CPU とメモリの組は決まっていて、刻みもそろっていません。

| CPU | 使えるメモリの例 |
|---|---|
| 0.25 vCPU | 512・1024・2048 MiB だけ |
| 8 vCPU | 4096 MiB 刻み |
| 16 vCPU | 8192 MiB 刻み |

- Control Plane は、どんな指定も使える組に寄せます。半端な値がタスク定義に届くことはありません
- そのため、**CPU を上げるとメモリも上がることがあります**。たとえば 4 vCPU は 8 GiB より下では動きません

## 作業ディスク

作業ディスクは**残りません**。ワークスペースを止めると消えます。残るのは EFS のホームだけです。

`WsDiskGiB` は、小さなファイルが多いツリーを EFS から作業ディスクへ移すスイッチも兼ねます。

| 移すもの | 移す側 |
|---|---|
| Go のビルドキャッシュ、`uv`、Go のモジュール | ワークスペースのエントリーポイント |
| `node_modules`・`target`・`.venv`・`build` | エージェント。作業コピーを作るたびに移す |

- どちらも、作業ディスクが **30 GiB 以上**のときだけ動きます。20 GiB ではイメージと並べてキャッシュが収まりません
- EFS の上では、これらのツリーの書き込みが 8〜30 倍遅くなります
- 既定は 50 GiB なので、移動は有効です

### 費用

- 無料の 20 GiB を超える分は、1 GiB・1 か月あたり約 $0.097 です。**タスクが動いているあいだだけ**かかります
- 止めずに動かし続けるワークスペースで月に約 $2.9、アイドルで止まるワークスペースなら月 $1 未満です
- 要らなければ `WsDiskGiB=0` にします。移動のない、以前と同じ動きになります

### 既存のスタックは前の値のまま

CloudFormation はパラメータの値を覚えています。`0` で作ったスタックは、更新しても `0` のままです。50 GiB にしたいときは、更新のときに `WsDiskGiB=50` を明示します。

## 200 GiB を超えるディスク

200 GiB を超えると、Control Plane は作業ディスクを ECS が管理する EBS ボリュームに切り替えます。

- ECS のインフラストラクチャロール（ポリシー `AmazonECSInfrastructureRolePolicyForVolumes`）を `AF_ECS_INFRA_ROLE` で渡す必要があります
- 参照用のスタックは、このロールを作りません。ロールがないと、200 GiB を超える指定は何も言わずに無料の既定に戻ります
- この経路は、実機ではまだ試していません。200 GiB までは、エフェメラルストレージで足ります
