# どのメモリを使うか決める

[English](which-memory.md) | 日本語

エージェントが「覚えている」ものは 3 つあります。

- **指示のファイル**：あなたやチームが書いておく決まりごと（`CLAUDE.md`・`AGENTS.md`、⚙設定 →「エージェントへの指示」）
- **エージェント自身のメモリ**：エージェントの種類ごとに、自分で書き溜めるメモリ（Claude Code の自動メモリ、Codex の memories、Muse Code のメモリ）
- **Agent Fleet のメモリ**：どの種類のエージェントも共有するメモリ（⚙設定 →「エージェントメモリ」）

## 全体像

| | 指示のファイル | エージェント自身のメモリ | Agent Fleet のメモリ |
|---|---|---|---|
| 誰が書くか | あなた（リポジトリのものはチーム） | エージェントが作業中に自分で | エージェントが af の `memory_*` ツールで。あなたもメモリビューで書ける |
| どこにあるか | リポジトリ（コミットされる）と、各エージェントの指示のファイル | 種類ごとのファイル（Claude Code の `MEMORY.md` など、Codex の `~/.codex/memories/`） | ワークスペースの中の、Agent Fleet が管理する保管場所 |
| どのエージェントが読むか | それぞれのファイルを読む種類。「エージェントへの指示」はほとんどの種類に届く | 書いたその種類だけ | スイッチがオンなら、af のメモリツールを持つすべての種類 |
| Console で見る・戻す | ⚙設定 →「**エージェントへの指示**」 | ⚙設定 →「**メモリのスナップショット**」（Claude Code・Codex・Muse Code） | ⚙設定 →「**エージェントメモリ**」の「**メモリ**」「**変更**」 |
| スイッチをオンにすると | あなたの文章の隣に、メモリのツールの短い決まった案内が入る | 対応する種類では切られる（次の表） | 新しいセッションが読み書きする |

スイッチは ⚙設定 →「エージェントメモリ」→「設定」の「**セッションに Agent Fleet のメモリを使わせる**」です（既定ではオフ）。入れかたは[メモリの使いかたを設定する](settings.ja.md)にあります。

## エージェント自身のメモリにスイッチがすること

| 種類 | オンの間、切るか | オンにしたとき取り込むか | オフにしたとき書き戻すか | スナップショットに残るか |
|---|---|---|---|---|
| claude | 切ります（新しいセッションとアシスタントのチャット） | 自動で取り込みます | 書き戻します。終わるまで切ったままです | 残ります |
| codex | 切ります（`features.memories`）。オフにすると元の値に戻します | しません | しません | 残ります（Codex の memories のフォルダがあるとき） |
| muse | 切ります（新しく起動するセッション） | 自動ではしません。「**muse から取り込む**」で手で取り込めます | しません | 残りません |
| agy・copilot・cursor・opencode・kiro・lcpp | Agent Fleet は切りません | しません | しません | Agent Fleet は履歴を取りません |

- どの種類も、切り替えたあとに起動したセッションから効きます
- 取り込みと書き戻しの手順は[メモリを取り込む・書き出す](import-export.ja.md)、履歴と巻き戻しは[スナップショットでメモリを戻す](snapshots.ja.md)にあります

## Agent Fleet のメモリをオンにするか

| オンにするとよいとき | オフのままでよいとき |
|---|---|
| いくつもの種類のエージェントを使う | 1 種類のエージェントしか使わない |
| 別の種類へ引き継ぐ、別の種類の子セッションを起動する | 覚えたことをほかの種類と共有する必要がない |
| 覚えたことを Console で読んで直したい | エージェント自身のメモリで足りている |
| 手元の Claude Code や claude.ai からも使いたい（「**Agent Fleet の外からメモリを使わせる**」は別のスイッチです） | |
