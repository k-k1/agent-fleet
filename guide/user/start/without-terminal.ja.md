# ターミナルを使わない人のための入口

[English](without-terminal.md) | 日本語

コマンドを打たずに、ボタンと入力欄だけで Agent Fleet を使うためのページです。
AI への質問や翻訳、資料を読むこと、開発の進み具合を見ることは、どれもターミナルを開かずにできます。

## 全体像

| あなたがやること | 使う場所 |
|---|---|
| AI に質問する・翻訳してもらう・文章を整えてもらう | 左ペインの「**アシスタント**」 |
| 思いついた要望を書き溜めて、開発に渡す | 左ペインの「**メモキュー**」 |
| ドキュメントやスライドを読む | 左ペインの「**ファイル**」 |
| 開発がどこまで進んでいるかを見る | 左ペインのセッションの一覧 |

- 「リポジトリで開発する」の手順（Git のサービスの接続やセッションの起動）は、使わなければ飛ばして構いません
- ワークスペースは使い終わったら止めておけます。次に使うときに「**起動**」を押せば戻ります（[一日の終わりにワークスペースを止める](end-of-day.ja.md)）

## 人あての質問に代わりに答えない

セッションが「質問あり」や許可待ちで止まっているのは、担当の開発者の返事を待っているからです。

- のぞいているあなたが、代わりに答えないでください。開発者の意図と違う方向に作業が進むことがあります
- 気づいたことがあれば、担当の開発者に声をかけるか、メモキューに書いて渡します
- 共有してもらったセッションで提案ができるときも、提案は所有者が承認してから届きます
