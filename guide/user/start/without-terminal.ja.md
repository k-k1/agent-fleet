# ターミナルを使わない人のための入口

[English](without-terminal.md) | 日本語

コマンドを打たずに、ボタンと入力欄だけで Agent Fleet を使うためのページです。
AI への質問や翻訳、資料を読むこと、開発の進み具合を見ることは、どれもターミナルを開かずにできます。

## 全体像

| あなたがやること | 使う場所 |
|---|---|
| AI に質問する・翻訳してもらう・文章を整えてもらう | 「**アシスタント**」ビュー |
| 思いついた要望を書き溜めて、開発に渡す | 「**メモキュー**」ビュー |
| ドキュメントやスライドを読む | 「**ファイル**」ビュー |
| 開発がどこまで進んでいるかを見る | 「**セッション**」ビュー |
| ほかのメンバーが共有した会話を読む | 「**共有セッション**」ビュー |

## まず読むページ

| 順番 | ページ | 内容 |
|---|---|---|
| 1 | [最初のセッションを始める](quickstart.ja.md) | サインインして、ワークスペースの起動とエージェントの接続を済ませる。「どちらから始めますか？」では「**チャットをはじめる**」を選びます |
| 2 | [画面の見かた](console-tour.ja.md) | 画面のどこに何があるか |
| 3 | [アシスタントに質問する](../chat/assistant.ja.md#チャットを始める) | 質問・翻訳・要約の頼み方と、チャットとセッションの違い |
| 4 | [翻訳や専用のアシスタントを使う](../chat/purpose-assistants.ja.md) | ファイルを翻訳する・用途別のアシスタントを使う |
| 5 | [ドキュメントや図を表示する](../files/view.ja.md) | 資料をブラウザで読む |
| 6 | [ファイルをセッションに渡す](../files/send.ja.md) | ファイルの翻訳や要約を頼む |
| 7 | [メモをためて渡す](../chat/memos.ja.md) | 要望を溜めて、まとめて渡す |
| 8 | [セッションの状態を読む](../sessions/status.ja.md) | 開発の進み具合を、行の印で読む |
| 9 | [共有された会話を読む](../team/share.ja.md#共有された会話を読む) | ほかのメンバーが共有した会話を開き、共有の権限を確認する |
| 10 | [スマートフォンで使う](phone.ja.md) | 外出先で進み具合を見る |

- 「リポジトリで開発する」の手順（Git のサービスの接続やセッションの起動）は、使わなければ飛ばして構いません
- ワークスペースは使い終わったら止めておけます。次に使うときに「**起動**」を押せば戻ります（[一日の終わりにワークスペースを止める](end-of-day.ja.md)）
