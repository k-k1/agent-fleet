# Start here if you don't use the terminal

English | [日本語](without-terminal.ja.md)

This page is for using Agent Fleet with buttons and input boxes only, without typing commands.
Asking the AI questions, translating, reading documents and following development all work without opening a terminal.

## How it works

| What you do | Where |
|---|---|
| Ask the AI a question, have it translate or tidy up text | **Assistants** in the left pane |
| Jot down requests and hand them to development | **Memo queue** in the left pane |
| Read documents and slides | **Files** in the left pane |
| See how far development has got | The sessions list in the left pane |
| Read a conversation a developer shared with you | **Shared sessions** in the left pane |

## Don't answer questions meant for someone else

A session stopped with "Question" or waiting for a permission is waiting for the developer in charge.

- Do not answer in their place while you are looking in. The work can go in a direction the developer did not intend
- If you notice something, tell the developer in charge, or write it in the memo queue and hand it over
- Where a shared session lets you propose a message, the proposal reaches the agent only after the owner approves it
