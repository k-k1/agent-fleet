# Agent Fleet でできること

[English](overview.md) | 日本語

Agent Fleet は、Claude Code や Codex などのコーディングエージェントを、ブラウザの Console から動かすサービスです。
このページで、何ができて、どのページから読めばいいかがわかります。

## 全体像

| あなたがやること | エージェントがやること |
|---|---|
| Console にサインインし、自分のワークスペースを起動する | — |
| 使うエージェントを接続し、リポジトリを選んでセッションを起動する | あなた専用のワークスペースの中で、コードを読み、書き、コマンドを実行する |
| 質問・許可・プランのカードに答える | 判断が要るところで止まって、あなたを待つ |
| 結果を確かめて、コミットや push を指示する | 指示どおりにコミットし、プルリクエストを作る |

ワークスペースはメンバー 1 人ずつに分かれています。リポジトリ・作業中の変更・セッションはその中にあり、
ブラウザを閉じてもセッションは動き続けます。

## できること

| やりたいこと | 読むページ |
|---|---|
| エージェントに仕事を任せる、返事をする、止める | [セッション](../README.ja.md#セッション) |
| リポジトリをクローンし、変更を確かめてコミットする | [コード](../README.ja.md#コード) |
| 使うエージェントを選んで接続する | [エージェント](../README.ja.md#エージェント) |
| AWS・Google Cloud・Jira・MCP サーバーなどをエージェントに使わせる | [連携](../README.ja.md#連携) |
| 画像を作る・並べて見比べる | [画像](../README.ja.md#画像) |
| ワークスペースの環境を整える、作り直す | [ワークスペース](../README.ja.md#ワークスペース) |
| リポジトリを使わずに、質問・翻訳・要約を頼む | [チャットとメモ](../../member/10-chat-memo.ja.md) |
