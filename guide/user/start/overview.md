# What you can do with Agent Fleet

English | [日本語](overview.ja.md)

Agent Fleet runs coding agents such as Claude Code and Codex from the Console in your browser.
This page shows what you can do with it and which page to read first.

## How it works

| What you do | What the agent does |
|---|---|
| Sign in to the Console and start your workspace | — |
| Connect the agent you use, pick a repository and launch a session | Reads code, writes code and runs commands inside your own workspace |
| Answer question, permission and plan cards | Stops where a decision is needed and waits for you |
| Check the result and ask for a commit or a push | Commits and opens a pull request as asked |

Every member has a workspace of their own. Repositories, uncommitted work and sessions live in it, and
sessions keep running after you close the browser.
