# 用語と全体像

[English](concepts.md) | 日本語

ガイドと画面に出てくる言葉の関係をまとめます。読み終えると、テナント・ワークスペース・セッション・エージェントが
どう入れ子になっているかがわかります。

## 全体像

| あなたがやること | エージェントがやること |
|---|---|
| テナントにサインインし、自分のワークスペースを起動する | — |
| ワークスペースにリポジトリを置き、セッションを起動する | セッションの中で、そのリポジトリの作業コピーを読み書きする |
| 接続でエージェントや外部サービスにログインしておく | 接続されたアカウントで、モデルや外部サービスを使う |

入れ子にすると次のようになります。

```
配備（Agent Fleet の 1 つのインストール）
└─ テナント（チームや部署）
   └─ あなたのワークスペース（あなた専用の作業環境）
      ├─ リポジトリ（作業コピー、worktree）
      │  └─ セッション（エージェントに任せる仕事 1 つ分）
      ├─ その他のセッション（ホームや shell で動くもの）
      └─ アシスタントのチャット（リポジトリを使わない相談）
```

## 用語

| 画面の言葉 | 意味 |
|---|---|
| テナント | 1 つのチームや部署。テナントが違うメンバー同士は、互いに見えません |
| ワークスペース | あなた専用の作業環境。リポジトリ・作業中の変更・セッションが入ります。止めても中身は残ります |
| ワークスペース操作バー | ワークスペースの起動・停止、「はじめる」、ペインの分割などが並ぶ帯 |
| セッション | エージェントに任せる仕事 1 つ分の、会話・作業場所・実行状態のまとまり |
| エージェント | セッションで動くコーディング AI（Claude Code・Codex・OpenCode など） |
| 実行方式 | セッションの動かし方。チャットで操作する「マネージド」と、エージェントの画面を端末で操作する「ターミナル（CLI）」があります |
| 作業コピー | ワークスペースの中の、実際に編集するリポジトリのフォルダ |
| worktree | 同じリポジトリの別の作業コピー。セッションごとに分けると、並行した作業がぶつかりません |
| アシスタント | リポジトリを使わない、目的別のチャット。セッションではありません |
| メモキュー | 思いついた指示を書き溜めて、あとでまとめてセッションに送る場所 |
| 接続 | Console に登録した資格情報（エージェント・Git のサービス・課題管理など） |
| ペイン | メイン領域の 1 区画。いくつも並べられます |

## サインインとログイン

このガイドでは 2 つの言葉を使い分けます。

| 言葉 | 使う場面 |
|---|---|
| サインイン | Agent Fleet（Console）に入るとき |
| ログイン | エージェントや外部のサービス（claude、GitHub、AWS など）に入るとき |
