# よくある質問

[English](faq.md) | 日本語

困ったときに最初に試すことと、よく聞かれる質問への短い答えをまとめています。症状がはっきりしているときは、[関連](#関連) の各ページから探してください。

## まず試すこと

1. **左ペインから項目が消えた**ときは、左ペインのいちばん上のバーが「**すべて**」になっているか見ます。作業グループを選んでいると、そのグループの分だけが出ます
2. ブラウザでページを**再読み込み**します
3. **ワークスペースが起動しているか**確かめます。止まっていると、多くの機能が使えません
4. それでも直らないときは、無理をせず**管理者に相談**します。ログインや接続、権限のことは管理者の担当です

## 消したセッションは戻せる？

戻せます。どう消したかで戻し方が違います。

| したこと | 戻し方 |
|---|---|
| アーカイブした | アーカイブの一覧で「**復帰**」 |
| 停止した | 停止中のまま一覧に残っているので、開けば再開できる |
| 削除した（shell や SSM も） | ごみ箱に入っているので、掃除の画面から戻す |

何が残って何が消えるかは [終わったセッションを片付ける](../sessions/cleanup.ja.md#何が残り何が消えるか) にあります。

## 「停止」「削除」「アーカイブ」「作り直す」は何が違う？

| 操作 | すること |
|---|---|
| 停止 | 止めるだけ。あとで再開できる |
| 削除 | 一覧から消して、ごみ箱へ移す |
| アーカイブ | 一覧から隠す。あとで復帰できる |
| 作り直す | 同じ場所で新しい会話を始める。いまの会話はアーカイブへ移る |

詳しくは [セッションを止める・再開する](../sessions/stop-resume.ja.md#止め方を選ぶ) にあります。

## ワークスペースを止めたら、作業は消える？

消えません。クローン、コミットしていない変更、セッションの一覧、接続は、どれも残ります。
ただ、コミットしていない変更はワークスペースの中にしかありません。残したい作業は、コミットして push してください（[Git のサービスを接続する](../code/connect-git.ja.md#push-する)）。

## 会社と自宅のパソコン、両方から使える？

使えます。ログインや接続も、フォントや文字サイズなどの表示の設定もサーバーに保存されるので、別のパソコンやブラウザでも同じになります。

## スマートフォンでも使える？

進み具合を見たり、短く返事をしたりするなら使えます。左ペインは画面の左上の ≡ から開きます。
じっくり作業するときは、パソコンのほうが快適です（[ターミナルやスマートフォンで操作できない](terminal-phone.ja.md)）。

## ターミナル（黒い画面）を触らずに使える？

使えます。セッションへの指示、返事、ファイルを見ること、コミットは、ボタンと入力欄でできます。

## チャットとセッションは何が違う？

| | 向いていること |
|---|---|
| アシスタントのチャット | リポジトリを使わない質問、翻訳、文章の整理 |
| セッション | エージェントにファイルを書き換えさせるような、本格的な作業 |

チャットの使い方は [アシスタントに質問する](../chat/assistant.ja.md#チャットとセッションを使い分ける) にあります。

## メモは誰に届く？

自動では届きません。あなたが送ったときに、あなたが選んだ稼働中のセッションへ届きます（[メモをためて渡す](../chat/memos.ja.md)）。

## いくつもの作業を同時に進めていい？

進めてかまいません。セッションごとに別の作業コピー（worktree）で作業すれば、編集がぶつかりません。
既定で worktree が作られます（[ワークツリーで並行して作業する](../sessions/worktrees.ja.md)）。

## opencode が、新しいセッションの種類に出てこない

⚙設定 →「エージェント」の opencode のカードで、次の 2 つがそろっている必要があります。

- 「**opencode を使う**」がオン。オフのときは、キーを登録していても出てきません
- 「**opencode.ai への課金**」で選んだものに、要るものがそろっている

| 課金の選択 | 要るもの |
|---|---|
| 「**無料モデルのみ**」 | 何も要らない |
| 「**Go（定額）**」 | opencode.ai の API キー |
| 「**Zen（従量）**」 | opencode.ai のアカウントのログインか API キー |
| 「**使わない（自分の鍵だけ）**」 | 自分のプロバイダーの API キーか、配備の自前エンジン |

詳しくは [OpenCode を接続する](../agents/opencode.ja.md#課金のしかたを選ぶ) にあります。

## 「使わないモデル」に入れれば、課金を防げる？

防げません。選び間違いを防ぐ設定です。起動ダイアログ・設定・アシスタントの一覧から消え、名前を指定した起動も断りますが、
ターミナルの中で `/model` を打つような、CLI そのものの操作までは止められません（[エージェントを選ぶ](../agents/choose.ja.md#使わないモデルを外す)）。

## 共有をやめれば、相手の手元からも消える？

消えません。やめられるのは、これから先のアクセスだけです。相手は表示された内容を保存できるので、すでに保存されたものは取り戻せません。
共有する前に、会話にシークレットが写っていないか確かめてください。自動では見つけてくれません（[会話を共有する](../team/share.ja.md)）。

## ビルドがメモリ不足で落ちる・固まる

ホストはほかの人と共有で、メモリにも上限があります。

- Node のビルドは、必要なコマンドだけヒープを上げます（例: `NODE_OPTIONS=--max-old-space-size=2048`）
- テストランナーの並列数を抑えます
- watcher や開発サーバーを動かしたままにしません
- Gradle は、使い終わったら `./gradlew --stop` を実行します
- 重いビルドは 1 つずつ動かします

メモリの上限と使い方は [マシンと使用状況を見る](../workspace/machine.ja.md) で確かめられます。

## `sudo` や `git-delta` が見当たらない

ワークスペースのイメージには、わざと入れていません。必要なツールは、自分のホームディレクトリに入れられます。
`pip install --user` で入れたものは、ワークスペースを止めても残ります。
