# ターミナルやスマートフォンで操作できない

[English](terminal-phone.md) | 日本語

端末で Ctrl+C やコピー＆ペーストが思ったとおりに動かない、ショートカットが効かない、スマートフォンで操作しづらい、メニューが出ないときに、原因と直し方を探せます。

## 端末で Ctrl+C が効かない・コピー＆ペーストできない

端末では、何も選択していないときの Ctrl+C はプログラムへの割り込み（SIGINT）になり、選択しているときの Ctrl+C はコピーになります。

| やりたいこと | 操作 |
|---|---|
| コピー | 選択するだけでコピーされる。選択したまま Ctrl+C か Ctrl+Shift+C でもよい |
| 貼り付け | 右クリック、中クリック、Ctrl+V、Ctrl+Shift+V |

- マウスで選択してボタンを離した直後の Ctrl+C は、割り込みになります。離した時点で、すでにコピーされているからです
- Ctrl+C / Ctrl+V でコピー・貼り付けになるのは、⚙設定 →「表示」の「**Ctrl+C / Ctrl+V でコピー・貼り付け**」がオンのときだけです（既定ではオンです）。オフにすると、どちらのキーもプログラムに渡ります
- Ctrl+Shift+C と Ctrl+Shift+V は、いつでも使えます

詳しくは [ターミナルを使う](../files/terminal.ja.md#コピーと貼り付け) にあります。

## コマンドパレットなど、アプリのショートカットが効かない

端末にフォーカスがあるとき、⚙設定 →「キー操作」の設定で、キーが端末に渡っている可能性があります。

| オンになっている設定 | 起きること | アプリを操作するには |
|---|---|---|
| 「**端末フォーカス中はアプリより端末を優先**」 | Ctrl のキーがすべて端末に渡る | リーダーは使えるので、Ctrl+K → ;（macOS は ⌘K → ;）でコマンドパレットを開く |
| 「**shell / SSM 端末へキーをすべて渡す（Ctrl+K・Ctrl+P 含む）**」 | shell と SSM の端末では、リーダーとパレットのキーも端末に渡る | ほかのペインにフォーカスを移す |

どのキーが何に割り当たっているかは、**?** で一覧を開けます（[キーボードとコマンドパレットで操作する](../start/shortcuts.ja.md)）。

## スマートフォンでキーボードが勝手に出る・操作しづらい

- 端末の下の**コントロールキー列**（`Esc` `Tab` 矢印 `^C` `⏎`）は、ソフトキーボードを出さずにキーを送れます
- 過去の出力は、端末の上を **1 本指で縦にスワイプ**するとさかのぼれます
- 左ペインは、画面の左上の **≡（メニュー）** で出し入れします

ほかの操作は [スマートフォンで使う](../start/phone.ja.md) にあります。込み入った作業は、パソコンのほうが快適です。

## ライトテーマにしても端末だけ暗い

仕様です。テーマを切り替えても、端末の背景は暗いままです。ファイルビューアやほかの画面はテーマに合わせて変わります。

## メニューが出ない

| 状況 | 理由 |
|---|---|
| ワークスペースが止まっている | ワークスペースの中で処理するメニューは、無効になるか表示されない |
| 項目がメニューにない | その種類が対応していない操作や、いまの状態に合わない操作は表示されない |
| 右クリックのメニューがすぐ閉じる | 外側のクリック、Escape、ウィンドウからフォーカスが外れたときに閉じる。フォーカスは開いた元の項目に戻る |

右クリックのメニューは、項目にフォーカスがある状態で**メニューキー**か **Shift+F10** を押しても開けます。
メニューの中身は [アイコン・バッジ・メニュー](../../ref/console-ui.ja.md#右クリックメニュー) にあります。
