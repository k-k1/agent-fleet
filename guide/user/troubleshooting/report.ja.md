# 不具合を報告する・要望を出す

[English](report.md) | 日本語

Agent Fleet そのものの不具合や、ほしい機能を、GitHub の Issue で伝えられます。

## 全体像

| あなたがやること | エージェントがやること |
|---|---|
| 症状と、出たメッセージを書く | 頼めば、Issue の文面を作って登録する |
| 貼る前に、外に出せない情報を消す | 頼めば、ログやエラー文からシークレットを取り除く |

## まず、どこに相談するか決める

| 困っていること | 相談先 |
|---|---|
| ログイン、接続、権限、マシンのサイズ、テナントの設定 | チームの管理者や情報システムの担当者 |
| チームの設定ではなく、Agent Fleet そのものの動きがおかしい | GitHub の Issue |
| ほしい機能がある | GitHub の Issue |

症状のページ（[よくある質問](faq.ja.md) の関連にあります）で直らなかったら、症状と、表示されたメッセージを添えて相談してください。

## Issue を登録する

1. <https://github.com/k-k1/agent-fleet/issues> を開きます
2. 起きたこと、期待していたこと、出たメッセージを書きます
3. 登録します

セッションの中からなら、エージェントに「この不具合を Issue にして」と頼むこともできます。

## 貼る前に消すもの

**このリポジトリは公開されています。** ログやスクリーンショット、エラー文を貼る前に、組織の外に出したくない情報を必ず取り除いてください。

- シークレット（トークン、パスワード、キー）
- 社内のホスト名や URL
- テナント名や顧客名

環境は、具体的な名前ではなく一般的な言葉で説明してください（例:「AWS の ECS で動かしている配備」）。
