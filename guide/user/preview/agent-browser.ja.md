# エージェントが開いたブラウザを操作する

[English](agent-browser.md) | 日本語

エージェントがワークスペースの中で自分のブラウザ（Chromium）を動かしていて、ログイン、ワンタイムコードの入力、同意のチェックのような
人にしかできない操作に行き当たったとき、そのページをあなたが引き取って操作できます。

## 全体像

| あなたがやること | エージェントがやること |
|---|---|
| ― | ページをあなたに渡し、返信にリンクを出す |
| リンクを押してページを開く | 操作をあなたに引き渡す |
| 頼まれた操作をして「操作完了」を押す | あなたの報告を受けて、作業を続ける |

[起動した Web アプリを見る](browser-pane.ja.md) のブラウザペインとは別のものです。あちらは自分で起動した Web アプリを開き、
こちらはエージェントがすでに開いているページを引き取ります。

## ページを引き取る

1. エージェントの返信に出る「**ブラウザを開いて操作する（このタブのペインで開きます）**」を押します。押さない限り何も開きません
2. ページが、今見ているタブのペインに開きます。開いた直後は「**閲覧のみ**」で、画面は動いていますが、クリックもスクロールもキー入力も届きません
3. エージェントが操作を引き渡すと「**ユーザー操作**」に変わり、触れるようになります
4. 「**ブラウザ操作の依頼**」に出ている内容のとおりに操作します
5. 終わったら「**操作完了**」を、やめるときは「**中止**」を押します。エージェントに伝わります

- 押しても反応しないときは、まだ「閲覧のみ」です。ペインの上にもそう出ます
- エージェントに伝わるのは、あなたが何をしたかです。サイトの側で処理が成功したことの証明ではありません。最後の送信・購入・同意のクリックをエージェントに任せないのも同じ理由です
- ペインの数が上限に達しているときは、今のペインを置き換えてよいか確認が出ます

## 表示を閉じる・開き直す

- 「**表示を閉じる**」は表示をやめるだけです。エージェントのブラウザもページもそのまま残ります
- 開いているものは、ワークスペース操作バーの「**プレビュー**」の「**接続中のブラウザ（エージェントが接続した既存 Chromium）**」から開き直せます
- 同じ Chromium にほかのタブがあれば、「**別のタブに切り替える**」で移れます

## 使えない配備

ワークスペースを Kubernetes（プレビュー版）か ECS Fargate で動かす配備にはブラウザ機能がなく、エージェントからページを渡してもらうこともできません。
理由は [ブラウザペイン — 利用契約](../../ref/browser-pane.ja.md#ブラウザペインが無い配備) にあります。
