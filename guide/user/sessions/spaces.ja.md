# スペースで作業を始める

[English](spaces.md) | 日本語

**スペース**は、リポジトリのない作業のために `~/spaces` に作る専用のフォルダです。文書の下書き、表の要約、調べもの
などに使います。エージェントが書いたものはそこに残り、ホームフォルダの他のファイルとは混ざりません。

## 全体像

| あなたがやること | 起きること |
|---|---|
| 「**スペースで始める**」にやってほしいことを書き、「**新しいスペースで始める**」を押す | `~/spaces` に新しいフォルダができ、書いた文章を最初のプロンプトにしてエージェントがそこで起動する |
| セッションビューを見る | セッションは「**スペース**」の、スペースの名前の下に並ぶ |
| スペースを削除する | フォルダとセッションがごみ箱へ移り、「**掃除 → ごみ箱（復元）**」から戻せる（[スペースを削除する](#スペースを削除する)） |
| ワークスペースを作り直す | スペースは残る。作り直しで消えるのは `~/repos` だけ（[ワークスペースを作り直す](../workspace/recreate.ja.md#何が残り何が消えるか)） |

## 新しいスペースで始める

1. ワークスペース操作バーの「**＋ はじめる**」を押し、「**スペースで始める**」を開きます（いちばん最初は開いています）
2. 「**何をしてもらいますか？**」にやってほしいことを書きます。ファイルは貼り付けるか落とすか、「**＋**」で添付します
3. 「**場所**」は「**新しいスペース**」です。名前を付けてもかまいません。空のままならフォルダ名で表示されます
4. 「**詳細**」は畳まれていて、エージェント・モデルなど使うものの要約が出ています。エージェント・モデルの経路・モデル・
   実行方式・推論の強さ・開始モード・権限確認を変えるときだけ開きます。ブランチの欄はありません。スペースはリポジトリではないからです
5. 「**新しいスペースで始める**」を押します（欄の中で Ctrl+Enter、送信キーの設定によっては Enter でも同じです）。
   ファイルを添付したときは、添付を受け取れるエージェントを選ぶか、先にファイルを外します

セッションはチャットの表示で開きます。

| エージェント | スペースでの動き方 |
|---|---|
| マネージドのあるもの | ふだんの既定によらず、マネージドで動きます。「詳細」で切り替えられます |
| Claude | ターミナル（CLI）で動きます（Claude の動き方はこれだけです）。ペインはチャットの表示で開き、ターミナルへはワンクリックで切り替えられます |

## 前に使ったスペースで始める

数日にまたがる作業は、同じスペースに置けます。「**場所**」を開き、「**新しいスペース**」の代わりに使いたいスペースを
選びます。

- 「**最近使った**」には、最後にセッションを始めた順に 5 つのスペースが並びます。まだセッションのないスペースは、
  作った日時で並べます
- 「**すべてのスペース**」には、それ以前のスペースが並びます
- スペースを選ぶと名前の欄は消え（名前はスペースを作るときに付けます）、ボタンは「**このスペースで始める**」になります。
  エージェントはそのフォルダで起動し、これまでのセッションが残したものを見られます

選ばないときは、始めるたびに新しいスペースができます。

## スペースの名前を変える

セッションビューの「**スペース**」で、スペースの行にポインターを合わせて鉛筆のボタンを押します。新しい名前を入力して
「**保存**」します（タッチ画面では鉛筆は常に表示されます）。名前を空にすると、フォルダ名の表示に戻ります。変わるのは Console に表示する名前だけです。フォルダと
中のファイル、中のセッションはそのままです。スペースがこの欄に出るのは、セッションかシェルがあるあいだです。最後の
ひとつを削除すると、スペースとファイルは残りますが、名前を変えたり削除したりする行はなくなります。

## スペースを削除する

セッションビューの「**スペース**」で、スペースの行にポインターを合わせてごみ箱のボタンを押します（タッチ画面では常に表示されます）。
ダイアログに、何が移るかが出ます。スペースのフォルダと中のファイルがすべてごみ箱へ移り、中のセッションも
[作業コピーを削除したとき](cleanup.ja.md#1-つの仕事の作業コピーをまとめて削除する)と同じように一緒に移ります。停止中の AI セッションはアーカイブへ、
シェルと SSM セッションはごみ箱へ入ります。

- **実行中のセッションや、削除ロックがかかったセッションがあると削除できません。** ダイアログがそのセッションを挙げ、ボタンは押せません。
  停止するかロックを外してから、もう一度押してください
- **ファイルは完全には削除されません。** スペースはフォルダごとごみ箱へ移るだけなので、ファイルの中身も更新日時もそのままです。
  「**掃除 → ごみ箱（復元）→ 復元**」で、フォルダが同じ名前で `~/spaces` に戻り、アーカイブへ移ったセッションも戻って、続きから再開できます。
  シェルと SSM セッションは、ごみ箱に別の行として入るので、1 つずつ復元します。シェルの画面履歴（記録された端末の出力）は、シェルを削除したときと同じく残りません
- スペースのフォルダ名の場所に、すでに何かがあると復元できません。それを動かすか削除してから、もう一度復元してください
- ごみ箱の行の「**完全に削除**」で、フォルダとファイルが消えます。行のサイズはフォルダの大きさです。ごみ箱は自動では空にならないので、それまで容量を使います
- ごみ箱と `~/spaces` が同じファイルシステムにあることが前提です（ワークスペースでは同じです）。違うときは何も削除せず、ダイアログがそう伝えます

セッションを 1 つ削除しても、スペースは削除されません。

## 添付するファイル

スペースのセッションに添付したファイルは、スペースの `attachments` フォルダにも元の名前でコピーされます
（`report.pdf`。同じ名前がもう一つあれば `report-2.pdf`）。ファイルは作業のそばにあり、同じスペースの次のセッション
でも使えます。最初のプロンプトでエージェントに示すのは、アップロードされたファイルそのものの場所です。
スペースにコピーできなかったファイルは添付されず、起動時にどのファイルかが表示されます。

## スペースに残るもの

- **フォルダ名は変わりません**。セッションと会話の履歴はフォルダに結び付いているので、フォルダの名前を変えたり
  移したりはしません。付けた名前はセッションビューに表示され、フォルダとは別に保存されるので、セッション
  ビューに行があるあいだは [変えられます](#スペースの名前を変える)
- **セッションを削除しても、スペースと中のファイルは残ります**。逆にスペースを削除すると、中のセッションも一緒に
  アーカイブとごみ箱へ移り、スペースと一緒に戻ります
- **ファイルブラウザからは削除も名前の変更もできません**。`~/spaces`、スペースのフォルダ、フォルダをスペースにして
  いる `.af-space.json` は拒否され、[スペースを削除する](#スペースを削除する) へ案内されます。スペースの中のファイルは
  自由に変えられます。`.af-space.json` はファイルツリーに表示されません
- **消えた `.af-space.json` は戻ります**。エージェントやあなたが別の方法で削除しても、ワークスペースがスペースの名前で
  書き直し、スペースの行とセッションはそのまま残ります。対象はワークスペースが作った、または一覧に出したスペースです。
  一度も一覧に出ていないスペース（古い Agent が作り、まだ一覧に出ていないもの）はまだ対象外です。フォルダを別の場所へ
  動かして同じ名前の別のフォルダを置いた場合も対象外で、新しいフォルダはスペースになりません。また、フォルダの作成
  日時を記録するファイルシステムが必要です。記録しない場合（EFS 上のホームなど）は、消えた `.af-space.json` は書き
  直されません
- **「ホームを掃除する」では消えます**（ホームの他のものと同じです）

> [!NOTE]
> スペースのセッションには、エージェントの記憶とリポジトリのスキルがありません。「はじめる」の欄からは、プロンプトの
> テンプレートも選べません。

## うまくいかないとき

### 「このワークスペースの Agent は古く、スペースでは始められません」と出る

ワークスペースの Agent が古く、そのまま起動するとセッションがホームで始まってしまいます。ワークスペースを停止して
起動し直すと、最新のイメージで起動します（[新しいイメージを取り込む](../workspace/recreate.ja.md#新しいイメージを取り込む)）。それまでは、
リポジトリで始めるか、「**その他 → ホームでエージェントを起動**」を使ってください。

### 「このスペースはもうありません」と出る

選んだスペースが、一覧を読んだあとに削除されています。ほかの場所へ送らずに、起動を止めます。書いた文章とファイルは欄に
残るので、ほかの場所か「**新しいスペース**」を選んでください。

### 「このワークスペースがスペースで始められるか確かめられませんでした」と出る

ワークスペースが応答しませんでした。起動の途中であることが多いので、少し待ってから「**もう一度確かめる**」を押します。
