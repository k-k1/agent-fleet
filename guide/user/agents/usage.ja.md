# 料金と使用量を確かめる

[English](usage.md) | 日本語

モデルの定価、契約の利用枠の残り、今の会話の長さ、何にトークンを使ったかを、Console の中で確かめられます。
RTK をオンにすると、使うトークンを減らせます。

## 全体像

| 見たいもの | 見る場所 |
|---|---|
| モデルの定価 | 起動ダイアログや設定の、モデルの一覧 |
| 契約の利用枠がどれだけ残っているか | WS バーの使用量チップ |
| 今の会話がどれだけ文脈を使っているか | セッション画面の「コンテキスト」のゲージ |
| 何にどれだけトークンを使ったか | ⚙設定 →「エージェント使用量」 |
| RTK でどれだけ節約できたか | ⚙設定 →「エージェント使用量」の「rtk 効果」 |

## モデルの定価を見る

モデルの一覧には、モデルごとの **API の定価**（100 万トークンあたりの入力／出力）とコンテキストの長さが並びます。
選んだモデルの下には、キャッシュ読み取りの単価と公開日も出ます。

- 値は models.dev が公表しているもので、**API を従量課金で使ったときの定価**です
- claude・codex・agy をサブスクで使うときの請求額ではありません。opencode は、opencode の側で実際にかかる価格です
- codex が廃止を予告しているモデルと、models.dev で非推奨のモデルには「**廃止予定**」が付きます
- cursor・muse・lcpp のモデルと、claude のティア名（Opus など）には出ません。claude でも、登録した完全な ID には出ます

## 利用枠の残りを見る

アカウントの利用枠を読み取れるエージェントでは、WS バーに **使用量チップ** が出ます。どのエージェントに出るかは、
[エージェントのリファレンス](../../ref/agents.ja.md) の「使用量 / 残量チップ」の行にあります。

- バーに残るのは、直近に使った 2 つだけです。ほかは右の「**+N**」に畳まれ、押すと開きます
- 上限に近づいたチップ（95% 以上など）は、しばらく使っていなくても表に出ます
- スマホでは「⋯」の中に縦に並び、畳まれません

チップのドロップダウンの「**WS バーでの表示**」で、出し方を選べます。

| 選択 | 出し方 |
|---|---|
| 常に出す | 直近に使っていなくても、いつもバーに出します |
| 自動（既定） | 直近に使ったエージェントのときだけ出します |
| 常に畳む | いつも「+N」の中に畳みます。上限に近づいても表に出しません |

3 つ目のチップをいつも出したいときは、「**常に出す**」を選びます。

## 会話の長さを見る

コンテキストのゲージがあるエージェントでは、セッション画面の上部に「**コンテキスト**」（狭いときは `ctx`）のゲージが出ます。

- マウスを重ねると、使っているトークンと上限、そのうちのキャッシュ再利用・新規キャッシュ・未キャッシュの内訳が出ます
- 上限に近づくと「**まもなく自動圧縮される可能性があります**」と出ます
- チャットの表示では、ターンごとのトークン消費の推移も見られます

長い作業で、急に前の話を覚えていないように感じたら、ここを見てください。
ゲージのあるエージェントは、[エージェントのリファレンス](../../ref/agents.ja.md) の「コンテキスト使用量ゲージ」の行にあります。

## 何にトークンを使ったかを見る

**⚙設定 →「エージェント使用量」** は、トークンを何に使ったかの台帳です。セッションそのものだけでなく、
Agent Fleet が裏で呼ぶもの（タイトルの提案・要約引き継ぎ・返信候補など）も同じ物差しで並びます。

| 項目 | 選べるもの |
|---|---|
| 期間 | 24 時間・7 日・30 日 |
| 割り方 | 機能・エージェント・モデル・セッションの出自・注入元 |
| 指標 | 消費トークン・呼び出し回数・キャッシュ読取・API 換算相当額（推定） |

- グラフの系列を押すと、その系列だけに絞り込めます。「**機能 × モデル**」の表もあります
- 「**計測できている範囲**」に、トークンを報告しない呼び出しが「回数だけ数えている」と出ます。消費が 0 という意味ではありません

### API 換算相当額を読む

**API 換算相当額（推定）** は、トークン数に各モデルの公表された API 単価をかけた目安で、`≈` を付けて出ます。
**サブスクの請求額ではありません。** この消費を API で払っていたらいくらになるか、を示す額です。

- キャッシュの書き込みは単価の 1.25 倍、読み取りは 0.1 倍で計算します
- 単価は、Anthropic のモデルは内蔵の表から、ほかは models.dev のカタログから取ります。opencode 経由の消費は、opencode の価格で計算します
- どの単価をどこから取ったかは、金額にマウスを重ねると出ます。claude の補助の呼び出しと opencode のセッションでは、エージェントが報告した金額も並びます（推定には足しません）
- カタログにないモデルは推定しません。「消費の N%（… トークン）は単価を持っていないモデルで実行されており」と出て、推定額には入りません
- カタログの取得日も出ます。カタログが新しくなると、過去の推定額も変わります

### Cursor のトークン

ターミナル（CLI）の cursor のセッションは、ターンごとのトークンを記録し、「**トークン: 一部のみ**」と出ます。

- 数字は cursor 自身の報告です
- Auto で動いたターンは、モデル名 `default` として記録されます
- マネージドの cursor のセッションは数えません

## RTK でトークンを節約する

多くのエージェントのカードに「**RTK（トークン節約）**」のオン／オフがあります。エージェントが実行するコマンドを書き換えて、
出力で使うトークンを減らす仕組みです。

効き方はエージェントによって違います。

- コマンドを毎回書き換えるもの：確実に効きます
- `AGENTS.md` で rtk を使うよう促すだけのもの：使うかどうかはエージェント次第です（ベストエフォート）

どのエージェントがどちらかは、[エージェントのリファレンス](../../ref/agents.ja.md) の「RTK（トークン節約）」の行と脚注にあります。

- ワークスペースのイメージに RTK がないときは、「**このワークスペースに rtk がありません**」と出ます
- 節約の効果は、⚙設定 →「エージェント使用量」の「**rtk 効果**」で、累計・平均の節約率・実行したコマンドの数を、日・週・月ごとに見られます
