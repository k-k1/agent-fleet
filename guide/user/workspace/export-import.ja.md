# 設定を書き出す・取り込む

[English](export-import.md) | 日本語

自分の設定をファイル 1 つにまとめて書き出し、別の Agent Fleet や別のアカウントで取り込めます。

## 全体像

| あなたがやること | 起きること |
|---|---|
| 「書き出す」を押す | 選んだ設定が `af-settings-<日付>-<時刻>.json` としてダウンロードされる |
| 移った先で「取り込む」を押してファイルを選ぶ | 中身を確かめたあと、今の設定に足される |
| 移った先でログインし直す | ファイルに入らない接続を、もう一度つなぐ |

## 入るもの、入らないもの

| 入るもの | 中身 |
|---|---|
| 個人設定 | 表示・キー操作・通知・エージェントの既定など |
| AWS プロファイル/SSM | プロファイルと SSM のホスト |
| Google Cloud プロファイル | プロファイル |
| エージェントへの指示 | 指示の文章。ワークスペースが起動しているときだけ書き出せます |

**接続は入りません。** Git・エージェント・AWS のトークンや API キー、Google へのログインは、移った先でつなぎ直してください。
シークレットが入らないので、このファイルは人に渡せます。チームで使う SSM のホストをまとめて配る、といった使い方ができます。

## 書き出す

1. **⚙設定 →「書き出し / 取り込み」** を開きます
2. 「**書き出す**」で、入れるものにチェックを付けます。それぞれに件数が出ます
3. 「**書き出す**」を押すと、ファイルがダウンロードされます

## 取り込む

1. 移った先で、同じタブの「**取り込む**」を開きます
2. 書き出したファイルを選びます。書き出した日時と中身が出ます
3. 取り込むものにチェックを付けて「**取り込む**」を押し、確認の画面で取り込みます

取り込みは**足すだけ**で、今の設定を消すことはありません。

| 種類 | 取り込み方 |
|---|---|
| 個人設定 | 今の設定に重ねます。学習済みの返信候補やキー割当のようにたまっていくものは、ファイルの側が空でも消えません |
| AWS プロファイル | 同じ名前のプロファイルがあれば、そのまま残します |
| SSM のホスト | 同じホスト（別名とインスタンス）があれば、そのまま残します |
| ロールを引き受ける AWS プロファイル | 元のプロファイルが同じラベル・同じサインインで、すでにあるか同じファイルに入っているときだけ取り込みます |
| Google Cloud プロファイル | 同じラベル（大文字と小文字は区別しません）があれば、そのまま残します。ラベルかプロジェクトのないものは飛ばします |
| エージェントへの指示 | **今の文章を置き換えます**。取り込む前に確認が出ます |

取り込んだ結果は、種類ごとに件数で出ます。すでにあった件数や、登録できなかった件数も同じ行に出ます。

## 手元の PC の設定から移る

別の Agent Fleet ではなく手元の PC から移るときは、それぞれのタブで設定ファイルを直接読めます。

| 手元のファイル | 読むところ |
|---|---|
| `~/.aws/config` | 「AWS プロファイル/SSM」のタブ（このタブの「**~/.aws/config から取り込む**」からも開けます）。[AWS SSO を使う](../integrations/aws-sso.ja.md#手元の-awsconfig-から取り込む) |
| `~/.config/gcloud/configurations/config_<名前>` | 「Google Cloud」のタブ。[Google Cloud を使う](../integrations/gcloud.ja.md#手元の-gcloud-の構成から取り込む) |

## 困ったとき

### 「AWS プロファイル/SSM: 今の登録を読み込めなかったため、何も追加していません」と出る

今の AWS プロファイルを読めなかったので、AWS の分は何も足していません。読めないまま進むと、すべてが二重にできるためです。
もう一度試してください。

### 「設定の書き出しファイルではありません」「この Console が知らないバージョンのファイルです」と出る

書き出しで作ったファイルではないか、より新しい Agent Fleet で書き出したファイルです。書き出した側と同じか、新しいバージョンの Agent Fleet で取り込んでください。

### エージェントへの指示が書き出せない

「**ワークスペース起動中のみ**」と出ているときは、ワークスペースを起動してから書き出してください。
