# Agent Fleet 利用ガイド

[English](README.md) | 日本語

はじめて使うなら [Agent Fleet でできること](user/start/overview.ja.md) から読み始めてください。
それ以外は、自分に当てはまるところから読み始めてください。

| あなたは | 読むもの | 答えるのは |
|---|---|---|
| Console でエージェントを動かす人 | [やりたいことから探す](user/README.ja.md) | どうやるの？ |
| チームのメンバーと上限を管理する人 | [テナントの管理](admin/README.ja.md) | チームのためにどう運用するの？ |
| 配備を構築して維持する人 | [配備の運用](operate/README.ja.md) | どう構築して、どう動かし続けるの？ |

**[リファレンス](ref/README.ja.md)** は全員が引くセクションです。何ができて誰ができるかを、
エージェントごと・リポジトリ種別ごと・配備形態ごと・ロールごとの表にしています。
言葉の意味は [用語集](ref/glossary.ja.md)。

**[更新履歴](../deploy/release/notes/SUMMARY.ja.md)** はリリースごとに何が変わったかの一覧です。
ある機能がどのバージョンで入り、ある不具合がどのバージョンで直ったかを、新しいバージョンから順に 1 項目 1 行で載せています。
バージョンごとの詳しいノートへもそこから辿れます。

ターミナルを一度も開かずに使いたい方は、[ターミナルを使わない人のための入口](user/start/without-terminal.ja.md) が近道です。

Console のアカウントメニューの「**利用ガイド**」を選ぶと、このガイドがドキュメントサイトとして
ブラウザの新しいタブで開きます。
