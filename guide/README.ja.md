# Agent Fleet 利用ガイド

[English](README.md) | 日本語

自分に当てはまるところから読み始めてください。

| あなたは | 読むもの | 答えるのは |
|---|---|---|
| Console でエージェントを動かす人 | [使いかた](member/README.ja.md) | どうやるの？ |
| チームのメンバーと上限を管理する人 | [テナントの管理](admin/README.ja.md) | チームのためにどう運用するの？ |
| 配備を建てて維持する人 | [配備の運用](operate/README.ja.md) | どう建てて、どう生かし続けるの？ |

**[リファレンス](ref/README.ja.md)** は全員が引く棚です——何ができて誰ができるか、
エージェントごと・リポジトリ種別ごと・デプロイ形態ごと・ロールごとの表。
言葉の意味は [用語集](ref/glossary.ja.md)。

端末を一度も開かずに使いたい方は、[かんたんガイド](member/lite.ja.md) が近道です。

ワークスペースが動いていれば、このガイドはアカウントメニューの**「利用ガイド」**から
いつでも Console で開けます。
