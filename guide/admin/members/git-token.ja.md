# メンバーの Git トークンを入れ替える

[English](git-token.md) | 日本語

メンバーがテナントの内部 Git にアクセスするトークンが漏れたかもしれないとき、新しいトークンに入れ替えられます。
古いトークンは、誰が持っていてもすぐに使えなくなります。

## 全体像

| あなたがやること | Agent Fleet がやること |
|---|---|
| メンバー詳細で **git トークンを再発行** を押す | 新しいトークンを発行し、古いトークンをすぐに無効にする |
| 受け取れなかったと出たら、ワークスペースを再起動してもらう | 起動中のワークスペースには、その場で新しいトークンを渡す |

メンバーは、ワークスペースが持っているトークンで内部 Git（「内部リポジトリ」タブ）に fetch・push します。
ログに貼ってしまった、別のマシンにコピーしたなど、トークンがワークスペースの外に出たおそれがあるときに使います。

## 入れ替える

1. **テナント設定 → 運用 → メンバー** で、そのメンバーのカードを開きます
2. **操作** の **git トークンを再発行** を押します（画面は [メンバーを外す](remove.ja.md#外す手順) にあります）
3. 確認のダイアログで **再発行する** を押します

トークン以外は何も変わりません。再発行は監査ログに残ります。

## 結果を読む

| 出たメッセージ | 次にやること |
|---|---|
| 新しい git トークンを発行し、起動中のワークスペースに渡しました。 | なし。メンバーはそのまま作業を続けられます |
| 新しい git トークンを発行しました。ワークスペースは次の起動で受け取ります。 | なし。停止中のワークスペースは次の起動で受け取ります |
| 新しい git トークンを発行しました。ワークスペースは起動中で、起動が終わると受け取ります。 | なし |
| 新しい git トークンを発行しましたが、起動中のワークスペースが受け取れませんでした。… | ワークスペースを再起動します。それまで、中のクローンは fetch も push もできません |
| 新しい git トークンを発行しました。この配備では内部 git が有効になっていません。 | なし |

## 外したメンバーのトークン

外したメンバーのトークンも入れ替えられます。古いトークンが出回っているおそれがあるなら、もう一度招待する前に入れ替えます。
招待し直すと同じメンバーシップが戻り、同じトークンも戻るからです。

## 全員のトークンを入れ替えたいとき

テナント管理者の画面からは 1 人ずつです。全員のトークンを一度に変えるには、配備管理者が配備のマスターキーを変えます。
