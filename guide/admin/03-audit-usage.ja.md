## まだ移していない質問

**Q. メンバーから「エージェント CLI のバージョンが何週間も同じ」と言われました。正常ですか？**
**設定 → ツールチェーン** を開き、ツールのバージョン表の下の行「上流のリリース監視: 最終成功 …」を見てください。
CLI のリリースは 2 時間ごとに監視していて、この配備が焼き込むバージョンはその監視が新版を報告したときにだけ
動きます。この行が新しく、警告が付いていなければ、本当にバージョンが動いていないだけで、することは
ありません。警告が付いているとき（特定の取得元を読めていない／48 時間以上成功していない）は、
バージョンが止まっていても、CLI の更新の有無については何も言えません。見直すべきは配備管理者側の監視です
（[operate/](../operate/README.ja.md)）。行そのものが **出ていない** ときは、この配備から GitHub に
届かないので何も分からない、という意味で、それ自体は異常ではありません。
