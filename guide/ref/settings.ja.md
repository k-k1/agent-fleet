# 設定 — どこで何を決めるか

[English](settings.md) | 日本語

挙動を決める層は 3 つあり、**この 3 つの取り違えが「変えたのに効かない」の定番の原因**です。
狭い順に:

| 層 | 決める人 | どこ | 効くタイミング |
|---|---|---|---|
| 個人 | 自分 | アカウントメニュー →**設定** | 即座、または次のセッションから |
| テナント | テナント管理者 | アカウントメニュー →**テナント設定** | そのテナントのメンバーに |
| 配備 | 配備を運用する人 | 環境変数（起動前）| 再起動時 |

**狭い層は広い層を広げられません。**個人設定はテナントの上限を超えられず、テナント設定は
配備が許す範囲を超えられません。**設定した値が効いている値と違うときは、1 つ外の層を見る。**

## 個人設定

| タブ | 決めるもの |
|---|---|
| 表示 | 言語・テーマ・情報密度 |
| キー操作 | ショートカットと再割り当て |
| エージェント | 各エージェントの接続・既定モデル・除外するモデル・挙動 |
| エージェントへの指示 | このワークスペースで起こす全エージェントに足される文 |
| エージェントメモリ | 版管理・ロールバック・書き出し / 取り込み |
| アシスタント | アシスタントチャットのエージェントとモデル |
| エージェント使用量 | 自分のトークン消費（機能別・エージェント別・モデル別）|
| クラウド費用 | 配備のクラウド費用のうち自分の分 |
| Gitホスティング | GitHub / Bitbucket の接続 |
| 内部リポジトリ | 配備自身がホストするリポジトリ |
| AWS SSM | リモートログイン先 |
| 課題管理 | Jira ほか作業項目の取得元 |
| チャット連携 | Discord / Slack のブリッジ |
| MCP サーバー | エージェントが使える連携サーバー |
| MCPトークン | 外部から自分のセッションを動かすためのトークン |
| 通知 | 何を、どう知らせるか |
| 読み上げ | 読み上げエンジンと声 |
| ツールチェーン | JDK ほかワークスペース毎のツールチェーン |
| 運用・監視 | 監視連携 |
| 書き出し / 取り込み | 設定を別の配備へ持って行く |
| アカウント | 自分のアカウントに紐づくサインイン方式 |
| 危険な操作 | 自分のワークスペースへの破壊的操作 |

## テナント設定

| タブ | 決めるもの |
|---|---|
| メンバー | 名簿。メンバー毎の資源・セッション・操作 |
| セッション | いまテナント内で動いている全部 |
| 上限・自動停止 | 効いている上限（**読み取り専用**——決めるのは配備管理者）|
| サインイン方式 | 自社の IdP や GitHub 組織を入口にする（承認が要る）|
| ログイン規則 | 効いている参加方式とドメイン（読み取り専用）|
| 接続元の制限 | メンバーがどこから接続してよいか |
| 連携アプリの OAuth | テナント自身の GitHub / Bitbucket OAuth アプリ |
| MCP 配布 | 全メンバーへ渡す連携サーバー |
| 監査 | 誰が・いつ・何を変えたか |
| 稼働時間 | メンバー毎のワークスペース稼働時間（書き出し可）|
| クラウド費用 | テナントのクラウド費用 |

## 配備の変数

Control Plane の起動前に設定します。注釈つきの一覧は
[deploy/compose/.env.example](../../deploy/compose/.env.example) で、**既定値の正は
そちら**です。ここに挙げるのは「他の全部の形を決めてしまう」ものだけ:

| 変数 | 決めるもの |
|---|---|
| `AF_RUNTIME` | デプロイ形態（[deploy-targets.md](deploy-targets.ja.md)）。不明な値は**起動時に拒否**される |
| `AUTH` | サインインの方式。`dev`（単独）/ `oauth`（CP 内蔵）/ `proxy`（上流のゲートウェイ）|
| `DATA_DIR` | 永続する状態が全部ここに在る＝**バックアップすべき対象** |
| `AF_MASTER_KEY` | at-rest 暗号の根。**失うと保存済みの資格情報は復元できない** |
| `SUPER_ADMIN_EMAILS` | 誰が配備管理者か |
| `PUBLIC_BASE_URL` | 利用者が到達する住所。OAuth のコールバックもここから組み立てる |
| `WS_MEMORY` | ワークスペースの既定メモリ上限 |

## 状態

タブの行は Console のラベルから起こしているので、**画面を黙って取りこぼしません**。
各タブが実際に何を意味するかは読者の棚（[use/](../member/README.ja.md) と
[admin/](../admin/README.ja.md)）、変数の手順は [operate/](../operate/README.ja.md) です。
