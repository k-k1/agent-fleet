# 用語

[English](glossary.md) | 日本語

列を 2 つにしているのは意図的です。読者向けのセクションは**画面**の語だけを使い、
`docs/build/` は**実装**の語を使います。対応表を 1 箇所に置いておくことが、
**問い合わせの会話とスタックトレースを同じものについての話にする**唯一の方法です。

| 画面 | 実装 | 意味 |
|---|---|---|
| ワークスペース | container / task | 1 人の私的な環境。リポジトリ・作業中のもの・セッションが入る。専用コンテナ（Docker 無しの形態ではサンドボックスされたホストプロセス）として動く |
| ワークスペース操作バー | — | ワークスペースの起動 / 停止、Start、プレビュー、ペイン分割が並ぶ帯 |
| セッション | session | 1 つの仕事の会話・作業場所・実行状態。**端末があることを意味しない** |
| 実行方式 | driver | Agent Fleet がエージェントを動かし、指示を届ける経路 |
| マネージド | paneless / managed driver | 共有ランタイムで動き、チャット画面から操作する。端末は無い |
| ターミナル（CLI）| tmux pane / PTY | エージェント自身の対話画面を端末で直接操作する |
| エージェント | kind | CLI のコーディング AI（claude / codex / opencode ほか）。[agents.md](agents.ja.md) |
| アシスタント | assistant chat | リポジトリを使わない目的別のチャット。セッションではない |
| ミラー | transcript / mirror | 実行中・停止中の会話を描画した画面 |
| 作業コピー | working copy / dir | ワークスペースの中の、実際に編集するリポジトリのフォルダ |
| worktree | git worktree | 同じリポジトリの独立した作業コピー。並行作業がぶつからない |
| 親 | parent clone | worktree の作成元。状態表示の比較対象になる |
| ペイン | pane | メイン領域の 1 区画 |
| 作業グループ | working set | リポジトリ・会話・セッション・スケジュールに名前を付けて束ね、左ペインを絞る。**何も移動も複製もしない** |
| 共有セッション | session share | 同じテナントの別メンバーへ会話を読み取り専用で見せること |
| 引き継ぎ | handoff | 会話を新しいセッションへ、または別のメンバーへ渡すこと |
| 分岐 | fork at message | 既存の会話の過去の一点から新しいセッションを起こすこと |
| 子セッション | spawn / origin `session` | 別のセッションが起こして仕事を渡したセッション。親は自分が起こした子の一覧・監視・停止・再開・改名だけができ、削除はあなたが行う。[02 セッション](../member/02-sessions.ja.md#セッションから別のセッションを起こす子セッション) |
| 作業項目 | work item | プロバイダから取り込んだ Issue / チケット / プルリクエスト。[repos.md](repos.ja.md) |
| メモキュー | memo | いま書き留めて、後でまとめてセッションへ送る指示 |
| 掃除 / ごみ箱 | cleanup / shelf | 停止したセッション・古い worktree・マージ済みブランチの一掃。消したものは退避され、復元できる |
| ブラウザペイン | browser pane | ワークスペース内の Chromium が `127.0.0.1:{port}` を描画してペインへ中継する。[browser-pane.md](browser-pane.ja.md) |
| 軽量プレビュー | preview proxy | 同じものを `/preview/{port}/` というサブパスで別タブに開く経路。WebSocket / SSE は通るが、絶対パスの asset を吐くアプリは崩れる |
| プレビュー用サブドメイン | preview subdomain | 起動のたびに発行される `https://＜ランダム＞-＜ポート＞.＜ドメイン＞/`。アプリがルート直下に配られ、複数ポートを同時に開ける。発行されない配備もある |
| 共有されているプレビュー | shared preview | 同じテナントのメンバーが「同じテナントのメンバーに見せる」をオンにしたプレビュー。ログインしたうえで開ける。相手が停止中は開けない |
| 接続 | connection / secrets | Console から結びつけた資格情報（エージェント・git プロバイダ・トラッカー）|
| テナント | tenant | 1 つのチーム / 部署。テナントが違うメンバー同士は互いに見えない |
| スロット | slot | EC2 形態で、ワークスペースを載せられるプール中の 1 インスタンス |
| 配備 | deployment | Agent Fleet の 1 つのインストール。1 社 1 配備 |
| 推論エンジン | engine / role (`llm`, `image`) | 配備が動かす・指す・借りるモデルサーバー。チャット用と画像用が 1 つずつ。画面最上部のピルが報告する対象 |
| エンジンの行 | engine row / `lifecycle` | 宣言されたエンジン 1 つ。配備自身の GPU、LAN の ComfyUI（外部管理）、別の配備から借りたもの（借用）、任意の OpenAI 互換の画像サーバー。どの行が絵を描くかはサーバーの種類でなく行で決まる |
| 借用エンジン | remote engine | 別の配備が動かし、ゲートウェイ越しに貸しているエンジン。こちらにあるカタログは読み取り専用の複製で、起動・停止・編集は向こうで行う |
| モデルカタログ | catalog | エンジンが読み込めるチェックポイント・LoRA・VAE の一覧。1 モデル 1 行、配備に 1 つ |
| ファミリー（画像生成ペインでは「系統」）| family / `base_model` | チェックポイントの系統——SD 1.5・SDXL・SD 3.5・FLUX.1・FLUX.2 klein・Z-Image・Anima・Krea 2。ワークフロー・既定の大きさ・どの設定を読むかを決める |
| 計画カード | ingest plan / `plan_token` | モデルを取り込む前に出る見積もり。要るファイル全部と、それぞれの費用（ダウンロードなら MiB、既に持っていれば取得なし）、ライセンス、警告。セッションが承認を求めるチャットのプランカードとは別物 |
| S3 Bucket | ledger / object store | 配備のストレージが実際に持っているものを並べるタブ（タブ名は「バケット」）。どのカタログ行も宣言していないオブジェクトも含み、登録・移動・削除ができる |
| 画像生成（ペイン）| imagegen pane | エージェントを介さずに配備の ComfyUI で絵を作るペイン。試走・一括投入・seed・LoRA |
| スタジオ | image studio / `ImageStudio` / `studios/<id>.json` | 画像生成の下書き 1 つと、それに結ばれた 0〜1 本のセッション。セッションと別の id を持つので、エージェントを替えても下書き・編集履歴・版は残る。生成は人が押し、エージェントは下書きを直して試走 1 枚まで |
| 下書き | draft | スタジオのフォームの中身（プロンプト・ネガティブ・つまみ・大きさ・LoRA・操作・参照画像・モデル）。エージェントと人の両方が書き、欄ごとの錠でエージェントの書き込みを止められる |
| 編集履歴 | draft log / `studios/<id>.log.jsonl` | 下書きが変わるたびに 1 件（時刻・書き手・変わった欄の前後）。「この時点に戻す」で戻しても消えず、戻したこと自体が 1 件になる |
| 版 | version / `press` 行 | 試走・投入・エージェントの試走を押した瞬間の下書きの写し。絵はどの版から作られたかを覚えていて、「この設定に戻す」はその版の下書きに戻す |
| 入力セット（画面には出ない）| input set / `~/.cache/agent-fleet/generated/console/inputs/<set>/` | 投入のときに参照画像とマスク画像を写す固定コピー。描く側は原本でなくこのコピーを読むので、投入後に原本を差し替えても結果は変わらない。そのグループが終われば消える |
| 画像ギャラリー | gallery pane | フォルダの画像をカードで並べるペイン。フォルダ・表紙・枚数・拡大表示つき |
| フリート俯瞰図 | fleetgraph pane | 1 セッション 1 レーン、横軸が時間の図。どのセッションがどれを起こし、何が行き来し、いつ動き・待ち・止まっていたか。セッション一覧の「経過」版 |
| LoRA | LoRA adapter | 1 つのファミリーに対して学習された小さな追加物で、チェックポイントの画風や題材を寄せる。合うファミリーの分だけが並ぶ |
| トリガー語 | trigger words | LoRA が効くためにプロンプトに要る語。選ぶ前に行に出て、選ぶとチップとして足される |
