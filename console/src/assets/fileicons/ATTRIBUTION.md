# File icon attribution

The file-type icons in this folder are the **VS Code Icons** set, used under the
MIT License. The extension → type-key mapping (`src/lib/fileicons.js`) is ported
from CodeLeaf's `ui/FileIcons.kt`.

| Set | Source | License |
|---|---|---|
| VS Code Icons | https://github.com/vscode-icons/vscode-icons | MIT |

Only the subset of icons actually mapped by `fileicons.js` is bundled (kept small).
Files with no brand icon fall back to a monochrome codicon; folders use codicons.
