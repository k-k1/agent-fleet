**だからこそ正確に書く価値があります**——ここで「うちの配備では動く」は最も高くつく
ドキュメントの誤りです。

それ以外は**起動時に失敗**します（黙って docker に落ちたりしません）。

## 状態

軸は確定、中身は P1 で記入。`ecs` と `ecs-ec2` をフラグでなく**別プロファイル**に
してあるのは意図的で、理由は決定記録に、EC2 プールの実測は凍結アーカイブに在ります。
