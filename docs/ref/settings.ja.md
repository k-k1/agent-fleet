# 設定 — どこで何を決めるか

[English](settings.md) | 日本語

Audience: 全員（ただし「つまみが見つからない人」に向けて書く）
Source of truth: 利用者/テナント設定は Console、配備の変数は `deploy/compose/.env.example`
Updated: 2026-08

挙動を決める層は 3 つあり、**この 3 つの取り違えが「変えたのに効かない」の定番の原因**です。
狭い順に:

| 層 | 決める人 | 効くタイミング |
|---|---|---|
| 個人設定 | メンバー自身（自分の設定）| |
| テナント設定 | テナント管理者 | |
| 配備の変数 | 配備を運用する人（起動前）| |

**個人設定はテナントの上限を広げられず、テナント設定は配備が許す範囲を広げられません。**

## 状態

軸は確定、中身は P1 で記入。タブの行は Console のタブ名から起こすので**画面を黙って
取りこぼせません**。変数の行は注釈つきの env の例示ファイルから起こし、既定値の正は
そちらに置いたままにします。
