## 読者向けの棚で避ける語

`driver` / `runtime` / TUI / PTY / tmux / 実装語としての pane / `kind` ——
これらは**どう作られているか**であって、読者が見るものではありません。
[build/](../build/README.ja.md) では使い、利用者向けの文書では
**読者が仕組みを訊いたときにだけ**補足します。
