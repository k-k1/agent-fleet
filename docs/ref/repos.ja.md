## 課題管理は別の軸

課題管理はコードのホストと同じ製品とは限りません（Jira は Bitbucket や GitHub の隣に
座ります）。トラッカー側は [features.md](features.ja.md#仕事を並べる) に並べ、詳細は
読者の棚に書きます。この表はリポジトリの話に留めます。

## 状態

軸は確定、中身は P1 で記入。記入時に**大きな声で書くべき**、既に分かっている直観に
反する事実が 2 つあります——**Bitbucket にはリポジトリ横断の項目検索が無い**こと、
そして**プロバイダからの 404 は「無い」の根拠には決してならない**こと。
