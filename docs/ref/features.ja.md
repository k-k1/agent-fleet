製品ができることを 1 行 1 つ、読者が出会う場所で束ねています。**誰が**はそれを使える
最小のロール（[roles.md](roles.ja.md)）、**どこ**は Console がその画面を呼ぶ名前です。

**機能を出したのにここに行が無ければ、その機能は完了していません**
（[CONVENTIONS §8](../CONVENTIONS.ja.md)）。
