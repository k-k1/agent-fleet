# アイコン・バッジ・メニュー — Console 共通リファレンス

[English](badges-and-menus.md) | 日本語

Audience: 画面の印が何を意味するのか知りたい人
Source of truth: Console そのもの（画面と食い違ったら画面が正）
Updated: 2026-08

> 対象: 左ペインの印の意味や、右クリックで何ができるかを確認したい人。
> メニュー項目は対象の種類、状態、権限、ワークスペースの状態によって変わります。

## セッションの表示

行の先頭にある色付きアイコンは、`claude`、`codex`、`cursor`、`copilot`、`kiro`、`agy`、`opencode`、`shell`、`ssm` の種類を
表します。行末の状態アイコンにマウスを重ねると状態名を確認できます。利用者の操作が必要な
状態は、アイコンだけでなく文字も表示されます。

| 状態 | 意味 |
|---|---|
| 進行中… | エージェントが処理中 |
| 質問あり | 質問への回答待ち |
| プランあり | プランの承認または却下待ち |
| 許可待ち | コマンド実行や編集などの許可待ち |
| 制限解除待ち · 19:50 | 利用上限に達してターンが止まった。時刻は自動再開の予定（無いときは時刻なし） |
| 残高上限 — 増枠が必要 | 残高・支出の上限に達した。待っても解けないので、増枠かクレジットの追加が要る |
| 入力待ち | 次の指示を受けられる状態 |
| 入力待ち · BG実行中 | 入力は受けられるがバックグラウンド処理が継続中 |
| 起動中 | 詳細な進行状態を持たないshell／ssmが稼働中 |
| 停止中 | プロセスが停止している |
| フォルダ無し — 再開不可 | 作業フォルダがなく、同じ会話を再開できない |
| メモリ不足で終了 | メモリ上限などにより強制終了した可能性がある |
| 強制終了／異常終了 | SIGKILL、シグナル、非ゼロ終了などを検出した |

スピーカーアイコンは回答の読み上げ中、警告とブランチ名は起動時とは別のブランチへ
作業コピーが切り替わったことを示します。

行にはこのほか、**「共有中」**（他のメンバーへ公開している。[02](02-sessions.ja.md#会話を共有する共有セッション)）と
**「削除ロック中」**（削除・自動整理の対象外。[02](02-sessions.ja.md#まとめて片付ける掃除)）が付くことがあります。

## リポジトリの状態表示

| 表示 | 意味 |
|---|---|
| 未コミット | コミットしていない変更がある |
| 親= | 親の作業コピーと同じコミット |
| 未取込 N | 親に含まれないworktree固有のコミットがN件ある |
| 親+N・FF可 | worktreeのHEADは親に含まれており、親が N コミット先行している。メニューの **「親を Fast-Forward で取り込む」** で取り込めます（[04](03-code.ja.md)） |
| 分岐 N↕M・FF不可 | worktreeと親の双方に固有コミットがあり、マージかリベースが必要 |
| 比較不可 | detached HEADなどで親との関係を判定できない |
| ↑N | originよりNコミット先行している |
| ↓N FF可 | originがNコミット先行し、fast-forwardできる |
| ↑N ↓M 要マージ | originと分岐し、マージかリベースが必要 |

`●N` はその作業コピーで稼働中のセッション数、数字だけの場合は停止中のセッション数です。
折りたたんだ親リポジトリでは、配下のworktreeのセッションも集計します。

## その他のバッジ

- 色付きの `1`、`2`… — 表示中のペイン番号。押すとそのペインへ移動します。
- 「未追跡」「追加」「変更」「改名」「削除」 — ファイルのGit変更種別です。
- アシスタント行の数字 — 会話のメッセージ数です。
- アシスタント行の回転アイコン／チェック — 回答を生成中／待機中です。
- プランカードの「承認待ち」「承認済み」「却下」 — プランに対する判断です。
- 「LFS ポインタ」 — Git LFSの実体ではなくポインタだけがあるファイルです。
- チャット表示の **「オペレーターから」「定時実行」「手動発火」「自動再開」「◯◯ から（別のセッションから）」** —
  あなたが入力したのではないプロンプトの出所です。フリート・オペレーター、スケジュール、
  中断からの自動再開、[セッション間メッセージ](02-sessions.ja.md#セッション同士でメッセージを送る)の順に対応します。
- スケジュール行の **「停止中」** — 一時停止したスケジュールです（[11](08-organising.ja.md)）。
- 共有セッションの **「承認待ち ◯件」** — 共有先からの提案が承認を待っています（[02](02-sessions.ja.md#会話を共有する共有セッション)）。
- 掃除モーダルの **「安全」「要確認」「保持」** — 片付けてよいかの判定です（[02](02-sessions.ja.md#まとめて片付ける掃除)）。

## 右クリックメニュー

### セッション

状態や種類に応じて、再開、SSMへの再ログイン、停止、リモートセッションを開く、IDのコピー、
タイトル変更、ブランチ名変更、会話の引き継ぎ、**共有する…**、**削除ロックの設定／解除**、
アーカイブ／削除、作り直しが表示されます。リポジトリに属さないセッションでは、
**作業グループへの割り当て**もここに出ます（チェック済みで押せない項目は、リポジトリや会話に
付いて自動で入っているものです）。
アーカイブは会話を保持して一覧から隠し、作り直しは現在の会話をアーカイブして同じ場所で
新しい会話を始めます。作業フォルダがない場合、再開、引き継ぎ、作り直しは表示されません。

### リポジトリ／worktree

コミットグラフを開く、フォルダを開く、変更をコミット、ブランチ切替、ブランチ名をコピー、
Fast-Forward（worktree では **「親を Fast-Forward で取り込む」**）、プロジェクト設定、**共有する…**、
**作業グループへの割り当て**、種類別のセッション起動、ワーキングコピーの削除ができます。通常クリックは
行を展開／折りたたみます。Ctrl／⌘+クリックまたは中クリックはコミットグラフを新しいペインで開きます。

### ファイル／フォルダ

新規ファイル、新規フォルダ、名前をコピー、相対パスをコピー、名前を変更、削除ができます。
ファイルにはさらに「朗読で開く」と「ダウンロード」が表示されます。ファイルをセッションや
アシスタントへ渡す操作は、ファイルを開き、ビュアーの「送る」から行います。

### アシスタント

新規チャット、新しいペインで開くが表示されます。利用者が作成したアシスタントには編集と
削除も表示されます。常設アシスタントは編集・削除できません。会話の行には、タイトル変更、
削除ロック、**作業グループへの割り当て**が表示されます。

### コミットグラフ

コミットの詳細表示、参照しているブランチへの切替、detached HEADでのチェックアウト、
そのコミットを基点とした新規ブランチ作成ができます。submodule表示中はブランチ変更項目が
表示されません。

## ペインのボタン

ペイン右上には、内容に応じて **折り返しの切替**、**別タブへ切り離す**（そのペインがブラウザの
別タブへ移ります）、**閉じる**（中クリック／Ctrl+クリックで確認なし）が並びます。切り離せない
種類のペインでは、切り離しボタンは出ません（[03](05-terminal.ja.md#複数を並べるペイン)）。

### タブ（タブ付きグリッド）

**セッションのタブ**を右クリックすると、左ペインのそのセッションの行と**同じメニュー**が出ます
（[03](05-terminal.ja.md#複数を並べるペイン)）。セッション以外のタブと、ワークスペース停止中は、
ブラウザ本来のメニューがそのまま出ます。

## メニューが表示されないとき

- ワークスペース停止中は、ワークスペース内で処理するメニューが無効または非表示になります。
- 種類が対応していない操作や、状態に合わない操作は表示されません。
- 右クリックメニューは、外側のクリック、Escape、ウィンドウからフォーカスが外れたときに閉じ、
  フォーカスは**開いた元の項目に戻ります**。
- これらのメニューは、項目にフォーカスがある状態の**メニューキー**（または **Shift+F10**）でも
  開けます。
