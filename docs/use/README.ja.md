# Agent Fleet を使う

[English](README.md) | 日本語

Audience: Console からエージェントを動かす人
Source of truth: Console そのもの（画面と食い違ったら画面が正）
Updated: 2026-08

この棚は、実際に作業する人の**「どうやるの？」**に答えます。セッションの起こし方、
エージェントの追い方と操縦、リポジトリとファイルの扱い、使いたいエージェントの接続、
そして詰まったときの抜け方。

## ここに書くもの

- 手順。読者が実際にやる順番で。
- 画面・バッジ・メニューが何を意味するか。
- おかしく見えるときに何を試すか。「まだ動いている」と「止まっている」の見分け方。

## ここに書かないもの

- **能力の事実。** どのエージェントが Plan モードに対応しているか、どのプロバイダが
  プルリクエストに対応しているか、どのロールが何をできるか——これらは
  [ref/](../ref/README.ja.md) にだけ置きます（写しを作らないため）。表へリンクしてください。
- **画面に出てこないもの。** env 変数名・内部の識別子・API パス・ソースのパスは書きません。
  Console に出ている言葉が正しい言葉です（[CONVENTIONS](../CONVENTIONS.ja.md)）。
- **管理の話。** 他人に影響することは [admin/](../admin/README.ja.md)、
  配備を建てて維持することは [operate/](../operate/README.ja.md)。

## 更新トリガ

読者が気づく画面・導線・既定値の変更。**機能を出したのにこの棚が何も言っていなければ、
その機能は完了していません**（[CONVENTIONS §8](../CONVENTIONS.ja.md)）。
