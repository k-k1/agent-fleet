# 07. チャットとメモ — 簡単な質問・翻訳・メモ溜め

[English](07-chat-memo.md) | 日本語

Audience: アシスタントチャットやメモキューを使う人
Source of truth: Console そのもの（画面と食い違ったら画面が正）
Updated: 2026-08

> 対象: セッションを起こすほどでもない質問・翻訳・要約を片付けたいメンバー。アシスタント
> チャット、走っているエージェントの会話を読む「チャット」表示、そしてメモキューを扱います。

## アシスタントチャットとは

左ペインの **アシスタント** から始める**チャット**は、作業セッションとは別物です。
セッションのマネージド実行で使う「チャット表示」と名前は似ていますが、こちらは作業場所や
継続的な実行状態を持たない、**リポジトリ不要の会話**です。Markdown 文書の翻訳や要約、ちょっとした
質問への回答に向きます。

**セッションとの使い分け**はこう考えてください。

- **チャット** — 短〜中くらいの質問・翻訳・要約。「この文章を日本語にして」「この関数、何をしてる？」など、その場で答えが返ればいいもの。
- **セッション** — ファイルを実際に読み書きする作業、コードの変更、大きなファイルの一括処理。ファイル出力を伴うならセッションへ（[05 ファイル](04-files.ja.md) の「送る」でファイルを渡せます）。

**アシスタント** セクションの **＋（新規チャット）** で会話を始めます。送信は Ctrl+Enter
（設定で Enter 送信にも変更可）。相手の発言は「アシスタント」、あなたの発言は「あなた」と
表示され、処理中は「考え中…」が出ます。入力欄に**画像を貼り付け**て一緒に送ることも
できます（スクリーンショットを見せて質問する、など）。

### 用途別のアシスタントと翻訳

Agent Fleet の使い方案内や SRE の相談など、固有の役割を持つアシスタントが用意されています。
通常の質問は新規チャットへそのまま入力し、ファイルの翻訳・要約はファイルの
右クリックメニューを使います。

自分用に用途を決めたアシスタントを **「アシスタントを作成」** で用意することもできます。名前・
説明（会話開始時の挨拶）・ペルソナ（役割や口調の指示）・使うエージェント／モデル、
そして **ツール許可**を設定します。

モデルを空欄にすると、新しい会話では選んだエージェントに合う既定モデルを使います。現在は
**codex は Luna**、**opencode は Nemotron** が既定です。ここでモデルを明示すればその指定が優先され、
すでに始めた会話のモデルは後から変わりません。

回答には、それを生成したモデルがエージェント名の横に表示されます（例: `sonnet 5`）。セッションの
ミラーがターンごとにモデルを出すのと同じ見え方です。回答ごとに記録するので、会話の途中でモデルを
変えたり別のエージェントへフォールバックしたりしても、過去の回答は当時のモデルのまま残ります。
モデルが表示されない回答は、CLI が自分の既定で動き、どのモデルだったかをこちらへ知らせない場合
（cursor の Auto など）です。推測は出さず空欄にしています。

- **なし** — 外部ツールなしで、チャット内だけで答えます。翻訳・要約はこれで十分です。
- **AF 読み取り** — 自分のワークスペースのセッション一覧・状態・出力のほか、エージェントの使用量・制限（claude / codex の使用率と解除日時）や、セッションごとのコンテキスト量・累積消費トークンを読み取れます（書き込み不可）。
- **AF 書き込み** — 読み取りに加え、セッションへプロンプトを送れます（作業の代行）。信頼できる用途にだけ許可してください。

ビルトインの **フリート・オペレーター**は「AF 書き込み」の代表例で、セッションの起動・
指示・完了報告の受け取りまでチャットで指揮できます。詳しくは
[11 フリート・オペレーター](08-organising.ja.md) を参照してください。

たとえば翻訳用なら、ペルソナに「あなたは技術文書の翻訳者です。訳文のみを返してください」、
挨拶に「文章を渡してください。日本語↔英語を翻訳します」と書いておく、といった具合です。

### 会話の途中でエージェントを切り替える

⚙設定 → 「アシスタント」タブの **エージェント優先順位** は、これから始める会話（と
タイトル提案などの短い処理）に効きます。**すでに進んでいる会話**を別の CLI へ移したいときは、
チャットのヘッダにあるエージェントのチップ（例: `Claude ▾`）を押して切り替えてください。

- それまでの会話は失われません。**次の送信**でまとめて新しいエージェントへ渡されるので、
  その1ターンだけトークン消費が増えます。
- モデルは、⚙設定 →「アシスタント」タブにある**切り替え先 CLI の行**から選び直されます
  （元のエージェント向けのモデル指定は引き継ぎません）。
- 未接続の CLI は選べません（設定 → 接続 でログインすると出てきます）。応答の生成中は
  切り替えられないので、いったん停止してから切り替えてください。
- 元のエージェントへ戻すこともできます。そのエージェントは自分が最後に応答した続きから
  再開し、留守にしていた間の会話だけを受け取ります。

チャットの**回答言語**は ⚙設定 → 「アシスタント」タブの「回答言語」で
決められます。「入力に合わせる」なら渡した文章の言語で返し、日本語／English を選ぶと
他言語の文章でもその言語で答えます（ファイル右クリックの「アシスタントで翻訳」は対象外 — 常に原文に応じて訳し分けます）。

### 会話が長くなってきたら（コンテキストの目安）

会話を重ねるほど、モデルに渡る文脈（コンテキスト）は増え続けます。最初の応答が返ると、
チャットのヘッダ下にセッションのミラーと同じ**コンテキストバー**（使用量／上限・%）が
表示されます。使用率が **80%** を超えるとバーが警告色になり、会話にもお知らせが 1 回
届きます（通知センターにも出ます）。

対処は 2 通りです。

- **圧縮（そのまま続ける）** — コンテキストバー右端の **「圧縮」** を押すと、これまでの
  会話を要約し、**要約だけを新しいセッションへ引き継いで**同じチャットで続けられます。
  画面の会話履歴はそのまま残り、引き継がれるのは要約のみです（要約の作成に 1 ターン分の
  トークンを使います）。長い会話をそのまま続けたいときに向きます。
- **新しいチャットを開く** — 区切りが良ければ、新規チャットを開いて必要な要点だけを
  自分で書いて渡すのが確実です。

いずれにせよ、長くなった会話をそのまま続けるほど、応答の品質低下・ターンの失敗・
トークン消費の増大につながります。

放置した場合の安全網も用意されています。使用率が **90%** を超えたまま次のやり取りを
始めると、先に自動で圧縮（要約引き継ぎ）してから応答します（⚙設定 → 「アシスタント」
タブの「コンテキストの自動圧縮」で OFF 可）。さらに、圧縮する前にコンテキストが上限を
超えてしまった場合でも、システムが自動で要約による引き継ぎを試みてから返信を再実行
します。それでも回復できないほど超えていたときは、その旨のお知らせが会話（と通知
センター）に出るので、「圧縮」か新しいチャットで対処してください。

### 忘れさせたくないことは「作業計画」に置く

圧縮しても新しいチャットへ移っても、**要約されずに原文のまま引き継がれる枠**があります。
コンテキストバーの隣の **「作業計画」** です。制約（この先ずっと効く前提）、前提（次の一手に必要な
既成事実）、これからやること（順序・依存）を書いておくと、会話が長くなっても土台がぶれません。

- **「編集」**で直接書けます。**「更新」**を押すと直近の会話から計画を引き直します
  （壁打ちで方針が変わった直後に押してください）。
- 圧縮のときは、直近の会話に合わせて自動で更新されます。
- **「クリア」**で空にできます（会話履歴と引き継ぎ要約はそのまま残ります）。
- 済んだ作業を並べる場所ではありません。「これが無いと次の一手を間違える」ことだけを書くと効きます。

## 走っているエージェントの会話を読む・返信する

claude、codex、cursor、copilot、kiro、agy、opencode のセッションは **チャット**表示で操作できます。ターミナル（CLI）実行なら
ペイン上部の **チャット ⇄ ターミナル** で切り替え、マネージド実行なら最初からチャット表示だけを
使います。チャット表示では
やり取りが**ターンごとのMarkdown**で読め、そのまま返信もできます。スマホで進捗を
追いながら短く返す、という使い方に向きます。

エージェントがあなたの判断を待っているときは、対応するカードが出ます。使えるカードや
選択肢はエージェントと状態によって異なります。

- **質問中** — 選択肢を選ぶ（または自由入力を書く）→ **「回答を送信」**で確定します。クリックしただけでは送られないので、選び直したり、選択肢に付くプレビューを見比べたりしてから送れます。
- **プラン承認待ち** — 提案されたプランを「承認して実行」か「却下（続ける）」。
- **許可待ち** — 編集やコマンドの実行を「許可」／「拒否」（以降このセッションで自動許可も選べます）。

下の入力欄からプロンプトを送れば、端末に打ち込むのと同じように指示できます（画像の
貼り付けも可）。**モード切り替え**で Plan（計画）⇄ 実装 を選べ、実行中は **「停止」**（Esc）
で止められます。送った直後は送信済みであることが表示され、エージェントが処理を始めると
会話に反映されます。

停止中のセッションは履歴の閲覧のみで、返信するには **「再開して続ける」** で再開します。

### プランに指摘を書き込む

長いプランに「ここだけ直して」と返したいとき、本文を引用して打ち直す必要はありません。
プランカードの **「ペインで開く」** で本文をペインに開くと **レビュー**の印が付き、
**本文を選択すると、その箇所にコメント**を書けます。

書いたコメントはプランカードの **「コメントを送る（◯）」** でまとめて届きます。承認待ちの
プランに対しては **「コメントを送って却下（◯）」** になります（本文を届けるには承認ダイアログを
閉じる必要があるため、却下と一体になっています）。エージェントは指摘を踏まえた改訂プランを出し直します。

### 返信サジェスト

入力欄の上に、よく使う短い返信（OK・進めて・commit など）と、直近の回答に沿った候補が
チップで並びます。クリックで入力欄に差し込み、**Ctrl・⌘・Alt のいずれかを押しながらクリックで即送信**。
候補はあなたが送った短文から学習し、右クリック（タッチは長タップ）で**ピン留め**や削除ができます。

キーボードだけでも使えます。入力欄が空のとき **Tab** で候補へ移り、**←→** で候補内を移動、
**Enter** で差し込み、**Ctrl（⌘）+Enter** で送信、**Esc** で入力欄へ戻ります
（Enter 送信の設定なら Enter と Ctrl+Enter の役割は入れ替わります）。

**✨ボタン**を押すと、直近の会話を AI に渡して文脈に沿った候補を追加で生成します
（トークンを使うのは押したときだけです）。表示のオン・オフは ⚙設定 →「キー操作」にあります。

### この発言から分岐する

過去の**自分の発言**にマウスを乗せる（またはフォーカスする）と、その吹き出しの下に
**「ここから分岐」** が出ます。押すと、そこまでの会話をそのまま引き継いだ**新しいセッション**が
生まれます。**いまのセッションはそのまま残ります**。

「あの指示のところで別のやり方を試したい」「途中で方針を間違えたので、そこからやり直したい」
というときに、会話をコピペし直さずにやり直せます。分岐のしかたは 2 つから選べます。

- **この発言をやり直す**（既定）— その発言は引き継ぎません。分岐先は「その発言を打つ直前」の
  状態で開き、元の文が入力欄に**下書き**として入っています。書き直して送るのも、そのまま
  送るのも 1 操作です。
- **この発言の続きから** — その発言と、それに対する回答まで引き継ぎます。うまくいった
  ところから別方向へ進めたいときに使います。

確認画面には、分岐点の発言・引き継がれるやり取りの件数・元が残ることが出ます。

**引き継ぎ（handoff）との違い**は覚えておくと迷いません。引き継ぎは*要約して別のエージェントへ
渡す*もの、分岐は*同じエージェントで会話をそのまま複製する*ものです。言い回しや細かい経緯まで
残したいなら分岐、別のエージェントに続きを任せたいなら引き継ぎです。

ボタンが出ない場合は次のどれかです。エージェントの発言や、まだ送信中の発言からは分岐できません。
また **claude・codex・opencode・copilot** のセッションだけが対応しており、codex と opencode は
**マネージド実行**のときだけ使えます（ターミナル（CLI）実行では分岐点を指定できないため）。

## メモキュー

思いついた指示を**その場で溜めておき、あとでまとめてセッションに流す**のがメモキューです
（左ペインの **メモキュー**）。通勤中にスマホで「あれ直したい」を書き溜め、PC で一気に
渡す、といった使い方ができます。

- **溜める** — 「走り書きメモを追加…（後でまとめて送信）」に書いて「追加」。ファイルを開き、[05](04-files.ja.md) の「送る」から溜めることもできます。リポジトリ・カテゴリでグループ分けされます。
- **AI で整理する** — メモを選び **「選択したメモをアシスタントで整理」** すると、走り書きを明確な指示文に整え、カテゴリを提案してくれます。結果は **必ずプレビュー**され、「◯件を反映」で承認するまで適用されません（勝手に書き換わらないので安心です）。
- **送る** — 送信先の稼働セッションを選び、**「選択を送信」** で一括送信します。カテゴリ単位の「送信」もできます。送信先の稼働セッションが無いときは、先にセッションを起動してください。
