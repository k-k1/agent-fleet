# 0091. 登録済みの一覧をカードのグリッドにし、カードは自分の幅で畳む

[English](0091-registered-catalogue-grid.md) | 日本語

- Status: **accepted**（2026-09-18）。同じ変更で実装済み。
- [0088](0088-model-catalogue-names-and-examples.ja.md) 決定 2 の**見せ方**を改める——作例画像が
  カードのどこにどれだけの幅で載るか。あの決定が定めたこと（URL を記録し、バケットにバイトを
  置かない）はそのまま。変わるのは描く幅だけで、その理由は決定 2 を書いた時点には存在しなかった。

## 背景

`登録済み` の一覧は 1 列で、1 行 1 カードだった（`grid-template-columns: minmax(0, 1fr)`）。
運用者が実際に使う幅——報告された画面では 1,450px——では、目録の 1 行が 1,450px の帯になる:
左端に見出し、右端にボタン 5 つ、その間に何も無い湖。4 モデルで画面が埋まり、20 件の目録は、
並べれば収まるものを比べるために 5 画面ぶんスクロールすることになる。

Console はその答えをすでに持っている。セッション一覧ペイン（ADR 0078、`.ovw-grid`）で、理由も
書かれている: 列数が幅に従うよう `auto-fill` + `minmax`、そしてカードは**自分自身がコンテナ**で
あること——「4 列のペインと 1 列のペインは、同じビューポートでもまったく違う幅を配る」。

## 決定

### 決定 1 — セッション一覧と同じ `auto-fill` + `minmax(380px, 1fr)`

380px を決めているのは**フッター**で、カードが抱えるいちばん幅の要るものだ: 最大 6 つのボタン
（配布元から名前を取る / 編集 / 有効にする / これで起動する / 揃える / 登録を消す）。これを
下回るとボタンが積み上がり、カードが 1 枚のカードでなくなる。

`auto-fit` ではなく `auto-fill`。理由は `gallery.css` が書いているものと同じ: 2 件しかない
ファミリーが、ペインいっぱいに引き伸ばされた 2 枚ではなく、カードの大きさのカードのままである
べきだから。

フッターには `margin-top: auto`。本文の高さが違うカードが並んでも、ボタンの行は 1 本に揃う。

### 決定 2 — カードは**カードの幅**で畳む。ビューポートの幅ではない

カードの内側に関する規則を `@media (max-width: 700px)` から
`@container engcard (max-width: 560px)` に移す。1,500px の 3 列ペインは 470px のカードを配るので、
ビューポートの規則では永久に畳まれない。畳む条件と畳まれる対象が、やっと同じ箱を測るようになる。

ビューポートの問い合わせに残るのは**ペイン**についてのもの: 役割タブ、表示タブ、操作グリッド。

### 決定 3 — 作例は「サムネイルの段」にして、切り抜く

ADR 0088 はこれに `flex: 0 1 50%` と `object-fit: contain` を与え、切り抜きに反対した——作例は
しばしば 2048x4096 で、縦長を横長の箱に切り抜くと、人がチェックポイントを判断する半分が
落ちるからだ。**それはカードがペインと同じ幅だったときには正しかった**。1,450px の半分は
本物の絵で、レターボックスは何も損なわない。

グリッドの大きさになると逆転する。1:2 のスウォッチを 555px のカードに描かせると、`contain` は
**555px の箱の真ん中に 110px の帯**を描く——幅は空白に使われ、絵は `探す` タブのサムネイルより
小さい。だからカードは、そのタブが ADR 0085 以来使ってきた答えを取る: 縦長のサムネイルの段と
`object-fit: cover`、そして全体はライトボックスで 1 クリック先。

畳み条件ではなく `flex: 0 0 clamp(88px, 22%, 132px)`: サムネイルは閾値で全幅に跳ぶのではなく
カードと一緒に縮む。そして全幅こそ、縦長の作例にとって最悪の場合だ。

🔴 同じコミットでスタブのスウォッチを 1:1.18 から **1:2** に変えた。ほぼ正方形のスウォッチは
このカードのスクショを常に問題なく見せ、実物の作例がレイアウトに何をするかを何も語らなかった
——この ADR が直す欠陥は、それを見せるはずのハーネスの中で見えなくなっていた。

## 実測したこと

| 主張 | 方法 |
|---|---|
| 実物の作例は 2048x4096 | Civitai の `MeinaMix` 1 枚目、実機 2026-09-18（ADR 0088） |
| グリッドの大きさのカードで `contain` は 110px の帯になる | 1,500px でヘッドレス描画、555px の 2 列 |
| ボタン 6 つのフッターに要るのは 380px | 同じ描画で、床を決める前後を見比べた |
