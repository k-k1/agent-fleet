# Agent Fleet ドキュメント

[English](README.md) | 日本語

自分に当てはまる棚から読み始めてください。棚は 1 人の読者のために書かれていて、
**その棚がそのまま配布の単位**でもあります（Control Plane は、そのユーザーの
ロールに許された棚だけをコンテナへ渡します）。

| あなたは | 棚 | 答えるのは |
|---|---|---|
| Agent Fleet でエージェントを動かす人 | [use/](use/README.ja.md) | どうやるの？ |
| テナント管理者 | [admin/](admin/README.ja.md) | チームのためにどう運用するの？ |
| 配備を建てて維持する人 | [operate/](operate/README.ja.md) | どう建てて、どう生かし続けるの？ |
| コードを変える人 | [build/](build/README.ja.md) | どう動いているの？ |

全員が読む棚が 2 つあります。

- **[ref/](ref/README.ja.md) — できること。** 機能ごと・エージェントごと・
  リポジトリ種別ごと・デプロイ形態ごと・ロールごとの能力表。他の棚はここを
  参照するだけで、同じことを書きません。本文と表が食い違ったら**表が正**です。
- **[decisions/](decisions/) — なぜそうなっているか。** 決定の記録（追記型）。
  捨てた選択肢も書いてあるので、誰かがうっかり再挑戦せずに済みます。

## ここに書くとき

[CONVENTIONS.ja.md](CONVENTIONS.ja.md) が全棚共通の執筆規範です。3 つの寿命を
分ける規則、必須の冒頭ヘッダ、棚ごとに使ってよい語彙、二言語の規則
（英語が正・日本語は `X.ja.md` として隣に置く）。`scripts/docs-check.py` が
CI と手元の両方で機械検査します。

## 棚ではないもの

- **[log/](log/README.md)** — かつて `docs/NN-*.md` と `docs/history/` だった
  作業ジャーナルの凍結アーカイブ。保守しないし配りません。**実測値・本番事故の
  因果・上流 CLI の契約・何かを諦めた理由**——他のどこにも無い事実を引くために
  だけ存在します。現役の文書はここへリンクしません。
- [HANDOFF.md](HANDOFF.md) — 開発ホストの稼働状態とホスト固有の作法。毎日変わります。
- [roadmap.md](roadmap.md) / [CHANGELOG-handoff.md](CHANGELOG-handoff.md) —
  前向きの計画と、日付つきの作業ログ。

## 移行中

`dev/` と `guide/` は旧レイアウトで、新しい棚が書き上がるまでは**そちらが正**です。
各棚の README に「どこまで新しい棚に在り、何がまだ旧い場所に在るか」を書いています。
