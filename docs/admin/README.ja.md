# テナントを管理する

[English](README.md) | 日本語

Audience: テナント管理者（チームのメンバー・上限・連携に責任を持つ人）
Source of truth: Console のテナント設定（画面と食い違ったら画面が正）
Updated: 2026-08

この棚は**「チームのためにどう運用するの？」**に答えます。誰がサインインできるか、
どれだけ使ってよいか、テナントとしてどの連携を提供するか、監査と費用の画面が何を
語っているか。

## ここに書くもの

- 効果が**他人に及ぶ**手順。メンバーの招待と削除、サインイン方式とログイン規則、
  接続元の制限、上限とアイドル自動停止、テナント独自の連携アプリの登録、
  メンバーへの配布。
- 監査・稼働時間・費用の画面の読み方と、**その数字が何を含み、何を含まないか**。

## ここに書かないもの

- **能力の事実**（どのロールが何をできるか、各プロバイダが何に対応しているか）。
  [ref/](../ref/README.ja.md) にだけ置きます。表へリンクしてください。
- **メンバーが自分のためにやること** — それは [use/](../use/README.ja.md)。
- **配備を建てる・上げる話** — それは [operate/](../operate/README.ja.md)。
  テナント管理者はホストの端末を持ちません。**この棚は端末があることを前提にしない。**
- 実装の語彙（変数名・内部識別子・API パス・ソースのパス）は地の文に書きません
  （[CONVENTIONS](../CONVENTIONS.ja.md)）。

## 更新トリガ

テナント単位の設定・上限・ロールの届く範囲・管理者向け画面が報告する内容の変更。
