## 画面の名前

Console は**上に 2 段のバー**、**左にペイン**、**中央にメイン領域**という構成です。
詳しい名称と用語は [画面と用語](ui-and-terms.md) にまとめています。

### 上段: TOP バー

画面いちばん上の横帯です。左からアプリ名（Agent Fleet）、**テナント選択**（部署などの
切り替え。既定は 1 つなので触らないことも多い）、右側に **⚙設定**、アカウント
（あなたの表示）が並びます。チームを管理する権限がある人だけ、さらに**盾のアイコン**
（管理者向けの画面）が出ます。

### 下段: WS（ワークスペース）バー

その下の帯が、あなた専用の環境＝**Workspace** の操作列です。

- **● 状態ランプ** — Workspace が動いている（running）か止まっている（stopped）かを色で示します。数秒ごとに自動で最新化されるので、手動更新は不要です。
- **起動 / 停止トグル** — 1 つのボタンで Workspace を Start ⇄ Stop します。
- **プレビュー** — Workspace 内で立ち上げた Web サービスを別タブで開く入口です（[08 一歩進んだ使い方](08-advanced.md)）。

### 左ペイン

Workspaceが動いているときは、次のセクションが縦に並びます。

- **アシスタント** — 使い捨てチャット（[07](07-chat-memo.md)）。
- **メモキュー** — あとでまとめて送る指示のメモ（[07](07-chat-memo.md)）。
- **リポジトリ** — 作業コピーと、その場所で動くセッション（[02](02-sessions.md)・[04](04-git.md)）。
- **その他のセッション** — リポジトリに属さないセッション（[02](02-sessions.md)）。
- **ファイル** — Workspace内のファイルブラウザー（[05](05-files.md)）。

Workspace停止中は、セッションを **セッション履歴**で確認できます。

（スマホでは左ペインは隠れていて、TOP バーの≡（ハンバーガー）で引き出します。詳しくは [03 ターミナル](03-terminal.md)。）

### メイン領域

中央の広い領域は、左ペインで何を選んだかによって表示が切り替わります。

- **端末（ターミナル）** — セッションの黒い画面（[03](03-terminal.md)）。
- **ソース管理** — 変更・diff・コミット・履歴（[04](04-git.md)）。
- **ファイルビュアー** — ファイルの中身の表示（[05](05-files.md)）。
- **チャット** — 走っている claude の会話や、使い捨ての質問・翻訳（[07](07-chat-memo.md)）。

claude セッションのペインは、上部の **チャット ⇄ ターミナル** トグルで会話表示と端末表示を
切り替えられます。メイン領域は複数のペインに分割して並べられます（[03](03-terminal.md)）。

## 用語（最小限）

- **Workspace** — あなた専用のコンテナ環境。クローンしたリポジトリと作業内容が入ります。停止しても中身は残ります。
- **セッション** — 1 つの AI エージェント（claude など）または shell の実行。端末 1 枚に対応します。
- **エージェント** — claude / codex / opencode などの CLI コーディング AI。
- **テナント** — 部署などのグループ。あなたの Workspace はテナントごとに分かれます（既定は 1 つ）。
- **worktree** — 1 つのリポジトリから、ブランチごとに独立した作業用フォルダを切り出す git の仕組み。セッションを起動すると既定でこれが作られ、複数タスクを互いに邪魔せず並行できます（[02](02-sessions.md) / [04](04-git.md)）。

詳しい定義と表記の基準は [画面と用語](ui-and-terms.md) を参照してください。
