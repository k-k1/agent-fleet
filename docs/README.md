- [0046-drawio-viewer.md](decisions/0046-drawio-viewer.md) — **`.drawio` は drawio 公式ビューアを同梱し、サンドボックス iframe に閉じ込めて表示する**。自前レンダラは却下（シェイプライブラリを使った図が「それらしく間違って」描かれる＝無言の低品質は非表示より悪い）、外部 embed も却下（図面が第三者サービスへ出る）、サーバ側 SVG 変換は Electron が要るので不可、npm に代替も無い。iframe に閉じ込めるのは**グローバル 932 個**と**lightbox の図面持ち出し**の 2 つが実測で出たため（`allow-popups` を与えないので設定漏れが事故にならない）。**新しい PaneKind は作らず File ペインの面を増やす**／**図の取得は 2 MiB で打ち切る `api/fs/file` ではなく `api/fs/download`**／**ステンシルは同梱せず CP プロキシ＋キャッシュ＋20 KB の台帳**（台帳は SSRF の防壁を兼ねる・閉域では枠と色だけに黙って劣化）／**ビューア本体はコミットするが `public/` ではなく Vite のハッシュ資産へ**（`/assets/*` だけが immutable）。編集は範囲外（難所は保存ではなく編集器の配布）

- [0047-tenant-network-restriction.md](decisions/0047-tenant-network-restriction.md) — **テナント接続元制限はアプリ層（認証の後）に置き、ネットワーク防御とは名乗らない**。送信元 IP は **XFF を右から N 番目**（`AF_TRUSTED_PROXY_HOPS`・既定 0＝`RemoteAddr`）で取り、ヘッダを読むのは最外周の 1 箇所だけ。**PAT/MCP・git・`/internal/*` は対象外**（送信元が本人の Workspace コンテナで人の所在を表さない）。締め出しの逃げ道は super_admin 対象外 ＋ **保存時に編集者の現在 IP を必ず通す** ＋ **誤設定（プロキシの後ろなのに `AF_TRUSTED_PROXY_HOPS` 未設定）はその場で拒否**——表示では不足で拒否が要る。**運用者の on/off スイッチは足さない**（ADR 0044 決定 3 の再発防止）。置き場は `tenant.allowed_cidrs`（既存の 30 秒キャッシュに相乗り）、編集は `tenantAdminFor` の新エンドポイント（super_admin 専用の `setTenantLogin` には足さない）。設計 [66](66-tenant-network-restriction.md)
- [0048-member-cloud-cost.md](decisions/0048-member-cloud-cost.md) — **メンバー毎の AWS 費用は「実費（Cost Explorer）」だけを出す。按分はしない・共有は配らない**。コスト配分タグは**バックフィルが無い**ので設計より先に有効化（`af-workspace` はメール由来の値なので**意図的に除外**）。**スロットインスタンスに `af-membership` を打つ**（紐づけたい費用の 91% がそこに乗っているのに付いていなかった。既存ロジックは不変・IAM 追加不要）。**稼働秒 × 単価の按分は採らない**（単価を更新しない限り静かに嘘をつく＝ 0044 決定 3 と同じ型）。**共有費（実測で 77.7%）は頭割りせず別カード・super_admin 限定**、メンバー向けラベルは「あなたのコスト」ではなく**「あなたのワークスペースに直接ひも付く費用（共有分は含みません）」**。「使用量」が既に 3 か所あるので金額は**「クラウド費用」**として新設（キー・API パスは触らない）。CE は $0.01/req なので **CP が 6 時間おきに 1 リクエストで取って DB を配る**（Console から直接叩かない）。**`ce:GetCostAndUsage` は足す**——**0045 決定 21（表示のために IAM を増やさない）を明示的にひっくり返す**（あちらは代替手段で同じ数字が出せたが、実費に代替は無い）。⚠️ 権限確認は `CpTaskRole` を assume して行う。ランタイム申告（`CostProfile()`）で **docker/native にはタブごと出さない**、Fargate のタグ伝播は**実機未検証と明記して出す**。設計 [67](67-member-cloud-cost.md)
- [0049-session-changed-files.md](decisions/0049-session-changed-files.md) — **セッションが直したファイルの一覧は「転写 × git の突合」で作り、ミラーのヘッド直下に置く**。母集合は転写の `Part.File`、行の状態は `fs/changes` との突合（**突合キーは browse 相対パスではなく `(repo, rel)`**）。**集計は Agent 側・全転写で `/messages` に同梱**（クライアント集計は tail 窓のせいで件数が増え続ける／2 本目のポーリングは同期ズレを生む）。**新しい PaneKind は作らない**（0046 と同じ判断）、**能力が無いものは帯ごと出さない**（共有ビュー・未対応 kind）、**「差分なし」の行は消さずに残す**（コミット済み / 取り消しの区別は P2）。fork の履歴もサブエージェントの編集も数える。ミラーの `caps.openDiff` 未配線も併せて塞ぐ。設計 [68](68-session-changed-files.md)
- [0050-transcript-marks.md](decisions/0050-transcript-marks.md) — **転写のマーカーは「元ターン由来の root ＋ 引用 ＋ 出現番号」で指し、実体は Agent、共有先へは別経路で配る**。`idx` もグループ相対の part 番号も使わない（前者は compaction で動き、後者は tail 窓の境界で両側がずれる）。**塗れるのは共有 DTO を素通りする本文だけ**——`quote` で allowlist を迂回させない。RW 共有先は**承認なしで直接書ける**（提案→承認はエージェントを動かす操作のための仕組みで、注釈には過剰）。**色と作成者は別の軸**（下線は `box-shadow: inset`——`border-bottom` は行送りを変える／所有者だけの会話では下線を出さない）、作成者の login id は共有先どうしにも見せて共有作成時に伝える。⚠️ **セッション名はスロット名で再利用される**ので削除時にファイルを消す（引き継ぎ提案が同じ穴を開けていたので併せて塞いだ）。塗り直しは「印・本文の長さ・いま載っている数」で判断する（毎回塗ると 400 ターン×毎秒、印の変化だけ見ると本文の再描画で印が消えたまま戻らない）。設計 [69](69-transcript-marks.md)
