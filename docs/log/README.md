# log/ — 凍結した作業ジャーナル

ここは**アーカイブ**です。棚ではありません。保守しません。配りません。
現役の文書からここへリンクしません（[CONVENTIONS §7](../CONVENTIONS.ja.md)・CI が弾きます）。

かつて `docs/NN-*.md`（67 ファイル・33,262 行）と `docs/history/` だったものです。
機能ごとに「設計 → 実装計画 → 実測 → 事故 → 撤回 → 次のラウンド」を時系列で積んだ
作業日誌で、**そこに現行の仕様も混じっていた**のが旧レイアウトが読めなくなった原因でした。
仕様は読者ごとの棚へ移し、日誌はここへ落としました。

## なぜ捨てないのか

コードにも画面にも無く、**取得に金と時間がかかった事実**がここにしか無いからです。

1. **実測値** — 起動レイテンシ、遅延ロードの採否、アーキ別のビルド時間、
   マウントの往復、Pricing API で実測した費用。
2. **本番事故の因果** — 何が起きて、なぜそうなったか。再現には事故が要ります。
3. **上流 CLI の契約の実測** — 各エージェント CLI の画面文字列やプロトコルは、
   上流が版を上げるたび壊れます。取り直すには実 CLI が要ります。
4. **撤回の理由** — 「やってみて駄目だった」。これを捨てると、必ず誰かが再挑戦します。

## 使い方

grep して、**事実を現役の文書へ転記してください**。ここを読ませるためのリンクを
書かないこと。番号は不変の ID として残してあるので、コード中のコメントの
`docs/log/NN` はそのまま引けます。
