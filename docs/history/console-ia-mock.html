C

進め方（小さく・都度目視）

全面 IA だが、後退を避けるため 共有プリミティブ → 左レール → バー → フォーム → 状態 の順で小さくコミット。各ステップ後 typecheck＋build グリーン、あなたがブラウザ目視 → OK ならコミット。

P0 共有プリミティブ

  • ConfirmDialog を全体で使える形に（danger ボタン統一）
  • トースト / インラインエラー（alert 置換）
  • Spinner・EmptyState・IconButton(label) を1本化

P1 左レール IA

  • セクションヘッダをアイコン＋ラベルに
  • Sessions/Repos/Files の行レイアウト統一（caps 駆動の状態チップ／バッジ／色）
  • ⋯ メニューをラベル付き・破壊操作は danger

P2 TopBar / WsBar

  • テーマ編集器をアカウントメニューから設定へ移設
  • WsBar のリソース4タイルを「リソース」ポップオーバへ集約
  • usage / preview の情報階層を整理（過密解消）

P3 フォーム & 状態

  • NewSession / NewRepo を縦積み・ラベル付き・余白調整
  • 空 / ローディング / エラーの一貫化を全画面へ展開
  • 最終 typecheck＋build、push

守るハード制約：no-store 配信（vite build --watch 維持）／ base-path 相対 URL ／ X-AF-Tenant ヘッダ ／ xterm は React 外。 機能インベントリ（console-redesign.md §18.2）は全維持。これは方向性の提案で、実装は上の順で小さく進めます。
