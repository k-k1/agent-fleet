Console UX 刷新 · §D 設定タブ再編

接続とエージェントを「対象」で分ける

Claude / Codex / opencode が接続タブと エージェントタブに二重登場していた問題を解消。 各エージェントの「接続＋挙動設定」を1カードに統合し、GitHub / Bitbucket はGit タブに分離。 SSM / MCP と同じ「ドメインでタブ」の軸に揃える。機能・API・認証フローは不変。

狙い

何が良くなるか

  • 二重登場の解消 — 「Claude を設定する」が 1 タブ・1 カードで完結（今は接続とエージェントを往復）。
  • ドメイン軸で一貫 — 既存の SSM / MCP と同じ「対象ごとにタブ」に。接続 vs 挙動という横断軸を廃す。
  • git を独立 — 挙動設定を持たない GitHub / Bitbucket は Git タブへ。エージェントカードに無関係な認証が混ざらない。
  • タブ数は 6 のまま — 接続→Git、エージェント認証はエージェントへ吸収。
