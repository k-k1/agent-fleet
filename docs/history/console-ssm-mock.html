「追加フォーム」を、無ラベルの詰め込みからガイド付きへ

機能・API は不変。プロファイル／ホストの追加 IF を、placeholder だけの入力グリッドから、ラベル・必須表示・ヒント・グループ分けのあるフォームへ。AWS 秘密情報を保存しない設計もそのまま。

診断

いまの追加フォームの何がつらいか

  • ラベルが無い — 6 個（プロファイル）/ 5 個（ホスト）の入力が placeholder だけ。1 文字打つと何の欄か消える。
  • 必須と任意が混在 — 「（任意）」を placeholder に書くだけ。何を埋めれば「追加」できるかが押すまで分からない（ボタンが無言で無効なだけ）。
  • 入力の意味・取得元が不明 — start URL の形式、SSO リージョンと既定リージョンの違い、instance-id やドキュメント名をどこで確認するかのヒントが無い。
  • プロファイル→ホストの依存が弱い — ホストは先にプロファイルが要るのに、0 件のときだけ一言。関係が図として見えない。
  • 2 フォームが素の grid で並ぶ — 見出し・区切り・余白が弱く、どこからどこまでが 1 つの登録か掴みにくい。
