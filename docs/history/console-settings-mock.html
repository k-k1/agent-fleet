Console UX 刷新 · §D 設定/管理の一貫化

設定ダイアログを 1 つのパターンに揃える

現状は 表示/環境 だけが「セクション見出し＋行」の整った形で、 接続・SSM・MCP・エージェント は各自の見出し（conn-head / ssm-section / pat-*-head）でバラついている。理想形 DisplayTab の ds-group/ds-title を全タブの共通パターンに昇格させる案。

01

統一ルール（共通トークン）

どのタブも次の 5 要素だけで組む。個別クラス（conn-head/ssm-section/pat-*-head/cname 見出し）は廃し、 共通クラスに寄せる。色はテーマ変数（ハードコード禁止）。

セクション見出し

.set-title 大文字・muted・下線ヘアライン。 1グループ = .set-group。

設定行

.set-row 左に固定幅ラベル .set-label（148px）、 右にコントロール。縦位置を揃える。

補助テキスト

.set-hint 11px・--muted に統一。 （旧 field-help=muted2 / role-hint=継承 を解消）。

項目カード

接続/SSM/MCP のリストは .set-card ＋ 共通 .set-card-head（状態ドット＋名前＋説明＋操作）。

危険ゾーン

.danger-title は --del（旧ハードコード #f3b6b6 を廃止。ライトでも見える）。

04

危険ゾーン・補助テキストの色

現状
⚠ 危険な操作
見出し色がハードコード #f3b6b6 → ライトテーマで消える。補助テキストは field-help=muted2 / role-hint=継承 でバラバラ。
統一案
⚠ 危険な操作
Workspace を作り直す コンテナを破棄し最新イメージで再生成（セッション・clone は失われます）。
作り直す
見出しは --del、補助は全て --muted に統一。
進め方: この骨格に合意後、1 タブずつ DisplayTab パターンへ寄せる（接続 → SSM → MCP → エージェント → 管理ダイアログ）。 各タブは小さくコミットし、ユーザーがブラウザで目視。既に 475d38b で危険色/補助色は先行統一済み。 参照: DisplayTab.tsx（理想形）、console-redesign-backlog.md §D。
