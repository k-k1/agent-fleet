Sessions can reach your phone or computer with Web Push while the Console is closed. Memo auto-run
memos can each name their own agent, model and effort and a start time, and a repository can carry
its queue settings in a file. Schedules that a session writes now wait for your approval.

### New

- **Web Push:** where an administrator has switched it on, ⚙ Settings → Notifications → "Push to
  this device" sends a question, a plan or permission waiting for you, or a finished answer to a
  phone or computer with the Console closed. You choose what is pushed per device; a session you
  are looking at is not pushed, and a tenant administrator decides whether a question's text goes
  along. ([#4750](https://github.com/k-k1/agent-fleet/issues/4750))
- **Schedules wait for approval:** a schedule that a session creates, or whose prompt, timing or
  target it changes, is held with an "Awaiting approval" badge and does not run until you choose
  "Review & approve" in the Schedules view. Schedules you make in the Console are not held.
  ([#4631](https://github.com/k-k1/agent-fleet/issues/4631))
- **Memo auto-run, per-memo recipe:** a memo's "Runs with" row picks the agent, model and effort for
  its run instead of the category's, and sessions can set them with `add_memo` / `update_memo`.
  ([#4845](https://github.com/k-k1/agent-fleet/issues/4845))
- **Memo auto-run, start time:** "Do not run before" in a queue memo's edit view keeps it from
  starting before a given time, and approving the memo keeps the time. ([#4777](https://github.com/k-k1/agent-fleet/issues/4777))
- **Memo auto-run, repository settings file:** a repository can hold its queue settings in
  `.agent-fleet/autorun.yaml`. The category's auto-run settings show how the file differs from
  yours, let you approve it field by field, and export your settings as such a file.
  ([#4881](https://github.com/k-k1/agent-fleet/issues/4881))
- **Go build cache trim:** when home disk runs low, the workspace deletes Go build cache entries
  unused for a day, oldest first. It can be turned off in Settings → Machine, and the reclaim list
  shows what the last trim freed. ([#4560](https://github.com/k-k1/agent-fleet/issues/4560))
- **gitleaks** is installed in the workspace image.
  ([#4904](https://github.com/k-k1/agent-fleet/issues/4904))

### Upgrade notes

- **Schedules written by sessions now wait for approval**, including those of the Fleet Operator.
  Existing schedules keep running.
- **A memo that waits for a run without a pull request** now needs that run's last answer to start
  with `Done:`. Ask the standing instruction of such a queue to end with a `Done:` line.
- **Web Push is off until an operator switches it on:** set the VAPID key and contact
  (`AF_WEB_PUSH*`, or `WebPush=on` and its parameters on ECS); see the operator guide's "Switch on
  Web Push".

Agent CLI pins: Antigravity 1.5.15, and gitleaks 8.30.1 is new (the rest unchanged from 0.48.0).
