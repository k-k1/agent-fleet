`native` ランタイムで Claude セッションが入力を一切受け付けなくなる不具合の hotfix
リリースです。あわせて配布リポジトリのドキュメントを大幅に充実させました。

### 修正

- **Claude セッションが入力を一切受け付けない（native）。** `git credential` の
  プロンプトが pty を占有し、エージェントへ向けた打鍵をすべて横取りすることがありました。
  ワークスペースで対話的な資格情報プロンプトを無効化し（`GIT_TERMINAL_PROMPT=0` /
  `GCM_INTERACTIVE=never`）、原理的に起こらないようにしました。GitHub アカウントを
  接続していない場合に該当し、すべてのデプロイ形態で踏み得ました。
- **初回起動時の一過性のダウンロード失敗が自己修復するようになりました。** boot-install と
  CLI のオンデマンド取得が再試行するようになり（`curl --retry`）、ワークスペースが
  中途半端な状態で残らなくなりました。
- 初回 `boot-install` の進捗を `af start` のターミナルへ転写するようにしました。回線が
  遅いときに、出力が何も出ないまま固まったように見えることがなくなります。
- `run-dev.sh reset` が Go モジュールキャッシュで "Permission denied" になる問題を
  修正しました。

### 新機能

- **ワークスペース起動中の進捗ダイアログ。** `GET /api/workspace` が boot-install の
  フェーズを公開し、Console が起動中にそれを表示します。停止中ワークスペースへの
  無駄なポーリングも停止しました。

### 改善

- dist リポジトリの README に Getting Started、機能一覧、アンインストール／データ消去の
  手順を追加し、**日本語版（`README.ja.md`）**を用意しました。
- インストーラの完了メッセージと同梱 README に、音声読み上げ（TTS）の利用手順への
  導線を追記しました。
