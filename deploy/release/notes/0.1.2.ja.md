`native` ランタイムで Claude セッションが入力をまったく受け付けなくなる問題の
hotfix です。

### Fixed

- **Claude セッションが入力をまったく受け付けませんでした（native）。**
  `git credential` のプロンプトが pty を奪い、エージェント宛のキー入力をすべて
  飲み込むことがありました。GitHub アカウントを接続していない人は、どのデプロイでも
  影響を受けました。
- **初回起動中のダウンロード失敗で Workspace が中途半端なまま残らなくなりました** —
  boot-install と CLI の随時ダウンロードが再試行します。
- 最初の `boot-install` の進捗を `af start` のターミナルに流すようにしました。初回
  起動が遅いときに、出力の無いハングに見えなくなります。

### New

- **Workspace 起動中の進捗ダイアログ** — boot-install がどの段階かを表示します。

### Improved

- dist リポジトリの README に Getting Started・機能一覧・アンインストール手順を
  追加し、日本語訳（`README.ja.md`）を用意しました。
