A rebuild that removes an internal string the Console bundle had been carrying,
plus the gate that will keep it from happening again. **The downloads for 0.1.0
through 0.5.0 have been withdrawn — please use this release instead.**

### Fixed

- **The Console bundle carried a source comment verbatim.** A theme stylesheet is
  imported as raw text so it can be handed to the slide renderer, which puts the
  whole file — comment header included — into the bundle as a string literal.
  Minification does not touch the inside of a string literal, so a comment that
  named something this project had removed from its sources shipped intact inside
  the control-plane image and the native tarball of every release from 0.1.0 to
  0.5.0. The comment is gone, and this release is built from the cleaned tree.

  No credentials, no keys and no user data were ever involved. If you have a copy
  of an earlier release, replacing it with 0.5.1 is enough.

### Improved

- **Every artifact is now checked before it can be published.** A release gate
  expands each tarball we build — recursively, down to the individual filesystem
  layers inside the air-gap image tar — and fails the publish if any byte of any
  of them contains a string this project has removed from its history. It runs on
  every release-gate build as well, and CI checks the sources on each run. The
  fault above could not have been caught by looking at the sources, because the
  bundler was the thing putting the text there; only reading the artifact finds it.
- **Branches and tags in the commit graph** are shown as one collapsed group with
  icons instead of a wide row of labels.

### Fixed (also)

- **Sessions replied in the wrong language.** With the reply language left on
  *auto*, an English Console still got Japanese answers, because the underlying
  default was Japanese rather than neutral. *auto* now follows the display
  language.

### Upgrade notes

Nothing to migrate and no configuration change: 0.5.1 is 0.5.0 plus the items
above. Install or update with the usual one-liner. The release pages for
0.1.0–0.5.0 are kept as a record of what shipped, but their downloads are gone.
