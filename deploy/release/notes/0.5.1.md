A rebuild that removes an internal string the Console bundle had been carrying, plus
the gate that will keep it from happening again. **The downloads for 0.1.0 through
0.5.0 have been withdrawn — please use this release instead.**

### Fixed

- **The Console bundle carried a source comment verbatim.** A theme stylesheet is
  imported as raw text so it can be handed to the slide renderer, which puts the whole
  file — comment header included — into the bundle as a string literal, where
  minification leaves it intact. It shipped inside the control-plane image and the
  native tarball of every release from 0.1.0 to 0.5.0. No credentials, keys or user
  data were involved; replacing an earlier copy with 0.5.1 is enough.
- **Sessions replied in the wrong language.** With the reply language left on *auto*,
  an English Console still got Japanese answers; *auto* now follows the display
  language.

### Improved

- **Every artifact is now checked before it can be published.** A release gate expands
  each tarball we build — recursively, down to the individual filesystem layers inside
  the image tar — and fails the publish if any byte contains a string this project has
  removed from its history. Reading the sources could not have caught the fault above,
  because the bundler was the thing putting the text there.
- **Branches and tags in the commit graph** are shown as one collapsed group with icons
  instead of a wide row of labels.

### Upgrade notes

Nothing to do: 0.5.1 is 0.5.0 plus the items above. Install or update with the usual
one-liner. The release pages for 0.1.0–0.5.0 are kept as a record of what shipped, but
their downloads are gone.
