AWS へのデプロイを一通り立ち上げる中で見つかった不具合をまとめた保守リリースです。ECS では
読み上げがそもそも一度も動いておらず、コントロールプレーンより後に作られたワークスペースには
到達できず、新しいデプロイが最初に見せる 2 つの画面——はじめかたガイドと、ワークスペースが
起動できない理由——が空白でした。Bitbucket は ECS でも接続できるようになります。

### Fixed

- **コントロールプレーンより後に作られたワークスペースに到達できませんでした。** ワークスペースは
  正常に動いているのに、セッション・リポジトリ・ファイルツリー・ツールのバージョン・チャットなど、
  ワークスペースを読む Console の面がすべて 502 になります。原因は AWS Service Connect の性質で、
  クライアント別名は DNS ではなく、**タスク起動時に ECS エージェントがタスクの `/etc/hosts` へ
  書き込む 1 行**です。そのため、後から名前空間に増えたサービスは、すでに動いているタスクからは
  見えません。時間でもワークスペースの再起動でも直らず、コントロールプレーンのタスクを差し替えた
  ときだけ直ります。実際には **新しいデプロイの最初のワークスペースと、新しく入ったメンバーの
  初回ワークスペース**が、誰かがコントロールプレーンを再起動するまで使えない状態でした。別名を
  解決できないときは Cloud Map で引き直すようにしました。
- **ECS では読み上げが必ず失敗していました。** コントロールプレーンはタスクロールで Amazon Polly
  を呼びますが、そのロールに `polly:SynthesizeSpeech` が与えられておらず、毎回 502 になっていました。
  失敗の仕方が悪く、リージョンが設定されているだけでプロバイダが「使える」と申告するため、Console
  は再生を提供し続け、押したときにだけ失敗していました。
- **読み上げ中に表示される声が、実際に喋っていないキャラクターの名前になることがありました。**
  エンジンが「自動」のとき、どこで合成するかを決めるのはコントロールプレーンですが、Console は
  設定だけを見てラベルを出していました。そのため VOICEVOX エンジンを持たないデプロイでは、Polly が
  読んでいるのに VOICEVOX のキャラクター名が出ます。そのキャラクター向けの音量調整も、同じ誤った
  判断で適用されていました。
- **ワークスペースを起動できないとき、何も表示されませんでした。** 理由は返ってきているのに捨てて
  おり、ボタンが一瞬「起動中」になって「不明」に戻るだけでした。原因がそれである場合、状態は
  「不明」ではなく**「未所属」**と表示され、次にすることがツールチップに出ます。起動の失敗は
  理由とともに通知されるようになりました。
- **はじめかたガイドが新規ユーザーに一度も出ませんでした。** 端末ペインの空状態に置かれていましたが、
  新規ユーザーの Console はペインが 1 枚も無い状態で開くため、**このガイドが存在する唯一の相手にだけ
  出ていませんでした**。

### New

- **ECS でも Bitbucket を接続できます。** OAuth コンシューマーの Key と Secret を CloudFormation の
  デプロイへ渡す方法が無く、その構成では email + API トークンの貼り付けしか選べませんでした。
  `BitbucketOauthKey` を設定し、Secret を `<SsmPrefix>/bitbucket-oauth-secret` に置いてください。
  コンシューマーのコールバック URL は
  `https://<あなたの FQDN>/api/oauth/bitbucket/callback` と完全に一致している必要があります。

### Improved

- VOICEVOX 向けの設定——話者・キャラクター一覧・感情スタイル・助詞の小休止・英語のカタカナ読み——は、
  VOICEVOX エンジンを持たないデプロイでは表示しなくなりました（選べても効かない設定でした）。
  エンジンの選択肢からも外れ、管理者のエンジン切り替えは操作できる見た目のままにせず、理由を添えて
  「無効」で固定されます。

### Upgrade notes

移行作業はありません。修正のうち 2 件はイメージではなく CloudFormation テンプレート側にあるため、
ECS のデプロイではタグの更新に加えてスタックの再デプロイが必要です。

- `20-platform` がコントロールプレーンに `polly:SynthesizeSpeech` を与えます。再デプロイしなければ、
  この版でも読み上げは壊れたままです。IAM だけの変更なので、走っているタスクは再起動なしで拾います。
- `30-ingress` に `BitbucketOauthKey`（任意）が増えました。
- README の構築手順で、`Transform: AWS::LanguageExtensions` を宣言している `10-data` に
  `--capabilities CAPABILITY_AUTO_EXPAND` が抜けていました。手順どおりに実行すると
  `Requires capabilities` で失敗します。
