0.20.0 で本番配備に出た障害への修正が 2 件です。左ペインのセッション行が 5xx 応答を
受けると全消えして戻らない問題と、設定 → Git ホスティングの読み込みが完了しない問題を
直しました。

### Fixed

- **5xx 応答を受けると、セッション行が全消えして自力では戻りませんでした。** `api()` は
  5xx で throw せずエラーオブジェクトを返すため、sessions ストアが「空の一覧」として
  扱い、レールが真っ白になっていました。push 接続が健全な間はポーリングが止まり、再接続
  時も whoami しか再取得しないため復帰しませんでした。ブラウザの再読込で即座に復元できます。
- **設定 → Git ホスティングの読み込みが完了せず、`/connections` リクエスト全体が
  ロードバランサーの 60 秒タイムアウトで切られることがありました。** agent がリクエスト
  のたびに `claude auth status` をタイムアウト無しで同期実行しており、この CLI は実測
  21〜28 秒かかっていました。同じコンフィグディレクトリを共有する他の Claude セッションと
  ファイルロックを競合するためです。修正ではプローブを非同期で走らせ、時間内に答えが
  来なければ直前の結果を返し、遅れた答えは次のポーリングで届けます。

### Upgrade notes

ECS 配備自体にやることはありません——コントロールプレーンのイメージを更新するだけで
Console の修正は届きます。

**agent の修正を受け取るには、ワークスペースの利用者全員がワークスペースを再起動する
必要があります。** 更新の前後を問わず走っていたワークスペースは旧版の agent バイナリの
ままで、Console に「再起動が必要」のバッジが出ます。
