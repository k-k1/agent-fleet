Follow-up prompts can wait in a per-session queue while a turn runs, folders download as zip,
and the Console terminal copies and pastes with Ctrl+C and Ctrl+V. Agent Fleet memory takes over
from claude's own memory while it is on, and can be written back to it. Expiring GitHub App and
Google Cloud tokens renew themselves, and Chromium works on ecs-ec2 workspaces.

### New

- **Waiting to send.** While a turn runs, the arrow beside Send (or Alt+Enter) offers **Add to
  waiting list**. Held prompts can be edited, reordered, deleted or sent now, and go out one at a time
  when the session is idle. Stopping the turn pauses the queue. The queue lives in this browser tab
  and is dropped on reload.
  ([#1083](https://github.com/k-k1/agent-fleet/issues/1083))
- **Download a folder as zip** from the folder menu of the Files tree and the image gallery (long-press
  on touch screens). `.git` and `node_modules` inside the folder are left out, and a toast says what
  else was skipped.
  ([#1829](https://github.com/k-k1/agent-fleet/issues/1829))
- **Ctrl+C / Ctrl+V copy and paste in the terminal.** Ctrl+C copies a selection you made; with nothing
  selected it still interrupts the program. Turn it off in Settings › Display.
  ([#1708](https://github.com/k-k1/agent-fleet/issues/1708))
- **Assume a role from another profile** is a new type in Settings › AWS profiles/SSM. It uses an SSO
  profile's sign-in to assume an IAM role, so no long-lived keys are needed, and works with
  `af-aws-exec` and SSM sessions.
  ([#1109](https://github.com/k-k1/agent-fleet/issues/1109))
- **Write Agent Fleet memory back to Claude Code.** Settings › Agent memory › **Write back to Claude
  Code** previews and copies a project's memories into claude's own memory, for when you turn Agent
  Fleet memory off.
  ([#1914](https://github.com/k-k1/agent-fleet/issues/1914))
- **Pinned memories.** Settings › Agent memory lets you pin memories so `memory_index` always lists
  them first; the rest are ranked by how often sessions read them.
  ([#1703](https://github.com/k-k1/agent-fleet/issues/1703))
- **A child session can share its parent's working copy.** `create_session` accepts
  `allow_shared_working_copy` to start a child in the parent's own checkout instead of refusing.
  ([#1826](https://github.com/k-k1/agent-fleet/issues/1826))

### Improved

- **Agent Fleet memory replaces claude's own memory while it is on.** New claude sessions neither load
  nor write claude's native memory, and every agent kind is told how to use the memory tools. Memory
  names, descriptions and bodies now hold anything claude's memory holds, so imports are no longer
  shortened.
  ([#1734](https://github.com/k-k1/agent-fleet/issues/1734),
  [#1733](https://github.com/k-k1/agent-fleet/issues/1733),
  [#1921](https://github.com/k-k1/agent-fleet/issues/1921))
- **A folded repository in the left pane shows its newest session**: its title and state appear in the
  repository row, and the running-count badge's tooltip lists the other live sessions.
  ([#1915](https://github.com/k-k1/agent-fleet/issues/1915))
- **The command palette groups child sessions under their parent**, and a child found by a search shows
  its parent's name.
  ([#1887](https://github.com/k-k1/agent-fleet/issues/1887))
- **More ticket references link.** Jira keys of any project on your Jira connection link in the mirror,
  a Jira issue or Bitbucket PR that is not in your inbox is read live when opened, and `#N` in a
  Markdown file's preview links against that file's repository, including both ends of a range like
  `#573-#598`.
  ([#1899](https://github.com/k-k1/agent-fleet/issues/1899),
  [#1661](https://github.com/k-k1/agent-fleet/issues/1661),
  [#1900](https://github.com/k-k1/agent-fleet/issues/1900),
  [#1909](https://github.com/k-k1/agent-fleet/issues/1909))
- **Expiring GitHub App tokens renew themselves.** A GitHub App can keep "Expire user authorization
  tokens" on; clones and pushes keep working after the 8-hour expiry without reconnecting.
  ([#1676](https://github.com/k-k1/agent-fleet/issues/1676))
- **Google Cloud profiles**: **Log out** is available in Settings › Google Cloud and the WS bar, and
  `af-gcloud-exec` renews its token while a long command runs. Programs that read the token only once
  at start, such as Terraform, do not see the renewal yet
  ([#1879](https://github.com/k-k1/agent-fleet/issues/1879)).
  ([#1850](https://github.com/k-k1/agent-fleet/issues/1850),
  [#1488](https://github.com/k-k1/agent-fleet/issues/1488))
- **`af-aws-exec` and `af-gcloud-exec` at your own terminal ask the Console for the login**, as they
  already did for agents, and wait up to 10 minutes. `--login` still logs in at the terminal.
  ([#1512](https://github.com/k-k1/agent-fleet/issues/1512))
- **The default GitHub work-item query names the type** (`is:issue OR is:pull-request`), so accounts
  that need one no longer pay for a retry on every refresh. Saved queries are unchanged.
  ([#1715](https://github.com/k-k1/agent-fleet/issues/1715))
- **The WS bar's Muse Code usage menu links to Meta's usage page**, as Claude and Codex do.
  ([#1892](https://github.com/k-k1/agent-fleet/issues/1892))

### Fixed

- **Chromium failed on ecs-ec2 workspaces** although browser features were offered. It works on
  ecs-ec2 now; on `ecs` (Fargate), where it cannot run, the Console greys the browser features out and
  says why.
  ([#1927](https://github.com/k-k1/agent-fleet/issues/1927))
- **The Remote control toggle had no effect**: claude sessions never connected to Remote Control. While
  the toggle is on, newly started claude sessions can connect; telemetry, error reports and
  auto-update stay off.
  ([#1254](https://github.com/k-k1/agent-fleet/issues/1254))
- **A leftover git `index.lock` blocked fast-forward for good.** When the lock is stale, the Console
  now offers to remove it and retries, and the agent's own status checks no longer take the lock.
  ([#1930](https://github.com/k-k1/agent-fleet/issues/1930))
- **`create_session` ignored arguments it did not know**, so `prompt` instead of `initial_prompt`
  started an idle child. Unknown or mistyped arguments to af MCP tools are now refused with an error
  that suggests the right name.
  ([#1905](https://github.com/k-k1/agent-fleet/issues/1905))
- **An unclosed `<a>` or other formatting tag in Markdown** made every following paragraph render as a
  link (or bold, italic, and so on). Such a tag now shows as text, and `<marquee>` is no longer
  rendered.
  ([#1846](https://github.com/k-k1/agent-fleet/issues/1846),
  [#1853](https://github.com/k-k1/agent-fleet/issues/1853),
  [#1876](https://github.com/k-k1/agent-fleet/issues/1876))
- **A command Antigravity ran in the background did not keep the workspace awake**, so idle auto-stop
  could stop it mid-run.
  ([#1825](https://github.com/k-k1/agent-fleet/issues/1825))
- **Command palette**: reopening it highlighted the previously chosen session instead of the first row,
  and a Conversations hit older than the loaded part of the conversation landed at its end.
  ([#1886](https://github.com/k-k1/agent-fleet/issues/1886),
  [#1663](https://github.com/k-k1/agent-fleet/issues/1663))
- **A member's detail offered "Delete this member" while their workspace still existed** (for example
  on ecs-ec2 after Clean home), and the delete was refused. It now offers **Destroy workspace** first.
  ([#1888](https://github.com/k-k1/agent-fleet/issues/1888))
- **Submitting a cloud login code could report an error** although the code had been delivered.
  ([#1885](https://github.com/k-k1/agent-fleet/issues/1885))
- **On a phone, the WS bar could be wider than the screen.** Its pane buttons now move into the ⋯
  menu when space runs out.
  ([#1650](https://github.com/k-k1/agent-fleet/issues/1650))

### Upgrade notes

- **Agent Fleet memory**: if "Let sessions use Agent Fleet memory" is on, claude sessions started
  after the upgrade no longer read claude's own memory. Run **Import from Claude Code** once more first
  so nothing claude learned since the last import is left behind. Sessions that are running keep their
  launch settings.
- **ecs-ec2**: each workspace picks up the browser change on its next Start. Update the stack and
  replace slots launched before it, as the ECS runbook describes, to apply the matching slot hardening.
