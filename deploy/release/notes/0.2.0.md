The largest release so far: sessions can now be driven from Discord and Slack,
prompts can run on a schedule, Cursor CLI joins the lineup, Subversion working
copies are supported, and the `native` host binary updates itself.

### New

- **Chat bridge for Discord and Slack** — each session gets its own thread, with
  five independently toggleable notification kinds (reply ready / question, plan
  approval, permission request, abnormal exit, completion report). Replying in the
  thread steers the session (all agent kinds, both Terminal and Managed execution,
  opt-in). Questions, plan approvals and permission requests can be answered with
  buttons. An optional full-transcript mode automatically redacts secrets and splits
  long messages. Mentioning the bot opens a fleet-operator conversation — the same
  conversation you see in the Console. Destructive operations requested over chat go
  through an approval gate that fails closed. Connecting is a token-paste wizard
  (Discord: a bot token; Slack: `xoxb` + `xapp` in Socket Mode). In the Console this
  lives under *Connections › Chat*, with a per-service master on/off under
  *Personal settings › Notifications*.
- **Scheduled execution** — ask the fleet operator in plain language to register a
  schedule (cron / interval / once, timezone and DST aware). A stopped workspace is
  woken to run and returned to its previous state afterwards; failures (wake,
  injection, quota, membership) surface in the Control Plane notification centre. A
  *Schedules* section in the left rail lists schedules and the last 50 runs, and
  offers pause / resume / run-now / delete. The scheduler is **on by default**
  (opt out with `AF_SCHEDULER_INTERVAL=0`). Long-lived sessions can be reused
  (`session_mode=reuse`) with pinning and rotation policies.
- **Cursor CLI support (`kind=cursor`)** — brings the total to six agent CLIs. Sign-in
  is login-only (browser approval, no code pasting), both Terminal and Managed
  (`cursor-agent acp`, the default) execution methods work, the model catalogue is
  fetched live for the signed-in account, and the CLI version is pinned with both of
  its self-update paths disabled. On a Free plan the model picker narrows to Auto +
  Composer, matching what the account can actually use.
- **Subversion checkout** — check out an SVN URL with basic auth (passed over stdin,
  auth cache disabled), including sub-path and multi-path checkouts. Credentials can
  optionally be stored in the encrypted store and are reused by longest-prefix match.
  Self-signed certificates can be trusted per server (opt-in). Working-copy locks
  self-heal (`cleanup` + retry) and there is an explicit "release lock" action. SVN
  working copies start in place — worktrees do not apply, so isolate concurrent work
  by checking out separate paths.
- **Automatic updates for the host `af` binary (native)** — a daily systemd user
  timer stages the latest release (`af update`, sha256-verified, on by default), and
  you apply it explicitly from *Settings › Environment* ("restart and apply") or by
  restarting manually, so running sessions are never cut off unexpectedly. Pin with
  `AF_VERSION` to stop it entirely.

### Improved

- **GitHub Copilot CLI** gained model selection from a live catalogue, and a usage
  chip with plan information in the workspace bar.
- **Consistent agent naming and colours** — a single three-tier naming scheme
  (short / label / display name) with the registry as the source of truth, and kind
  colours defined once as CSS custom properties.
- **The settings modal was reorganised** from ten flat tabs into three groups in a
  left rail, separating connections from behaviour and unifying confirmation dialogs.
- **Console-to-Control-Plane traffic was cut substantially** — gzip and immutable
  caching, ETag/304 revalidation, WebSocket permessage-deflate, and a single
  server-sent-events stream (`/api/events`) replacing four standing pollers, which
  now only act as a fallback.
- **Mirror robustness** — scroll following is honest about the current position, the
  initial position settles at the bottom, a sticky "jump to latest" button was added,
  the blank gap before a reply rendered is gone, the "waiting" state after sending a
  slash command clears, and the image lightbox responds to the browser Back button.
- Keyboard: the notification toggles were regrouped under `n` (voice, Slack, Discord,
  limit reset) with a state toast.
- Shell and SSM sessions: connections are named by alias plus timestamp, the
  connection modal shows quick-connect cards ranked by frequency, and the leader key
  can be passed through to the terminal (`Ctrl+K` / `Ctrl+P`, off by default).
- The launch modal accepts image attachments from a phone, and the left pane refreshes
  immediately after a cleanup.
- **The user guide is now bilingual** — English is canonical (`.md`) with Japanese
  alongside (`.ja.md`).
- The appearance popover gained a details button.

### Fixed

- **A plan rejection was being recorded as an approval.** Rejecting now interrupts the
  session as intended.
- Remote Control now defaults to off (applied once to existing workspaces too).
- The Chromium pin was moved forward because Debian purged the previous build from its
  mirrors, which had made the image unbuildable.

### Other changes

- `install-compose.sh` was added as a fetch helper for the Compose distribution.
- AWS (ECS / CloudFormation, EC2-Single) is no longer surfaced in the public README.
  The `aws/` tree is still bundled in the Compose artifact, unchanged.
