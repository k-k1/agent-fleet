The largest release so far: sessions can be driven from Discord and Slack, prompts can
run on a schedule, Cursor CLI joins the lineup, Subversion working copies are
supported, and the `native` host binary updates itself.

### New

- **Chat bridge for Discord and Slack.** Each session gets its own thread; replying in
  it steers the session, and questions, plan approvals and permission requests can be
  answered with buttons. Five notification kinds toggle independently, and mentioning
  the bot opens the same fleet-operator conversation you see in the Console. Opt-in,
  under *Connections › Chat*.
- **Scheduled execution.** Ask the fleet operator in plain language to register a cron,
  interval or one-off schedule; a stopped workspace is woken to run it and returned to
  its previous state afterwards. A *Schedules* section lists them with the last 50 runs.
  On by default (`AF_SCHEDULER_INTERVAL=0` opts out).
- **Cursor CLI support** brings the lineup to six — browser sign-in, both execution
  methods, a live model catalogue, and a pinned CLI version.
- **Subversion checkout.** Check out an SVN URL with basic auth, including sub-path and
  multi-path checkouts, with optional credential storage and per-server trust for
  self-signed certificates. Worktrees do not apply to SVN — isolate concurrent work by
  checking out separate paths.
- **Automatic updates for the host `af` binary (native).** A daily timer stages the
  latest release; you apply it explicitly from *Settings › Environment*, so running
  sessions are never cut off. `AF_VERSION` pins it.

### Improved

- **GitHub Copilot CLI** gained model selection from a live catalogue and a usage chip.
- **Console-to-Control-Plane traffic was cut substantially** — gzip, ETag
  revalidation, and a single server-sent-events stream replacing four standing pollers.
- **The settings modal was reorganised** from ten flat tabs into three groups.
- **The user guide is now bilingual**, and agent naming and kind colours come from one
  registry instead of being defined per screen.
- Mirror: honest scroll following, a sticky "jump to latest" button, no blank gap
  before a reply, and the image lightbox responds to the browser Back button.
- Smaller: notification toggles regrouped under `n`, quick-connect cards for shell and
  SSM sessions, leader-key pass-through, and image attachments in the launch modal.

### Fixed

- **A plan rejection was being recorded as an approval.** Rejecting now interrupts the
  session as intended.
- Remote Control now defaults to off, applied once to existing workspaces too.

### Other changes

- `install-compose.sh` was added as a fetch helper for the Compose distribution.
- AWS (ECS / CloudFormation, EC2-Single) is no longer surfaced in the public README.
  The `aws/` tree is still bundled in the Compose artifact, unchanged.
