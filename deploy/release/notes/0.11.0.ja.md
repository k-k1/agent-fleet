git の OAuth アプリをテナント管理者が自分で登録できるようになり、Control Plane を
Graviton で動かせるようになりました。「起動中」から進まなくなる、あるいは黙って費用が
かかり続ける `ecs-ec2` の不具合もまとめて直しています。

### New

- **git の OAuth アプリをテナント管理者が登録します。** 「OAuth で接続」が使うアプリは
  デプロイに 1 つで、運用者が環境変数で設定するものでした。しかしアプリが置かれるのは
  テナント自身の GitHub org / Bitbucket ワークスペースです。これをテナントの設定にし、
  あわせて Bitbucket のトークン更新を Control Plane で回すようにしたので、テナントの
  client secret が全メンバーのワークスペースに複製されることもなくなりました。
  **環境変数はもう読みません** — Upgrade notes を参照してください。
- **Control Plane のイメージを x86_64 と arm64 の両方で出します。** どちらで動かすかは
  `CpArch` で選びます。workspace のイメージは x86_64 のみのままなので、Graviton の
  スロットには引き続き自前でビルドした arm64 の workspace イメージが要ります。
- **毎日使う操作に Alt の直キーを足しました。** リーダーの和音と併存します：タブ／ペインを
  閉じる、全部閉じる、はじめる、メモ、作業グループ、読み上げ、レールの絞り込み、設定、
  前後のタブ。文字サイズは `Alt+=` / `Alt+-` / `Alt+0` で、アクティブなペインが属する面に
  効きます。
- **golden スナップショットを焼いている最中が、管理画面のプール画面に出ます。** いまどの段
  なのか、始めてからの経過、候補の進捗、予約 workspace が押さえているスロットが見えます。
  焼いていないときはその理由（空きスロット待ち・2 回失敗して打ち切り・自動焼きが OFF）を
  述べます。

### Improved

- 学習済みの返信候補から「1 回だけの候補」をまとめて消せます。常用の候補とピン留めは
  残ります。
- `ecs-ec2` の配備を立てる・眠らせる・畳む操作をスクリプトにしました（`deploy/aws/ecs/`）。
  対象の配備は AWS プロファイルで指します。手順書を手で追う必要はありません。

### Fixed

- **Antigravity のセッションが、選んだモデルとは別のモデルで動くこと**があり、そのまま
  課金されていました。知らせは CLI の画面の中の 1 行だけです。ピンを 1.1.19 へ上げ、
  自己更新がピンを追い越さないようにし、モデル一覧の新旧どちらの形式も解釈します。
- **`ecs-ec2` の空きスロットが眠りませんでした。** 立ち退き・サイズ変更・破棄などで
  workspace を失ったスロットは、アイドルのマシンを止めるスイープの対象から外れ、使用中と
  同じ料金のまま起動し続けていました。`Ec2SlotSleepSec=0` は説明文どおり「眠らせない」に
  なりました。
- **メンバーのマシン種別を変えると、その人の Workspace が二度と起動しなくなること**が
  ありました。メンバーの設定は、保存できているのに保存できていないように見えてもいました。
  名簿には各メンバーが何で動いているかを出します。
- **「起動中」から進まない Workspace を Console から停止できず、理由も分かりませんでした。**
  永久に配置を拒否される場合があり、そこから抜ける経路が無いうえ、電源の操作は「起動」しか
  示していませんでした。停止できるようになり、理由も画面に出ます。
- **Control Plane を再起動すると、ワークスペースを起動し直すまで 3 つが壊れていました**：
  Bitbucket の OAuth 接続の保存、`af_*` ツール全部、そして通知（オフラインと報告されて
  いました）。
- **0.10.0 を新規に `ecs-ec2` へ配備すると、スロットプールのスタックが必ず最後の段で
  ロールバック**していました。
- **他セッションの ToDo 帯がミラーの上に固着し**、ペインがセッションを持ち替えるたびに
  1 枚ずつ積み上がっていました。
- **スマホでミラーをピンチズームすると、コンポーザーが画面の中ほどに貼り付き**、読みたい
  位置へパンしても引き戻されていました。
- `ecs-ec2` の細かい修正：golden スナップショットが別アーキの候補から焼かれることがあり、
  管理画面が起動中の Workspace をアイドルと表示することがありました。

### Upgrade notes

**git の OAuth アプリは、テナントごとに登録し直しが要ります。** ワークスペースの
`GITHUB_OAUTH_CLIENT_ID` と、Control Plane の `BITBUCKET_OAUTH_KEY` /
`BITBUCKET_OAUTH_SECRET` はもう読みません（フォールバックにもしません）。テナント管理者が
テナントの設定でアプリを入れるまで、「OAuth で接続」は出ません。（`GITHUB_OAUTH_CLIENT_ID`
のもう一つの役目＝サインインはそのままです。）追加専用のマイグレーションが 1 本、
テーブルを足します。アップグレード時に既に起動していたワークスペースは、Bitbucket の
更新が効くまでに 1 度だけ「停止 → 起動」が要ります。設定の誤りに見えないよう、Control
Plane がその旨を表示します。

`ecs-ec2` では `30-ingress` に `CpArch` が加わりました（既定は `x86_64` なので、再デプロイ
しても何も動きません）。arm64 の AMI を渡さないとスロットプールのスタックが作成できない
問題も直っています。Control Plane のイメージはマニフェストリストになったため、ローカルの
`docker pull` / `docker tag` では運べません。自分のレジストリへ複製するときは `crane copy`
を使ってください。

エージェント CLI の固定版：Claude Code 2.1.241、OpenCode 1.18.21、Antigravity 1.1.19。
その他は 0.10.0 から変わりません。
