An image studio, where a session's agent rewrites the generation draft as you talk and a person
presses generate, and session deletion that always goes through the trash and never takes a
worktree with it. Around them, a cleanup for the cache deleted sessions leave behind, a view of
the disk Agent Fleet uses, translation for questions and peer messages, and selectable text in PDFs.

### New

- **Image studio.** The image generation pane's **Attach an agent** binds a session to the draft:
  ask it to read your material and "put her in a harbour at dusk", then "darker", and the agent
  rewrites the prompt, negative, steps, cfg, size, LoRAs and references. A person always presses
  generate. Fields can be locked, every edit is in a history you can rewind to, model, seed and
  mask stay yours alone, and **Switch agent** rebinds the studio without losing the draft. claude
  and copilot, cursor and kiro attach as Terminal (CLI) only, opencode not as Managed, and Muse
  Code not yet.
- **Deleting a session always goes to the trash, and can be undone.** Shell and SSM sessions
  deleted from a row, a bulk tidy-up or a working-copy delete now land in the trash as AI sessions
  do. **Deleting a session no longer deletes its worktree**; deleting a worktree moves its
  stopped sessions to the archive. The trash tab gains **Delete permanently: older than 30 days**
  — the trash never empties on its own.
- **The cleanup dialog clears the cache of deleted sessions** — pasted images and images codex
  read — once nothing refers to them any more. **Settings › Machine** shows the disk Agent Fleet
  uses, with each folder's path; a path opens in the file tree, and an image folder in the
  gallery.
- **Questions, answered questions and messages from other sessions have a Translate button**
  when they came in another language. Only the display is translated; answers are matched
  against the original.
- **Text in a PDF can be selected and copied.**
- **Release history in the user guide.** The guide carries every release's notes and this
  index, and the builtin assistants can answer "what changed in which version" from them (in a
  new conversation).

### Improved

- **A session can run up to 10 children at once** (was 6); the default stays 3.
- **Settings › Notifications › Notify when a child session is waiting for input** can be turned
  off. Questions and approvals from a child still notify.
- **Thinking blocks take less room:** a collapsed one is a single line with a preview, and the
  close bar appears only on long ones.
- **A pasted image chip opens in the lightbox** in the mirror's composer and the launch dialog.
- **Long file names in the left pane are shortened in the middle**, keeping the extension and
  the end of the name, and the tooltip shows the full path.

### Fixed

- **The fleet operator and SRE assistant on Antigravity answered "no response from agy"**
  whenever the model tried a command or read its reference material. They now answer, a
  refused command is declined in words, and when agy does fail its reason is shown.
- **Opening the thumbnail cache folder in the gallery kept making thumbnails of thumbnails.**
