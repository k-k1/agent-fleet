設定の AWS のプロファイルがワークスペースの AWS CLI・SDK・ビルドツールから使えるようになり、
ログインが要るときは Console が知らせます。消した worktree はごみ箱に入り、未コミットの変更ごと
同じパスに戻せます。対応が要るセッションが目立つようになり、**Alt+U** で次へ移れます。画像の
スタジオはスマホで使え、リポジトリの行から始められ、いくつも並べて使えます。モデルの選択肢には
API 定価・コンテキスト長・廃止予定が出ます。

この版から、不具合と要望は GitHub の Issue（<https://github.com/k-k1/agent-fleet/issues>）で
管理しています。報告は配布用リポジトリではなくこちらへお願いします。以下の各項目の末尾には、
元になった Issue の番号を付けています。

### New

- **設定 › AWS SSM のプロファイルが AWS CLI・SDK・ビルドツールから使えます。** `~/.aws/config`
  に書き出され、`af-aws-exec --profile <名前> -- <コマンド>` でワークスペース自身の AWS の身元では
  なく、あなたとしてコマンドを実行します。ログインが切れていると Console のトーストがログインを
  求めます。デバイスコードは押したときにだけ発行され、エージェントは 1 分半ほど待ちます。
  ([#998](https://github.com/k-k1/agent-fleet/issues/998),
  [#1026](https://github.com/k-k1/agent-fleet/issues/1026),
  [#1036](https://github.com/k-k1/agent-fleet/issues/1036))
- **worktree の削除を元に戻せます。** 削除はブランチと未コミットの変更ごとごみ箱に入り、戻すと
  同じパスに worktree を作り直し、変更をステージしない状態で戻し、中のセッションをアーカイブから
  戻します。この版より前に消した worktree は、アーカイブの**作業コピーを作り直す**でブランチから
  作り直せます。
  ([#1040](https://github.com/k-k1/agent-fleet/issues/1040),
  [#1042](https://github.com/k-k1/agent-fleet/issues/1042))
- **対応が要るセッションが目立ち、Alt+U で次へ移れます。** 質問・計画の承認・許可の要求がある
  行は琥珀色の枠で、ペインは琥珀色の輪で囲まれます。未読の行はタイトルが太字になります。
  **Alt+U** は回答待ちのセッション、次に未読のセッションの順にたどります。通知は、それが指す先が
  画面に出た時点で既読になるようになりました。報告は、その会話を開くまで未読に残ります。
  ([#1057](https://github.com/k-k1/agent-fleet/issues/1057))
- **モデルの選択肢に API 定価・コンテキスト長・廃止予定が出ます。** models.dev と codex 自身の
  情報で、廃止予定のモデルには日付と後継が付きます。API の定価で、サブスクリプションの請求額
  ではありません。cursor・Muse Code・llama.cpp と claude の段階名（エイリアス）には出ません。
  ([#1021](https://github.com/k-k1/agent-fleet/issues/1021))
- **ターミナル（CLI）のセッションでプログラムが出すデスクトップ通知**（OSC 9・99・777）が、
  通知センターと OS の通知に届きます。claude・codex・opencode はもともと自前のフックで知らせて
  います。
  ([#1058](https://github.com/k-k1/agent-fleet/issues/1058))
- **設定 › マシン › 使われなくなったファイル**で、もう誰も読まないファイルを消せます。残った
  ヘッドレス Chromium のプロファイル、どのセッションにも属さない `~/.af-work` のフォルダ、古くなった
  Node のパッチ版、古い Kiro です。Agent の起動時にも、古い Copilot・Cursor の版とあわせて消します。
  ([#1038](https://github.com/k-k1/agent-fleet/issues/1038),
  [#981](https://github.com/k-k1/agent-fleet/issues/981))
- **設定 › エージェント › セッション › 停止中セッションのアーカイブ**で、配備の既定ではなく自分の
  期間（1〜30 日、またはオフ）を選べます。
  ([#982](https://github.com/k-k1/agent-fleet/issues/982))
- **clip skip・FLUX の guidance・Anima の shift を指定できます。** スタジオ・カタログの行・
  `generate_image` から設定します。SDXL は ComfyUI がもともと最後から 2 番目の層で止めるので、
  絵が変わるのは 3 以上です。
  ([#1035](https://github.com/k-k1/agent-fleet/issues/1035))

### Improved

- **画像のスタジオがスマホで使え、リポジトリや worktree の行から始められ**（**画像スタジオを
  始める**）、**いくつものスタジオ**を並べて使えます。結果はスタジオごとに分かれます。狭いペインでは
  コンポーザーの上に下書きの帯が出て、サンプラーの設定は**詳細**に畳まれ、ライトボックスで結果を
  たどりながら**参照画像にする**・**この設定に戻す**を押せます。ペインは必ずスタジオを編集する
  ようになり、以前のペインの下書きは一度だけ新しいスタジオへ移ります。
  ([#1074](https://github.com/k-k1/agent-fleet/issues/1074))
- **課題管理の行にラベルがすべて、トラッカーの色で**優先度から並びます。取得した件数より多く
  一致したクエリはそう表示し、GitHub は 100 件まで取得し、**トラッカーで探す**で取りこぼした分も
  探せます。
  ([#993](https://github.com/k-k1/agent-fleet/issues/993),
  [#994](https://github.com/k-k1/agent-fleet/issues/994),
  [#1095](https://github.com/k-k1/agent-fleet/issues/1095))
- **管理画面とテナント設定が、前回閉じた場所で開きます。**
  ([#1100](https://github.com/k-k1/agent-fleet/issues/1100))
- **設定の同期に失敗すると設定画面に出て**、再試行できます。同じブラウザに別のアカウントが残した
  設定が、自分の設定に混ざらなくなりました。
  ([#1023](https://github.com/k-k1/agent-fleet/issues/1023))
- **llama.cpp のセッションは、引数を変えながら同じツールを呼び続けるモデルを止めます。**
  12 ターン目で警告し、20 ターン目で止めます。
  ([#953](https://github.com/k-k1/agent-fleet/issues/953))
- **小さな表示の改善:** 時間内に上がらないエンジンは ECS が返した理由を示します
  ([#967](https://github.com/k-k1/agent-fleet/issues/967))。アシスタントの設定が断られたときは
  理由を利用者の言語で示します ([#971](https://github.com/k-k1/agent-fleet/issues/971))。
  フリート俯瞰図でセッションを右クリックするとメニューが開きます。

### Upgrade notes

作業は不要です。`~/.aws/config` を自分で書いている場合、Agent がその末尾に自分用の区画を
書き足します。すでに使っているプロファイル名は上書きせず、飛ばしたプロファイルとその理由は
`af-aws-exec --list` が示します。

エージェント CLI のピン: Claude Code 2.1.283・Codex 0.157.1・Antigravity 1.2.11・
Cursor 2026.09.26-dd393fe・Kiro 2.24.1・Muse Code 1.4.0-R4161.1。Copilot と OpenCode は
0.23.2 から変わりません。
