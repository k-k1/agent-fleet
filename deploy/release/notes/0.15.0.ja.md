ワークスペースのイメージが Debian 13 になり、ファイル一覧がエージェントの作業に自分で
追随するようになり、AI 補助の設定が独立したタブになりました。新しいベースイメージに伴い
python が 3.11 から 3.13 に上がります（Upgrade notes 参照）。

### New

- **ファイル一覧が自分で更新されます。** FILES は、セッションが入力待ちに戻ったとき、
  走行中は低頻度で、タブに戻ったときに更新され、前に見たときから増えた行には目印が付きます。
  更新ボタンはそのまま残っています。
- **コマンドパレットがセッションから開きます。** `Ctrl`/`⌘`+`P` の先頭がセッション一覧になり、
  注目してほしい順に並びます。行にはリポジトリ・worktree・状態が出ます。
- **AI 補助の設定が独立したタブになりました。** タイトル・返信サジェスト・ブランチ名・
  ファイル編集の提案を 1 か所で設定でき、CLI の優先順位とモデルもアシスタントとは別に
  持ちます。ブランチ名とファイル編集の提案はオフにできるようになりました。読み上げの
  言語は回答言語の流用をやめ、独立した設定になりました。
- **設定 > ツールチェーンから node を導入できます**（JDK と同じ導線です）。未導入の版を
  選ぶと「インストール」ボタンが出ます。これまでは、選んでもワークスペースを再起動する
  まで何も起きず、その旨も出ませんでした。

### Improved

- **ワークスペースのイメージが Debian 13 (trixie) になりました。** chromium が新しくなり、
  git-delta が入りました。
- **アーキテクチャを変えても、自分で入れたものが入れ直されます。** `pip --user`・`uv` の
  ツール・グローバル導入の npm パッケージを、起動時に新しいアーキ用へ入れ直します。直せない
  もの（`~/repos` のビルド生成物、`~/.local/bin` の自前バイナリ）は通知センターに名指しで
  出るようになり、後日の `Exec format error` で気づく形ではなくなりました。
- **Codex / OpenCode の常駐サーバーが、そのエージェントにログインしていなければ起動しなく
  なりました。** 誰も使わない状態が数分続けば畳まれ、数百 MB がワークスペースに戻ります。
- **「作業を始める」で打った最初のプロンプトが、閉じても残ります。** リポジトリごとに保持し、
  セッションが実際に起動できたときだけ消えます。
- エージェントのサインインエラーが Console の言語に従うようになりました（英語 Console でも
  日本語が出ていました）。
- worktree の行のツールチップにディレクトリ名が出るようになり、右クリックメニューから
  起動ボタンと重複する項目を外しました。
- セッションの ⋯ メニューから「変更ファイル」を外しました。一覧そのものはミラーのヘッダ下の
  帯とコマンドパレットに残っています。

### Fixed

- **セッション間メッセージが有効なとき、Claude のセッションがターンを開始できないことが
  ありました。** ツールのスキーマが不完全なまま広告され、ターンの手前で要求が拒否されて
  いました。
- **添付が消えなくなりました。** 貼り付け／ドロップした画像が、起動モーダルを閉じても、
  セッションを持ち替えても、送信を断られても残ります。これまでは文章だけが戻り、画像は
  消えていました。
- **ファイルビュアーが読み位置を保つようになりました**（別のタブへ移って戻ったとき）。
  タブを切り替えたときに、ミラーの前に生の端末が一瞬映るのも直しました。
- **質問カードをキャンセルすると、コンポーザーから送信できなくなることがありました。**
  どこにも無いカードへの回答を求められる状態でした。
- **スマートフォンで画像をピンチズームして動かすと、別のセッションに切り替わっていました。**
- **ECS のすべての配備経路が止まっていました。** `cfn/30-ingress.yaml` が CloudFormation の
  51,200 バイト上限を超え、立ち上げも更新も失敗していました。テンプレートを上限の内側に
  戻し、超える場合はスクリプトが S3 経由に回します。
- **バックエンドの障害中に、アカウントメニューから管理系の項目が消えていました。**
  リロードするまで戻りませんでした。
- 未ログインで起動できなかったマネージドなセッションが「しばらく待ってから再試行して
  ください」と言っていました。何が問題なのかを言うようにしました。
- 改行をまたいで文字列を選ぶと、マーカーのピッカーが出ませんでした。
- 会話が消えている通知が行き止まりでした。報告元のセッションへ移動し、理由を伝えます。
- メモリの取り込みで、秘密スキャンの失敗が「秘密なし」と同じ画面になっていました。
- Codex が生成した画像を共有ファイルのプレビューから開けるようになりました。
- 運用まわりの細かい修正: 撤収がバケットを空にできなかった理由を出す、stand-up の preflight が
  控えのパラメータを現在のテンプレートと突き合わせる、控えが Output にしか無い値も保存する
  （立て直しで Elastic IP が孤児にならない）。

### Upgrade notes

**python が 3.11 から 3.13 に上がるため、`pip install --user` や `uv tool install` で入れた
ものは入れ直しが必要です。** 消えてはいません（`~/.local/lib/python3.11/site-packages` に
残ります）が、3.13 はそこを見ないため、`~/.local/bin` のランチャは起動だけして
`ModuleNotFoundError` になります。対象のパッケージ一覧と入れ直すコマンドは、ワークスペースの
起動ログに出ます。新しいイメージでの初回起動時に、すべてのワークスペースが 1 回だけ通る
ものです（自動で入れ直されるアーキテクチャ変更とは別の話です）。
