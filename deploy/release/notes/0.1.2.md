A hotfix for the `native` runtime, where Claude sessions could become completely
unable to accept input.

### Fixed

- **Claude sessions took no input at all (native).** A `git credential` prompt could
  seize the pty and swallow every keystroke meant for the agent. Anyone whose GitHub
  account was not connected was affected, on every deployment.
- **A transient download failure during first start no longer leaves the workspace
  half-provisioned** — boot-install and on-demand CLI downloads retry.
- The first `boot-install` progress is echoed into the `af start` terminal, so a slow
  first start no longer looks like a hang with no output.

### New

- **A progress dialog while the workspace starts**, showing the boot-install phase.

### Improved

- The dist repo README gained getting-started, feature and uninstall sections, plus a
  Japanese translation (`README.ja.md`).
