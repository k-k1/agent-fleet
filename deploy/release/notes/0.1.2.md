A hotfix release for the `native` runtime, where Claude sessions could become
completely unable to accept input, plus much fuller documentation in the
distribution repo.

### Fixed

- **Claude sessions took no input at all (native).** A `git credential` prompt could
  seize the pty and swallow every keystroke meant for the agent. Interactive
  credential prompting is now disabled in the workspace
  (`GIT_TERMINAL_PROMPT=0` / `GCM_INTERACTIVE=never`), so this cannot happen. Anyone
  whose GitHub account is not connected was affected, on every deployment.
- **Transient download failures during first start now heal themselves.** The
  boot-install step and on-demand CLI downloads retry (`curl --retry`) instead of
  leaving the workspace half-provisioned.
- The first `boot-install` progress is now echoed into the `af start` terminal, so a
  slow first start no longer looks like a hang with no output.
- `run-dev.sh reset` failed with "Permission denied" on the Go module cache.

### New

- **A progress dialog while the workspace starts.** `GET /api/workspace` exposes the
  boot-install phase, and the Console shows it while starting up. Pointless polling
  of stopped workspaces is stopped.

### Improved

- The dist repo README gained a Getting Started section, a feature list, and
  uninstall / data-removal instructions — plus **a Japanese translation
  (`README.ja.md`)**.
- The installer's completion message and the bundled README now point at the
  text-to-speech (read-aloud) setup.
