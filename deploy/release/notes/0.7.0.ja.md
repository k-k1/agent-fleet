opencode.ai のアカウントで Console からサインインできるようになり、セッションが使う枠も
選べます。中断した Claude のターンはアシスタントを介さずエージェント自身が再開し、
AWS の Agent Toolkit が組み込み MCP 連携に加わりました。

### 新機能

- **Console から OpenCode にサインインできます。** これまで OpenCode の認証は API キーを
  貼る経路だけで、opencode.ai のアカウントでサインインするには端末セッションで CLI を
  叩くしかありませんでした。設定 › エージェント › OpenCode で device flow を実行できます
  ——表示されたコードの一致を確認するだけで、稼働中の daemon が再起動なしで資格情報を
  拾います。API キー方式はそのまま残り、両者は独立して併存します（どちらか一方だけでも
  成立します）。
- **ワークスペースが使う OpenCode の枠を選べます。** カードに「使う枠」（無料枠 / Go /
  Zen）を追加しました。無料枠は認証がまったく不要なので、無料枠を選んだワークスペースは
  未接続のまま起動できます。またそのとき `OPENCODE_API_KEY` を注入しません——「無料枠で
  使う」と決めたワークスペースが、鍵が保存されたままというだけで Go の枠を消費すること
  はありません。カードには利用枠ページへのリンクと、上限に当たった直後はどの枠がいつ
  リセットされるかも出ます。利用率の % は出しません——取得手段が無いものを、それらしい
  数字にして見せない方がましだからです。
- **Agent Toolkit for AWS を 4 つ目の組み込み MCP 連携に。** PagerDuty / Grafana /
  CloudWatch と並んで、AWS 自身の MCP Server を設定 › 接続 › 運用・監視から接続できます。既定は
  読み取り専用で、AWS API 約 15,000 アクションを呼ぶツールと任意コードを走らせるツールは
  「書き込みツール」を明示的に有効にしたときだけ生えます。相談チャットだけでなく
  **セッションにも配る唯一の builtin** でもあります——中身が「AWS 上に作る」ための道具
  だからです。
- **中断したターンをエージェント自身が再開します。** ストリームのアイドルタイムアウトや
  接続断など、再試行で直る失敗で Claude のターンが落ちたとき、バックオフののち最大 2 回
  まで「続けて」を自分で送るようになりました。誰かが気付くまでセッションが止まったまま、
  ということが無くなります。Console から直接起動した（アシスタントの会話に紐付かない）
  セッションも対象です。走行中や、質問・プラン・許可待ちのあいだは何も送りません。
  ミラーには注入元バッジ「自動再開」が付きます。既定 ON、設定 › エージェント › Claude で
  切り替えられます。
- **エージェントが次のセッションを提案できます。** 作業中のエージェントが、続きを担当する
  セッション向けの初回プロンプトと表示名を提示できます。提案は保存されてミラーに現れ、
  編集も破棄もできます。起動は通常の起動ダイアログを通るので、エージェントとモデルは
  利用者が選びます——承認するまで新しいセッションは作られません。
- **配下のフォルダでセッションを始められます。** レポ行／worktree 行からの起動で、
  エージェントの起動位置を作業コピー直下ではなく配下の任意のフォルダにできます
  （monorepo で `console/` や `apps/web` だけを触るタスク向け）。worktree の扱い・掃除・
  グルーピングから見た作業コピーは変わらず、動くのはエージェントの作業ディレクトリだけ
  です。前回のフォルダはリポジトリ単位で記憶して次回の既定に出します。fork・作り直し・
  MCP の `create_session` にも引き継がれます。
- **親レポのコミットを worktree へ取り込めます。** worktree 行のバッジが「親が N 進んだ」
  「親へ FF 可能」「分岐」を区別するようになり、親が直系で先行しているときは右クリックの
  項目で親のコミットを fast-forward で取り込めます。分岐している履歴は拒否します（勝手に
  マージしません）。
- **Claude の登録モデル一覧を持てます。** Claude Code にはアカウント連動のモデルカタログが
  無く、旧モデルの完全 ID は起動時に直接入力するしかなく、次回には消えていました。設定 ›
  エージェント › Claude に自分で保守する一覧を置けるようにし、起動候補・既定モデル・MCP の
  `list_models` に同じ一覧を反映します。不正形式と重複は Console と Agent の両側で落とし、
  実際に応答するかどうかの最終判定は Claude Code に委ねます。
- **Tab で返信サジェストをたどれます。** コンポーサーに打つとチップ行は前方一致で絞られ
  ますが、そこから先を Tab でシェルの補完のように入力欄へ入れられるようにしました。
  Shift+Tab で逆回り、一周すると自分が打った文字へ戻ります。サイクル中はチップ列が凍結
  するので、選んでいる最中に一覧が動きません。
- **引用ブロックのコピー、コードブロックの折り返し。** Markdown の引用ブロックにコピー操作を、
  コードブロックに長い行の折り返し切り替えを追加しました。
- **サーフェス色を 5 色追加（計 11 色）。** 外観の配色にティール / ローズ / ピンク /
  インディゴ / グラファイトを足しました。色を足すときに効く制約はライトテーマのセグメント
  選択状態のコントラストなので、5 色ともそこを実測し、既存の最悪ケースを下回らないことを
  確認しています。

### 改善

- **Claude の認証切れが「失敗」として見え、直し方も出ます。** 資格情報が切れたセッションは、
  CLI 向けの文面（"Please run /login"）が普通の回答として表示されるだけで、Console から
  実行できる操作ではありませんでした。しかもエージェントカードは接続済みのまま——
  `claude auth status` は手元の資格情報を見るだけで、サーバ側の失効を知らないからです。
  いまは codex / opencode と同じ赤いエラーブロックとして描画し、カードから再認証へ誘導
  します（切断→接続を手で踏む必要はありません）。
- **利用上限が、止まった場所で見えます。** 利用上限で停止した managed の Codex セッションは
  「入力待ち」に見えていましたが、Claude と同じ「上限で停止 — 操作が必要」バッジが付く
  ようになりました。メニューを出さずに 429 でターンを畳むモデル別の上限も検知します——
  従来は理由がどこにも出ないまま「正常完了」として通知されていました。
- **選択式の質問は「選ぶ」と「送る」が別になりました。** 選択肢をクリックした瞬間に送信
  されて取り消せなかったのを、選択してからボタンで確定する形にしました。プレビューを持つ
  選択肢は、その内容を選択肢と一緒に表示します。
- **返信サジェストの学習が全角/半角を同一視します。** 全角の `！` で打った言い回しが、
  半角版と別枠を取ることがなくなりました（チップ行でも設定の一覧でも）。チップの表示上限は
  12 → 20 件、保存上限は 60 → 100 件になりました。
- 設定 › ツールチェーンの「ツールのバージョン」に AWS / ops MCP 系 4 つを掲載しました。
- CLI のピン: Claude Code 2.1.224 / Codex 0.147.0 / OpenCode 1.18.15 /
  GitHub Copilot 1.0.78 / Antigravity 1.1.11 / Cursor 2026.08.04 / Kiro 2.16.2 /
  rtk 0.44.2。

### 修正

- **ターンがミラーから永久に欠落することがありました。** claude は転写を 4KiB 単位で追記
  するため、長い行は複数回に分けて書かれ、読み手が「書きかけの行」を観測しえます。読み手は
  その断片も 1 行と数えてカーソルを先へ進める一方、パーサは断片を parse できず捨てるので、
  以降の読み出しは配信されていないターンより後から始まっていました。見え方は「TUI の回答が
  ミラーに出ない」で、その下に「反映待ち」のプロンプトが残り続けます。行末までの断片は
  次回の読み出しに残すようにしました。
- **誰にも見えない場所で発火し続けるスケジュールがありました。** スケジュール行は所有する
  membership への外部キーを持たないため、membership が停止・削除されても行が残り、毎スロット
  no-op で発火し続けていました。一覧も実行履歴も membership スコープなので、その様子は誰にも
  見えません。最初のスキップでスケジュールを停止し、理由を記録するようにしました——アクセスが
  戻れば「一時停止中のスケジュール」として再び現れます。
- スケジュール関連の修正あと 3 件: 作業グループで絞り込みから漏れる、`whoami` のブート固定で
  欄が消える、一覧の取得失敗が「まだありません」に化ける。
- **submodule を取得できていない worktree が、そう表示され、自力で直ります。** 取得中に起動を
  kill すると、git 自身は健全と申告する wedge 状態で残っていました。起動は裏で継続し、状態を
  可視化して fetch / checkout での修復を案内します。
- **打ち切り報告の直後に、それを否定する訂正が出なくなりました。** 報告が中断から数分遅れて
  出るようになったことで、補償の判定が中断レコード自身の鮮度を「また動き出した」と誤読して
  訂正を配っていました。
- **全角 `｜` で書かれた表が表として描画されます。** 日本語 IME は縦棒を U+FF5C で確定するため、
  エディタ上は整って見える表がプレビューでは 1 つの段落に潰れていました。補正は意図的な全角
  ｜を壊さないよう狭く取っています（半角 | を含む行や混在した行には触りません——セルの中に
  バーを入れる唯一の手段が全角 ｜ だからです）。長音記号がハイフンに潰れる問題と、ヘッダ行
  だけ全角で残った表も直しました。
- **返信サジェストが途中報告だけから作られていました。** 窓が直近 2 ターン固定で、ツールを
  使う普通の回答は「2 点をトリムします。」級の途中報告が何本も並ぶため、実質的な回答も依頼も
  モデルに渡っていないことがよくありました。同一話者の連続発言を畳んだうえで、窓をターン数
  ではなく文字予算にしました。
- OpenCode の修正: モデル一覧を稼働中の daemon から読む（CLI はログインを見ない）、daemon 起動
  直後のサインイン開始が 500 で落ちる、切断が実際には資格情報を消していない、API キーの変更が
  稼働中の daemon に届かない、サインイン手順が「貼り付け」ではなく「コードの一致確認」になった、
  利用枠ページの URL をそのまま貼れる。OpenCode の最終回答がミラーへライブで反映されるように
  なりました。
- ミラーの修正: 既存セッションを開いたときの着地位置を最下部に確定、セッション切替時も最下部へ
  再初期化、引き継ぎカードは提案時刻の位置に置いて会話の着地位置を奪わない、回答フッターの日時を
  ターン開始ではなく着地時刻に、回答中の `"` で表示が途切れない、選んだ選択肢が「自由入力」に
  化けない、コンポーサーのスクロールを Ctrl+↑↓ / PgUp・PgDn / Ctrl+End へ。
- 起動モーダルの修正: スマホのソフトキーボードが勝手に開かない、並びをエージェント → モデル →
  プロンプトへ戻した、接続チェックの失敗を固定せず取り直す（停止中だっただけのワークスペースで
  起動ボタンが押せなくなることがありました）。
- 別端末で選んだモデル設定が復帰時に同期される、エージェント選択をホイールで横スクロールできる、
  Chromium 接続ツールが対話セッションにも配られる、`node_modules` の除外がシンボリックリンクにも
  効く。

### アップグレード時の注意

migration はありません。OpenCode の旧「モデル一覧」設定は新しい「使う枠」へ自動で移行します
（hide-zen → Go、それ以外 → Zen）。設定していた場合はカードを確認してください。中断ターンの
自動再開は既定 ON で、設定 › エージェント › Claude で切り替えられます。AWS 連携は「書き込み
ツール」を有効にするまで読み取り専用です。Compose 環境は従来どおり新しいイメージを pull、
native 版はワンライナーで更新できます。**新しくピン止めした各エージェント CLI を取り込むには、
ワークスペースの Stop → Start が必要です。**
