OpenCode に Console から opencode.ai アカウントでサインインでき、セッションを動かす
プランを選べるようになりました。中断した Claude のターンはアシスタントを介さずに
自分で再開し、AWS の Agent Toolkit が内蔵 MCP 連携に加わりました。

### New

- **Console から OpenCode にサインイン。** Settings › Agents › OpenCode がデバイス
  フローを代行し、動作中の daemon が再起動なしで資格情報を拾います。API キーの経路は
  そのままで、両方を併用できます。
- **Workspace が使う OpenCode のプランを選べます** — 無料枠・Go・Zen。無料枠は資格情報
  を必要とせず、無料枠に設定した Workspace には `OPENCODE_API_KEY` を注入しないので、
  キーが残っていても Go の枠を黙って消費することはありません。カードから使用量ページ
  へ行け、どの枠が尽きていつ戻るかも表示します。
- **AWS の Agent Toolkit を 4 つ目の内蔵 MCP 連携として追加**しました（PagerDuty・
  Grafana・CloudWatch に加えて）。既定は読み取り専用で、*書き込みツール*を有効にした
  ときだけ書き込み系が現れます。チャットだけでなくコーディングセッションにも渡される
  唯一の内蔵連携です。
- **中断したターンが自分で再開します。** 再試行で直る種類のエラーで Claude のターンが
  落ちたとき、バックオフを置いてから自分で「continue」を送ります（最大 2 回）。誰かが
  気付くまでセッションが止まったままになりません。ターンの実行中や、質問・プラン・
  許可要求の待ち中には何も送りません。既定 on（Settings › Agents › Claude）。
- **エージェントが次のセッションを提案できます** — すぐ使える最初のプロンプトと名前を
  渡します。提案は保存されてミラーに出て、編集も破棄もできます。通常の起動ダイアログを
  通すまで何も作られません。
- **作業コピー配下のフォルダでセッションを開始**できます。monorepo で 1 ディレクトリ
  しか触らない作業に便利です。動くのはエージェントの作業ディレクトリだけで、最後に
  使ったフォルダをリポジトリごとに覚えます。
- **親リポジトリのコミットを worktree へ取り込めます。** worktree のバッジが「親が
  進んでいる」「fast-forward できる」「分岐した」を区別し、右クリックから fast-forward
  できます。分岐した履歴はマージせず拒否します。
- **Claude のモデル一覧を自分で持てます。** 起動ダイアログ・既定モデル設定・MCP の
  `list_models` から参照されます。Claude Code にはアカウント連動のカタログが無く、
  古いモデルの完全な ID は打ち込んでも次には消えていました。
- **Tab で返信候補を巡回**できます（シェルの補完と同じ挙動）。Shift+Tab で戻り、
  一周すると自分が打った文字列に戻ります。
- **外観の色が 5 つ増えました。** Markdown の引用ブロックにコピー、コードブロックに
  折り返しの切り替えが付きました。

### Improved

- **Claude のログイン切れが失敗として見え、直し方も示されます** — CLI の「Please run
  /login」が普通の返信として表示される代わりに赤いエラーブロックになり、カードは接続の
  解除・再接続ではなく再認証を案内します。
- **利用上限が、止められた場所で見えます。** 上限で止まった managed の Codex セッション
  にも*要対応*のバッジが付き、モデル固有の Claude の上限も検出します（以前は完了した
  返信として報告されていました）。
- **選択式の質問への回答が 2 段階になりました** — 選んでから確定します。プレビューを
  持つ選択肢はその場で表示します。
- 返信候補の学習が全角と半角を同一視するようになり、チップ列に学習済み候補を最大 20 件
  出します。
- CLI の固定版: Claude Code 2.1.224、Codex 0.147.0、OpenCode 1.18.15、GitHub Copilot
  1.0.78、Antigravity 1.1.11、Cursor 2026.08.04、Kiro 2.16.2、rtk 0.44.2。

### Fixed

- **ターンがミラーから永久に消えることがありました。** 長い転写の行は分割して書かれ、
  書きかけを掴むと読み取りカーソルが「まだ配送していないターン」を飛び越えてしまい、
  その下のプロンプトが「保留」のまま残っていました。
- **誰にも見えない場所でスケジュールが永久に発火し続けることがありました。** 所有する
  membership が無効化・削除されたスケジュールが空振りを繰り返し、一覧にも実行履歴にも
  出ませんでした。最初の空振りでスケジュールを停止し、理由を記録します。
- **submodule を取得できていない worktree が、その旨を表示して自分で修復します。**
  git 自身は健全と報告する状態で固まっていました。
- **全角の `｜` で書かれた表が表として描画されます。** 日本語 IME は U+FF5C を確定する
  ため、表全体が 1 つの段落に潰れていました。
- **返信候補が実際の回答ではなく進捗の断片から作られていました。**
- OpenCode の修正: モデル一覧を動作中の daemon から読み、接続解除で資格情報を実際に
  消し、API キーの変更が daemon に届き、最終回答が次の更新を待たずにミラーへ届きます。
- ミラーの修正: セッションを開いた／切り替えた直後は末尾に着地し、回答のフッターは
  開始ではなく終了時刻を示し、回答中の `"` で表示が途切れなくなりました。
- 起動ダイアログの修正: スマートフォンのソフトキーボードが勝手に開かなくなり、接続確認
  の失敗が再試行されるようになりました（起動ボタンが固着しなくなります）。

### Upgrade notes

移行作業はありません。旧 OpenCode の*モデル一覧*設定は新しいプラン選択へ自動変換
されます（hide-zen → Go、それ以外 → Zen）。設定していた場合はカードを確認してください。
Claude の中断ターン自動再開は既定で on です。AWS 連携は書き込みツールを有効にするまで
読み取り専用です。新しい CLI の固定版を反映するには Workspace の Stop → Start が必要です。
