A Bitbucket query in the issue tracker is now assembled from what you pick instead of a
string you had to invent, and a ticket that several queries return is listed once. A
Claude session no longer reports itself as waiting for input while it is still writing.

### Improved

- **A Bitbucket query is built from what you tick, not typed.** Choose what to list —
  review requests, a repository's pull requests, your own — and the target from the
  Bitbucket repositories you already have; each box you tick becomes a query. The
  repository list is read through the workspace, so while it is stopped you write the
  query by hand as before.
- The screen is called **Issue tracker** in both the left rail and settings, which used
  to carry two names for the same thing.

### Fixed

- **A Claude session was shown as waiting for input while it was still writing its
  answer**: the stop button disappeared, and the completion notification and the report
  went out early. A session counts as idle only once its screen has stopped changing.
- **Starting from a handoff card could fail with "title is too long"** although the same
  name had been accepted when it was written. Session names are limited to 80 characters
  everywhere now, and a longer name that is filled in for you is trimmed to fit.
- **The same ticket appeared once per saved query** in the issue tracker rail. Queries
  that overlap — two of them normally do — collapse to one row per ticket.
- **A browser pane could stay black and never draw**, having lost the first frame of the
  page.
- Smaller interface fixes: the chat/terminal switch in the mirror follows the top bar's
  colour, and the source selector in the query form is readable in dark mode.
