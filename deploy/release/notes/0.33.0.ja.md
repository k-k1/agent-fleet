テナントのメンバー画面が、メンバーごとのカードで稼働中のセッション・最終アクティブ・home ディスク・メモリと CPU を
示すようになりました。home ディスクの空き不足や CLI のインストール失敗は、壊れたセッションとしてではなく、メンバーと
テナント管理者に知らされます。コマンドパレットでエージェントメモリを検索でき、Markdown 中のループバック URL は
ワークスペースのプレビューで開きます。

### 新機能

- **テナントのメンバー画面が、メンバーごとのカードになりました。** 状態を言葉で示すバッジ、件数、絞り込み、並べ替え、
  検索があります。カードには稼働中と全体のセッション数、最終アクティブ、home ディスクの使用量、画面に見えている
  稼働中ワークスペースのメモリと CPU が出ます。
  ([#2385](https://github.com/k-k1/agent-fleet/issues/2385),
  [#2388](https://github.com/k-k1/agent-fleet/issues/2388),
  [#2389](https://github.com/k-k1/agent-fleet/issues/2389))
- **home ディスクの空き不足と CLI のインストール失敗が見えるようになりました。** 専用の home ディスクでは空きが
  少なくなると Console が警告し、起動時にインストールできなかった CLI は設定 › ツールチェーンに「インストール失敗:
  <理由>」と出て、その種類のセッションは理由を添えて開始を断ります。テナント管理者のメンバー画面にも同じメンバーが
  示されます。入りきらないインストールは始めないので、インストール済みの CLI はそのまま使えます。
  ([#2383](https://github.com/k-k1/agent-fleet/issues/2383),
  [#2398](https://github.com/k-k1/agent-fleet/issues/2398))
- **コマンドパレットでエージェントメモリを検索できます。** エージェントメモリがオンのときに出る **メモリ** モードで、
  名前と説明はすぐに、本文は少し待ってから照合し、Enter で設定のそのメモリを開きます。
  ([#2407](https://github.com/k-k1/agent-fleet/issues/2407))
- **Markdown 中のループバック URL が、そのポートのワークスペースプレビューで開きます。** 会話、アシスタントの
  チャット、ドキュメントとファイルのビューアーで使え、右クリックでポートのチップと同じメニューが出ます。インライン
  コードの URL は、そのポートをセッションが使っている間だけリンクになります。
  ([#2414](https://github.com/k-k1/agent-fleet/issues/2414),
  [#2419](https://github.com/k-k1/agent-fleet/issues/2419),
  [#2426](https://github.com/k-k1/agent-fleet/issues/2426))
- **セッションツリー全体が止まると、親に一度だけ知らせます。** 親と稼働中の子がみな 15 分アイドルで、やり取り中の
  メッセージもないとき、親に通知が 1 回届き、会話には **停滞通知** と表示されます。あなたの応答を待っている
  セッションがあるときは届きません。待ち時間は `AF_STALLED_TREE_MINUTES` で変えられます（`0` で無効）。
  ([#2397](https://github.com/k-k1/agent-fleet/issues/2397))

### 改善

- **ターミナルセッションの返答にある `$AF_WORK_DIR/…` のパスがリンクになりました。** home の下のフォルダにある
  ファイルのメニューには **フォルダを開く** と **フォルダをギャラリーで開く** が出ます。
  ([#2429](https://github.com/k-k1/agent-fleet/issues/2429))
- **コマンドパレットのモードを逆順に切り替えられます。** パレットのキーに Shift を足す（既定は Ctrl/⌘+Shift+P）と
  逆順になり、PageUp/PageDown で 1 ページ動きます。モード切替のヒントは別の行になり、欠けなくなりました。
  ([#2412](https://github.com/k-k1/agent-fleet/issues/2412),
  [#2421](https://github.com/k-k1/agent-fleet/issues/2421))
- **別のエージェントへ移す の移動先に kiro を選べます。** cursor はまだ出ません。
  ([#2252](https://github.com/k-k1/agent-fleet/issues/2252))
- **移したセッションの引き継ぎファイル**が Console の言語で書かれ、停止で捨てられた入力を載せ、古い読み取り専用の
  ツール呼び出しをより多く省きます。
  ([#2233](https://github.com/k-k1/agent-fleet/issues/2233))
- **Muse Code 1.4.11 に対応しました。** 新しい種類の記録は 1 行の要約で表示します。
  ([#2394](https://github.com/k-k1/agent-fleet/issues/2394))
- **ECS: `pause.sh` が、休止中は NAT ゲートウェイを削除します。** `--up` で同じ送信元 IP のまま作り直します
  （`--keep-nat` で残せます）。休止中の RDS インスタンスを AWS が 7 日後に起動しても、また止めます。
  ([#2386](https://github.com/k-k1/agent-fleet/issues/2386))

### 修正

- **ワークスペース起動時の CLI のインストールが途中で失敗しても成功と記録され**、壊れたバイナリがその後も使われ
  続けていました。rtk・agy・cursor は不可分に入れ替え、動かないときは入れ直します。
  ([#2384](https://github.com/k-k1/agent-fleet/issues/2384))

### アップグレードの注意

- **ECS のデプロイ:** RDS を止め直すルールを入れるため、`10-data` スタックを一度デプロイしてください。この版から
  `pause.sh` は既定で NAT ゲートウェイを削除します。休止中もインターネットへ出る必要があるものがあれば
  `--keep-nat` を付けてください。
