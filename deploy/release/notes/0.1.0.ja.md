最初の公開リリースです。Agent Fleet は AI コーディングエージェントを群れとして
動かすためのセルフホスト Console で、メンバーごとに隔離された環境が与えられ、
ブラウザからエージェントのセッションを動かします。

### このリリースに入っているもの

- **5 種のエージェント CLI を 1 つの Console から** — Claude Code、Codex CLI、
  OpenCode、GitHub Copilot CLI、Antigravity CLI。セッションごとにモデルを選べ、
  CLI の版は固定されています。
- **ユーザーごとの隔離** — CPU / メモリのクォータ付きコンテナ（Docker 不要の native
  ランタイムでは bubblewrap サンドボックス）、永続する home、ユーザー間のネットワーク
  分離。
- **実際の git リポジトリで並列にセッション** — GitHub / Bitbucket の資格情報での
  HTTPS clone、Git LFS、submodule、git-worktree による隔離。ターミナルの隣に会話の
  ライブミラーが出ます。
- **Go 製の Control Plane** — Workspace のオーケストレーション、資格情報の保存時
  暗号化、リソースクォータ、管理画面。
- **2 つの配布形態** — WSL2 / Linux の 1 人用で Docker 不要の `native` パッケージ
  （`install.sh` → `af start`）と、セルフホスト用の Docker Compose バンドル。
  オフライン導入用のイメージアーカイブも付属します。

### 補足

- 配布イメージは**軽量ビルド**です。エージェント CLI は再配布せず、各 Workspace が
  初回起動時に上流から取得します。
- ダウンロードは `SHA256SUMS` で検証してください。native のランチャは同梱の
  `rootfs.json` の sha256 で rootfs も検証します。
