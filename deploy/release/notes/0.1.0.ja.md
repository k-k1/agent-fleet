最初の公開リリースです。Agent Fleet は、AI コーディングエージェントをフリートとして
運用するためのセルフホスト型コンソールです。メンバーごとに隔離された環境が与えられ、
エージェントのセッションをブラウザから起動・操作・管理できます。

### このリリースに含まれるもの

- **5 種のエージェント CLI を 1 つのコンソールで** — Claude Code / Codex CLI /
  OpenCode / GitHub Copilot CLI / Antigravity CLI を並べて動かせます。セッションごとの
  モデル選択に対応し、CLI の版は検証済みの組み合わせにピン留めされます。
- **ユーザーごとの隔離** — cgroup で CPU／メモリをクォータ管理した Docker コンテナ
  （Docker 不要の native ランタイムでは bubblewrap サンドボックス）、永続ホーム、
  ユーザー間のネットワーク分離。
- **実リポジトリでの並行セッション** — GitHub / Bitbucket のトークンまたは OAuth
  device flow による HTTPS clone、Git LFS、サブモジュール、git-worktree による隔離。
  各会話はターミナルと並べてミラー表示でライブに追えます。
- **Go のコントロールプレーン**によるワークスペースのオーケストレーション。資格情報の
  at-rest 暗号化、リソースクォータ、管理コンソールを備えます。
- **2 つの配布ターゲット** — WSL2 / Linux の単一ユーザー向けの Docker 不要な
  `native` パッケージ（`install.sh` → `af start`）と、セルフホスト用の Docker Compose
  バンドル。オフライン導入用の air-gap イメージアーカイブも同梱します。

### 注意

- 配布イメージ・rootfs は **lean 構成**です。エージェント CLI は再配布せず、各利用者の
  ワークスペースが初回起動時に配布元からピン版を取得します（air-gap 用の代替手順は
  同梱 README に記載）。
- ダウンロードした成果物は `SHA256SUMS` で検証してください。native のランチャーは
  加えて、同梱の `rootfs.json` に記載された sha256 で workspace rootfs を検証します。
