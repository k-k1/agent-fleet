Each version is now one GitHub Release that carries the workspace rootfs too, and the native package
ships for arm64 Linux as well as amd64. Stop in a Managed session now takes two steps: the first ends
the running turn and keeps what is queued, and a second also discards the queue. The mirror shows a
claude reply while it is being written. On AWS, Recreate and Clean home used to report success and
remove nothing; they now work on ecs-ec2 and are refused on ecs.

### New

- **Native package for arm64 Linux.** `install.sh` and `af update` pick the package for the machine
  they run on. Versions before 0.26.0 have no arm64 package.
  ([#1345](https://github.com/k-k1/agent-fleet/issues/1345))
- **Two-stage Stop for Managed sessions.** The first Stop ends the running turn only; your queued
  follow-ups and peer messages then run one per turn. Stop again, or pick **Stop and discard the
  queue**, to discard what is still queued; a notice lists it and **Put back** returns your own input
  to the input box. Queued bubbles have **Back to input** and **Remove**. Terminal (CLI) sessions keep
  the CLI's own Esc.
  ([#1289](https://github.com/k-k1/agent-fleet/issues/1289),
  [#1292](https://github.com/k-k1/agent-fleet/issues/1292),
  [#1293](https://github.com/k-k1/agent-fleet/issues/1293),
  [#1294](https://github.com/k-k1/agent-fleet/issues/1294),
  [#1244](https://github.com/k-k1/agent-fleet/issues/1244),
  [#1256](https://github.com/k-k1/agent-fleet/issues/1256))
- **The mirror shows a claude reply while it is being written**, typed out character by character by
  default. Settings › "Stream replies in the chat view" offers Off / Line by line / Typewriter; with
  reduced motion, Typewriter behaves as Line by line.
  ([#1250](https://github.com/k-k1/agent-fleet/issues/1250),
  [#1274](https://github.com/k-k1/agent-fleet/issues/1274),
  [#1396](https://github.com/k-k1/agent-fleet/issues/1396))
- **Initialize Git Flow from the Console**: a repository's right-click menu (and a work-item launch
  when `origin` has `develop` but nothing is declared) writes the git-flow settings and creates local
  tracking branches for `main`/`develop` that exist only on origin.
  ([#1126](https://github.com/k-k1/agent-fleet/issues/1126),
  [#1329](https://github.com/k-k1/agent-fleet/issues/1329))
- **A workspace stuck starting is stopped after 30 minutes**, and you get a notification saying where
  it stopped. Tenant admins see the auto-stop and its reason in the member list.
  `AF_WORKSPACE_START_DEADLINE` sets the limit (`0` turns it off).
  ([#1240](https://github.com/k-k1/agent-fleet/issues/1240),
  [#1298](https://github.com/k-k1/agent-fleet/issues/1298),
  [#1384](https://github.com/k-k1/agent-fleet/issues/1384))
- **Tenant admins can limit the self-hosted LLM and image engines to the members they grant**
  (Tenant settings › Operations › Engine access). The default stays "every member".
  ([#1215](https://github.com/k-k1/agent-fleet/issues/1215))
- **Recreating a worktree whose branch was squash- or rebase-merged on GitHub** offers the merged pull
  request's head, and a reused branch name resolves to its newest merge.
  ([#1043](https://github.com/k-k1/agent-fleet/issues/1043),
  [#1397](https://github.com/k-k1/agent-fleet/issues/1397))
- **Overview cards show the context gauge, token trend, answering model and last line for every
  agent kind**, not only Claude.
  ([#1342](https://github.com/k-k1/agent-fleet/issues/1342),
  [#1362](https://github.com/k-k1/agent-fleet/issues/1362))
- **The skill picker offers your personal skills from the other agents** (for example a claude skill
  in a Muse Code or Codex session).
  ([#1351](https://github.com/k-k1/agent-fleet/issues/1351))
- **llama.cpp sessions have a row in Settings › Agent instructions**, and it applies from the next
  turn.
  ([#1202](https://github.com/k-k1/agent-fleet/issues/1202))
- **ECS: the EFS file system is backed up daily under `Persistence=retain`** (7 days by default). Not
  yet run on a real deployment
  ([#1235](https://github.com/k-k1/agent-fleet/issues/1235)).
  ([#1195](https://github.com/k-k1/agent-fleet/issues/1195))
- **ECS: `standup.sh` and `update.sh` take `--comfy-digest`** to pin the ComfyUI image they copy, and
  always print the digest that landed in ECR.
  ([#966](https://github.com/k-k1/agent-fleet/issues/966),
  [#1319](https://github.com/k-k1/agent-fleet/issues/1319))

### Improved

- **Muse Code**: a resumed session's mirror fills in turns finished while the Agent was down, attached
  images show as thumbnails, and a command left running after a turn shows as "background command

### Upgrade notes

- **Release assets**: there is no separate `rootfs-<r>` release any more; the rootfs is attached to
  `v<version>` and each release's `SHA256SUMS` lists exactly its assets. Installed copies and
  `af update` need nothing; only a script or mirror that downloads from `rootfs-<r>` releases has to
  follow. ([#1345](https://github.com/k-k1/agent-fleet/issues/1345))
- **A deployment that signs people in without `AF_MASTER_KEY`** now logs a warning and shows a banner
  to super admins; nothing stops. ([#1080](https://github.com/k-k1/agent-fleet/issues/1080))
- **Without `PUBLIC_BASE_URL`, internal git's clone, push and LFS routes now answer 503.** Set it if
  you use internal git. ([#1212](https://github.com/k-k1/agent-fleet/issues/1212))
- **`AF_USAGE_SAMPLE_INTERVAL`, `AF_GIT_GC_INTERVAL`, `AF_SCHEDULER_INTERVAL` and
  `AF_CLOUD_COST_INTERVAL` set to `0` now really turn their loop off.**
  ([#1186](https://github.com/k-k1/agent-fleet/issues/1186))
- **The admin MCP tool that stops another member's session is now `stop_user_session`.** Under the
  old name it never ran. ([#1188](https://github.com/k-k1/agent-fleet/issues/1188))
- **ECS**: the CP role may run SSM commands only on its own slot instances; if you override
  `AF_ECS_EC2_POOL`, keep it equal to the cluster name. A `retain` data stack's name may be at most
  37 characters, and enabling the EFS backup on a live deployment is in the ECS runbook.
  ([#1182](https://github.com/k-k1/agent-fleet/issues/1182),
  [#1195](https://github.com/k-k1/agent-fleet/issues/1195))
