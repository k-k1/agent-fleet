過去のセッションの会話を、コマンドパレットからもエージェントからも検索できるようになりました。セッションは、
ひも付いた Issue や PR からも探せます。セッションに費用の予算を持たせると、達したところでターンの終わりに止まります。
エージェントはすべての種別で共有する Agent Fleet のメモリを使えます（メンバーが各自でオンにするまでは無効です）。
GitHub は組み込みのアプリで接続でき、インペイントのマスクは画像の上で塗れ、LAN の ComfyUI は管理パネルで設定
できます。AWS ではメンバーの秘密情報を KMS のキーで封印できます。

### New

- **過去の会話を検索。** コマンドパレットの「会話」モードで、このワークスペースの過去のセッションで話されたことを、
  すべての種別・停止中やアーカイブ済みも含めて探し、そのターンでセッションを開きます。エージェントも af MCP の
  `search_sessions` ツールで同じ履歴を検索できます（設定 › エージェント › 過去セッションの検索。既定はオン）。
  ([#1558](https://github.com/k-k1/agent-fleet/issues/1558))
- **Issue や PR からセッションを探す。** 左ペインの絞り込みやコマンドパレットに `#1662`・`owner/name#1662`・
  `PROJ-123` と入れると、それが PR のセッションや、そのチケットから起動したセッションが見つかります。
  ([#1665](https://github.com/k-k1/agent-fleet/issues/1665))
- **ミラーとアシスタントのチャットのチケット番号が作業項目へのリンクになります。** `#N`・`owner/name#N`・Jira の
  キーで作業項目の詳細を開きます。Ctrl／⌘ を押しながらのクリックではトラッカーを開きます。
  ([#1659](https://github.com/k-k1/agent-fleet/issues/1659))
- **費用の予算。** 「予算（USD）」を付けて始めたセッション、または設定 › エージェント › 新しいセッションの予算 の
  対象のセッションは、推定の費用が予算に達するとターンの終わりに止まり、通知が届きます。「予算を上げて再開」で
  続けられます。1 ターンで予算の 2 倍に達したときはターンの途中で止めます。トークン数を出さない種別は止まりません。
  ([#1054](https://github.com/k-k1/agent-fleet/issues/1054))
- **Agent Fleet のメモリ。** 設定 › エージェント › Agent Fleet のメモリ をオンにすると、すべての種別のセッションが
  af の `memory_*` ツールで 1 つの共有メモリを読み書きします。既定はオフです。書き込みは承認なしで反映されるため、
  Console が変更ごとに書いたセッションを示し、元に戻すことも消すこともできます。
  ([#1569](https://github.com/k-k1/agent-fleet/issues/1569))
- **組み込みのアプリで GitHub に接続。** 「OAuth で接続」は組み込みの OAuth App か GitHub App を使えます。自前の
  アプリを持たない配備の既定のテナントは、組み込みの OAuth App を使います。テナントの自前のアプリは、保存したときに
  OAuth App か GitHub App かを見分けます。
  ([#1667](https://github.com/k-k1/agent-fleet/issues/1667))
- **インペイントのマスクを画像の上で塗る。** 「この部分を直す」で画像に重ねたキャンバスが開き、ブラシ・消しゴム・
  拡大・元に戻すで塗ったマスクを次の実行のために保存します。
  ([#956](https://github.com/k-k1/agent-fleet/issues/956))
- **画像ギャラリー**はサブフォルダーも含めて表示でき、メニューから画像をセッションやアシスタントへ送れます。
  幅×高さはカメラの向きを反映します。
  ([#961](https://github.com/k-k1/agent-fleet/issues/961))
- **LAN の ComfyUI**: super admin は 管理 › 推論エンジン で URL とキーを設定でき、Control Plane の再起動は要りません。
  `deploy/comfyui-lan/comfyui-lan.sh` は、固定した版の同じ ComfyUI イメージを LAN の GPU ホストで動かします。
  ([#957](https://github.com/k-k1/agent-fleet/issues/957),
  [#958](https://github.com/k-k1/agent-fleet/issues/958))
- **AWS: メンバーの秘密情報を KMS のキーで封印**できます（`AF_KEY_CUSTODIAN=kms` と `AF_KMS_KEY_ID`。ECS では
  `CustodianKmsKeyArn` パラメータ）。それまでに封印した値はローカルのキーで開き続けます。任意の機能で、実際の配備では
  まだ動かしていません。
  ([#969](https://github.com/k-k1/agent-fleet/issues/969))

### Improved

- **設定 › 通知 が 1 つの表になりました**: 通知の種類ごとに、未読の印・OS の通知・読み上げを選べます。これまでの
  選択は引き継ぎます。
  ([#1085](https://github.com/k-k1/agent-fleet/issues/1085))
- **WS バーは幅に合わせて畳みます**: ラベルはアイコンだけになり、項目は `⋯` の中へ移ります。折り返して高くなることは

  ([#1642](https://github.com/k-k1/agent-fleet/issues/1642))
- **codex のターミナルと OpenCode のセッションで、コンパクト化中をその場で示します。** OpenCode が報告する費用を

  [#1082](https://github.com/k-k1/agent-fleet/issues/1082))

### Upgrade notes

- **GitHub**: 自前の GitHub アプリを持たない配備では、既定のテナントが組み込みの OAuth App で「OAuth で接続」を
  出すようになります。組み込みのアプリを出さないなら、Control Plane に `AF_GITHUB_BUILTIN_APPS=off` を設定してください。
  ([#1667](https://github.com/k-k1/agent-fleet/issues/1667))
- ほかに作業はありません。KMS のキーと LAN の ComfyUI のパネルは任意の機能で、`update.sh` は `CustodianKmsKeyArn` を
  空のままにします。

エージェント CLI のピンは 0.27.0 から変わりません。
