これまでで最大のリリースです。Discord と Slack からセッションを動かせるように
なり、プロンプトを定時実行でき、Cursor CLI が加わり、Subversion の作業コピーに
対応し、`native` のホストバイナリが自分で更新するようになりました。

### New

- **Discord / Slack のチャットブリッジ。** セッションごとにスレッドが立ち、そこへの
  返信でセッションを操作できます。質問・プラン承認・許可要求はボタンで答えられます。
  通知は 5 種類を個別に切り替えられ、bot にメンションすると Console と同じ
  fleet オペレーターとの会話が開きます。opt-in で、*Connections › Chat* にあります。
- **定時実行。** fleet オペレーターに普通の言葉で頼めば、cron・間隔・1 回きりの
  スケジュールを登録できます。停止中の Workspace は起こして実行し、終わったら元の
  状態に戻します。左レールの *Schedules* に一覧と直近 50 件の実行履歴が出ます。
  既定で有効です（`AF_SCHEDULER_INTERVAL=0` で無効）。
- **Cursor CLI 対応**で 6 種になりました。ブラウザでのサインイン、両方の実行方式、
  アカウントに応じたモデル一覧、版の固定に対応します。
- **Subversion のチェックアウト。** basic 認証で SVN URL をチェックアウトできます
  （サブパス・複数パスも可）。資格情報は暗号化保存でき、自己署名証明書はサーバー毎に
  信頼できます。SVN に worktree は使えないので、並行作業は別パスへのチェックアウトで
  分けてください。
- **ホストバイナリ `af` の自動更新（native）。** 毎日のタイマーが最新版を用意し、
  適用は *Settings › Environment* から明示的に行います。実行中のセッションが不意に
  切れることはありません。`AF_VERSION` で固定できます。

### Improved

- **GitHub Copilot CLI** がモデル選択と使用量チップに対応しました。
- **Console↔Control Plane の通信量を大きく削減しました** — gzip、ETag による再検証、
  4 本の定期ポーリングを 1 本の Server-Sent Events に置き換え。
- **設定モーダルを 10 個の平らなタブから 3 グループに再編しました。**
- **利用者ガイドを二言語化**し、エージェントの命名と色を 1 つの registry から引く
  ようにしました。
- ミラー: スクロール追従が現在位置に対して正直になり、「最新へ」ボタンを常設し、
  返信描画前の空白を無くし、画像ライトボックスがブラウザの戻るに応答します。
- 細かいところ: 通知トグルを `n` に集約、shell / SSM のクイック接続カード、
  リーダーキーの透過、起動モーダルでの画像添付。

### Fixed

- **プランの却下が承認として記録されていました。** 却下は意図どおりセッションを
  中断します。
- リモートコントロールの既定を off にしました（既存 Workspace にも 1 度だけ適用）。

### Other changes

- Compose 版の取得補助として `install-compose.sh` を追加しました。
- 公開 README から AWS（ECS / CloudFormation、EC2-Single）の記載を外しました。
  `aws/` 一式は Compose の成果物に今までどおり同梱されています。
