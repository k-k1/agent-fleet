これまでで最大のリリースです。Discord / Slack からセッションを操縦できるようになり、
プロンプトを定時実行でき、Cursor CLI が加わり、Subversion の作業コピーに対応し、
`native` のホストバイナリが自己更新するようになりました。

### 新機能

- **チャットブリッジ（Discord / Slack）** — セッションごとにスレッドが立ち、5 種の通知を
  個別にトグルできます（応答あり／質問、プラン承認、許可リクエスト、異常終了、完了報告）。
  スレッドへの返信でセッションを操縦できます（全エージェント種別・ターミナル／マネージド
  両対応・opt-in）。質問・プラン承認・許可リクエストはボタンで回答できます。任意で有効に
  できる全文モードは、秘密情報を自動で伏字化し、長文を分割して送ります。ボットへ
  メンションするとフリート・オペレーターとの会話が始まります（Console で見えるものと
  同一の会話です）。チャット経由の破壊的操作は fail-closed な承認ゲートを通ります。
  接続はトークンを貼るだけのウィザードです（Discord は Bot トークン 1 本、Slack は
  Socket Mode の `xoxb` + `xapp`）。Console では「接続 › チャット連携」タブにあり、
  「個人設定 › 通知」にサービスごとのマスタ ON/OFF があります。
- **定時実行** — フリート・オペレーターに自然言語で依頼してスケジュールを登録できます
  （cron / interval / once、タイムゾーンと DST に対応）。停止中のワークスペースは wake して
  実行し、終わったら元の状態へ戻します。失敗（wake・注入・クォータ・メンバーシップ）は
  コントロールプレーンの通知センターに出ます。左レールの「スケジュール」セクションに
  一覧と直近 50 件の実行履歴があり、一時停止／再開／今すぐ発火／削除ができます。
  スケジューラは**既定で ON** です（`AF_SCHEDULER_INTERVAL=0` で opt-out）。長寿命
  セッションの再利用（`session_mode=reuse`）にも対応し、ピン留めとローテーションを
  指定できます。
- **Cursor CLI 対応（`kind=cursor`）** — 対応エージェント CLI は 6 種になりました。
  サインインは login のみ（ブラウザで承認・コードの貼り付けは不要）、ターミナルと
  マネージド（`cursor-agent acp`・既定）の両実行方式に対応、モデルカタログはサインイン中の
  アカウントに対してライブに取得します。CLI の版はピン留めし、公式の自己更新 2 経路を
  無効化しています。Free プランではモデルピッカーを Auto + Composer に絞り、実際に使える
  ものだけを出します。
- **Subversion チェックアウト** — SVN の URL を基本認証（stdin 渡し・auth cache 無効）で
  チェックアウトできます。サブパス指定・複数 path にも対応します。資格情報は任意で暗号
  ストアに保存でき、最長プレフィックス一致で再利用されます。自己署名証明書はサーバ単位で
  信頼できます（opt-in）。作業コピーのロックは自己修復し（`cleanup` + 再試行）、明示的な
  「ロックを解除」操作もあります。SVN の作業コピーはその場で起動します（worktree は
  適用外）。並行作業は別 path のチェックアウトで隔離してください。
- **ホストの `af` バイナリの自動更新（native）** — 日次の systemd user timer が最新
  リリースを stage します（`af update`・sha256 検証・既定 ON）。適用は明示操作で、
  「設定 › 環境」の「再起動して適用」または手動 restart で行います。実行中のセッションが
  不意に切れることはありません。`AF_VERSION` でピン留めすれば完全に停止できます。

### 改善

- **GitHub Copilot CLI** が動的カタログからのモデル選択と、ワークスペースバーの使用量
  チップ（プラン表示付き）に対応しました。
- **エージェント表示の統一** — 3 段命名（short / label / displayName）をレジストリを正として
  一本化し、種別の色を CSS カスタムプロパティに 1 ソース化しました。
- **設定モーダルを再編**しました。10 個のフラットなタブから、左レールの 3 グループへ。
  接続と動作を分離し、確認ダイアログの導線も統一しました。
- **Console↔コントロールプレーンの通信量を大幅に削減**しました。gzip と immutable
  キャッシュ、ETag/304 による再検証、WebSocket の permessage-deflate、そして 4 本の常設
  ポーラーを置き換える単一の Server-Sent Events ストリーム（`/api/events`）です。ポーラーは
  フォールバックとしてのみ動きます。
- **ミラーの堅牢化** — スクロール追従が現在位置を正直に反映し、初期位置が最下部で安定し、
  sticky な「最新へ」ボタンを追加しました。返信が描画される前の空白は解消し、スラッシュ
  コマンド送信後の「反映待ち」も解消、画像ライトボックスがブラウザの「戻る」に応答します。
- キーボード: 通知トグル群を `n` グループへ再編しました（音声・Slack・Discord・制限
  リセット、状態トースト付き）。
- shell / SSM セッション: 接続名を別名＋日時にし、接続モーダルに頻度順のクイック接続
  カードを出し、リーダーキーを端末へ透過できるようにしました（`Ctrl+K` / `Ctrl+P`・
  既定 OFF）。
- 起動モーダルがスマートフォンからの画像添付に対応し、掃除後に左ペインが即時反映される
  ようにしました。
- **利用ガイドを二言語化**しました。英語を正（`.md`）とし、日本語を併記します（`.ja.md`）。
- 外観ポップオーバーに詳細ボタンを追加しました。
