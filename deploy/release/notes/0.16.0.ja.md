自分では絵を描けないセッションが画像を生成できるようになり、できた絵は会話の中に出ます。
ずんだもんの声は聴いている人がいる間だけ動くようになり、設定に「マシン」タブが増えて、
自分のワークスペースが何の上で動いているのかが分かるようになりました。

### New

- **セッションが画像を生成できるようになりました。** 自前の画像生成を持たないエージェント
  （claude / opencode など）に `generate_image` ツールを出します。Codex のセッションは
  これまでどおり CLI 内蔵のものを使います。画像 1 枚ごとに接続中の ChatGPT プランの枠を
  消費するため既定は OFF で、設定 > エージェントで会員ごとに有効にします。
- **生成した画像が会話の中にカードで出ます。** サムネイル付きで、押せば原寸で開けます。
  これまではツールの痕跡とパスだけが残り、絵を見るには自分で探しに行く必要がありました。
  claude / opencode / copilot のセッションが対象です。
- **ずんだもんの声をオンデマンドで起動できるようになりました。** ECS の配備では VOICEVOX
  エンジンの起動と停止を Agent Fleet 自身が行います。管理者は「無効 / 常時稼働 /
  オンデマンド」から選び、オンデマンドは読み上げの需要が溜まった時点で起動し、しばらく
  誰も読み上げなければ停止します。起動が終わるまでは Polly が代読し、読み上げ設定の
  「ずんだもんを呼ぶ」で待たずに起こせます。
- **設定に「マシン」タブが増えました。** 自分のワークスペースが動いている箱
  （インスタンス種別・アーキテクチャ・vCPU・メモリ上限）を、コンテナの中から実測した値と
  配備の宣言値の 2 段で出します。1 時間ぶんのリソース推移のグラフは、アイドル中も動き
  続けます。ワークスペースバーのリソースのポップオーバーからも辿れます。
- **`Ctrl`+`R` で過去に送った文を検索できます**（ミラーのコンポーザー・bash の
  reverse-i-search と同じ操作）。一致した文はコンポーザー本体に映るので、長いプロンプトも
  全文を読んでから決められます。`Ctrl`+`R` / `Ctrl`+`S` で前後へ、`Enter` で入力欄に入れ
  （送信はしません）、`Esc` で元の下書きに戻ります。
- **設定 > ツールチェーンから Node 26 を導入できます。**

### Improved

- **共有された画像は、ペインではなく絵として開きます。** 「共有ファイル」の画像カードは
  ライトボックスで原寸表示になり、ファイルペインはカード右上のボタンに移りました。
  ライトボックスはズームとパンができます（ホイール・ピンチ・ダブルクリック・拡大中の
  ドラッグ）。
- **長い会話ほど開くのが遅くなる、が無くなりました。** 長い Codex のセッションに戻るたび
  数秒かかっていたのは、ポーリングのたびに会話を丸ごと読み直していたためです。OpenCode の
  転写もメッセージごとに 1 クエリ引いていました。どちらも増えた分だけを読みます。
- **共有画像のパネルはサムネイルを取得します。** これまでは原寸のバイトを落としてから
  ブラウザで縮めていました。
- Node 18 は 2025 年 4 月に EOL のため、設定 > ツールチェーンの一覧から外しました。すでに
  選んでいるワークスペースはそのまま使えます。

### Fixed

- **スマートフォンでワークスペースバーが画面幅を超えていました。** ページがブラウザに
  ズームアウトされ、等倍でなくなると横スワイプが一切効かなくなります（左ペインを引き出す
  端スワイプを含む）。「要再起動」のピルは目立つきっかけでしたが原因ではありませんでした。
- **質問カードの選びかけが、タブを切り替えると消えていました。** 選択肢を選んでから、
  根拠のファイルや差分を見に行って戻ると、カードが空になっていました。
- **スマートフォンで、選択の色チップがブラウザ純正のコピー／共有メニューに隠れていました。**
  あのメニューはページ側からは抑止できないため、チップを画面の下端へ逃がしました。
- **すでに終了したエージェントのプロセスが「稼働中」と報告されることがありました。**
  Console 上では生きているセッションに見えていました。
