Sessions now link themselves to the issues, tickets and pull requests they work on, and tell you
when a pull request is ready to merge, merged or closed. Plans can be reviewed automatically for
several rounds, Home gets an "At a glance" section, and OpenCode 1.x is no longer supported.

### New

- **Sessions link to the work they do.** Besides the item a session was launched from, a session
  is linked to its branch's pull request (GitHub and Bitbucket), the Jira keys in its branch name
  or PR title, and the issues its PR closes; agents can add links with the `link_work_item` tool,
  and children, forks and moves inherit them. Item details list every linked session, also while
  the workspace is stopped, with a Remove button, and merged or closed PRs are drawn as done.
  ([#3134](https://github.com/k-k1/agent-fleet/issues/3134),
  [#3147](https://github.com/k-k1/agent-fleet/issues/3147),
  [#3166](https://github.com/k-k1/agent-fleet/issues/3166))
- **Pull request notifications.** The notification centre tells you once when a session's GitHub PR
  is ready to merge (checks passed, mergeable, approved or no review needed), merged or closed.
  ([#3131](https://github.com/k-k1/agent-fleet/issues/3131))
- **Automatic plan review rounds.** The live plan card has "Review automatically, up to N rounds"
  (off by default): while the reviewer asks for changes, each re-presented plan goes back to it
  without a click, and the loop stops on approval, an unclear verdict or the round limit.
  ([#2810](https://github.com/k-k1/agent-fleet/issues/2810))
- **"At a glance" on Home:** tiles for the machine, running time, agents, model usage and usage
  limits, each opening its detailed view. ([#2362](https://github.com/k-k1/agent-fleet/issues/2362))
- **Region format and time zone.** Settings › Display has both next to the display language; dates
  and numbers across the Console, and Markdown exports, follow them.
  ([#2185](https://github.com/k-k1/agent-fleet/issues/2185))
- **"Not responding" workspaces.** When a running workspace's Agent stops answering for a few
  minutes, the workspace bar shows a Not responding badge advising stop and start, and tenant
  admins see it in member stats and get a notification. Nothing is stopped automatically.
  ([#2518](https://github.com/k-k1/agent-fleet/issues/2518))
- **Admin notifications for member problems:** tenant admins are told when a member's home volume
  is nearly full or the member's last start failed to install a tool.
  ([#2427](https://github.com/k-k1/agent-fleet/issues/2427))
- **GKE: optional egress archive bucket.** The GKE Terraform stack can create, or grant access to, a
  Cloud Storage bucket for the egress archive. Acceptance against real Cloud Storage is still open.
  ([#2733](https://github.com/k-k1/agent-fleet/issues/2733))

### Improved

- **Re-authenticate for every agent card.** Antigravity, Cursor, Kiro and Muse Code cards in
  Settings › Agents have a Re-authenticate button, and a refused prompt's toast names the agent
  whose login expired. ([#3025](https://github.com/k-k1/agent-fleet/issues/3025),
  [#3122](https://github.com/k-k1/agent-fleet/issues/3122))
- **Usage-limit auto-resume:** a booked auto-resume stays visible on a stopped session, moves
  earlier when a Claude or Codex limit lifts early, and is cancelled when you carry on by hand.
  ([#3185](https://github.com/k-k1/agent-fleet/issues/3185),
  [#3186](https://github.com/k-k1/agent-fleet/issues/3186),
  [#3196](https://github.com/k-k1/agent-fleet/issues/3196))
- **Usage chips keep their last reading** across Agent restarts, with its real age.
  ([#3127](https://github.com/k-k1/agent-fleet/issues/3127))
- **Settings › Machine lists the Maven and npx caches** among the tool caches you can size and
  empty. ([#3079](https://github.com/k-k1/agent-fleet/issues/3079))
- **The audit log covers more changes:** connections and API keys, MCP servers, locks and spend
  caps. ([#2883](https://github.com/k-k1/agent-fleet/issues/2883))

### Fixed

- **An approval decided right at its timeout** could still be reported as approved although nothing
  ran. ([#3042](https://github.com/k-k1/agent-fleet/issues/3042),
  [#3157](https://github.com/k-k1/agent-fleet/issues/3157))
- **A pending Claude question was drawn twice** in the mirror, once as an inert card and once as
  the one to answer. ([#3190](https://github.com/k-k1/agent-fleet/issues/3190))
- **Work-item details on a narrow screen:** the linked sessions' rows overflowed the dialog and long
  titles dropped below their icon. ([#3175](https://github.com/k-k1/agent-fleet/issues/3175))

### Upgrade notes

- **OpenCode 1.x is no longer supported.** The image has shipped OpenCode 2 since 0.32.0; Agent
  Fleet now refuses to start an OpenCode 1.x, and a rollback means pinning an earlier 2.x release.
  A leftover `opencode-ai` install in `~/.local` is removed at workspace start, and a home whose
  OpenCode history is still in the 1.x format is migrated once, as before. If you had tried the
  earlier `opencode-major 2` opt-in, its install and database under `~/.local/share/agent-fleet/`
  (`opencode2`, `opencode2-data`) are no longer read and were never merged; delete them when you
  no longer need them.
  ([#3132](https://github.com/k-k1/agent-fleet/issues/3132))
