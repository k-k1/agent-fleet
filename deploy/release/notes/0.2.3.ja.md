メモをセッションへ直接ドラッグできるようになりました。細かい修正も入っています。

### New

- **メモをセッションの入力欄へドラッグできます。** キューに溜めたメモをそのまま
  入力欄へ落として送れます。メモキュー自体も並び順と行の見分けが良くなりました。

### Improved

- GitHub トークンを発行するときに必要な権限を設定モーダルが説明します。
- clone / チェックアウトが終わると左ペインを再読み込みするので、新しい作業コピーが
  手動更新なしで現れます。
- `native` ランタイムでアカウントメニューを常時表示にし、SVN のフォルダ命名と
  作業開始モーダルの文言を直しました。

### Fixed

- 切り離しボタンがペインヘッダーの操作と重なっていました。
