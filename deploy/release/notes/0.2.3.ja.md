メモをセッションへ直接ドラッグできるようになりました。あわせて小さな修正をいくつか
入れています。

### 新機能

- **メモをセッションのコンポーサーへドラッグ入力。** キューに溜めたメモを、コンポーサーへ
  直接ドロップして入力できます。メモキュー自体の整列と行の区別も分かりやすくしました。
- `native` ランタイムでアカウントメニューを常時表示するようにしました。

### 改善

- GitHub トークンを発行するときに必要なパーミッションを、設定モーダルで補足するように
  しました。
- clone / checkout の完了時に左ペインを再読み込みするようにしました。手動で更新しなくても
  新しい作業コピーが現れます。
- SVN: フォルダ名の付け方と、作業開始モーダルの文言を修正しました。

### 修正

- ポップアウトボタンがペインヘッダのコントロールと重なっていました。
- dist README の表記と、利用ガイドのエージェント羅列を修正しました。
