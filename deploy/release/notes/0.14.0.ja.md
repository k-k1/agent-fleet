ワークスペースで動かしている Web アプリを、専用の URL で開けるようにしました。起動のたびに
発行されるサブドメインで、既定ではログインが要り、同じテナントのメンバーにも見せられます。
File ペインは PDF を描き、Office 文書も簡易プレビューできます。利用ガイドは英語と日本語の
独立したツリーになりました。

### New

- **ワークスペースの起動ごとに、専用のプレビュー URL を発行します。** 許可したポート
  （既定は `3000, 8080`）が `https://{slug}-{port}.{プレビュー用ドメイン}/` の**ルート
  直下**に出ます。React / Next.js や Spring Boot の組み合わせが必要とするのはこの形で、
  `/preview/{port}` のパス方式では出せませんでした。既定ではログインが要り、URL を起動を
  またいで固定する・同じテナントのメンバーに見せる・ログインなしで公開する、が選べます
  （最後のものは起動のたび OFF に戻ります）。デプロイ側にプレビュー用ドメインが要ります
  （Upgrade notes 参照）。無い場合はこれまでどおりパス方式だけになります。
- **PDF を File ペインで開けます。** 「(バイナリ, 86.8 KB)」で終わらず、縦の連続スクロール・
  ズーム・ページ番号で読めます。フォントを埋め込んでいない日本語の PDF も文字化けしません。
- **Word・Excel・PowerPoint・OpenDocument・EPUB を簡易プレビューできます。** 本文と表は
  出ますが、ページの体裁・図形・セルの色は再現しません。画面にそう明示し、原本の
  ダウンロードも隣に残しています。
- **まだどこにも無いものを、新しく始められます。** フォルダを作ると git リポジトリとして
  初期化され、そのまま「作業を始める」へ続きます。最初のコミットまでは新しい作業コピーを
  作れないので、起動ダイアログにその旨を出します。
- **セッション本体にも金額が付きます。** 個人設定のタブは **「エージェント使用量」** に
  改称し、セッションが使ったトークンを API 換算した推定額を出します。Anthropic 以外の
  モデルも換算します。推定は `≈` 付きで実測とは分けて表示し、単価を持たないモデルの消費は
  0 と混ぜずにその旨を申告します。
- **端末のヘッダにワークスペースまでの往復時間を出します。** 「打鍵が遅い」ときに、回線が
  遅いのか画面が遅いのかを切り分けられます。

### Improved

- **端末の反応が速くなりました。** Esc が常に 0.5 秒遅れており（claude・codex・vim の
  Esc 起点のキーも同様）、さらに打鍵が途中の DB 書き込みを待たされることがありました。
- **ドキュメントを読者で分けました。** 英語と日本語の利用ガイド、プロダクトを紹介する
  README、そして開発者向けの資料、の 3 つです。ガイドはすべてのワークスペースに丸ごと
  配られます。これまではロールで棚を切っていたため、読者によってはガイド内のリンクが
  どこにも行き着きませんでした。
- **タブを右クリックすると、左ペインのセッション行と同じメニューが出ます**（停止・改名・
  引き継ぎ・アーカイブなど）。メニューキーでも開きます。
- **長い作業過程・思考は、本文の末尾からも閉じられます。** 見出しまでスクロールして戻る
  必要がなくなりました。

### Fixed

- **キャンセルした質問が、何も効かないカードとして出直していました。** ミラーの質問を
  キャンセルすると同じ質問が回答フォーム付きで再び現れ、選んでも送ってもキャンセルしても
  まったく無反応でした。
- **承認したプランに「却下」バッジが付くこと**がありました。プラン本文が却下ややり直しに
  触れているだけで、そう判定されていました。
- **共有先では、質問が出ているあいだ何も見えませんでした。** 会話がそこで終わったように
  見え、一覧のチップだけが「質問中」と言っている状態でした。
- **他のセッションからのメッセージが途中で消えることがありました。** claude 自身の経路で
  届いたものは CLI には来ていても画面には出ていませんでした。送信元のセッション名付きで
  表示されるようになり、セッション間メッセージを切る設定はこの経路にも効きます。
- **新しい作業コピーで始めたセッションが、何週間も前の状態から始まることがありました。**
  ブランチは `origin` の先端から切ります。作ったばかりの作業コピーの中だけで寄せるので、
  切り出し元は動きません。
- **SQLite で新規に構築したコントロールプレーンで、後から足した列が失われていました。**
  ワークスペースごとの設定を保存する先がありませんでした。新しい DB は自分で直します。
  既存の DB は元から影響を受けていません。
- **ミラーの入力欄で打鍵のたびに転写が最新のメッセージから浮いていました。** 末尾への
  追従が切れるほど浮くことがありました。
- **OpenCode のモデル一覧の並びが、ピッカーを開くたびに変わっていました。**
- **`ecs-ec2` で golden を焼き直すと、ECS サービスと 50 GiB のディスクが残ることが
  ありました。** ログには 1 行も出ず、課金だけが続きます。
- 細かい表示の修正: アシスタントチャットのタブが全部「チャット」ではなく会話名になり、
  課題管理の行の文字サイズが周りの行にそろいました。

### Upgrade notes

ホスト方式のプレビューにはデプロイ側のプレビュー用ドメインが要ります。`30-ingress` に
`PreviewDomain=pv.example.com`（Console の名前の**兄弟**・同じホストゾーン）を渡すと、
ワイルドカードの証明書と DNS レコード、コントロールプレーンの `AF_PREVIEW_DOMAIN` が
足されます。既存の証明書には触れません。空のままなら何も作られません。

エージェント CLI のピンは 0.13.1 から変わりません。
