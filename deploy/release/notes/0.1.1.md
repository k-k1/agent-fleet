A documentation and packaging follow-up to the first release, plus one Console change.

### New

- **Assistant settings tab** — the fleet assistant's configuration moved out of the
  session settings into its own tab, so the assistant model and the session defaults
  are no longer entangled.

### Improved

- **Everything a user of the distribution sees is now in English** — `install.sh`, the
  release and build scripts, the deployment READMEs and the CI workflows.
- The READMEs open with what Agent Fleet is and which agent CLIs it supports, and
  compare the Docker and Docker-less native runtimes.
