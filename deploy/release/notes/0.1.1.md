A documentation and packaging follow-up to the first release, plus one Console
change.

### New

- **Assistant settings tab** — the fleet assistant's configuration moved out of the
  session settings into its own tab in the settings modal, so the assistant model
  and the session defaults are no longer entangled.

### Improved

- **English-first distribution text.** Everything a user of the distribution sees
  is now in English: `install.sh`, the release/build scripts, the deployment
  READMEs, and the CI workflows. (The private repo's own docs stay as they were.)
- **A product overview in the READMEs.** The top-level README and the dist repo
  README now open with what Agent Fleet actually is and which agent CLIs it
  supports, instead of internal development status.
- The README overview gained a runtime comparison (Docker/cgroup vs. the
  Docker-less native runtime) and a note on Antigravity CLI support.
