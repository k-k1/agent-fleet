Token usage is broken down by feature, files open for edit in the Console, things you
lock stay put, and a turn that dies mid-flight resumes itself.

### New

- **Usage by feature.** A usage tab graphs token spend (and real USD where the CLI
  reports it), with session turns and the fleet's own helper calls — assistant chat,
  titles, reply suggestions, compaction, bridge replies — in one ledger, so you can see
  which feature is eating the budget.
- **Text and code editing in the File pane.** Open a file for edit, keep a dirty buffer
  with undo, and save through the workspace with revision checks. Markdown keeps edit /
  preview / split, including Marp. Nothing discards unsaved work without asking.
- **Deletion locks.** Pin a session, a working copy or an assistant conversation so
  neither a manual delete nor an automatic prune can remove it. Enforcement is on the
  REST layer, so the Console, operator tools and chat bridge all hit the same refusal.
- **Auto-resume after an aborted turn.** When a turn dies for a reason resending would
  fix, the fleet operator restarts it — twice at most, then it escalates to you. On by
  default, under Settings › Assistant. A session with no conversation linked to it is
  not auto-resumed; you still get the notification.
- **Per-purpose model picks for the assistant** — one model for assistant chat and
  another for helper generation, with a **Recommended** choice resolved from the live
  catalogue and your connection.

### Improved

- OpenCode: the model list can be shaped for Go / Zen catalogues, and a failed turn
  surfaces clearly instead of vanishing.
- Mobile settings open from a list rather than one long sheet.

### Fixed

- **Opening another chat could mix answers between conversations.**
- **Deletion-lock state lagged in the Console until a refresh.**
- Re-presented plans kept the wrong approval badge on the mirror.
- File save and restore races: a timed-out PUT no longer proceeds after the client gave
  up, and a stale read can no longer look like a successful save.
- Usage ledger: dropped folds, blocked writes and double-counted rows closed.

### Upgrade notes

Nothing to do. Auto-resume defaults to on — turn it off under Settings › Assistant if
you prefer every abort to wait for you. Existing workspaces have no deletion locks
until you set them.
