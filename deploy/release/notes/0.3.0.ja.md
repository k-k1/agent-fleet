Kiro がエージェント CLI に加わり、入力欄が返信候補を出すようになり、fleet
オペレーターが代わりに質問へ答えプランを審査できるようになりました。

### New

- **Kiro CLI 対応**で 7 種になりました。両方の実行方式、版を固定した随時インストール、
  ミラーでのコンテキストとクレジット使用量の表示に対応します。
- **返信サジェスト。** 入力欄に押せる候補チップが出ます（セッションミラーと
  アシスタントチャットの両方）。学習した定型返信を直近のメッセージで並べ替えたものと、
  ✨ ボタンで文脈に沿った候補をその場で生成したものの 2 系統です。キーボードだけで
  操作できます。
- **fleet オペレーターがセッションの質問に答え、プランを承認・却下できます。**
  プラン審査のループを無人で回す自動走行モードも追加しました（自動返信の上限は
  設定可能・既定 10・最大 50）。
- **スケジュールをセッションではなくオペレーターとの会話へ発火**できます。定時実行の
  ターンにはバッジが付き、配送はターンが実際に始まった証拠と突き合わせて確認します。
- **メモを折りたためるカテゴリにまとめました。**
- **ホスト更新の案内（native）** — 用意済みの新しいビルドを設定画面ではなく上部バーに
  出します。

### Improved

- **エージェント CLI の自己更新が実際に前へ進むようになりました。** 全ツールを 1 つの
  シャドウ方式に統一し、焼き込んだ固定版は不変のまま、自己更新を off にすれば即座に
  そちらへ戻ります。
- 使用量の推定で Opus 5 / Sonnet 5 を 1M コンテキストとして扱います。
- モバイル: エージェント選択が横スワイプになり、モーダル内でも送信キー設定が効きます。

### Fixed

- **バックグラウンドのサブエージェントが動いている最中にセッションが終わると、完了
  報告が失われることがありました。** 報告を保持して後から配送します。
- **スキルがコマンドタグを逆順に出すと、利用者のターンが丸ごとミラーから消えること
  がありました。**
- 有効なスケジュールが参照している worktree やセッションの削除を、黙ってスケジュールを
  壊す代わりに拒否するようにしました。

### Other changes

- **ライセンスと帰属を、ソフトウェアを受け取る場所に明記しました。** 配布リポジトリに
  `LICENSE` と `NOTICE` を置き、README に Apache-2.0 であることを書きました。
- **今後のリリースにはリリースノートが付きます。** 過去の版の分も遡って用意し、
  [CHANGELOG.md](CHANGELOG.md) から辿れます。
