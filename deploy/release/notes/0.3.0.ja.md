エージェント CLI に Kiro が加わり、コンポーサーに返信サジェストが付き、フリート・
オペレーターが質問への回答とプランのレビューを代行できるようになりました。

### 新機能

- **Kiro CLI 対応（`kind=kiro`）** — Kiro が加わり、対応エージェント CLI は 7 種に
  なりました。実行方式は両方に対応（ターミナル（CLI）と、`kiro-cli acp` による
  マネージド）。CLI は sha256 でピン留めした版をオンデマンド導入し、コンテキスト量と
  クレジットの使用量はミラーとセッション使用量にライブ表示されます。ピンが新しく
  なった場合は接続カードから任意に更新できます。
- **返信サジェスト** — コンポーサーに、押すだけで返信できる候補チップが出ます
  （セッションのミラーとアシスタントチャットの両方）。候補は 2 系統: 学習したクイック
  返信を直近のエージェント発言で再ランクしたものと、✨ ボタンで LLM が文脈から生成する
  ものです。キーボードだけで操作でき（Tab でフォーカス、←/→ で選択、Enter で挿入、
  Ctrl+Enter で送信）、Ctrl+クリックで即送信、画面が狭いときは 1 行に固定して左右
  スクロールします。
- **オペレーター: 質問への回答とプランのレビュー** — オペレーターがセッションの未回答の
  質問に答えられるようになりました（`answer_session_question`）。質問を消費せずに途中
  経過だけ報告することも、プランを承認・却下することもできます
  （`respond_session_plan`）。新しい自動走行モードは、プランのレビュー承認ループを
  無人で回します。自動応答の上限は設定可能です（既定 10・最大 50）。プランは会話へ
  全文転記せず、セッションへのリンクで参照します。
- **定時実行: アシスタント発火と注入元の明示** — スケジュールをセッションではなく
  オペレーターの会話へ発火できるようになりました（`session_mode=assistant`）。ユーザー
  ターンには定時実行か手動発火かを区別するバッジが付きます。また、配達はターンが実際に
  始まった証拠に照らして確認するようになり、発火していないのに fired と記録される
  ことがなくなりました。
- **メモキュー: カテゴリ階層** — メモをカテゴリごとのセクションにまとめ、折りたたみ
  できるようにしました。Ctrl+K M で開いたときはテキストエリアに自動フォーカスします。
- **ホスト更新の誘導表示（native）** — 新しいホストビルドが stage 済みのとき、設定の中で
  見つけてもらうのではなく、TOP バーのビルド表示の脇に出すようにしました。

### 改善

- **エージェント CLI の自己更新が実際に前進するようになりました。** 更新を `PATH` の
  実効 prefix に対して適用し、全ツールを統一 shadow モデルへ移行しました。焼き込みの
  `/usr/local` ピンは不変で、自己更新を OFF にすれば即座にそこへ戻ります。OpenCode 自身の
  背景 auto-updater は停止しました。
- 使用量: Opus 5 / Sonnet 5 を 1M コンテキストとして認識します（コンテキスト窓の推定を
  「200k 側だけ例外」に反転）。
- lean イメージは `—` ではなくピン留め版をカッコ付きで表示します。
- モバイル: エージェント選択を横スワイプにし、モーダル内でも送信キー設定に従うように
  しました。
- エージェント CLI のピンを、契約検証済みの最新の組み合わせへ更新しました。
- アシスタントの「ID をコピー」は会話 slug をコピーします（メニューにも slug を表示）。

### 修正

- バックグラウンドのサブエージェントが実行中にセッションが早期停止すると、完了報告が
  失われることがありました。報告を保留して後から配送します。
- ミラー: スキルが command タグを逆順で出したとき、ユーザーターンが丸ごと消えることが
  ありました。Codex 0.145 でのプラン表示の変更にも追随しました。
- 起動既定の正規化から `copilot` が漏れていました。
- 有効なスケジュールが参照している worktree／セッションの削除を、黙ってスケジュールを
  壊すのではなく拒否するようにしました。
- Kiro のレビュー指摘対応: セッション ID のフェンス、承認待ちのガード、導入処理の
  クラッシュ安全化、クロスプロセス排他、マネージドドライバでの resume／切替の堅牢化。

### アップグレード時の注意

マイグレーションや設定変更は不要です。エージェント CLI の版を固定している場合、同梱の
ピンが前進していることに注意してください。`AF_VERSION` と自己更新の opt-out の挙動は
従来どおりです。
