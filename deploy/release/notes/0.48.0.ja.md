エージェントメモリが Console に専用のビューを持ち、メモリ一つずつをファイルのように開いて編集できる
ようになりました。メモの自動実行には実行を一覧する「自動実行」ビューが加わり、キューのメッセージは
ほかのメッセージを待ったり、キューに戻されたりできます。メンバーとテナントの管理者は日ごとの利用の
履歴を見られ、Claude Code では使用量の上限のあと誰がセッションを再開するかを選べます。

### 新機能

- **メモリのビュー:** アクティビティバーのビューに、画面のプロジェクトのエージェントメモリが並び、
  検索、スコープと種類の絞り込み、整理の提案が出ます。メモリは専用のペインで開き、読む・編集する・
  ピン留めする・忘れる・履歴を見るができ、保存していない文字はファイルと同じように守られます。
  ([#4567](https://github.com/k-k1/agent-fleet/issues/4567),
  [#4568](https://github.com/k-k1/agent-fleet/issues/4568),
  [#4569](https://github.com/k-k1/agent-fleet/issues/4569))
- **「自動実行」ビュー:** アクティビティバーのビューに、メモの自動実行の実行がカテゴリごとに並び、
  作業項目、プルリクエストとその状態、実行が起動したセッションが出ます。行のメニューで実行の
  セッションを止めたり worktree を消したりでき、「終了した実行を片付ける」で終わった実行をまとめて
  片付けます。実行があなたを待っているときや最初のターンが失敗したときはアイコンに印が付きます。
  自動実行のセッションは「セッション」ビューから外れ、スケジュールのセッションは「スケジュール」
  ビューのそのスケジュールの下に入ります。
  ([#4646](https://github.com/k-k1/agent-fleet/issues/4646),
  [#4670](https://github.com/k-k1/agent-fleet/issues/4670),
  [#4674](https://github.com/k-k1/agent-fleet/issues/4674),
  [#4727](https://github.com/k-k1/agent-fleet/issues/4727),
  [#4728](https://github.com/k-k1/agent-fleet/issues/4728))
- **「共有セッション」ビュー:** 共有されたセッションはアクティビティバーの専用のビューに移り、
  引き継ぎを提案されている間は印が付きます。([#4645](https://github.com/k-k1/agent-fleet/issues/4645))
- **メモの自動実行・順序とキューへの戻し:** キューのメッセージは、同じキューのほかのメッセージが
  問題なく実行され、そのプルリクエストがマージされるまで待てます。実行は自分のメッセージをあとで
  やり直すためにキューへ戻せ、人が実行を「キューに戻す」こともできます。
  ([#4540](https://github.com/k-k1/agent-fleet/issues/4540),
  [#4541](https://github.com/k-k1/agent-fleet/issues/4541))
- **メモの自動実行・続き:** メモを承認すると、その実行が追加する続きのメモも決まった数まで承認なしで
  受け付けます（既定は 4、カテゴリごとに設定）。「続き K / M」と表示され、「連鎖を止める」で止められます。
  ([#4606](https://github.com/k-k1/agent-fleet/issues/4606))
- **メモの自動実行・実行を終える:** 開いている実行は実行履歴の行から終了でき、セッションを止めて枠を
  空けます（アーカイブはしません）。([#4515](https://github.com/k-k1/agent-fleet/issues/4515))
- **利用の履歴:** 稼働時間のグリッドの下に、ワークスペースの CPU・メモリ・負荷の測定値が日ごとの表で
  出ます。テナントの管理者はメンバーごととテナント全体の表を見られます。
  ([#4414](https://github.com/k-k1/agent-fleet/issues/4414),
  [#4493](https://github.com/k-k1/agent-fleet/issues/4493))
- **Claude の使用量上限後の再開:** 設定 → エージェント → Claude Code で、**AF で自動再開**（既定。待つ間
  ワークスペースを止めて再開時に起こせます）、**Claude の自動継続**（Claude Code 自身の待機）、**オフ**
  から選べます。([#1422](https://github.com/k-k1/agent-fleet/issues/1422))
- **Codex の起動の既定:** 新しい設定「Codex 自身のモデルと推論レベルを記憶」をオフにすると、ターミナル
  の codex で選んだモデルが、既定のまま起動した新しいセッションに持ち越されなくなります。
  ([#4590](https://github.com/k-k1/agent-fleet/issues/4590))
- **Fleet Operator:** メモの自動実行のカテゴリと実行履歴を読めるようになり、変えるときは Console の
  どの操作を押せばよいかを案内します。([#4626](https://github.com/k-k1/agent-fleet/issues/4626))

### 改善

- **メモキュー:** 実行履歴と「今すぐ実行」がカテゴリの見出しに移り、何も始められないときは理由が
  出ます。開始済みと置き換え済みのメモは一行に畳まれ、リポジトリとカテゴリの見出しはスクロールしても
  残り、リポジトリの下にカテゴリを追加でき、承認待ちのメモの数がメモのアイコンに出ます。「送信済み」は
  「開始済み」になり、メモを作ったセッションと作業項目は Console の中で開きます。あなたの対応が要る
  待ちの理由（1 日の上限、使用量の上限、置き場所がない）は警告として出ます。
  ([#4534](https://github.com/k-k1/agent-fleet/issues/4534),
  [#4682](https://github.com/k-k1/agent-fleet/issues/4682),
  [#4512](https://github.com/k-k1/agent-fleet/issues/4512),

  ([#4542](https://github.com/k-k1/agent-fleet/issues/4542))
- **モデルの利用:** テナントの「制限」タブは保存すると何が隠れるかを保存前に示し、テナントより上の

- **Kiro と Muse Code** のインストールと更新は「エージェント」ページのカードから行います。
  ([#4352](https://github.com/k-k1/agent-fleet/issues/4352))
- **ECS の EC2:** WS バーにワークスペースの負荷とホームのディスクがメンバーにも出て、テナント設定には
  選んだブーストのサイズが出ます。([#4550](https://github.com/k-k1/agent-fleet/issues/4550),
  [#4521](https://github.com/k-k1/agent-fleet/issues/4521))
- **Console:** セッションの行の PR のチップは作業項目を Console の中で開き、Bitbucket のマージの
  ダイアログは「ソースブランチを閉じる」を覚え、スマートフォンではアクティビティバーをスワイプして
  ビューを切り替えられます。([#4652](https://github.com/k-k1/agent-fleet/issues/4652),
  [#4592](https://github.com/k-k1/agent-fleet/issues/4592),
  [#4557](https://github.com/k-k1/agent-fleet/issues/4557))
- **Antigravity:** 使用量の読み取りが安定し、使用量のページへのリンクが付きます。
  ([#4694](https://github.com/k-k1/agent-fleet/issues/4694))
- **エージェント CLI の自己更新が失敗したとき**は前の版に戻します。
  ([#4641](https://github.com/k-k1/agent-fleet/issues/4641),

### 修正

- **メモの自動実行:** プルリクエストがマージされたあとや、チェックが動いていないのに実行が開いた
  ままになり、親のセッションが子の答えを待っている間に実行が閉じられることがありました。
  ([#4508](https://github.com/k-k1/agent-fleet/issues/4508),
  [#4532](https://github.com/k-k1/agent-fleet/issues/4532),
  [#4643](https://github.com/k-k1/agent-fleet/issues/4643))
- **Claude Code:** Claude Code 2.1.330 で「再認証」が失敗し、確認ありのセッションが確認なしの auto
  モードで始まっていました。([#4687](https://github.com/k-k1/agent-fleet/issues/4687),
  [#4713](https://github.com/k-k1/agent-fleet/issues/4713))
- **Antigravity:** バックグラウンドのコマンドが終わったセッションがいつまでも待機のままになることがあり、
  途中のターンの終わりがターンの終わりとして報告されていました。
  ([#4581](https://github.com/k-k1/agent-fleet/issues/4581),
  [#4267](https://github.com/k-k1/agent-fleet/issues/4267))
- **OpenCode:** セキュリティのための再起動のあと、マネージドのセッションが止まったままになることが
  ありました。([#4552](https://github.com/k-k1/agent-fleet/issues/4552),
  [#4281](https://github.com/k-k1/agent-fleet/issues/4281))
- **モデルの利用:** 禁止したエージェントが、切り替えのダイアログ、チャットのエージェントのメニュー、
  AI アシストの固定、オンボーディングに残っていました。
  ([#4360](https://github.com/k-k1/agent-fleet/issues/4360))
- **ECS の EC2:** ホームのアタッチが遅いと正常なスロットが隔離され、隔離されたスロットを終了できません
  でした。([#4511](https://github.com/k-k1/agent-fleet/issues/4511),
  [#4510](https://github.com/k-k1/agent-fleet/issues/4510))
- **Console:** ライトテーマでアクセント色の上の文字、セグメントの選択、アクティビティバーの印が
  読みにくく、WS バーに空の「でリセット（）」の行が出て、PR のマージの注記はチェックが動いている間も
  失敗と言っていました。([#4525](https://github.com/k-k1/agent-fleet/issues/4525),
  [#4595](https://github.com/k-k1/agent-fleet/issues/4595),
  [#4549](https://github.com/k-k1/agent-fleet/issues/4549),
  [#4483](https://github.com/k-k1/agent-fleet/issues/4483))
- **起動されたセッションのプロンプト**が、呼び出し元の指定した返事のしかたを上書きしていました。
  ([#4642](https://github.com/k-k1/agent-fleet/issues/4642))
- **同梱の GitHub CLI** を CVE-2026-78661 の修正版に上げました。
  ([#4703](https://github.com/k-k1/agent-fleet/issues/4703))
