Bitbucket 接続の修正と、セッション引き継ぎモーダルの統一です。

### 新機能

- **セッションの引き継ぎを 1 つのモーダルに統一。** 作業を新しいセッションへ引き継ぐ操作
  （従来の「fork」）が単一のダイアログになり、先に引き継ぎ先を選ぶ形になりました。選択肢は
  起動モーダルと同一です。内部名は *fork* から *handoff* へ変更しました。

### 改善

- **Bitbucket 接続が必要なものを明示するようになりました。** 接続カードからトークン発行
  ページへ直接リンクし、必要なスコープを明示します。接続時にスコープの充足を検査するため、
  権限が足りないトークンは後で失敗する前に検出されます。
- Cursor のセッションで、応答ごとにモデルバッジを表示します。
- 送信キーの設定を、他のキーボード設定と並ぶ「Keys」タブへ移動しました。

### 修正

- **Bitbucket の API トークンでの clone / push が認証に失敗する問題**を修正しました。
- **質問への回答・プラン承認・委譲の結果が、ライブのミラーに反映されない問題**を修正しました
  （リロードするまで表示されませんでした）。
