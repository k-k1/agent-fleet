Bitbucket 接続の修正と、セッション引き継ぎモーダルの統一です。

### New

- **セッションの引き継ぎが 1 つのモーダルになりました。** 作業を新しいセッションへ
  持ち越す操作（旧「fork」）は、最初に引き継ぎ先を選ぶ 1 つのダイアログになり、
  選択肢は起動モーダルと同じです。

### Improved

- **Bitbucket の接続カードが必要なものを教えてくれます。** トークン発行ページへの
  リンクと必要なスコープを示し、接続時にスコープを検査するので、権限不足のトークンが
  後で失敗する形にならなくなりました。
- Cursor のセッションは返信ごとにモデルのバッジを表示します。送信キーの設定は
  *Keys* タブに移しました。

### Fixed

- **Bitbucket API トークンでの clone / push が認証に失敗していました。**
- **セッションが動いている間、質問への回答・プラン承認・委任がミラーに出ません
  でした** — 再読み込みするまで表示されませんでした。
