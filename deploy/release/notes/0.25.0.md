Branch names for a session started from a work item now follow the repository's own rules — its
git-flow settings, a `.agent-fleet/branches` file or Bitbucket's branching model. Open pull requests in
Work items show their CI status and conflicts. `af-aws-exec` runs your assume-role and
`credential_process` profiles, and Settings › AWS profiles/SSM logs in from the profile's row. A
Managed session that fails to start now shows what its CLI printed.

### New

- **Branch names follow the repository's rules.** Starting a session from a work item fills in the
  branch name and its base from the repository's `.agent-fleet/branches`, its git-flow settings
  (`.gitflow` or the clone's `gitflow.*`) or Bitbucket's branching model, says which rule chose the
  base, and notes a name that does not match. It never refuses a name. The rename dialog offers the
  repository's branch kinds, and the branch template gains `{ref}`, `{num}`, `{project}`, `{type}`
  and `{prefix}`. Initializing git-flow from the Console is still to come
  ([#1126](https://github.com/k-k1/agent-fleet/issues/1126)).
  ([#1120](https://github.com/k-k1/agent-fleet/issues/1120),
  [#1124](https://github.com/k-k1/agent-fleet/issues/1124),
  [#1125](https://github.com/k-k1/agent-fleet/issues/1125))
- **Open pull requests in Work items show their CI status and merge conflicts** — failing, running
  or passing, and a mark when the PR conflicts with its base. Nothing is drawn when GitHub has no
  answer yet.
  ([#1113](https://github.com/k-k1/agent-fleet/issues/1113))
- **The work item's "already started" list shows session names**, and a session that has since been
  archived can be restored from there.
  ([#1108](https://github.com/k-k1/agent-fleet/issues/1108))
- **`af-aws-exec` runs your own assume-role (`role_arn` + `source_profile`) and `credential_process`
  profiles** when you name the account with `--account`. It checks the whole chain first and passes
  only short-lived credentials. Assuming a role from a Settings SSO profile is still to come
  ([#1109](https://github.com/k-k1/agent-fleet/issues/1109)).
  ([#1107](https://github.com/k-k1/agent-fleet/issues/1107))
- **Settings › AWS profiles/SSM** (was "AWS SSM") has **Log in** and a login-state badge on each
  profile row, so you can sign in before a command asks.
- **A Managed session that fails to start shows the last lines its CLI printed**, with secrets
  removed, instead of only "did not start in time".
  ([#1076](https://github.com/k-k1/agent-fleet/issues/1076))
- **`create_session` can set the child's reasoning effort** (it needs `model` too).
  ([#1068](https://github.com/k-k1/agent-fleet/issues/1068))

### Improved

- **The image studio on a phone**: the draft bar stays in view while you type, the composer sits on
  the pane's bottom edge, toasts no longer cover the composer, and a tap outside dismisses them.
  "N pictures are ready" stays until you look, and a studio started in a new worktree takes that
  worktree's name.
  ([#1089](https://github.com/k-k1/agent-fleet/issues/1089),
  [#1090](https://github.com/k-k1/agent-fleet/issues/1090))
- **AI-suggested titles for a session started from a work item keep the item's key** (`#1146`,
  `PROJ-123`).
- **The Work items filter** has the same box and × as the other filters, and Escape clears it.
- **A translated question card asks again for the fields the first translation dropped.**
  ([#1114](https://github.com/k-k1/agent-fleet/issues/1114))
- **The engine catalogue sizes the memory of gemma-4, LFM2.5 and GPT-OSS models correctly**, so they
  can be enabled without declaring their memory by hand.
  ([#975](https://github.com/k-k1/agent-fleet/issues/975))
- **llama.cpp sessions with long conversations read faster in the mirror.**

### Fixed

- **codex sessions on Terminal (CLI) ran in the home directory** instead of their working copy, could
  not be resumed, and Agent Fleet's own tools could not tell which session called them. Switching a
  Managed codex session to Terminal no longer stops at "This conversation is open in another app".
  ([#1131](https://github.com/k-k1/agent-fleet/issues/1131))
- **On AWS deployments, an AI suggestion (title, branch name, reply) could fail** when the model took
  close to a minute to answer.

alone.
