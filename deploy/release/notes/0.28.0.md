Past sessions' conversations can be searched from the command palette and by agents, and sessions can
be found by the issue or pull request they belong to. A session can carry a spend budget and stops
after its turn when it reaches it. Agents can share an Agent Fleet memory across every agent kind,
off until each member turns it on. GitHub can be connected through a built-in app, the inpaint mask
is painted on the picture, and a LAN ComfyUI can be set from the admin panel. On AWS, member secrets
can be sealed with a KMS key.

### New

- **Search past conversations.** The command palette's **Conversations** mode finds what was said in
  this workspace's past sessions, every kind, stopped and archived ones included, and opens the
  session at that turn. Agents can search the same history with the `search_sessions` af MCP tool (Settings › Agents ›
  Past-session search, on by default).
  ([#1558](https://github.com/k-k1/agent-fleet/issues/1558))
- **Find a session by its issue or PR.** `#1662`, `owner/name#1662` or `PROJ-123` in the left-pane
  filter or the command palette finds the session whose pull request it is or that was launched from
  that ticket.
  ([#1665](https://github.com/k-k1/agent-fleet/issues/1665))
- **Ticket references in the mirror and the assistant chat link to the work item.** `#N`,
  `owner/name#N` and Jira keys open the work item's detail; Ctrl/⌘-click opens the tracker.
  ([#1659](https://github.com/k-k1/agent-fleet/issues/1659))
- **Spend budgets.** A session started with **Budget (USD)**, or under Settings › Agents › Budget for
  new sessions, stops after its turn when its estimated spend reaches the budget, and you are notified;
  **Raise budget & resume** carries on. A turn that runs to twice the budget is halted. Kinds that
  report no token counts are not stopped.
  ([#1054](https://github.com/k-k1/agent-fleet/issues/1054))
- **Agent Fleet memory.** With Settings › Agents › Agent Fleet memory on, sessions of every kind read
  and write one shared memory through af's `memory_*` tools. It is off by default. Writes need no
  approval, so the Console lists every change with its author and lets you revert or forget it.
  ([#1569](https://github.com/k-k1/agent-fleet/issues/1569))
- **Connect GitHub with a built-in app.** "Connect with OAuth" can use a built-in OAuth App or GitHub
  App; the deployment's default tenant uses the built-in OAuth App when it has no app of its own. A
  tenant's own app is recognised as an OAuth App or a GitHub App when it is saved.
  ([#1667](https://github.com/k-k1/agent-fleet/issues/1667))
- **Paint the inpaint mask on the picture.** **Fix this part** opens a canvas over the picture with a
  brush, an eraser, zoom and undo, and saves the mask for the next run.
  ([#956](https://github.com/k-k1/agent-fleet/issues/956))
- **The image gallery** can include subfolders, sends a picture to a session or the assistant from its
  menu, and reads width × height with the camera's orientation.
  ([#961](https://github.com/k-k1/agent-fleet/issues/961))
- **LAN ComfyUI**: super admins set its URL and key under Admin › Inference engines without restarting
  the Control Plane, and `deploy/comfyui-lan/comfyui-lan.sh` runs the same pinned ComfyUI image on a
  LAN GPU host.
  ([#957](https://github.com/k-k1/agent-fleet/issues/957),
  [#958](https://github.com/k-k1/agent-fleet/issues/958))
- **AWS: seal member secrets with a KMS key** instead of the local key (`AF_KEY_CUSTODIAN=kms` with `AF_KMS_KEY_ID`; on ECS
  the `CustodianKmsKeyArn` parameter). Values sealed before keep opening with the local key. Opt-in,
  and not yet run on a real deployment.
  ([#969](https://github.com/k-k1/agent-fleet/issues/969))

### Improved

- **Settings › Notifications is one table**: each kind of notification against the unread dot, the OS
  notification and read-aloud. Existing choices carry over.
  ([#1085](https://github.com/k-k1/agent-fleet/issues/1085))
- **The WS bar folds by width**: labels go icon-only and items move behind `⋯` instead of wrapping into
  a tall bar.
  ([#1642](https://github.com/k-k1/agent-fleet/issues/1642))
- **Compacting is shown live for codex Terminal and OpenCode sessions**, and OpenCode's reported cost is
  used in usage.
  ([#1139](https://github.com/k-k1/agent-fleet/issues/1139),
  [#1082](https://github.com/k-k1/agent-fleet/issues/1082))

### Fixed

- **A session whose first request was refused by the usage limit declined it when auto-resumed**; it
  now carries the request out.
  ([#1658](https://github.com/k-k1/agent-fleet/issues/1658))
- **Picking an option on a single-choice question erased the text typed into its free-text row.** The
  text is kept, greyed out, and only the picked option is sent.
  ([#1653](https://github.com/k-k1/agent-fleet/issues/1653))
- **A turn could be reported finished early when one of your own Stop hooks blocked the stop.**
  ([#1600](https://github.com/k-k1/agent-fleet/issues/1600))
- **Changed files misplaced files when `~/repos` or `~/.af-work` is a symlink.**
  ([#1610](https://github.com/k-k1/agent-fleet/issues/1610))

### Upgrade notes

- **GitHub**: the default tenant of a deployment with no GitHub app of its own now offers "Connect with
  OAuth" through the built-in OAuth App. Set `AF_GITHUB_BUILTIN_APPS=off` on the Control Plane to
  withdraw the built-in apps.
  ([#1667](https://github.com/k-k1/agent-fleet/issues/1667))
- Nothing else to do: the KMS key custodian and the LAN ComfyUI panel are opt-in, and `update.sh`
  leaves `CustodianKmsKeyArn` empty.

Agent CLI pins are unchanged from 0.27.0.
