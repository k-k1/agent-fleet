ペインを別のブラウザタブに切り離せるようになり、スケジュールに詳細・編集画面が
付き、Cursor でアシスタントチャットを動かせるようになりました。

### New

- **ペインを別タブに切り離せます。** どのペインも独立したブラウザタブへ切り離して
  そのまま使えます。ミラーやターミナルを 2 枚目のモニタに置くのに便利です。
- **スケジュールの詳細・編集モーダル** — スケジュール行のケバブメニューから開きます。
  登録済みのスケジュールを、オペレーターとの会話を経由せずに確認・変更できます。
- **Cursor をアシスタントチャットに使えます。**
- メモキューの行とアシスタント会話の行に `⋯` メニューが付き、削除をその中へ入れ
  ました。常時表示の削除ボタンはスマートフォンで誤って押しやすいためです。

### Improved

- 設定モーダルを大きくし、スマートフォンでは現在のタブを見出しに出します。
- shell / SSM セッションは最大セッション数に数えなくなりました。`native` ランタイム
  には上限がありません。
- 引き継ぎモーダルの選択肢を起動モーダルに揃え、コマンドパレットの矢印キー選択が
  選択位置に追従してスクロールするようにしました。
- エージェント種別ごとの機能対応表をドキュメントに追加しました。

### Fixed

- **ヘッドレスの Cursor が、確認なしに書き込み操作を実行できてしまいました。**
  アシスタントチャットでは読み取り専用で動かします。
- **長期セッションを再利用する定時実行が、黙って消えることがありました。** 配送は
  受け入れ可能かを確認してから行い、重複によるスキップは通知センターに出るように
  しました。
