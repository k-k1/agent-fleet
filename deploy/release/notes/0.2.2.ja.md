ペインをブラウザの別タブへ切り離せるようになり、スケジュールに詳細・編集画面が付き、
アシスタントチャットのバックエンドに Cursor を選べるようになりました。

### 新機能

- **ペインを別タブへ切り離し。** どのペインも別のブラウザタブへ切り離して、そのまま使い
  続けられます。ミラーやターミナルを別のモニタに置きたいときに便利です。
- **スケジュールの詳細・編集モーダル** — スケジュール行のケバブメニューから開けます。
  登録済みのスケジュールを、オペレーターとの会話に戻らずに確認・変更できます。
- **アシスタントチャットで Cursor を使えるようになりました。** アシスタント作成の
  ピッカーに Cursor が出るようになり、既定モデルを機能対応表に記載しました。
- 行メニュー: メモキューの行と、左ペインのアシスタント会話行の両方に `⋯` メニューと
  右クリックメニューを追加し、削除をそこへ集約しました（常時表示の削除ボタンは、
  スマートフォンで誤タップしやすかったため置き換えています）。
- アシスタントの回答が完了したとき、コンポーサーにフォーカスが戻ります（スマートフォンを
  除く）。
- **エージェント種別ごとの機能対応表**をドキュメントに追加し、自律実行に関する免責も
  記載しました。

### 改善

- 設定モーダルを拡大しました（1000×760）。スマートフォンでは現在のタブを見出しとして
  表示します。
- アシスタントの優先順位に Cursor を追加しました。
- 最大セッション数の制限から shell / SSM セッションを除外しました。`native` ランタイムでは
  制限なしです。
- コマンドパレットの矢印キー選択が、選択位置にスクロール追従するようになりました。
- 引き継ぎモーダルの選択肢を起動モーダルと整合させ、英語プロンプトにも対応しました。

### 修正

- **ヘッドレスの Cursor が、依頼していない書き込み操作を実行することがありました。**
  アシスタントチャットでは read-only（`--mode ask`）で動かすようにしました。
  `cursor-agent -p` は自力では fail-closed にならないことがライブ検証で判明したためです。
- **長寿命セッションを再利用する定時実行が、無音で消えることがありました。** 配送を
  readiness ゲートで確認するようにし、`skipped_overlap` も「無人での非配送」として
  通知センターに出すようにしました（従来は気づかれずに通り過ぎていました）。
