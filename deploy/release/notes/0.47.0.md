Tenant and deployment administrators can now choose which model routes members may use, and
whatever they forbid disappears from members' screens. The Console's left pane becomes an activity
bar with one view at a time, memo auto-run can tidy the waiting memos and take work items, and an
ECS EC2 member can boost their next start one size up. On ECS, read the Upgrade notes before
running `update.sh`: `10-data` has to be updated first.

### New

- **Model access:** under Tenant settings → Operations → Model access (and Admin → Deployment →
  Model access for the whole deployment), restrict routes by type of credential and destination:
  no subscriptions, only Amazon Bedrock, every metered key except one provider. Each layer can only
  narrow the one above it, the page shows what each layer hides, and provided routes show their
  source, grant and budgets. Forbidden routes leave the launch dialog, the agents and credentials
  pages, image generation and the assistant.
  ([#4169](https://github.com/k-k1/agent-fleet/issues/4169),
  [#4376](https://github.com/k-k1/agent-fleet/issues/4376))
- **Settings reorganised around credentials:** sign-ins and keys move to Settings → Model
  credentials, grouped by where the prompts go, each card saying which agents can use it. Settings →
  Agents keeps one card per agent with its on/off switch, default route and where it runs, and
  Sessions and Image generation get pages of their own.
  ([#4169](https://github.com/k-k1/agent-fleet/issues/4169))
- **Activity bar:** the left edge of the Console is a column of icons that chooses one view for
  the left pane (sessions, assistants, issue tracker, memo queue, schedules, files) and opens Home
  and other panes. Marks on an icon tell you about a view you are not looking at.
- **Memo auto-run, tidy before a run:** a category can let a model in the workspace merge, split
  and move its waiting memos before an automatic run, and you can tidy a selection by hand with a
  before/after preview. Every tidy shows in the run history and can be undone.
  ([#4152](https://github.com/k-k1/agent-fleet/issues/4152))
- **Memo auto-run, work items:** "Add to auto-run" on an issue, ticket or pull request files a link
  to it, with a note of your own, and a run holding one link links its session to the item and
  names its branch after it. ([#4404](https://github.com/k-k1/agent-fleet/issues/4404))
- **Memo auto-run, skip the approval for your own sessions:** per category, memos added by sessions
  you started yourself can be accepted without the approval card. Off by default.
  ([#4151](https://github.com/k-k1/agent-fleet/issues/4151))
- **ECS EC2 boost:** once a tenant administrator allows it, a member can raise their next start one
  machine size in the same class for a limited time, from Settings → Machine. The monthly
  hours budget is saved but not enforced yet.
  ([#4335](https://github.com/k-k1/agent-fleet/issues/4335))
- **Light ECS EC2 slot classes:** the operator guide documents opt-in 4 GiB classes (`m8g.medium`,
  `t4g`, `t3`) for members who mostly read, edit and run small commands.
  ([#4332](https://github.com/k-k1/agent-fleet/issues/4332))
- **Docker Compose egress fence (opt-in, not yet run on a real Docker host):** workspace networks
  can be left with no route out, so the egress proxy is the only exit.
  ([#1181](https://github.com/k-k1/agent-fleet/issues/1181))

### Improved

- **Egress allowlist:** the built-in list admits the hosts the agent CLIs need at run time
  (sign-in, inference, model catalogues), so codex, Antigravity, OpenCode and Claude Code keep
  working in enforce. Add `www.googleapis.com` yourself if a workspace signs in to Antigravity.
  ([#4392](https://github.com/k-k1/agent-fleet/issues/4392))
- **Egress gateway:** it gets its own row in Admin → Cloud cost, the gateway log says "closed"
  rather than "log-only" while it waits for its first policy, and observed destinations count a
  TLS connection once instead of twice.
  ([#4440](https://github.com/k-k1/agent-fleet/issues/4440),
  [#4394](https://github.com/k-k1/agent-fleet/issues/4394),
  [#4393](https://github.com/k-k1/agent-fleet/issues/4393))
- **A memo a worktree session adds** is filed under the parent repository, so that repository's
  auto-run category sees it. ([#4175](https://github.com/k-k1/agent-fleet/issues/4175))
- **Every first instruction the Agent gives up on** now shows a toast, not only one lost to an
  expired login. ([#4343](https://github.com/k-k1/agent-fleet/issues/4343))
- **The issue tracker view** lists every row instead of folding after ten.

### Fixed

- **Terminal panes stayed blank on a slow link:** a healthy but slow connection was cut off and
  retried forever. ([#4432](https://github.com/k-k1/agent-fleet/issues/4432))
- **An input queued "when ready" for a stopped session** was accepted and then dropped; it is now
  refused. ([#4202](https://github.com/k-k1/agent-fleet/issues/4202))
- **Launch defaults:** saving any setting could drop some of them, and re-selecting the agent in
  the launch dialog reset the chosen route.
  ([#4427](https://github.com/k-k1/agent-fleet/issues/4427))
- **Memo auto-run:** a slow workspace could delay other members' runs settling, and a note filed
  by a session under a new category name had no category of its own.
  ([#4245](https://github.com/k-k1/agent-fleet/issues/4245),
  [#4411](https://github.com/k-k1/agent-fleet/issues/4411))
- **The MCP `create_session` description** named routes the tenant policy forbids.
  ([#4323](https://github.com/k-k1/agent-fleet/issues/4323))
- **Console:** the Files change list kept the previous tenant's changes after a switch, and the
  Sessions view wrapped repository rows and cut the header title.
  ([#4431](https://github.com/k-k1/agent-fleet/issues/4431),
  [#4357](https://github.com/k-k1/agent-fleet/issues/4357))
- **ECS EC2:** member limits reported a home shrink on every save when the home was larger than
  the setting. ([#4406](https://github.com/k-k1/agent-fleet/issues/4406))

### Upgrade notes

- **ECS: update `10-data` before `update.sh`.** On `ecs-ec2` the slot now mounts each member's EFS
  access points instead of the workspace task, and `update.sh` stops until `10-data` has the new
  outputs. Once every workspace has been stopped and started on 0.47.0, set
  `EfsWorkspaceIngress=deny` to close the file system to workspace tasks (leave it at `allow` on
  Fargate). See "Keep workspace tasks off NFS" in the ECS upgrade guide.
  ([#3903](https://github.com/k-k1/agent-fleet/issues/3903))
- **ECS, switching to `EgressRoute=gateway`:** deploy `00-network` with `GatewayRouteEnabled=false`
  first, run `update.sh`, wait for the gateway's first policy, then set it to `true`, as in the
  egress gateway guide. ([#4399](https://github.com/k-k1/agent-fleet/issues/4399))
- **ECS with the egress gateway:** the next `00-network` deploy replaces the gateway instance once
  (a short outage, like an AMI update) to add its cost tags.
