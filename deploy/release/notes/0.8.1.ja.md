サインインが Google 固定ではなくなり、任意の OpenID Connect プロバイダを使えるように
なりました。メールアドレスが変わっても、別のプロバイダで入っても、同じ人は同じ
Workspace のままです。Chrome で Console が数秒固まる問題も直しました。

### New

- **Google だけでなく、任意の OpenID Connect プロバイダでサインイン。** Entra ID・
  Okta・Keycloak・Auth0・Cognito・GitLab などを、issuer・client ID・secret を添えて
  `AF_OIDC_PROVIDERS` に並べれば有効になります。サインイン画面にはプロバイダごとの
  ボタンが出て、複数を併用できます。**Google 側の変更は不要です。** 設定が不完全な
  プロバイダは警告付きで無効化され、他の人のサインインを巻き添えにしません。テナント
  許可リストの無い `common`/`organizations` の Microsoft issuer は起動時に拒否します
  ——Microsoft アカウントを持つ全員を玄関に立たせることになるからです。
- **メールアドレスが変わっても、別のプロバイダで入っても、Workspace は 1 つのまま。**
  本人の識別をメールアドレスではなくプロバイダ側の不変なアカウント id で行うように
  しました。姓の変更やドメイン統合で空の Workspace がもう 1 つ生えることはありません。
  どのメールアドレスにも一致しないサインインは、意図的に**新しい人**として扱い、
  サインイン直後の画面でそう伝えます。
- **Claude セッションがログイン切れを教えます。** バッジは**ログイン切れ — 再サイン
  イン**になり、接続カードは「接続済み」と言わずに期限日を出し、プロンプトの送信は理由
  付きで拒否されます。これまでは「何も始まらない」ことだけが手掛かりでした。キー入力は
  ペインに届くので、ターミナルで `/login` すれば復旧できます。

### Fixed

- **Chrome で Console が数秒間固まっていました。** ペインが健全な GPU コンテキストを
  作り直し続け、やがてブラウザが「表示中のターミナルが使っているコンテキスト」を追い
  出し、代替の描画経路が文字ごとの幅をページレイアウト経由で測っていました。日本語の
  画面には異なる文字が数千あります。ターミナルは canvas の描画へ退避し、ペイン同士が
  追い出し合わないようにしました。Firefox とタッチ端末は影響を受けていません。
- **エージェントは正しく答えているのに「Workspace Agent に到達できません」と出て
  いました** — 停止中セッションのターミナルを開くと接続失敗と表示され、本当の答え
  （セッションは動いておらず、表示できる履歴も残っていない）が捨てられていました。
- **Claude の質問に打ち込んだ自由入力が捨てられていました**（選択肢がプレビューを持つ
  場合）。入力は質問への注記として送られます。閉じた質問には**却下**のバッジが付き、
  回答済みとして描かれなくなりました。
- **共有セッションのタブがすべて「Shared session」でした** — セッション自身の名前と、
  エージェントの色付きアイコンが付くようになりました。

### Upgrade notes

移行作業はありません。どのプロバイダのアカウントでサインインしたかを記録するテーブルが
起動時に追加されますが、アップグレード前のデータは持たず、古いビルドからは無視されるので
ロールバックは安全です。home ディレクトリは移動しません。`AF_OIDC_PROVIDERS` を設定する
までサインインの挙動は変わりません。エージェント CLI の固定版は 0.8.0 から変わりません。
