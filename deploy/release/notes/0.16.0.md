Sessions that cannot draw can now generate images, and the pictures land in the
conversation. The Zundamon voice runs only while someone is listening instead of around
the clock, and Settings gains a Machine tab that says what your workspace is actually
running on.

### New

- **Sessions can generate images.** A `generate_image` tool is offered to agents that have
  no image generation of their own — Claude, OpenCode and the rest; Codex sessions keep
  using their built-in one. Each image spends the connected ChatGPT plan's quota, so it is
  off by default and turned on per member in Settings > Agents.
- **Generated images appear in the conversation as cards**, with a thumbnail you can open
  full size, instead of a tool trace and a path you had to go looking for. Claude, OpenCode
  and Copilot sessions show them.
- **The Zundamon voice can be started on demand.** On an ECS deployment the VOICEVOX engine
  is now stood up and shut down by Agent Fleet itself: administrators pick off, always on,
  or on demand, and on demand starts the engine once read-aloud demand builds up and stops
  it after nobody has listened for a while. While it is coming up, Polly reads instead, and
  a "Call Zundamon" button in the read-aloud settings starts it without waiting.
- **Settings has a Machine tab.** It shows what your workspace runs on — instance type,
  architecture, vCPU, memory ceiling — measured from inside the container and shown next to
  what the deployment declares, with an hour of resource graphs that keep moving even while
  the workspace is idle. The resource popover in the workspace bar links to it.
- **`Ctrl`+`R` searches what you have sent**, bash-style, in the mirror's composer. Matches
  are shown in the composer itself so a long prompt can be read in full before you take it;
  `Ctrl`+`R`/`Ctrl`+`S` walk the matches, `Enter` puts one in the input without sending, and
  `Esc` gives your draft back.
- **Node 26 can be installed from Settings > Toolchains.**

### Improved

- **Shared images open as pictures, not as a pane.** An image card in "Shared files" opens
  full size in the lightbox, and the file pane moved to a button in the card's corner. The
  lightbox now zooms and pans — wheel, pinch, double-click, and drag while zoomed in.
- **Long conversations stop getting slower to open.** Returning to a long Codex session
  could take seconds every time, because the whole conversation was re-read on each poll;
  OpenCode transcripts were loading one query per message. Both now read only what is new.
- **A panel of shared images downloads thumbnails**, not the full-size originals scaled down
  in the browser.
- Node 18 has been end-of-life since April 2025 and is no longer offered in Settings >
  Toolchains. A workspace that already has it selected is unaffected.

### Fixed

- **On a phone the workspace bar was wider than the screen**, which let the browser zoom the
  page out — and with the page not at 1:1, every horizontal swipe stopped working, including
  the edge swipe that opens the left pane. The "restart required" pill made it obvious but
  was not the cause.
- **A question card lost a half-made answer when you switched tabs.** Choosing an option and
  then going to look at the file or the diff it was about emptied the card on the way back.
- **On a phone, the selection colour chips were hidden** behind the browser's own copy/share
  menu, which draws above everything a page can put there. They now dock at the bottom of
  the screen.
- **An agent process that had already died could be reported as running**, so the Console
  showed a session as alive when it was not.

### Upgrade notes

Nothing to do, unless you run on ECS and want the Zundamon voice: deploy the new
`cfn/50-tts.yaml` stack, then choose the mode in Settings > Admin. Without that stack
read-aloud keeps working through Polly exactly as before.
