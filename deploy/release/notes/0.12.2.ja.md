エージェントのメモリを履歴ごと引き継げるようになり、ワークスペースのリソースが ECS 構成でも
測れるようになりました。管理画面の「通信」が Postgres 配備で開けなかったのも直しています。

### New

- **メモリの取り込みに「移設」が加わり、相手の環境の履歴ごと引き継げます。** これまでの
  適用は bundle が運んできた過去を捨てて最新の状態だけを使っていました。新しい環境へ
  移って履歴ごと持っていく、というのが一番自然な期待なのにできませんでした。移設すると
  取り込んだ系譜へ付け替わるので、履歴一覧・差分・巻き戻しがそのまま相手の履歴に効きます。
  元の履歴も消えず、あとから辿れます。
- **ワークスペースのリソース（メモリ・CPU・ディスク）が ECS 構成でも出ます。** メンバー
  詳細では 3 つとも「–」のままでした。Control Plane とワークスペースが同じホストに載って
  いる前提で測っていたためで、それが成り立つのはローカルの Docker 配備だけです。ディスクは
  永続 home が載っているファイルシステムの使用量と容量になります。

### Fixed

- **管理画面の「通信」が Postgres 配備で開けませんでした。** MCP 経由の通信の統計も同じく
  失敗していました。SQLite 配備では起きません。
