Bitbucket connection fixes and a unified session handoff modal.

### New

- **Session handoff is now a single modal.** Carrying work over to a new session
  (previously "fork") is one dialog where you pick the target first, with the same
  choices as the launch modal.

### Improved

- **Bitbucket connections tell you what they need.** The card links straight to the
  token-issuing page, states the required scopes, and checks the token against them at
  connect time instead of failing later.
- Cursor sessions show a model badge on each response, and the send-key preference
  moved to the *Keys* tab.

### Fixed

- **Cloning and pushing with a Bitbucket API token failed to authenticate.**
- **Answers, plan approvals and delegations did not appear in the mirror while a
  session was live** — they showed up only after a reload.
