Bitbucket connection fixes and a unified session handoff modal.

### New

- **Session handoff is now a single modal.** Carrying work over to a new session
  (previously "fork") is one dialog where you pick the target first, with the same
  choices as the launch modal. The internal name changed from *fork* to *handoff*.

### Improved

- **Bitbucket connections tell you what they need.** The connection card links
  straight to the token-issuing page and states the required scopes, and the
  connection is checked against them so an under-scoped token is caught at connect
  time instead of failing later.
- Cursor sessions show a model badge on each response.
- The send-key preference moved to the *Keys* tab, next to the rest of the keyboard
  settings.

### Fixed

- **Cloning and pushing with a Bitbucket API token failed to authenticate.**
- **Answers to questions, plan approvals and delegations did not appear in the mirror
  while a session was live.** They showed up only after a reload.
