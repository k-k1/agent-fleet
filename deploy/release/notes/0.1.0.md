First public release. Agent Fleet is a self-hosted console for running AI coding
agents as a fleet: each member gets an isolated per-user environment, and starts,
drives and manages agent sessions from the browser.

### What ships in this release

- **Five agent CLIs, one console** — Claude Code, Codex CLI, OpenCode, GitHub
  Copilot CLI and Antigravity CLI run side by side, with per-session model choice
  and pinned, verified CLI versions.
- **Per-user isolation** — a Docker container with cgroup CPU/memory quotas (or a
  bubblewrap sandbox in the Docker-less native runtime), a persistent home, and
  network separation between users.
- **Parallel sessions on real git repos** — HTTPS clone with GitHub / Bitbucket
  tokens or OAuth device flow, Git LFS, submodules and git-worktree isolation, with
  a live mirror view of each conversation alongside the terminal.
- **A Go control plane** orchestrating workspaces, with at-rest encryption for
  credentials, resource quotas, and an admin console.
- **Two distribution targets** — a Docker-less `native` package for a single user
  on WSL2 / Linux (`install.sh` → `af start`), and a Docker Compose bundle for
  self-hosting, plus an air-gap image archive for offline installs.

### Notes

- The distributed images and rootfs are a **lean build**: agent CLIs are not
  redistributed. Each user's workspace pin-installs them from their upstream source
  on first start (air-gap alternatives are documented in the bundled README).
- Verify downloads against `SHA256SUMS`; the native launcher additionally verifies
  the workspace rootfs against the `rootfs.json` sha256 it ships with.
