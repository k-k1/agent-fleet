First public release. Agent Fleet is a self-hosted console for running AI coding
agents as a fleet: each member gets an isolated environment and drives agent sessions
from the browser.

### What ships in this release

- **Five agent CLIs, one console** — Claude Code, Codex CLI, OpenCode, GitHub Copilot
  CLI and Antigravity CLI, with per-session model choice and pinned CLI versions.
- **Per-user isolation** — a container with CPU/memory quotas (or a bubblewrap sandbox
  in the Docker-less native runtime), a persistent home, and network separation.
- **Parallel sessions on real git repos** — HTTPS clone with GitHub / Bitbucket
  credentials, Git LFS, submodules and git-worktree isolation, with a live mirror of
  each conversation beside the terminal.
- **A Go control plane** — workspace orchestration, at-rest encryption for credentials,
  resource quotas and an admin console.
- **Two distribution targets** — a Docker-less `native` package for a single user on
  WSL2 / Linux (`install.sh` → `af start`), and a Docker Compose bundle for
  self-hosting, plus an air-gap image archive.

### Notes

- The images are a **lean build**: agent CLIs are not redistributed, and each workspace
  installs them from their upstream source on first start.
- Verify downloads against `SHA256SUMS`; the native launcher also verifies the
  workspace rootfs against the `rootfs.json` sha256 it ships with.
