One fix for a production outage first seen in 0.20.0 where the agent exhausted EFS
burst credits by sweeping all project directories on every transcript lookup.

### Fixed

- **The agent swept every project directory on EFS on every transcript lookup, exhausting
  EFS burst credits and slowing all sessions to a crawl.** `filepath.Glob("projects/*/<sid>.jsonl")`
  expands the wildcard by calling ReadDir on the projects directory and then on each matched
  subdirectory. With 38 project directories in production, a single workspace agent issued
  821 directory reads per second, consuming the entire EFS burst budget across all workspaces.
  The fix memoises the `projects/*` scan so that the per-project ReadDir only runs when the
  cached project path is stale, cutting EFS metadata I/O by roughly 99 %.

### Upgrade notes

No action needed on the ECS deployment — the Control Plane image update is enough for
the Console changes from 0.20.1.

**All workspace users must restart their workspaces** to receive the agent fix from both
0.20.1 and 0.20.2. Workspaces that were running during or before the upgrade are still on
the previous agent binary; the Console will show a "restart required" badge until they do.
