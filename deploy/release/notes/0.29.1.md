A fix release for 0.29.0: Agent Fleet's own MCP tools work again with the Claude Code version 0.29.0
ships, and a finished claude session no longer shows as in progress for up to a minute.

### Fixed

- **Several af MCP tools failed in claude sessions with a schema validation error.** Claude Code
  2.1.292 rejected the results of `list_repos`, `list_my_sessions`, `get_session_status`,
  `get_session_usage`, `get_session_output` and the image studio tools, so a parent session could
  not read its child's output. They work again.
  ([#1842](https://github.com/k-k1/agent-fleet/issues/1842))
- **A claude session could stay "in progress" for 45 to 60 seconds after its answer** in the mirror
  and the session list, when the Console looked while claude's Stop hook was still running.
  ([#1834](https://github.com/k-k1/agent-fleet/issues/1834),
  [#1836](https://github.com/k-k1/agent-fleet/issues/1836))

### Upgrade notes

Both fixes are in the workspace image. A workspace that is running keeps 0.29.0 until it is
stopped and started again; the WS bar's **Update available** badge says when.

Agent CLI pins are unchanged from 0.29.0.
