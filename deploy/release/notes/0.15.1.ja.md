### Improved

- **公開する workspace イメージが arm64 に対応しました。** `ecs-ec2` の配備で Graviton の
  スロットクラスを宣言し、この版のイメージのまま動かせます。これまでは運用者が自分で
  arm64 のイメージを用意する必要がありました。コントロールプレーンのイメージは 0.11.0 から
  両アーキテクチャに対応しています。

### Upgrade notes

**Graviton のスロットを出すには**、プールスタックの `SlotAmiIdArm64` に arm64 の
ECS 最適化 AMI を設定し、`Ec2SlotTypes` に `arch=arm64` のクラスを足して、同じ AMI を
`Ec2SlotAmiArm64` に渡してください（arm64 のクラスがあるのに未設定だと、コントロール
プレーンは起動を拒否します）。クラスを足すだけでは誰も移りません。自分で選んでいない
メンバーがどこに載るかは `Ec2DefaultSlotClass` が決めます。移ったメンバーは次回の起動で
home のアーキテクチャ依存のツールを入れ直すので、その 1 回だけ起動が遅くなります。

0.14.x から上げる場合は、0.15.0 の python 3.11 → 3.13 の注意がこの版にも当てはまります。

エージェント CLI のピンは 0.15.0 から変わりません。
