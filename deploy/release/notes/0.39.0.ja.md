セッションが取り組んでいる Issue・チケット・プルリクエストに自分でリンクし、プルリクエストがマージ可能・
マージ済み・クローズになると知らせるようになりました。プランは複数回まで自動でレビューでき、ホームに
「ひと目で」が加わり、OpenCode 1.x のサポートは終了しました。

### 新機能

- **セッションが取り組む作業にリンク。** 起動元の項目に加えて、ブランチのプルリクエスト（GitHub と
  Bitbucket）、ブランチ名や PR タイトルの Jira キー、PR がクローズする Issue にリンクします。エージェントは
  `link_work_item` ツールでリンクを追加でき、子セッション・フォーク・移動先はリンクを引き継ぎます。項目の
  詳細はリンクしたセッションをすべて（ワークスペースの停止中も）一覧し、**外す** で外せて、マージ済み・
  クローズの PR は完了として表示します。
  ([#3134](https://github.com/k-k1/agent-fleet/issues/3134),
  [#3147](https://github.com/k-k1/agent-fleet/issues/3147),
  [#3166](https://github.com/k-k1/agent-fleet/issues/3166))
- **プルリクエストの通知。** セッションの PR がマージ・クローズされたとき、また GitHub ではマージ可能
  （チェック通過・マージ可能・承認済みかレビュー不要）になったとき、通知センターが 1 回知らせます。
  ([#3131](https://github.com/k-k1/agent-fleet/issues/3131))
- **プランの自動レビュー。** ライブのプランカードに「最大 N 回まで自動で再レビュー」があります（既定は
  オフ）。レビュー役が修正を求めている間は、出し直されたプランをクリックなしでレビュー役へ戻し、承認・
  判定が読めない・回数の上限のどれかで止まります。
  ([#2810](https://github.com/k-k1/agent-fleet/issues/2810))
- **ホームに「ひと目で」:** マシン・稼働時間・エージェント・モデル使用量・使用量の上限のタイルがあり、
  それぞれ詳しい画面を開きます。([#2362](https://github.com/k-k1/agent-fleet/issues/2362))
- **地域の形式とタイムゾーン。** 設定 › 表示の表示言語の隣で選べます。Console の日時・数値と Markdown の
  エクスポートがこれに従います。([#2185](https://github.com/k-k1/agent-fleet/issues/2185))
- **「応答なし」のワークスペース。** 実行中のワークスペースの Agent が数分応答しないと、ワークスペースバーに
  停止して起動し直すよう促す「応答なし」のバッジが出て、テナント管理者にはメンバーの統計に表示し通知も
  届きます。自動では止めません。([#2518](https://github.com/k-k1/agent-fleet/issues/2518))
- **メンバーの問題を管理者へ通知:** メンバーのホームボリュームがほぼいっぱいになったとき、また直近の起動で
  ツールのインストールに失敗したとき、テナント管理者に知らせます。
  ([#2427](https://github.com/k-k1/agent-fleet/issues/2427))
- **GKE: 外向き通信のアーカイブ用バケット（任意）。** GKE の Terraform スタックが、外向き通信の
  アーカイブ用の Cloud Storage バケットを作るか、既存のバケットへの権限を付けられます。実際の
  Cloud Storage での受け入れ確認はまだです。
  ([#2733](https://github.com/k-k1/agent-fleet/issues/2733))

### 改善

- **すべてのエージェントのカードに再認証。** 設定 › エージェントの Antigravity・Cursor・Kiro・Muse Code の
  カードに「再認証」ボタンがあり、断られたプロンプトのトーストはログインが切れたエージェントの名前を
  出します。([#3025](https://github.com/k-k1/agent-fleet/issues/3025),
  [#3122](https://github.com/k-k1/agent-fleet/issues/3122))
- **使用量の上限からの自動再開:** 予約した自動再開が停止中のセッションにも表示され、Claude や Codex の
  上限が早く解けたときは前倒しされ、手で続けたときは取り消されます。
  ([#3185](https://github.com/k-k1/agent-fleet/issues/3185),
  [#3186](https://github.com/k-k1/agent-fleet/issues/3186),
  [#3196](https://github.com/k-k1/agent-fleet/issues/3196))
- **使用量のチップが最後の読み取りを保持**し、Agent を再起動しても実際の経過時間つきで表示します。
  ([#3127](https://github.com/k-k1/agent-fleet/issues/3127))
- **設定 › マシンのツールキャッシュに Maven と npx** が加わり、大きさを測って空にできます。
  ([#3079](https://github.com/k-k1/agent-fleet/issues/3079))
- **監査ログの対象が広がりました:** 接続と API キー、MCP サーバー、ロック、支出の上限の変更を記録します。
  ([#2883](https://github.com/k-k1/agent-fleet/issues/2883))

### アップグレードの注意

- **OpenCode 1.x のサポートを終了しました。** イメージは 0.32.0 から OpenCode 2 を同梱しています。
  Agent Fleet は OpenCode 1.x の起動を断り、戻すときは以前の 2.x へピンします。`~/.local` に残った
  `opencode-ai` はワークスペースの起動時に取り除かれ、OpenCode の履歴がまだ 1.x の形式のホームは、これまで
  どおり 1 回だけ移行されます。以前の `opencode-major 2` のオプトインを試していた場合、
  `~/.local/share/agent-fleet/` の下のインストールとデータベース（`opencode2`・`opencode2-data`）はもう
  読まれず、統合もされていません。不要になったら削除してください。([#3132](https://github.com/k-k1/agent-fleet/issues/3132))

エージェント CLI のピン: Claude Code 2.1.316、Codex 0.166.0、Copilot 1.0.105、Antigravity 1.4.12、
Cursor 2026.10.22-27dcf5f、Kiro 2.37.0、OpenCode 2.2.5、Muse Code 1.4.14-R7309.1。
