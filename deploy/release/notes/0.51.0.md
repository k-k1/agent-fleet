Spaces now support more ways to start and hand off work, and share one Agent memory project. Distributed MCP servers can share a sign-in, the Active view shows recent stops, and Auto-run keeps tracking a session when you move it to another agent.

### Improved

- **Spaces** — Start an inbox request or attach an image studio to a space, and run a memo queue in
  a space. Handoffs and plan reviews can start in the source space. A child launched with
  `create_session` from a space defaults to a new space.
  ([#5220](https://github.com/k-k1/agent-fleet/issues/5220),
  [#5222](https://github.com/k-k1/agent-fleet/issues/5222),
  [#5223](https://github.com/k-k1/agent-fleet/issues/5223),
  [#5232](https://github.com/k-k1/agent-fleet/issues/5232))
- **Agent memory in spaces** — All of your spaces share the **Spaces** project and can recall what
  another of your spaces saved there. ([#5221](https://github.com/k-k1/agent-fleet/issues/5221))
- **MCP OAuth** — Tenant administrators can set the requested scopes and share one sign-in per
  member across HTTPS servers using the same OAuth client and authorization server. Disconnecting a
  shared sign-in ends it for the group. Sign-in compatibility with Google Workspace MCP servers has
  also improved. ([#5173](https://github.com/k-k1/agent-fleet/issues/5173),
  [#5175](https://github.com/k-k1/agent-fleet/issues/5175))
- **Bedrock for Claude Code and OpenCode** — A marked AWS profile can supply the Bedrock route
  without the earlier deployment switches, where the route gateway is enabled and policy allows it.
  ([#3282](https://github.com/k-k1/agent-fleet/issues/3282))
- **Active view** — Sessions stopped within the past 24 hours still show as cards. Each expanded
  group counts other stops too old to list or with no recorded stop time.
  ([#5155](https://github.com/k-k1/agent-fleet/issues/5155))
- Open a reused session from the schedule's details. If you have unsaved edits, the return button
  takes you back to them. ([#5298](https://github.com/k-k1/agent-fleet/issues/5298))
- **Service status watches** — An agent can wait for an outage to clear on the public status pages
  of GitHub, Bitbucket Cloud, Jira Software Cloud and Confluence Cloud.
  ([#5204](https://github.com/k-k1/agent-fleet/issues/5204))
- Fleet watches show the watched session's display name and Git branch beside its link. Timer
  watches show their due times in your browser's time zone.
  ([#5305](https://github.com/k-k1/agent-fleet/issues/5305),
  [#5324](https://github.com/k-k1/agent-fleet/issues/5324))
- Guide search can match additional keywords in both languages. The guide also covers recent stops,
  reused sessions, Spaces memory, watch links and Bitbucket merge checks.
  ([#5064](https://github.com/k-k1/agent-fleet/issues/5064),
  [#5321](https://github.com/k-k1/agent-fleet/issues/5321))
- **Workspace image** — The agent CLIs are updated to OpenCode 2.4.2, Copilot 1.0.116 and
  Antigravity 1.5.18. Other bundled tools move to AWS CLI 2.42.4, GitHub CLI 2.106.0 and bkt 0.41.1.
  ([#5211](https://github.com/k-k1/agent-fleet/issues/5211))

### Fixed

- **Auto-run and usage limits** — Booked auto-resumes go ahead without an extra approval. The
  Console shows usage-limit holds and offers eligible moves even after a session stops. A moved run
  keeps its slot until the replacement run settles.
  ([#5212](https://github.com/k-k1/agent-fleet/issues/5212),
  [#5292](https://github.com/k-k1/agent-fleet/issues/5292),
  [#5293](https://github.com/k-k1/agent-fleet/issues/5293))
- Auto-run waits while a peer message is still being delivered. A memo also stays available if its
  attachments or first prompt fail to reach a newly created session.
  ([#5270](https://github.com/k-k1/agent-fleet/issues/5270),
  [#5077](https://github.com/k-k1/agent-fleet/issues/5077))
- Starting a second agent in a busy space asks first. Space and working-copy deletion refuse when a
  start is in progress or the workspace cannot verify which sessions are running there.
  ([#5230](https://github.com/k-k1/agent-fleet/issues/5230),
  [#5122](https://github.com/k-k1/agent-fleet/issues/5122))
- Space folders and their marker files are protected in the file browser. Session views keep spaces
  separate from repositories, even when the folders have the same name.
  ([#5231](https://github.com/k-k1/agent-fleet/issues/5231),
  [#5219](https://github.com/k-k1/agent-fleet/issues/5219),
  [#5278](https://github.com/k-k1/agent-fleet/issues/5278))
- A member receiving a handoff from a space starts in a new space and sees that the source files
  stay with the sender. An agent moving a Japanese session can find the summary boundary in the
  handover. ([#5233](https://github.com/k-k1/agent-fleet/issues/5233),
  [#5291](https://github.com/k-k1/agent-fleet/issues/5291))
- Bitbucket pull request details explain blocking merge checks even when there is no branch
  conflict, and direct you to Bitbucket if the details are unavailable.
  ([#5306](https://github.com/k-k1/agent-fleet/issues/5306))
- Watch notices are shown separately from member messages. In Codex, an AWS profile badge follows
  the tool call that used it, including after Code Mode calls.
  ([#5299](https://github.com/k-k1/agent-fleet/issues/5299),
  [#5295](https://github.com/k-k1/agent-fleet/issues/5295))
- Starting an already-running Docker workspace repairs a stale Agent address left by a Control Plane
  restart. ([#5257](https://github.com/k-k1/agent-fleet/issues/5257))

### Upgrade notes

- If your deployment used the earlier Claude Code or OpenCode Bedrock rollout switches, update the
  workspace image before restarting workspaces under the new Control Plane. Older Agents still need
  switches that the new Control Plane no longer sends.
