セッションは、同梱の `confluence` CLI で既存の Jira 接続のまま Confluence を使えるようになり、
セッションの行にはプルリクエストの修正依頼とマージコンフリクトが出るようになりました。
バックグラウンドのシェルを 1 件ずつ止められ、「作業を始める」の下書きをメモに退避でき、Claude の
アイドル中の自動圧縮をオフにできます。

### 新機能

- **すべてのワークスペースで Confluence。** `confluence` CLI をイメージに焼き込み、メンバーの Jira 接続で
  サインインするので、トークンなしで `confluence search`・`read`・`create`・`update` が動きます。テナントごとの
  オプトインです（アップグレードの注意を参照）。
  ([#2212](https://github.com/k-k1/agent-fleet/issues/2212),
  [#3266](https://github.com/k-k1/agent-fleet/issues/3266),
  [#3267](https://github.com/k-k1/agent-fleet/issues/3267),
  [#3309](https://github.com/k-k1/agent-fleet/issues/3309))
- **プルリクエストへの反応をセッションの行に。** PR チップは CI の結果に続けて、レビュアーが修正を依頼した
  PR とマージコンフリクトのある PR に印を付けます（GitHub と Bitbucket）。
  ([#3129](https://github.com/k-k1/agent-fleet/issues/3129))
- **バックグラウンドのシェルが見えて止められる。** Claude では会話の入力欄の上にバックグラウンドコマンドが
  1 件ずつ並び、動いている時間と **止まっているかもしれません** の警告が出て、**停止** でそのコマンドだけを
  終了します。([#3279](https://github.com/k-k1/agent-fleet/issues/3279))
- **「作業を始める」の下書きをメモキューへ。** **メモに一時保存** でプロンプトと添付を退避し、メモの
  **この内容で始める** で新しい「作業を始める」に戻せます。
  ([#3289](https://github.com/k-k1/agent-fleet/issues/3289))
- **Claude のアイドル中の自動圧縮をオフに。** 設定 › エージェント › Claude に **アイドル中の自動圧縮** の
  スイッチがあり、長い会話を圧縮されないまま戻ってきたいときに切れます。
  ([#3303](https://github.com/k-k1/agent-fleet/issues/3303))

### アップグレードの注意

- **Confluence はテナント管理者のオプトインが要ります。** 何もしないテナントでは何も変わりません。使うには、
  管理者ガイド（アクセス、Jira）にある Confluence の 10 個のスコープをテナントの Atlassian アプリに追加し、
  テナントの Jira カードで Confluence のチェックを入れ、メンバーに Jira を接続し直してもらいます。
  ([#2212](https://github.com/k-k1/agent-fleet/issues/2212),
  [#3309](https://github.com/k-k1/agent-fleet/issues/3309))
