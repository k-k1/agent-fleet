`watch` can now wait for GitHub releases and tags, a PR's first failing check, and another
session going idle or stopping, and the mirror shows a session's live watches. Tenant
administrators can set launch defaults and team repositories for Start, and the ECS EC2 pool gains
wedged-slot detection, opt-in rescue steps for dark slots and a force-stop for registered slots.
Read the Upgrade notes if your sign-in or Git provider sits behind a redirect to another host.

### New

- **`watch` gains new sources and types:**
  - GitHub releases and tags (`github.release.published`, `github.tag.created`), with an optional
    name pattern and pre-releases on request.
    ([#3970](https://github.com/k-k1/agent-fleet/issues/3970))
  - `pr.checks.failing`, told once per head commit as soon as one check fails while others still
    run. Existing `pr.checks.*` watches hear it too.
    ([#4054](https://github.com/k-k1/agent-fleet/issues/4054))
  - A `fleet` source for a child or peer session going idle, stopping, or getting its quota back,
    so a parent no longer needs a timer as a backstop.
    ([#3969](https://github.com/k-k1/agent-fleet/issues/3969))
- **Watches in the mirror:** a panel above the composer lists a session's live watches and can end
  one, the idle state chip says how many are waiting, and a PR watch's link opens the work item
  dialog. ([#3947](https://github.com/k-k1/agent-fleet/issues/3947),
  [#3951](https://github.com/k-k1/agent-fleet/issues/3951),
  [#4010](https://github.com/k-k1/agent-fleet/issues/4010))
- **Launch defaults for a tenant:** **Member defaults** in tenant settings sets the agent, model,
  execution method, permission prompts and budget the launch dialog starts on, team repositories
  listed first in Start, and ops settings such as the Grafana and AWS sign-in links. A member can
  keep their own default instead, and a team repository that is not cloned yet appears in Start as
  a clone shortcut.
  ([#3884](https://github.com/k-k1/agent-fleet/issues/3884),
  [#3976](https://github.com/k-k1/agent-fleet/issues/3976))
- **Jira attachments from the terminal:** `jira issue attachment add | list | download | delete`.
  ([#3945](https://github.com/k-k1/agent-fleet/issues/3945))
- **Low-disk cleanup:** the low-disk notice estimates what can be reclaimed and offers the cleanup
  directly, and `af-clean` runs the same cleanup from a terminal (a dry run unless `--apply`).
  ([#3880](https://github.com/k-k1/agent-fleet/issues/3880),
  [#3882](https://github.com/k-k1/agent-fleet/issues/3882))
- **ECS EC2 pool:**
  - A **wedged** slot (its agents still answer but its workspace does not) is now reported like a
    dark one, and the pool view shows how long a slot has been dark and its rescue step.
  - **Rescue steps**, off unless you set them: `AF_ECS_EC2_DARK_SLOT_ACTION=rescue` stops a dark
    slot and frees its home (a Start on that home then lands on another slot), `quarantine` also
    holds back a slot that goes dark again, and `AF_ECS_EC2_WEDGED_SLOT_ACTION=release` frees a
    wedged slot's home.
  - **Stop (force)** is offered on a registered slot too, behind an acknowledgement. It runs to the
    end even if the page closes, and a slot it deregistered is replaced on the occupant's next Start.

### Improved

- **Watches are easier to get right:** repeating the same `watch` returns the existing one,
  overlapping watches give one notice, and a workflow or pipeline watch also counts a run that
  started up to about 10 minutes before it.
  ([#4051](https://github.com/k-k1/agent-fleet/issues/4051),
  [#4033](https://github.com/k-k1/agent-fleet/issues/4033))
- **Copilot, Cursor, Kiro and Antigravity sessions** no longer read the previous turn's end as the
  new one's, and for Copilot, Cursor and Antigravity an input the CLI never took ends as "input not
  delivered" instead of leaving the session "working". ([#4007](https://github.com/k-k1/agent-fleet/issues/4007),
  [#4047](https://github.com/k-k1/agent-fleet/issues/4047))
- **Cloud command names:** `af-gcloud-exec` runs show the gcloud command on the run row and the
  login card, and the AWS confirmation card names the `aws` operation and links the asking session.
  ([#4036](https://github.com/k-k1/agent-fleet/issues/4036),
  [#4034](https://github.com/k-k1/agent-fleet/issues/4034))
- **OpenCode under Managed** can use the deployment's Bedrock model route, which was Terminal only.
  ([#4004](https://github.com/k-k1/agent-fleet/issues/4004))
- **Credentialed connections stay on their host:** calls that carry a token (Jira, GitHub,
  Bitbucket, sign-in, the Control Plane) no longer follow a redirect to another host or to plain
  HTTP; such a call now fails. ([#4070](https://github.com/k-k1/agent-fleet/issues/4070),
  [#3952](https://github.com/k-k1/agent-fleet/issues/3952))
- **The Console's guide links open agent-fleet.org/docs** in a new tab, and on-screen labels use
  the same wording as the guide. ([#3463](https://github.com/k-k1/agent-fleet/issues/3463),
  [#4039](https://github.com/k-k1/agent-fleet/issues/4039))

### Upgrade notes

- **If your identity provider, Git provider or Jira answers a token or API call with a redirect to
  another host**, that call now fails instead of following it. Point the configuration at the
  final URL. ([#4070](https://github.com/k-k1/agent-fleet/issues/4070))
- **ECS EC2 pool: wedged-slot reporting is on by default** (`AF_ECS_EC2_WEDGED_SLOT_ACTION=detect`)
  and tags such instances `af-wedged-since` with the permissions the Control Plane already has.
  Set it to `off` to turn it off. The rescue steps above stay off until you set them; no
  CloudFormation template changed. ([#3963](https://github.com/k-k1/agent-fleet/issues/3963))

### Other changes

- **The operator runbooks moved into the user guide**, which now reads the same on
  agent-fleet.org/docs, the Japanese guide uses one polite style and consistent terms, and new
  reference pages list what is in the workspace image and the skills Agent Fleet installs.
