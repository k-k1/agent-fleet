サインインが Google 固定ではなくなり、任意の OpenID Connect プロバイダと GitHub を
使えるようになりました。1 つのデプロイを、独自のサインインページ・名簿・接続元制限を
持つ部署に分けられます。AWS には、各人の home を停止しても消えないディスクに置く
新しいランタイムが加わり、クラウドの請求額をメンバーごとに表示します。Console では
`.drawio` が図として開き、セッションごとに変更したファイルが並び、共有した相手にも
届くマーカーを会話に引けます。

### New

- **任意の OpenID Connect プロバイダ、または GitHub でサインイン。** Entra ID・Okta・
  Keycloak・Auth0・Cognito・GitLab などを、issuer・client ID・secret を添えて
  `AF_OIDC_PROVIDERS` に並べれば有効になります。GitHub は別アダプタで、指定した
  organization の所属を条件にします。複数を併用でき、**Google 側の変更は不要**です。
  設定が不完全なプロバイダは警告付きで無効化され、他の人のサインインを巻き添えにしま
  せん。テナント許可リストの無い `common`/`organizations` の Microsoft issuer は拒否
  します——Microsoft アカウントを持つ全員を玄関に立たせることになるからです。設定手順は
  運用者ガイドに通しで載せました。
- **メールアドレスが変わっても、別のプロバイダで入っても、自分でサインイン方法を
  足しても、Workspace は 1 つのまま。** 本人の識別をメールアドレスではなくプロバイダ側の
  不変なアカウント id で行うようにしました。設定に **アカウント** タブが加わり、自分に
  紐づくサインイン方法の一覧・追加（既にサインインしている自分の同意で紐づきます）・
  解除ができます。どのメールアドレスにも一致しないサインインは、意図的に**新しい人**と
  して扱い、サインイン直後にそう伝えます。
- **1 つのデプロイを、独自のサインインページ・名簿・サインイン方法を持つ部署に分け
  られます。** テナントは自分のログイン URL（`/login/<slug>`）と、誰を入れるかを決める
  1 本の名簿、そして自分のサインイン方法の一覧を持ちます。テナント管理者はホスト上の
  ファイルを触らずに自分のディレクトリ向けの方法を登録できますが、**デプロイ管理者が
  承認するまで何も起きません**。「この人は誰か」を宣言できること自体が、なりすましに
  十分だからです。方法ごとに*受け入れる*と*ボタンとして出す*を切り替えられるので、
  子会社が本社の人を入れつつ、使えないボタンを画面に出さずに済みます。テナント管理者
  には専用の**テナント設定**ダイアログ（メンバー・セッション・使用量・監査・MCP 配布）
  が付き、管理ダイアログはデプロイ管理者専用になりました。
- **テナント管理者が、メンバーの接続元ネットワークを制限できます。**
  **これはネットワークの防御ではありません** — リクエストは Control Plane まで届き、
  セッション検証の後に拒否されるので、認証前の脆弱性・DoS・スキャンには効きません。
  効くのは「資格情報を持つ人が、許可していない場所からデータに触ること」を止めることです。
  `/mcp` と `/git` は対象外です（メンバー自身のコンテナから来るため）。
- **停止しても消えないディスクに home を置く、新しい AWS ランタイム（`ecs-ec2`）。**
  共有のネットワークファイルシステムではなく、人について回る EBS ボリュームがプールされた
  EC2 スロットに付きます。小さなファイルの書き込みが 8〜30 倍速く、home は停止・起動を
  跨いで本当に残り、Workspace の大きさは Fargate の上限に縛られません。起動時間は選ぶ
  理由になりません（Fargate の温かい再起動と互角です）。長く使われない home はスナップ
  ショットへ退避でき（テナント単位の opt-in）、新しい人の home は温めた *golden*
  スナップショットから作れます。home は AZ に分散します。運用者にはスロットプール画面と
  **Workspace の破棄**が付きます。ランタイムの選択はプロファイル 1 行で、Fargate 側は
  そのままです。
- **Workspace の大きさを、人ごと・テナントごとに選べます。** メモリ・CPU・ディスクの
  3 軸を独立に持ち、個人の上限に加えてテナントの上限も設定できます。`ecs-ec2` では画面が
  そのランタイムの実際を示します——CPU は設定できず、メモリの値は上限ではなく「どの箱に
  乗るか」を決め、ディスクの値は永続 home の大きさ（作成時に決まります）です。ECS 系では、
  ネットワークストレージで高くつき作り直しは安いビルド生成物をローカルの作業ディスクへ
  逃がします。
- **クラウドの実際の請求額を、メンバーごとに。** Cost Explorer から取った実費を、管理
  ダイアログ・テナント設定・自分の設定・メンバー詳細に表示します（合計・日別・サービス別・
  期間指定）。あえて「あなたの費用」とは呼びません。請求のうち人に紐づくのは一部だけで、
  共有分が含まれないことをラベルに書いています。
- **`.drawio` が図として開きます**（生の XML の代わりに）。XML ソースへの切り替えも
  できます。Ctrl / ⌘ + ホイールでポインタ中心のズーム、ドラッグでパン、2 本指でピンチ、
  ダブルタップで全体表示と 1:1 の切り替え。図はライト／ダークのテーマに追従し、ビューアは
  同梱なので外部通信はありません。
- **セッションごとに、変更したファイルが並びます。** ミラーのヘッダ下の折りたためる帯と、
  コマンドパレットの 4 つ目のモードが「*このセッション*が何を触ったか」に答えます。既存の
  ファイル一覧は作業コピー単位なので答えられませんでした。既にコミットされたファイルは
  **committed** と印が付き、差分の無いファイルと混ざりません。Claude・Codex・OpenCode・
  Cursor・Copilot が対象です。
- **会話にマーカーを引くと、共有した相手にも届きます。** ミラーで選択した範囲を 4 色の
  いずれかで印を付けられます。書き込み権のある共有相手も自分の印を足せるので、レビュアーが
  「この 3 行」を言葉で説明せずに指し示せます。会話そのものが Control Plane の DB へ複製
  されることはありません。
- **共有された会話が、セッションの中身をより多く運びます** — 引き継ぎ提案の内容、読んで
  いた位置、セッション名とエージェントのアイコンが付いたタブ。
- **スマートフォンで、動いているセッションを横スワイプで切り替え**られます。ドロワーを
  閉じた状態で左スワイプすると次の実行中セッションへ、右で戻ります。順序は左ペインと
  同じです。**返信の先頭へ**で最新の返信の頭に飛べます。
- **返信の中のファイルパスがリンクになります。** 実在するパスはファイルならペインで開き、
  フォルダなら左ペインを展開してキーボードを渡します。解決は Workspace 側で行うので、
  作業ディレクトリがサブフォルダでも、リポジトリルート基準で書かれたパスが解決されます。
- **Claude セッションがログイン切れを教えます。** バッジは**ログイン切れ — 再サイン
  イン**になり、接続カードは期限日を出し、プロンプトの送信は理由付きで拒否されます。
  キー入力はペインに届くので、ターミナルで `/login` すれば復旧できます。
- **利用上限で止まったセッションが、そう表示し、いつ戻るかも示します** — 仕事を終えた
  セッションと同じ「入力待ち」ではなく、**上限の解除待ち**とリセット時刻を出します。
  残高・支出上限は待っても明けないので、**残高上限 — 引き上げが必要**と表示します。
- **セッション間メッセージに種別が必須になりました** — *request*・*question*・*answer*・
  *notice*。封筒が「どんな返信を期待しているか」を受け手に伝えます。ここが欠けていました
  ——「了解」の 1 通が相手のターンを丸ごと 1 回消費します。
- **新規インストールは閉じた状態から始まります。** テンプレートの既定を招待制にしました。
  membership の無い人がサインインすると、すべての操作が失敗する Console ではなく、招待が
  必要だと説明する画面が出ます。
- **AWS の ingress テンプレートで WAF を有効にできます** — レート制限と IP レピュテー
  ションのみで、どちらも既定 off。シグネチャのルールセットは意図的に提供しません。この
  製品はコードやシェルコマンドを普通の通信として運ぶので、コアルールセットは正常な作業を
  無作為に弾いてしまいます。

### Improved

- **Chrome でのターミナルペインの描画が大幅に軽くなりました**（ペイン内の変更のたびに
  ブラウザがペイン全体を再評価していました）。
- **アイドルのセッションと Workspace が自分で停止します。** タイムアウトは以前からあり
  ましたが既定が*しない*だったので、一晩置いたデプロイは全部動いたまま課金されていました。
  既定はセッション 1 時間・Workspace 2 時間です。
- **ECS のデプロイでも Docker と同じ更新バッジが出ます。** 1 コマンドの更新手順も付きます。
- **一時的なプロバイダ障害でターンが終わらなくなりました**（OpenCode と Codex）。中断
  として分類し、Claude と同じ managed の再開経路に乗せます。元のプロンプトを送り直さない
  ので、副作用が繰り返されません。
- 共有された会話にもミラーの表示設定が効きます。スキルピッカーは説明に 1 行を割きます。
  外観ポップオーバーの並びとラベルを整えました。
- **ガイド**: サインイン方法の設定手順を、ID プロバイダ側の作業も含めて追加しました。
- CLI の固定版: Claude Code 2.1.238、Codex 0.149.0、OpenCode 1.18.19、GitHub Copilot
  1.0.80、Antigravity 1.1.17、Kiro 2.19.0、Cursor 2026.08.11、rtk 0.45.0。

### Fixed

- **Chrome で Console が数秒間固まっていました。** ペインが健全な GPU コンテキストを
  作り直し続け、やがてブラウザが「表示中のターミナルが使っているコンテキスト」を追い出し、
  代替の描画経路が文字ごとの幅をページレイアウト経由で測っていました。日本語の画面には
  異なる文字が数千あります。Firefox とタッチ端末は影響を受けていません。
- **設定の学習内容と履歴が、全端末で同時に初期化されることがありました。** 返信候補の
  学習チップ・ピン・SSM の履歴・キー割り当てが一斉に初期状態へ戻る問題です。既定値で
  始まった端末がそれを全体に上書きしていました。保存済みの内容を読み終えるまで何も送信
  しません。
- **Claude の質問に打ち込んだ自由入力が捨てられていました**（選択肢がプレビューを持つ
  場合）。*送信*を押しても何も起きず、入力は *user declined to answer questions* として
  返ってきていました。閉じた質問には**却下**のバッジが付き、回答済みとして描かれなく
  なりました。
- **承認待ちの質問やプランが二重に表示されていました。**
- **使用量グラフが 1 ターン遅れたままでした**（何度か更新を押すまで）。
- **`[保留]: …` のような行がミラーから消えていました** — Markdown ではこの形はリンク参照
  定義で、何も描画されません。日本語の文には ASCII の空白が無いので、普通の箇条書きが
  この形に一致していました。
- **起動時の最初の指示が届きませんでした。** その画面が表示されている間しか送られず、
  タブを初めて開いた瞬間に送信されたように見え、同じ指示が二重に出ることもありました。
  配送は Workspace 側で行うようにしました。
- **エージェントは正しく答えているのに「Workspace Agent に到達できません」と出て
  いました**（停止中セッションのターミナルを開いたとき）。
- **完了報告を off にした定時実行が、ミラーでバッジを持ちませんでした。** いちばん多い
  種類のスケジュールが、自分で打ったものと区別できませんでした。
- **スマートフォンで、特定のセッションだけ横スワイプが完全に効かなくなっていました。**
  転写の中の折り返せない長い文字列（`sha256:…` や URL）が 1 つあるだけで、転写全体が
  スワイプを拒否していました。
- **OpenCode が、選んでいないプランで動き出していました。** 未設定の値が Zen として扱われ、
  キーを 1 つ保存しただけで課金される経路が使われることがありました。新しい Workspace は
  選ぶまで何も使いません。
- **ECS のデプロイでメンバーガイドが開けませんでした** — そのアダプタでは配置経路が用意
  されておらず、メニュー項目が何もしませんでした。同じ領域で、Settings › toolchains から
  JDK をボタン 1 つで入れられるようにしました。
- ECS の修正: 起こした直後の Workspace 内 OAuth サインインが失敗する、初回起動がゲート
  ウェイタイムアウトを返す、何も変わっていないのに「要再起動」が点く。
- タブを閉じると無関係なタブへ飛ぶ、スマートフォンで Claude の選択肢説明が 2 行に切られる、
  共有セッションのタブがすべて「Shared session」になる、も直しました。

### Upgrade notes

手作業の移行はありません。起動時に 9 本の追加専用マイグレーションが走りますが、アップ
グレード前のデータは持たず、古いビルドからは無視されるのでロールバックは安全です。home
ディレクトリは移動せず、`AF_OIDC_PROVIDERS` を設定するかテナントに方法を登録するまで
サインインの挙動は変わりません。

既定値の変更が 3 つあります。

- **アイドル停止が on**: セッション 1 時間・Workspace 2 時間。従来の挙動に戻すには
  `AF_SESSION_IDLE_TIMEOUT` / `AF_WS_IDLE_TIMEOUT` に `0` を設定してください（明示的な
  `0` が尊重されるようになりました。以前は既定値に置き換えられていました）。
- **新規インストールは招待制。** 変わったのはテンプレートだけなので、既存の `.env` の
  挙動は今までどおりです。既存の ECS スタックを再デプロイすると新しいパラメータ既定を
  拾います。名簿に載っている人はそのまま使え、止まるのは新規参加者の自動受け入れだけです。
- **ECS の作業ディスクの既定が 50 GiB。** ビルド生成物の退避が実際に働く条件（30 GiB
  以上）を満たすためです。既存スタックはデプロイ時の値を保ちます。`WsDiskGiB=0` で従来の
  挙動に戻ります。

`ecs-ec2` ランタイムは opt-in で、Fargate 経路は変わりません。費用の表示には Cost
Explorer が必要です。Control Plane は初回に必要なコスト配分タグキーを有効化します。
アカウントの請求設定への書き込みはこれだけです。
