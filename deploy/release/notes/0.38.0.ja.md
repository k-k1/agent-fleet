同じ IAM Identity Center ポータルを使う Settings の AWS プロファイルが 1 回のログインを共有でき、
`af-aws-exec` の実行は呼び出したセッションに表示され、手元の `~/.aws/config`・`~/.ssh/config`・gcloud の
構成を Settings に取り込めます。

### 新機能

- **AWS のサインインを共有できます。** 同じ IAM Identity Center ポータルを使う Settings の AWS
  プロファイルは 1 つのサインインを共有でき、1 回のログイン・ログアウトがその全プロファイルに効きます。
  既存のプロファイルは **1 つのサインインを共有** でまとめられ、取り込みはまとめ方を提案します。
  ([#3014](https://github.com/k-k1/agent-fleet/issues/3014),
  [#3077](https://github.com/k-k1/agent-fleet/issues/3077))
- **AWS の実行をセッションのミラーに表示し、使う前に確認できます。** `af-aws-exec` の実行が、実際に使った
  アカウント・ロール・リージョンつきで呼び出したセッションに表示され、SSM のペインは使う ID を表示します。
  プロファイルごとに、各セッションで初めて使う前に Console で確認を求めるよう設定でき、その場合は
  `af-aws-exec` 経由でだけ使えます。
  ([#3050](https://github.com/k-k1/agent-fleet/issues/3050),
  [#3064](https://github.com/k-k1/agent-fleet/issues/3064))
- **手元の設定ファイルを取り込み・書き出しできます。** Settings に `~/.aws/config` から AWS プロファイルを、
  `~/.ssh/config` から SSM ホストを、gcloud の構成から Google Cloud プロファイルを、作られる内容を
  プレビューしてから取り込めます。ファイルはブラウザの中で読まれ、送信されません。Settings の AWS
  プロファイルは `~/.aws/config` の断片として書き出せます。
  ([#3010](https://github.com/k-k1/agent-fleet/issues/3010),
  [#3017](https://github.com/k-k1/agent-fleet/issues/3017))
- **ホームのディスクの内訳が見られます。** Settings › Machine で、ホームのボリューム全体を分類別
  （作業コピー・ビルド出力・ツールのキャッシュ・`~/.af-work`・ごみ箱など）に表示します。
  ([#3083](https://github.com/k-k1/agent-fleet/issues/3083))
- **Codex の再認証。** Codex のカードに再認証ボタンが付き、取り消されたログインで失敗したターンはログインの
  問題として表示され、サインインし直すまで次のプロンプトは断られ、し直すとセッションが自動で再開します。
  Claude と Codex 以外の種類にはまだこの経路がありません。
  ([#3021](https://github.com/k-k1/agent-fleet/issues/3021))
