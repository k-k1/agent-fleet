Memos can be dragged straight into a session, and a set of smaller fixes.

### New

- **Drag a memo into a session's composer.** Queued memos can be dropped directly
  onto the composer as input, and the memo queue itself sorts and distinguishes its
  rows more clearly.
- The account menu is always visible in the `native` runtime.

### Improved

- The settings modal explains which permissions a GitHub token needs when you issue
  one.
- Finishing a clone or checkout reloads the left pane, so the new working copy appears
  without a manual refresh.
- SVN: folder naming and the wording in the start-work modal were corrected.

### Fixed

- The pop-out button overlapped the pane header controls.
- The dist README's wording and the agent list in the user guide were corrected.
