Memos can be dragged straight into a session, plus a set of smaller fixes.

### New

- **Drag a memo into a session's composer.** Queued memos can be dropped directly onto
  the composer as input, and the memo queue sorts and distinguishes its rows more
  clearly.

### Improved

- The settings modal explains which permissions a GitHub token needs when you issue one.
- Finishing a clone or checkout reloads the left pane, so the new working copy appears
  without a manual refresh.
- The account menu is always visible in the `native` runtime, and SVN folder naming and
  start-work wording were corrected.

### Fixed

- The pop-out button overlapped the pane header controls.
