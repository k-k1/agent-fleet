作業グループで左ペインをプロジェクト単位に分けられるようになり、自分の MCP サーバー
を登録でき、エージェントのメモリが版管理され、エディタが変更案を出して差分で確認
できるようになりました。

### New

- **作業グループ。** リポジトリ・チャット・セッションをプロジェクト単位でまとめ、
  左ペインを切り替えられます。忙しい fleet でも目の前の仕事に要るものだけが出ます。
  スケジュールも同じ切り替えに従います。
- **自分の MCP サーバー。** stdio でもリモート HTTP でも設定から登録でき、アシスタント
  用・セッション用・両方のいずれかに向けられます。保存前に接続テストができます。
  テナント管理者は全員へ配布できます。
- **エージェントのメモリ管理。** メモリのファイルを版管理し、履歴と差分を見て、1 
  ファイルまたはメモリ全体をある時点へ戻せます。バンドルの書き出し／取り込みで環境間
  を移動できます（持ち出す前に秘匿情報を走査します）。
- **エディタの AI 変更案。** 開いているファイルへの編集を依頼し、結果を差分で確認して
  から受け入れます。受け入れるまで何も書き込まれません。
- **セッションチャットのスキルピッカー。** 引数付きで選べ、別種別のエージェントの
  スキルも選べます。
- **プランへのコメント。** 一節を選んで注釈を付け、まとめて送れます。
- **Claude の利用上限からの自動復帰。** 費用のかからない「リセットを待つ」を自動で
  確定し、上限が明ける時刻に 1 回だけの再開を予約します。どちらも通知センターに出ます。
- **会話の途中でエージェントを切り替え**られます。**使わないモデルを種別ごとに隠す**
  こともでき、隠したモデルはピッカーから消え、起動時にも拒否されます。
- **作業計画が引き継ぎで失われません** — アシスタントの計画は要約に畳まれず、次の会話
  へそのまま持ち越されます。

### Improved

- **アシスタント↔セッション間のトークン消費を大きく減らしました** — 早めの compact、
  自動ターンのまとめ、出力末尾の切り詰め、自動返信用の軽いモデル、静かな完了報告。
  5 つのつまみはすべて設定にあります。
- **ライトモードを実測コントラストに基づいて作り直しました。** 白地のグレー文字が、
  目立つ場所だけでなく Console 全体で読めるようになりました。
- **掃除を段階制にしました** — アーカイブ → worktree の削除 → 棚の解放。候補ごとに
  なぜ候補なのかを示します。
- **既存ブランチで worktree を作れるようになりました。** 同じブランチを 2 か所で
  チェックアウトすることはできなくなりました。
- 稼働中のバックエンドがデプロイ済みより古いとき、Workspace バーに**要再起動**の
  バッジが出ます。
- 左ペインのファイルはプロジェクトとブランチでまとまり、スケジュールは既定で静かに
  終わるようになり、Markdown は YAML front matter をプロパティとして表示し、commit
  ハッシュやセッション id を自動でリンクします。
- 名前を分かりやすく: SCM ペインは**コミットグラフ**、設定の「ミラー」は**セッション
  チャット**になりました。
- CLI の固定版: Claude Code 2.1.220、Codex 0.146.0、OpenCode 1.18.10、GitHub Copilot
  1.0.77、Antigravity 1.1.9、Cursor 2026.07.23、Kiro 2.16.0、rtk 0.44.1。

### Fixed

- **利用上限のメニューが出た後、セッションが「実行中」のまま戻らなくなることが
  ありました**（再起動以外に手が無い状態）。
- **OpenCode 1.18.8 で MCP ツールが全部消えました** — 新しいプロトコル era が要求する
  項目を送っていませんでした。
- **完了報告が消えることがありました。** OpenCode のアシスタントセッションはそもそも
  報告を届けておらず、Codex のセッションも報告に失敗することがありました。
- **ファイル検索やスキルピッカーで Console が真っ暗になることがありました。**
- Docker の fleet で要再起動バッジが消えなくなる問題と、AI が提案する件名が前置きを
  伴い表示言語を無視する問題を直しました。

### Upgrade notes

作業はありません。作業グループは空から始まるので、作るまで左ペインの挙動は今までと
同じです。スケジュールは既定で静かに終わるようになったので、完了報告に頼っていた
場合はスケジュールごとに戻してください。Claude の利用上限からの自動復帰は既定で on
です（Settings › Agents › Claude）。
