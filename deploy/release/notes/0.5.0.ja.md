作業グループで Console の左ペインを案件ごとに分けられるようになり、独自の MCP
サーバーを登録でき、エージェントのメモリはバージョン管理されて持ち運べるように
なりました。エディタは AI の変更案を差分でレビューしてから取り込めます。

### 新機能

- **作業グループ** — リポジトリ・チャット・セッションを案件ごとにまとめ、左ペインの
  表示をまとめて切り替えます。セッションが増えても、今の作業に要るものだけが並びます。
  スケジュールも同じ切り替えで絞り込まれます。
- **独自の MCP サーバー登録** — 設定から MCP サーバーを登録できます（stdio / リモート
  HTTP）。アシスタント・セッション・その両方のどれに配るかを選び、保存前に接続テストが
  できます。テナント管理者はテナント全体へ配布でき、テナント配布と名前が衝突して
  使われていない個人登録は、黙って無視せず明示します。
- **エージェントメモリの版管理** — エージェントのメモリファイルをバージョン管理下に
  置きます。履歴の閲覧・差分表示・ファイル単位／メモリ全体のその時点への復元に加え、
  bundle の書き出し／読み込みで別環境へメモリを移せます（書き出す内容は事前に
  シークレット走査を通ります）。codex のメモリも管理対象で、フリートオペレーターは
  MCP 経由で参照できます。
- **エディタの AI 変更提案** — 開いているファイルへの変更を依頼し、結果を差分で
  レビューしてから accept / reject します。生成チャネルは read-only なので、accept
  するまで何も書き込まれません。外部での変更にも追従し、未編集のバッファは自動で
  読み直し、編集中のバッファは上書きせずに知らせます。
- **セッションのチャットからスキル選択** — コンポーザーから引数付きでスキルを選べます。
  別種のエージェントが持つスキルも選べ、その場合はコピーではなくプロンプトとして
  注入されます。
- **プランへのコメント** — プランの一節を選んで注釈を付け、セッションのチャットから
  まとめて送れます。プラン承認待ちのセッションへ自由文を送った場合は、回答として
  解釈せずに拒否するようになりました。
- **Claude 利用上限からの自動復帰** — 上限メニューは自動で確定し（費用の増えない
  「リセットを待つ」側）、リセット時刻に一回限りの再開を予約します。上限到達と自動再開は
  通知センターにも出ます。既定は ON で、再開を OFF にしてもメニューの自動確定は
  行われます。
- **会話途中でのエージェント切替** — 新しい会話を始めずに、アシスタントチャットが使う
  CLI を切り替えられます。
- **使わないモデル** — エージェント種別ごとに使わないモデルを隠せます。一覧から消え、
  起動時にも弾かれます。
- **作業計画の引き継ぎ** — アシスタントの作業計画は要約に畳まれず、原文のまま次の会話へ
  引き継がれます。固定しておけば以降のターンでも保持されます。

### 改善

- アシスタント↔セッションのトークン消費を大幅に削減しました（圧縮閾値の前倒し・
  自動ターンの束ね・出力末尾のクリップ・自動応答の軽量モデル・静かな完了報告）。
  5 つのノブはいずれも設定から変更できます。
- 使用量タブに rtk の節約効果を詳細カードで表示します（本チャート・粒度切替・表ビュー）。
- ライトモードを実測コントラストで全面的に見直し、白背景のグレー文字が Console 全体で
  読めるようになりました。
- 左ペインのファイルはプロジェクト＋ブランチでグループ化され、絞り込みは slug・
  ブランチ名・フォルダ名にも一致します。
- 掃除を段階制に再編しました（アーカイブ → worktree 削除 → 棚の回収）。候補はその理由を
  自分で説明し、削除ロック済みのセッションは worktree を残します。
- 既存ブランチでも worktree を作成できます（fetch / fast-forward 込み）。同じブランチの
  二重チェックアウトはできなくなりました。
- 返信サジェストをピン留めでき、チップごとのメニューが付きました。行はホイールで
  左右にスクロールします。
- 稼働中のバックエンドが配備済みのものより古いとき、ワークスペースバーに
  **要再起動** バッジが出ます。
- スケジュールは静かに完了できます（新しい既定）。従来どおりの完了報告も選べます。
- Markdown は YAML front matter をプロパティとして表示し、コミットハッシュ・
  セッション／会話 ID を自動でリンクします。
- 名称を分かりやすくしました。SCM ペインは **コミットグラフ**、設定の「ミラー」は
  **セッションのチャット** です。
- CLI のピン更新: Claude Code 2.1.220 / Codex 0.146.0 / OpenCode 1.18.9 /
  GitHub Copilot 1.0.76 / Cursor 2026.07.23 / Kiro 2.14.2 / rtk 0.44.1。
- チャットの通知文は保存時の言語ではなく、表示言語に追従します。
- Console・コントロールプレーン・ワークスペースエージェント・ドキュメントの
  レビューで、細かな不具合およそ 200 件を解消しました。

### 修正

- 利用上限のメニューが出たあと、セッションが「進行中」のまま永久に貼り付くことが
  ありました（再起動以外に戻す手段がありませんでした）。
- OpenCode 1.18.8 で MCP ツールが全滅していました（新しいプロトコル era は
  `tools/list` に `ttlMs` と `cacheScope` を要求しますが、送っていませんでした）。
- バックグラウンドのサブエージェント待ちの完了報告が、誤った「入力待ち」判定と
  重なると消えることがありました。
- OpenCode のアシスタントセッションから完了報告が届きませんでした。
- codex セッションで、フリート自身の MCP ツールがエージェント API の認証情報なしに
  起動し、報告に失敗することがありました。
- スキルピッカーで画面全体が真っ黒になることがあり、ボタンから開いた場合に絞り込みが
  効きませんでした。
- 「使わないモデル」が意図より広く一致していました。
- ファイル検索で画面が白紙になることがありました。
- ファイルビューのヘッダーボタンがペイン操作ボタンと重なっていました。
- Docker 構成のフリートで「要再起動」が恒久的に点灯していました。
- AI の件名提案に前置きが混じり、表示言語が反映されませんでした。
- 返信サジェストの行が貼り付くこと、✨ サジェストに余分な見出し行が残ることが
  ありました。
- rtk チャートの間引き目盛りが基線より下に沈んでいました。

### アップグレード時の注意

移行作業や設定変更は不要です。作業グループは空の状態から始まるので、作成するまで
左ペインの挙動はこれまでどおりです。スケジュールは既定で静かに完了するようになった
ため、完了報告に頼っていた場合はスケジュールごとに ON へ戻してください。Claude の
利用上限からの自動再開は既定 ON で、設定 › エージェント › Claude にあります。
