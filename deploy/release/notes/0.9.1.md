A maintenance release for AWS deployments, from standing one up end to end: read-aloud
never worked on ECS at all, a workspace created after the Control Plane started could
not be reached from it, and the two screens a brand-new deployment shows first were
blank.

### Fixed

- **A workspace created after the Control Plane started was unreachable from it.**
  Every Console panel that reads the workspace answered 502 while the workspace itself
  ran normally, and only replacing the Control Plane task healed it. In practice the
  first workspace of a fresh deployment, and every new member's first workspace, were
  dead until somebody restarted it. Resolution now falls back to Cloud Map.
- **Read-aloud on ECS always failed.** The Control Plane's task role was never granted
  `polly:SynthesizeSpeech`. It failed in the worst way: the provider reported itself
  ready, so the Console kept offering playback and only the click failed.
- **The voice shown while speaking could name a character that was not speaking**, and
  the volume adjustment meant for that character was applied on the same mistaken basis.
- **A workspace that could not start said nothing** — the button flashed "starting" and
  settled back on "unknown". The state now reads *No tenant* when that is the cause,
  and any failure to start is reported.
- **The first-run guide never appeared for a new user.** It was attached to the empty
  state of a terminal pane, and a new user's Console opens with no pane at all.

### New

- **Bitbucket can be connected on ECS.** Set `BitbucketOauthKey` and put the secret at
  `<SsmPrefix>/bitbucket-oauth-secret`; the consumer's callback URL must be exactly
  `https://<your-fqdn>/api/oauth/bitbucket/callback`.

### Improved

- VOICEVOX settings are hidden on deployments that have no VOICEVOX engine, where they
  could be chosen but never took effect.

### Upgrade notes

Two of the fixes are in the CloudFormation templates rather than the image, so an ECS
deployment should re-deploy the stacks as well as move the tag:

- `20-platform` grants the Control Plane `polly:SynthesizeSpeech`. Without re-deploying
  it, read-aloud stays broken on this release too. It is an IAM-only change and the
  running task picks it up without a restart.
- `30-ingress` gained `BitbucketOauthKey` (optional).
- The README's stand-up procedure was missing `--capabilities CAPABILITY_AUTO_EXPAND`
  for `10-data`; following the old procedure verbatim failed with `Requires
  capabilities`.
