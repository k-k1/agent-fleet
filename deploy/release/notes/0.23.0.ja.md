セッションの種類が 2 つ増えました。**llama.cpp** は、配備のチャットエンジンか自分の
llama-server の上でフリート自身のハーネスが動くもの、**Muse Code** は Meta のコーディング
エージェントです。あわせて、全セッションを時間軸のレーンとして描く俯瞰図、マスクと参照画像を
使った指示による画像編集、機能ごとにエージェントとモデルを固定できる AI補助、そして期限が来ても
消えずにアーカイブへ移る停止セッションが入りました。

### New

- **llama.cpp のセッション。** 背後に CLI を持たないセッション種別です。フリート自身のハーネスが
  配備のチャットエンジンと話し、ツール・MCP サーバー・承認・正確な使用量はミラーに出ます。
  端末ペインはありません。最初から有効で、切るのは設定 › エージェントの **llama.cpp を使う**です。
  同じカードの**自分の接続先**に LAN の llama-server を入れるとそちらが優先され、起動する前からカードと
  エンジンのピルが到達できるかを言います。
- **Muse Code のセッション。** Meta の Muse Code をセッション種別として使えます。イメージには
  入っていないので、設定 › エージェントのカードから 1 回だけホームに導入し、ブラウザで Meta
  アカウントにサインインするか API キーを入れて、他のエージェントと同じように起動します。
  質問・使用量とコンテキストゲージ・スキル・MCP サーバー・フォーク・引き継ぎはミラーを通ります。
  Muse 自身の OS サンドボックスはワークスペースでは動かず、それを切った Muse はツールを動かす前に
  尋ねません。Muse のセッションは shell のセッションと同じ形でコンテナに触ります。
- **フリート俯瞰図。** セッション一覧に**俯瞰図**への切り替えが付きました。セッションごとに
  1 本のレーンを時間軸に描き、いつ始まり止まったか、どこで子を起こし、メッセージを送り、報告を
  返したか、いま何の状態かが見えます。家系は畳め、アーカイブ済みのレーンは出し入れでき、窓は
  直近 24 時間から前後に動かして拡大縮小できます。
- **指示で絵を編集できます。** Qwen-Image-Edit のファミリー（2509 と 2511）は、変更を書いた
  一文と最大 3 枚の参照画像、そして inpaint 用の**マスク画像**（白いところを塗り直す）を受け取ります。
  絵は全体が編集の対象で、切り落とされる部分はありません。スマホ写真の向きはそのまま読まれ、
  マスクは寸法が違っても絵の同じ場所を指します。エンジンの覚醒と生成は別々に計られ、編集した絵の
  再現情報にはプロンプト・negative・寸法が残ります。Qwen-Image 2.1 もファミリーに加わり、1 つの
  モデルで生成と編集の両方をします。寸法は 2K までです。
- **停止したセッションは消えずにアーカイブへ移ります。** 停止セッションの保持期限が来ると、
  会話ごとアーカイブへ移り、そこから復元できます。人が頼まない限り何も削除されないので、
  worktree もセッションと一緒には消えなくなりました。回収は掃除ダイアログからです。
- **AI補助を機能ごとに指定できます。** 設定 › AI補助で、タイトル・ブランチ名・返信の提案、
  ファイル編集の提案、作業計画の更新、回答の翻訳のそれぞれにオン／オフとエージェント・モデルを
  持たせられます。オフにした機能は
  ボタンごと隠れ、カードにはいまどのエージェントとモデルを使うかが出ます。
- **プランを別のセッションにレビューさせられます。** ミラーのプランに**別セッションでレビュー**が
  付きました。プランを却下し、選んだエージェントでレビュー用のセッションを起こします。そちらは
  何も変更せずにプランをコードと突き合わせ、決まった形式で答えます。
- **GPU の自動停止までの時間が設定になりました。** エンジンの管理画面に役割ごとの
  **自動停止まで**（分）が付き、固定の時間ではなくなりました。
- **Spot は受け入れがないと買いません。** Spot の提案は、super admin が役割に
  **中断を許容する**を入れたときだけ買います。それ無しで固定された Spot の提案は飛ばされて自動
  選択に戻り、外した場合は走っているインスタンスではなく次のインスタンスから効きます。
- **登録済みモデルのカードに「別バージョン…」か「別サイズ…」が付きました。** 同じ配布元の他の
  バージョンや量子化がサイズと収まりの判定つきで並び、取り込むと新しい行になります。
- **リポジトリや worktree 配下のセッションをまとめて停止**できます。右クリックから、すぐ停止か
  ターン終了後かを選び、止められないセッションには理由が並びます。
- **opencode のカードが電源と課金の選択に分かれました。** **opencode を使う**（新しいワークスペース
  ではオフ）が種別全体の電源で、切ると起動メニューから消え、API から直接作ろうとしても拒まれます。
  課金の選択には**使わない（自分の鍵だけ）**が増え、この経路では opencode.ai の鍵を渡しません。
- **未読の通知があるセッションに赤い点が出ます。** 通知センターには**すべて既読にする**が
  付きました。

### Improved

- **起動時にモデル一覧の様子が分かります。** 「モデル一覧を取得しています…」が出て、空のときは
  理由を言います——設定で全モデルを除外している、課金の選択で 1 つも残らない、ワークスペースの
  起動直後、のどれかです。
- **WS バーの使用量チップは直近で使った 2 つだけ残し**、残りは「+N」に畳みます。チップごとに
  常に出す／常に畳むを選べます。
- **エンジンのピルに載っているモデルが出て**、リクエストが走っている間は**使用中**、最後に
  使った時刻も分かります。
- **ギャラリーのカードに右クリックメニューが付きました**——パスや名前のコピー、名前の変更、
  削除、生成したセッションを開く。ライトボックスの情報パネルはテーマに追従します。チャットに
  貼り付けた画像も同じライトボックスで開きます。
- **変更ファイルの帯が llama.cpp・Kiro・Muse Code・Antigravity のセッションにも出ます。**
- **編集の寸法警告が、入力ではなく実際に出てくる絵の寸法を名指します。** どのファミリーでも同じです。

### Fixed

- **借用エンジンのモデルが読み込み中のとき、チャットが待たずに「時間内に上がらなかった」と
  答えていました。** 待ちはストリームで続き、向こうの配備の断りはそのまま中継されます。
- **フリート自身のチャットエンジン上のセッションのコンテキスト使用量が推測値でした。**
  エンジンが実際に読み込んだ窓を読むようになりました。
- **チャットモデルの量子化の「収まるか」の判定が誤ることがありました。** ファイル自身から読み、
  行の一生を通じて同じ判定を保ちます。
- **モデルの取り込み:** 誰も宣言していない `llm` のファイルに「消す」だけでなく「登録」も出ます。
  計画カードで id を書き換えても「古い計画」で失敗しなくなり、ダイアログが 2 回計画することも
  なくなりました。分割ファミリーの部品が別ファミリーのファイルに重なるのは計画の時点で捕まえ、
  置き場所を誤ったファイルの移設は下のスタック更新の後に通ります。
- **claude のセッションで、端末には実況が出ているのにミラーが長いツール実行の間だけ無言に
  見えていました。** その実況は claude の thinking（Fable 5.1 や Opus 5.5 では要約された思考）で、
  ミラーがそれを捨てていました。畳める**思考**ブロックとして出るようになり、設定 › エージェントの
  Claude のカードに**思考を展開して表示**が付きました。使用量はパートごとではなく 1 応答 1 回で
  数えます。
- **フリート自身の画像エンジンで長い生成が走っている最中に、まだ動いているのに失敗と報告される
  ことがありました。** ジョブが待ち行列に残っている間は待ち続けます。
- **ポップオーバーや右クリックメニューの外側をクリックすると、その下のもの——ボタン・セッションの
  行・コンポーザー——まで押されていました。** 外側のクリックはメニューを閉じるだけになりました。
- **Discord ブリッジが同じ「回答ができた」通知を 2 回送ることがありました。**
- **ミラーの引用をコピーすると段落の区切りが消えていました。** スマホで幅の広い表を横に
  スワイプすると左ペインが開いていました。

### Upgrade notes

- **エンジンを動かす `ecs-ec2` 配備は `60-engines` スタックを更新し、ComfyUI のタグは自分で
  動かしてください。** テンプレートからは、大きめのモデルの読み込み中に ComfyUI を止めていた
  タスク単位のメモリ上限が無くなり、取り込みのロールに移設の修復が要る S3 のタグ権限が付きます。
  この 2 つは `update.sh` が運びます。ComfyUI のイメージは Qwen-Image 2.1 のファミリーが要る
  `v0.37.0` に上がりますが、稼働中のスタックはいまのタグを持ち続けます。`deploy/aws/ecs/README.md`
  のとおりイメージを ECR へコピーしてから、パラメータを 1 度だけ名指ししてください——

  ```sh
  aws cloudformation deploy --stack-name af-ecs-engines \
    --template-file deploy/aws/ecs/cfn/60-engines.yaml \
    --parameter-overrides ImageComfyImageTag=v0.37.0 \
    --capabilities CAPABILITY_NAMED_IAM --no-fail-on-empty-changeset
  ```

- **Spot の提案を既に並べている配備は、Spot を買わなくなります**——super admin がエンジンの
  管理画面でその役割に**中断を許容する**を入れるまでです。Spot の行を並べること自体は受け入れでは
  なくなりました。
- **llama.cpp のエンジンイメージをダイジェストで固定できます。** `standup.sh --llm-digest
  sha256:…` です。指定しなければコピーはこれまでどおりで、`LlmImageTag` は変わりません。
- **Muse Code はイメージに入っていません。** 利用者が求めたときだけ Meta の配布チャネルから
  その人のホームへ取得します（約 299 MB）。`NOTICE` に記しました。
- **ディスク:** 停止したセッションの worktree は自動では消えなくなりました。行き先は掃除
  ダイアログです。
