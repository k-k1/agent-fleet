人の返事を待っているだけの Workspace が、起動したまま課金され続けることはなくなりました。
畳むときに画面に出ていた質問・計画の承認・許可要求は取っておき、あとからセッション一覧で
答えられます。ツールの承認は「毎回スキップ」ではなく選べるようになり、セッションを同じ
テナントの別メンバーへ引き継げるようになりました。

### New

- **質問で止まっているセッションが、Workspace を起こし続けることはなくなりました。**
  質問・計画の承認・許可要求はこれまで「作業中」と数えられていたため、誰かが答えるまで
  コンテナは起動したままでした。夜をまたごうと週末をまたごうと、です。これらには専用の
  タイムアウト（`interaction_idle_timeout`・既定はセッションのタイムアウトと同じ）が
  付きました。
- **畳んだ時点で画面に出ていたものは取っておき、Console から答えられます。** 開いていた
  質問・計画・許可要求はセッション一覧にカードとして残ります。答えを選ぶと Workspace が
  起動し直し、エージェントへ文章として届きます。停止中のセッションには質問を抱えている
  ことが出て、未回答のまま畳んだときは通知が届きます。
- **ツールの承認を選べるようになりました。** これまではどのエージェントも承認を全部
  スキップして起動していました。エージェントの種類ごと、あるいはセッション単位で「毎回
  たずねる」を選べ、承認は Console から答えられます。**既定は変わりません** — 切り替え
  られるエージェントは Upgrade notes を参照してください。
- **セッションを別のメンバーへ引き継げます。** 共有しているセッションの続きを同じテナントの
  誰かに差し出すと、相手は受信箱から受け取り、前埋めされた起動ダイアログが開きます。
  未 push の作業があるときは差し出せません（相手はリモートから始めるためです）。
- **「自動停止しない」ピン**で、セッションと Workspace を 4 時間だけアイドル停止から守れます。
  端末を閉じたまま回す長いビルドや `ssm` 越しの作業のように、外から見て作業中と分からない
  ものが対象です。期限が来ると自動で解除されます。
- **管理画面の名簿に、各メンバーの Workspace が「いつ止まるか」「なぜ止まらないか」**（在席・
  実行中のセッション・背景の作業・ピン）が出ます。reaper が最後に見た時刻も添えます。

### Improved

- 在席の判定を、接続があるかどうかではなく直近の打鍵で見るようにしました。端末のタブを
  開いたままにしても Workspace が永久に温まり続けることはありません。ミラーを読んでいる
  あいだも在席と数えるので、追いかけて読んでいる最中に止まることもありません。
- 背景の作業（サブエージェント・Workflow）が走っているセッションは、その間は畳みません。
- 引き継ぎ先を、元のセッションの作業コピーではなく新しい worktree で始められます。
- 新規アカウントの初期設定では **Claude Fable を非表示**にしました。Team プランでは
  誤って選ぶと API クレジットで課金されるためです。保存済みの設定は変えません。

### Fixed

- **作業グループなどの累積した設定が、別のアカウントへ漏れることがありました。** テナントや
  ユーザーを切り替えても前の持ち主のデータがメモリに残り、消失を防ぐための自己修復が
  それを新しいアカウントの設定へ書き戻していました。
- **一部の利用者が、Workspace を起動するたびに赤い「agent が応答しません」を踏んで**
  いました。数秒後には普通に使えていました。エージェントの到達が想定より遅いのは状態で
  あって、起動の失敗ではありません。
- **背景のサブエージェントや Workflow が走っている最中に出た質問に答えられませんでした。**
  ミラーにカードは出るのに、回答を送る手段がありませんでした。
- **日本語の文中でボールドと打ち消し線が効きませんでした。** 記号の隣が空白ではなく
  かっこや全角の約物だと、そのまま生の記号で出ていました。

### Upgrade notes

**未回答の質問で起動し続けていた Workspace は、これから停止します。** 失われるものは
ありません（質問は持ち越され、セッション一覧から答えられます）が、実質「質問が開いている
おかげで生きていた」Workspace は `AF_INTERACTION_IDLE_TIMEOUT`（テナント別は
`interaction_idle_timeout`・既定はセッションのタイムアウトと同じ）で眠るようになります。
打鍵の無い端末を在席と数える猶予は `AF_PRESENCE_IDLE_TIMEOUT`（既定 30 分）で、`0` に
すると従来の挙動に戻ります。追加専用のマイグレーションが 2 本、起動時に走ります。

ツールの承認を「毎回たずねる」にできるのは Claude Code / Cursor / Copilot / Kiro /
Antigravity です。Codex と OpenCode は従来どおりスキップします — 外すべきフラグが状態検出
まで兼ねているためで、Console は切り替えが効く相手にだけ設定を出します。

エージェント CLI の固定版：Codex 0.149.1。その他は 0.11.0 から変わりません。
