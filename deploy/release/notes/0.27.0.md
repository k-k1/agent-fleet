Members can run Google Cloud commands as themselves with `af-gcloud-exec`, from profiles in Settings with
a Console login, as they already could for AWS. The WS bar shows which AWS and Google Cloud profiles are
signed in, and a single AWS profile can be logged out. Peer, operator and scheduled messages queued for a
Managed session now survive a stop or an Agent restart. On ECS, Recreate, Clean home and Destroy reach
the EFS home, and ecs-ec2 slots can be reserved for replacement at their next start. The CP task role on
ECS is narrowed further; operators of a custom AMI or a restricted deployer have something to check.

### New

- **Google Cloud profiles.** Settings › Google Cloud holds a member's profiles (project, quota project,
  account, service account to impersonate, region and zone from a list), and
  `af-gcloud-exec --profile <name> --project <id> -- <command>` runs gcloud, `kubectl` against GKE or
  Terraform with a short-lived token of that profile. The login is finished in the Console, no Google
  credential is stored in Agent Fleet, and the first run installs the Google Cloud SDK into the home.
  A badge in the WS bar shows which profiles are logged in.
  ([#1495](https://github.com/k-k1/agent-fleet/issues/1495),
  [#1496](https://github.com/k-k1/agent-fleet/issues/1496),

  [#1511](https://github.com/k-k1/agent-fleet/issues/1511),
  [#1517](https://github.com/k-k1/agent-fleet/issues/1517))
- **AWS profiles in the WS bar.** A chip, tinted by state, shows how many Settings AWS profiles are signed
  in; its popover lists them with **Log in**. **Log out** (there and in Settings) signs out one profile
  only, the Console warns before a login that cannot renew runs out, and region fields are picked from

- **Session rows show the branch's pull request and listening ports.** The PR's state and, while open,
  its checks; each port opens the browser pane on it.
  ([#1062](https://github.com/k-k1/agent-fleet/issues/1062))
- **Schedules choose where their result goes**: the assistant, the notification center, Discord or
  Slack. **Stay silent when there is nothing to report** delivers nothing when the run answers
  `[SILENT]`; failures are always notified.
  ([#1560](https://github.com/k-k1/agent-fleet/issues/1560))
- **The launch modal's first prompt** has searchable templates (your own, the repository's
  `.agent-fleet/launch-prompts.md`, and recent prompts), the skill picker, and attachments of any file
  type. A provisional branch name is asked for again for up to 45 seconds.
  ([#1469](https://github.com/k-k1/agent-fleet/issues/1469),
  [#1448](https://github.com/k-k1/agent-fleet/issues/1448),

  (worktree)…**, the menu opens the session's repository menu in the left rail, and a session link in
  the mirror or the assistant chat opens the session menu on right-click or long press.
  ([#1445](https://github.com/k-k1/agent-fleet/issues/1445),
  [#1557](https://github.com/k-k1/agent-fleet/issues/1557),
  [#1553](https://github.com/k-k1/agent-fleet/issues/1553))
- **A session can read a peer's recent output** with the new `peek_session_output` af MCP tool, under
  the same switch and kinds as peer messages.
  ([#1061](https://github.com/k-k1/agent-fleet/issues/1061))

- **ecs-ec2: reserve slots for replacement.** Settings › Admin › Slots (super admin) shows each slot's

  ([#1473](https://github.com/k-k1/agent-fleet/issues/1473))
- **Tenant admins can rotate one member's internal git token** from the member's details.
  ([#1199](https://github.com/k-k1/agent-fleet/issues/1199))

### Upgrade notes

- **ECS: the CP task role is narrowed.** Its EC2 writes are limited to this deployment's own slots and
  engine instances, and it launches them only from Amazon-owned or public images. A slot or engine
  launch template pointing at an AMI of your own now fails with `UnauthorizedOperation`.
  ([#1423](https://github.com/k-k1/agent-fleet/issues/1423),
  [#1522](https://github.com/k-k1/agent-fleet/issues/1522))
- **ECS: `update.sh` now deploys stacks with `CAPABILITY_NAMED_IAM`** and creates managed policies named
  `af-<stack>-cp-…-<region>`. A restricted deploying role also needs the IAM policy actions listed in
  `deploy/aws/ecs/cfn/PARAMETERS.md`. On ecs-ec2, the slot-pool stack is deployed before 20-platform.
  ([#1576](https://github.com/k-k1/agent-fleet/issues/1576))
- **ecs-ec2: to move slots launched before 0.26.0 onto the new user data**, reserve them in Settings ›
  Admin › Slots and have users stop and start, rather than setting `Ec2SlotTerminateAfterSec`. If you
  set it only for that move, set it back to 0.
  ([#1473](https://github.com/k-k1/agent-fleet/issues/1473))
- **Upgrading from 0.25.0 or earlier**: the operator steps in 0.26.0's Security section still apply.
