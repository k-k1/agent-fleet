SVN の作業コピーでログとローカルの変更を見られるようになり、claude の既存の自動メモリを Agent Fleet のメモリへ
取り込めるようになりました。進まなくなったターミナル（CLI）の claude と Antigravity のセッションが、ワークスペースを
動かし続けることはなくなりました。Antigravity と codex による画像生成は再び動き、Muse Code の質問に答えられるようになり、
Console の日本語は 1 つの用語集に沿って揃えました。

### New

- **SVN のログとローカルの変更。** SVN の作業コピーのメニューから、リビジョンの履歴（作業コピーより新しいリビジョンも
  含みます）と、まだコミットしていない変更を、それぞれ差分付きで開けます。どちらも読み取り専用です。
  ([#1705](https://github.com/k-k1/agent-fleet/issues/1705))
- **claude の自動メモリを Agent Fleet のメモリへ取り込む。** 設定 › エージェントメモリ の「Claude Code から取り込む」で、
  作業コピーごとの claude のメモリを確認し、選んだものを取り込みます。新しい `af-memory` コマンドでもシェルから同じ
  ことができます。秘密情報に見えるメモリは取り込まず、忘れさせたメモリを戻すこともありません。
  ([#1569](https://github.com/k-k1/agent-fleet/issues/1569))
- **テナントごとの外観。** 「テナントごとに外観を分ける」（上部バーの外観メニュー、または 設定 › 表示）をオンにすると、
  テナントごとにテーマと配色を持ち、テナントを切り替えるとその外観に変わります。このスイッチは 2 つ以上のテナントに
  所属しているときだけ表示され、既定はオフで、このブラウザに保存されます。
  ([#1692](https://github.com/k-k1/agent-fleet/issues/1692))

### Improved

- **進まなくなったセッションが、ワークスペースを動かし続けなくなりました。** ターミナル（CLI）の claude と Antigravity の
  セッションは、進んだ様子が 1 時間ないと実行中として数えなくなり、アイドル自動停止がワークスペースを止められます。
  Antigravity の途切れたターンも終わったと判断します。設定 › テナント › メンバー の「自動停止の見通し」には、停止を
  止めているセッションがどれだけ実行中だったかを表示します。
  ([#1811](https://github.com/k-k1/agent-fleet/issues/1811),
  [#1818](https://github.com/k-k1/agent-fleet/issues/1818),
  [#1819](https://github.com/k-k1/agent-fleet/issues/1819))
- **Agent Fleet のメモリのスイッチは 設定 › エージェントメモリ へ移りました。** 変更の一覧と取り込みの隣にあり、
  ワークスペースが停止中でも切り替えられます。今の設定はそのまま引き継ぎます。
  ([#1735](https://github.com/k-k1/agent-fleet/issues/1735))
- **メモリが多くても `memory_index` が大きくなりすぎなくなりました。** フィードバックとユーザーのメモリを先に、
  次に新しいものを並べ、入りきらないものは黙って切らずに名前を挙げます。
  ([#1702](https://github.com/k-k1/agent-fleet/issues/1702))
- **「アーカイブ済みセッション」がすぐに開き、幅も広くなりました。**
  ([#1701](https://github.com/k-k1/agent-fleet/issues/1701))
- **ミラーからリンクしたマージ済みの PR や閉じた Issue も、作業項目の詳細にタイトル・状態・担当者を表示します。**
  作業項目の一覧にないものも対象です。
  ([#1697](https://github.com/k-k1/agent-fleet/issues/1697))
- **Antigravity の画像生成で、参照画像（3 枚まで）から画像を編集できます。** 画像生成が提供されていないアカウントでは、
  そのことを伝えるエラーになります。
  ([#1718](https://github.com/k-k1/agent-fleet/issues/1718))

### Fixed

- **Antigravity による画像生成が何も作らず、codex による画像生成は ChatGPT のアカウントで失敗していました。**
  どちらも再び動きます。codex 経由で使うモデルは `AF_IMAGEGEN_CODEX_MODEL` で変えられます。
  ([#1716](https://github.com/k-k1/agent-fleet/issues/1716),
  [#1711](https://github.com/k-k1/agent-fleet/issues/1711))
- **Muse Code の質問に答えることも、取り消すこともできませんでした。** ツール呼び出しの前に書かれた文も表示されず、
  質問を待っている間も実行中と表示されていました。今は答えが質問に届き、チップに質問中と表示され、答えた質問は
  ミラーに残ります。
  ([#1695](https://github.com/k-k1/agent-fleet/issues/1695))
- **使用量の上限で止まった Muse Code のセッションが自動再開されず、アイドルと表示されていました。** 今は claude や
  codex と同じく上限に達したことを表示し、上限が解除されると再開します。
  ([#1766](https://github.com/k-k1/agent-fleet/issues/1766))
- **RTK をオン／オフすると、自分で設定した Claude Code の Bash フックが消えていました。** また、自分の質問・計画・
  許可のフックがあると、Agent Fleet の状態フックが入りませんでした。今は両方を並べて残します。
  ([#1779](https://github.com/k-k1/agent-fleet/issues/1779))
- **git のワークツリーで動く claude のセッションが、フォルダーの信頼の確認で止まっていました。** メインの作業コピーが
  信頼されておらず、リポジトリに許可のルールがある場合です。今はメインの作業コピーも信頼します。
  ([#1784](https://github.com/k-k1/agent-fleet/issues/1784))
- **ターミナル（CLI）の claude のセッションで、画像付きの長いプロンプトが `[Image #N]` として届き、エコーが保留中の
  ままになっていました。**
  ([#1686](https://github.com/k-k1/agent-fleet/issues/1686))
- **テナントを切り替えた後も、左ペインと上部バーに前のテナントのデータが残っていました。** リポジトリ、ファイル、
  接続の状態、AWS と Google Cloud のログイン、取り込みのジョブ、アシスタントのチャットです。
  ([#1680](https://github.com/k-k1/agent-fleet/issues/1680))
- **スケジュールでワークスペースを起動したときやホームの容量を変えたときに、テナントの既定のマシンの種類が使われて
  いませんでした。** メンバーの一覧にも配備の既定が表示されていました。
  ([#1687](https://github.com/k-k1/agent-fleet/issues/1687))
- **GitHub の作業項目の更新が、理由のない 422 で失敗していました。** 今は GitHub が示す理由を表示し、`is:issue` も
  `is:pull-request` も含まない検索は、それを付けてやり直します。
  ([#1690](https://github.com/k-k1/agent-fleet/issues/1690))
- **キャッシュした SSO のトークンが期限切れになった後は、AWS プロファイルからログアウトしても AWS 側のセッションが
  終わっていませんでした。**
  ([#1689](https://github.com/k-k1/agent-fleet/issues/1689))
- **回転情報を持つ JPEG の写真が、ギャラリーのサムネイルで横倒しに表示されていました。**
  ([#1643](https://github.com/k-k1/agent-fleet/issues/1643))
- **ミラー**: スキルピッカーの項目が押しつぶされて説明の行が消えていました。子セッションのバッジのツールチップは、
  親のセッションの名前を表示するようになりました（英語では `{name}` がそのまま出ていました）。
  ([#1782](https://github.com/k-k1/agent-fleet/issues/1782),
  [#1752](https://github.com/k-k1/agent-fleet/issues/1752))
