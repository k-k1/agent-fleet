リポジトリに属さない作業に専用のフォルダを持たせるスペースが加わり、作り直した「はじめる」画面から
始められます。シェルと SSM セッションにはターミナルのビューができました。いま動いているものを
並べる稼働中のビューが加わり、起動ダイアログでは最初のプロンプトの下の帯でエージェント・経路・
モデルを選べます。Web Push は発生元ごとに止められます。

### 新機能

- **スペース:** 「はじめる」画面の「スペースで始める」で、`~/spaces` の下の新しいフォルダか既存の
  フォルダでセッションを始められます。リポジトリではない作業のためのものです。スペースはセッションの
  ビューに専用の欄で並び、名前を変えられ、削除するとセッションごとごみ箱へ移ります。スペースの
  セッションに添付したファイルは、そのスペースの `attachments` フォルダにも写されます。
  ([#4963](https://github.com/k-k1/agent-fleet/issues/4963),
  [#4965](https://github.com/k-k1/agent-fleet/issues/4965))
- **「はじめる」画面:** 「スペースで始める」「リポジトリで始める」「その他」の 3 つの欄に分かれ、一度に
  開くのは 1 つです。最初のプロンプトの下書きはどの欄でも共通です。「作業を始める」は、何をするかを
  先に、次に場所、残りを「詳細」の中で聞くようになりました。
  ([#4963](https://github.com/k-k1/agent-fleet/issues/4963))
- **ターミナルのビュー:** アクティビティバーのビューで、シェルを場所（ホーム・リポジトリ・スペース）
  ごとに、SSM セッションをホストごとに並べます。**+** で「ターミナルを開始」が開きます。
  ([#4966](https://github.com/k-k1/agent-fleet/issues/4966),
  [#5169](https://github.com/k-k1/agent-fleet/issues/5169))
- **稼働中のビュー:** アクティビティバーのビューで、いま動いているセッションと、止まっていても
  あなたを待っているセッションを、リポジトリとスペースごとにカードで並べます。子のセッションは親の
  下に折りたたまれます。自動実行とスケジュールの実行は、最初は折りたたまれた専用の 2 つのグループに
  入ります。([#5154](https://github.com/k-k1/agent-fleet/issues/5154),
  [#5165](https://github.com/k-k1/agent-fleet/issues/5165))
- **アクティビティバーのアイコン:** アクティビティバーの右クリック（長押し）で、ビューごとに
  アイコンを出す・隠すを選べます。選択はブラウザをまたいで引き継がれます。隠したビューに待っている
  ものがあると、琥珀色の点が出ます。([#4964](https://github.com/k-k1/agent-fleet/issues/4964))
- **実行する設定の帯:** 起動ダイアログとスペースのフォームでは、最初のプロンプトの下の帯で
  エージェント・経路・モデルを選びます。最近使ったモデルはワンクリックで選べ、起動のボタンには
  何を始めるかが出ます。([#5146](https://github.com/k-k1/agent-fleet/issues/5146))
- **メモの自動実行、次に実行:** 待っているメモのメニューで「次に実行」の印を付けると、次に空いた
  枠が古いメモより先にそのメモを取ります。`add_memo` でもキューに足すメモに印を付けられます。
  ([#5021](https://github.com/k-k1/agent-fleet/issues/5021))
- **スケジュール、「セッション一覧にも表示」:** これをオンにしたスケジュールでは、実行が自分の
  ワークツリーで始めたセッションが、リポジトリのツリーとセッションのビューにあなたのものとして
  並びます。([#5070](https://github.com/k-k1/agent-fleet/issues/5070))
- **Web Push の発生元:** ⚙ 設定 →「通知」で、自動実行やスケジュールのセッション、またはそれらが
  起動したセッションからのプッシュを止められます。プッシュのタイトルにはどこから来たかが出ます。
  ([#5081](https://github.com/k-k1/agent-fleet/issues/5081))
- **メモリ、プロジェクトの文書へ昇格:** 「取り込み・書き出し」→「メンテナンス」に、実績を積んだ
  メモリが並び、リポジトリ自身の文書への変更を提案し、その変更がマージされたらメモリを退かせます。
  lint のレポートはそうした文書の行き先を確かめ、付け替えやメモリの復帰を提案します。
  ([#3498](https://github.com/k-k1/agent-fleet/issues/3498))
- **ブーストの予算:** テナントの月ごとのブーストの予算が効くようになり、超えるブーストは断られます。
  テナントのブーストのカードにメンバーごとの今月のブースト時間が並び、メンバーの詳細にも出ます。
  ([#4417](https://github.com/k-k1/agent-fleet/issues/4417))

### 改善

  ([#5115](https://github.com/k-k1/agent-fleet/issues/5115))

  [#5148](https://github.com/k-k1/agent-fleet/issues/5148))
- **ツールチェーン:** 行に製品名が出て、配布元のページへリンクします。gitleaks と Session Manager

- **ワークスペースのイメージ:** OpenCode 2.4 に対応し、Chromium・Go・AWS CLI・gcloud・bkt・

### 修正

- **カスタム API のエンドポイント:** 承認したカスタムのエンドポイントがワークスペースの唯一の
  プロバイダーだと、マネージドのセッションが始まりませんでした。
  ([#4789](https://github.com/k-k1/agent-fleet/issues/4789))
- **メモ:** 保存を断られるとエディタが閉じて下書きが失われ、送信のやり直しで先に送ったまとまりを
  もう一度送ることがあり、メモの削除の直前に貼った画像のファイルが消えることがあり、メモの選択で
  指しているメモが見えない位置へずれることがありました。
  ([#4939](https://github.com/k-k1/agent-fleet/issues/4939),
  [#4830](https://github.com/k-k1/agent-fleet/issues/4830),
  [#4827](https://github.com/k-k1/agent-fleet/issues/4827),
  [#4943](https://github.com/k-k1/agent-fleet/issues/4943))
- **スケジュール:** 承認を断られた直後の「確認して承認」が古い内容を開き、欄を閉じたあとに「終了」の
  折りたたみが開き直ることがありました。
  ([#4856](https://github.com/k-k1/agent-fleet/issues/4856),
  [#4762](https://github.com/k-k1/agent-fleet/issues/4762))
- **Web Push:** 別のテナントからのプッシュをタップすると今のテナントでセッションを開き、サインアウトや
  登録し直しのあとで端末のスイッチが違う状態を示し、セッションを離れたあともプッシュが止まったままに
  なることがありました。([#4870](https://github.com/k-k1/agent-fleet/issues/4870),
  [#4841](https://github.com/k-k1/agent-fleet/issues/4841),
  [#4866](https://github.com/k-k1/agent-fleet/issues/4866))
- **通知:** 大きすぎる・壊れた通知が 1 件あると、その後の通知が届かないことがありました。
  ([#4862](https://github.com/k-k1/agent-fleet/issues/4862),
  [#4863](https://github.com/k-k1/agent-fleet/issues/4863))
- **秘密情報の伏せ字:** 伏せたトークンのすぐ後ろに続く文字が伏せられず、短い GitHub の `ghs_`
  トークンの一部を見分けられませんでした。([#4945](https://github.com/k-k1/agent-fleet/issues/4945),
  [#4948](https://github.com/k-k1/agent-fleet/issues/4948))
- **Console:** メモリの整理の「今すぐ実行」が、確認の間にテナントを切り替えると別のテナントへ書くことが
  あり、外したメンバーがメンバーの詳細に戻って見えることがあり、自由入力の欄でブラウザが保存済みの
  住所を勧めていました。([#4925](https://github.com/k-k1/agent-fleet/issues/4925),
  [#4903](https://github.com/k-k1/agent-fleet/issues/4903),
  [#5123](https://github.com/k-k1/agent-fleet/issues/5123))
- **ECS の撤去:** `SsmPrefix` が `/af-ws/` の下にあると、`--purge-secrets` なしでも撤去が
  Control Plane の秘密情報を消していました。([#4894](https://github.com/k-k1/agent-fleet/issues/4894))

### アップグレードの注意

- **ブーストの予算が効くようになりました:** 月ごとのブーストの予算を設定したテナントでは、メンバーの
  ブースト時間が予算に達するとブーストが断られます。テナントのブーストのカードで予算を見直してください。
- **スペースには新しいワークスペースが要ります:** ワークスペースが 0.50.0 で動くまでは、「はじめる」画面は
  その Agent にスペースが無いと示し、そこでは起動しません。

エージェント CLI のピン: Claude Code 2.1.332、OpenCode 2.4.1、Codex 0.172.0、Copilot 1.0.115、
Antigravity 1.5.16（ほかは 0.49.0 から変わりません）。
