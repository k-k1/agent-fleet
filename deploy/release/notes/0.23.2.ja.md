ターミナルのセッションごとに作業用のフォルダが付き、セッションと一緒に消えるようになりました。
**設定 › マシン**では、go・npm・uv・pip がホームに溜めるキャッシュを空にできます。ほかに、通知
しないと決めた子の入力待ちが赤いドットを残さなくなり、作業コピーの削除でそこで動くセッションが
分かるようになり、ファイルペインから Agent Fleet 自身のデータのフォルダが見えなくなりました。

### New

- **ターミナル（CLI）のセッションごとに作業用のフォルダ `$AF_WORK_DIR` が付きます。**
  `~/.af-work/<セッション>/` で、セッションの起動時に作られ、セッションの削除で消えます。
  エージェントの試し書き・レビュー用のチェックアウト・スクリーンショットがホームに散らばらなく
  なります。マネージドのセッションにはまだ付きません。
- **設定 › マシン › ツールのキャッシュ**に、go・npm・uv・pip がホームに持つキャッシュが並びます。
  上限なく育ち、ひとりでに空になることはありません。**測る**は押したときだけ数え、**空にする**は
  確認のうえ 1 つずつ消します。実行中のビルドやインストールが使っているキャッシュは**使用中**と
  出て、それが終わるまで空にできません。

### Improved

- **作業コピーの削除の各行に、そこで動くセッションが出ます。** 種別のアイコンと表示名、稼働中の
  ものには状態のチップが付きます。フォルダ名が乱数でも、何の作業のコピーか分かります。
- **利用ガイドのトップで、更新履歴がリファレンスの直後の独立した段落になりました。**

### Fixed

- **「子セッションの入力待ちを通知」をオフにしても、子の行・ペインのタブ・通知センターに未読が
  残っていました。** いまは届いた時点で既読になります。子からの質問と許可の要求、ほかのセッションの
  入力待ちはこれまでどおり未読に残ります。
- **ファイルペインで `~/.local/share/agent-fleet` を開けていました。** ターミナルのスクロール
  バック・削除したセッションの転写を含む掃除のアーカイブ・使用量の台帳が入っているフォルダです。
  いまはほかの Agent Fleet のフォルダと同じく開けません。
- **`ecs-ec2`: `pause.sh` がエンジンの GPU の箱を止めずに残し、誰かが終わらせるまで課金が続いて
  いました。** 箱を終わらせられる唯一の CP を、箱を見ないまま止めていたためです。いまはエンジンが
  アイドルで止まるのを待ち（`--fast` なら箱を終わらせ）、CP が止まった後に残った箱を掃除し、
  データベースも止めます（`--keep-db` で残せます）。`--up` は CP より先にデータベースを起こし、
  `--status` は CP の居ない GPU の箱と、CP の休止中に動いているデータベースを警告します。

### Upgrade notes

することはありません。`ecs-ec2` の `pause.sh` は RDS のデータベースも止めるようになりました。
動かしたままにするなら `--keep-db` を付けてください。
