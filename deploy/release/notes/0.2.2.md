Panes can be popped out into their own browser tab, schedules gained a detail and
edit view, and Cursor can now back the assistant chat.

### New

- **Pop a pane out into its own tab.** Any pane can be detached into a separate
  browser tab and keeps working there — useful for putting a mirror or terminal on a
  second monitor.
- **Schedule detail and edit modal** — reachable from the kebab menu on a schedule
  row, so a registered schedule can be inspected and changed without going back
  through the operator conversation.
- **Cursor can be used for assistant chat.** Cursor now appears in the assistant
  creation picker, and the feature-support matrix records its default model.
- Row menus: memo queue rows and left-pane assistant conversation rows both got a
  `⋯` menu and a context menu, with delete collected into it (this replaces the
  always-visible delete button that was easy to hit by accident on a phone).
- The assistant's composer regains focus when an answer completes (not on phones).
- **A per-agent-kind feature support matrix** was added to the documentation, along
  with a disclaimer about autonomous execution.

### Improved

- The settings modal is larger (1000×760), and on a phone it shows the current tab as
  a heading.
- Cursor was added to the assistant priority order.
- The maximum-session-count limit no longer counts shell and SSM sessions; the
  `native` runtime has no limit.
- Arrow-key selection in the command palette scrolls to follow the selection.
- The handoff modal's choices were aligned with the launch modal, and it works with an
  English prompt.

### Fixed

- **Headless Cursor could execute write operations without being asked.** Assistant
  chat now runs it read-only (`--mode ask`); `cursor-agent -p` does not fail closed on
  its own, which was found in live testing.
- **Scheduled runs reusing a long-lived session could vanish silently.** Delivery is
  now confirmed against a readiness gate, and `skipped_overlap` is surfaced in the
  notification centre as an unattended non-delivery instead of passing unnoticed.
