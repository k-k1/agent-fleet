Panes can be popped out into their own browser tab, schedules gained a detail and edit
view, and Cursor can back the assistant chat.

### New

- **Pop a pane out into its own tab.** Any pane can be detached into a separate browser
  tab and keeps working there — useful for putting a mirror or terminal on a second
  monitor.
- **Schedule detail and edit modal**, from the kebab menu on a schedule row, so a
  registered schedule can be inspected and changed without going back through the
  operator conversation.
- **Cursor can be used for assistant chat.**
- Memo queue rows and assistant conversation rows gained a `⋯` menu, with delete
  collected into it instead of an always-visible button that was easy to hit by
  accident on a phone.

### Improved

- The settings modal is larger, and shows the current tab as a heading on a phone.
- Shell and SSM sessions no longer count against the maximum-session limit; the
  `native` runtime has no limit at all.
- The handoff modal's choices were aligned with the launch modal, and arrow-key
  selection in the command palette scrolls to follow the selection.
- A per-agent-kind feature support matrix was added to the documentation.

### Fixed

- **Headless Cursor could execute write operations without being asked.** Assistant
  chat now runs it read-only.
- **Scheduled runs reusing a long-lived session could vanish silently.** Delivery is
  confirmed against a readiness gate, and an overlap skip is surfaced in the
  notification centre instead of passing unnoticed.
