このリリースの大半は、Control Plane・Agent・AWS テンプレートのセキュリティ診断にもとづく強化で、
サインイン・Cookie・トークン・ターミナルのクリップボードの既定がより厳しくなりました。Console の
ターミナルを開いたままでもアイドルのセッションは停止されるようになり、長い Bash コマンドや複数行の
Bash コマンドでも許可カードの **許可** がまた効くようになりました。更新の前にアップグレードの注意を
読んでください。`AUTH` の指定が必須になり、ECS では先に `10-data` をデプロイします。

### 改善

- **設定 › エージェント のカードがすぐに出ます。** 接続の状態がわかるまで、各カードに **確認中…** の
  チップが付きます。タブ全体が待たされることはなくなりました。
  ([#3385](https://github.com/k-k1/agent-fleet/issues/3385))
- **作業項目の状態が色付きのピルで出ます。** 詳細パネルのタイトルの下に、open・draft・merged・
  closed・In Progress などを表示します。
  ([#3542](https://github.com/k-k1/agent-fleet/issues/3542))
- **セッションが停止するとターミナルのペインにそう表示され**、**再開** を案内します。何も言わずに
  固まることはなくなりました。([#3472](https://github.com/k-k1/agent-fleet/issues/3472))
- **ECS:** `30-ingress` に新しいパラメータ `EgressEventRetentionDays` が加わり、egress イベントの
  保持日数を指定できます（空なら 30 日）。
  ([#3403](https://github.com/k-k1/agent-fleet/issues/3403))

### 修正

- **Console のターミナルがつながっていると、誰も入力していなくてもアイドルのセッションが停止され
  ませんでした。** ターミナルの自動応答・再接続・表示中のブラウザペインでもワークスペースが起きた
  ままになっていました。今は、在席の猶予時間内の実際の入力だけを数えます。どの Control Plane レプリカ
  でも同じです。
  ([#3460](https://github.com/k-k1/agent-fleet/issues/3460),
  [#3461](https://github.com/k-k1/agent-fleet/issues/3461),
  [#3473](https://github.com/k-k1/agent-fleet/issues/3473),
  [#3462](https://github.com/k-k1/agent-fleet/issues/3462))
- **一部の Bash コマンドで許可カードの「許可」が失敗し**（折り返された、複数行の、または claude の
  「Dangerous rm operation」ダイアログに出たコマンド）、カードが消えませんでした。
  ([#3491](https://github.com/k-k1/agent-fleet/issues/3491),
  [#3521](https://github.com/k-k1/agent-fleet/issues/3521))
- **会話ビューの自動翻訳**が、別のタブを見ている間に終わった応答や、バックグラウンドの作業が
  残っている間の応答では動きませんでした。
  ([#3437](https://github.com/k-k1/agent-fleet/issues/3437))
- **コンテキスト長はわかるが出力上限が不明なエンジンの opencode** が compaction を一度もせず、
  長い会話がエンジンに拒否されていました。
  ([#3559](https://github.com/k-k1/agent-fleet/issues/3559))
- **ターミナルのクリップボード:** ワークスペース内のプログラムが、利用者の操作なしに手元の
  クリップボードを書き換えられました。ターミナル内からのコピーは毎回確認するようになりました
  （**許可** / **1 分間許可**）。**設定 › 表示 › ターミナル › マウスドラッグ直後は確認なしでコピー**
  をオンにすると、自分のドラッグによるコピーでは確認を省けます。
  ([#3487](https://github.com/k-k1/agent-fleet/issues/3487),
  [#3518](https://github.com/k-k1/agent-fleet/issues/3518))
- **ハンドオフの最初のメッセージが勝手に送られなくなりました。** 入力欄に入った状態になり、送信を
  押したときに送られます。([#3488](https://github.com/k-k1/agent-fleet/issues/3488))
- **サインイン・Cookie・リクエスト:** Console の Cookie を使った別サイトからの書き込みを拒否し、
  Console はフレームに埋め込めなくなりました。リダイレクト先・中継するパス・テナントの OIDC
  エンドポイントの検査を厳しくし、Jira と Bitbucket の接続のコールバックは始めたメンバーに
  結び付けました。
  ([#3448](https://github.com/k-k1/agent-fleet/issues/3448),
  [#3508](https://github.com/k-k1/agent-fleet/issues/3508),
  [#3490](https://github.com/k-k1/agent-fleet/issues/3490),
  [#3506](https://github.com/k-k1/agent-fleet/issues/3506),
  [#3481](https://github.com/k-k1/agent-fleet/issues/3481))
- **メンバー間・テナント間:** 招待で別テナントの ID のメールアドレスを設定できる、テナント IdP の ID が
  ほかのテナントのメンバーシップを持てる、PAT の発行と管理画面にテナントのサインイン方式・
  ネットワークの規則がかからない、メンバーを外しても PAT と MCP の許可が残る、という問題を直しました。
  PAT には必ず期限が付きます（既定で最長 365 日）。
  ([#3451](https://github.com/k-k1/agent-fleet/issues/3451),
  [#3489](https://github.com/k-k1/agent-fleet/issues/3489),
  [#3450](https://github.com/k-k1/agent-fleet/issues/3450))
- **共有の機能:** ComfyUI エンジンでほかのメンバーのジョブを見たり止めたりできる、チャットの返信が
  シェルや SSM のセッションに打ち込まれる、共有セッションの提案に承認カードに出ない項目を
  載せられる、通知の ID がメンバー間で衝突しうる、という問題を直しました。
  ([#3482](https://github.com/k-k1/agent-fleet/issues/3482),
  [#3507](https://github.com/k-k1/agent-fleet/issues/3507),
  [#3483](https://github.com/k-k1/agent-fleet/issues/3483))
- **プレビューと描画する内容:** プレビュードメインがあるとき、Console 自身のアドレスでの
  `/preview/<port>/` の形はプレビュードメインへリダイレクトします。無いときはサンドボックスで
  表示するので、Cookie や自前の WebSocket が要るアプリはプレビュードメインかブラウザペインを
  使ってください。描画した Markdown には、フォーム部品・インラインスタイル・Console の API を指す

  ([#3447](https://github.com/k-k1/agent-fleet/issues/3447),
  [#3449](https://github.com/k-k1/agent-fleet/issues/3449))
- **ワークスペースのファイル:** ファイルブラウザの保護フォルダに、名前の変更・アップロード・
  シンボリックリンク経由で届いてしまう、ブランチの `.gitmodules` で新しいワークツリーの
  サブモジュールの準備の仕方を左右できる、という問題を直しました。
  ([#3502](https://github.com/k-k1/agent-fleet/issues/3502),
  [#3484](https://github.com/k-k1/agent-fleet/issues/3484))
- **ログと AWS リソースの秘密情報:** アクセスログ・claude の監査行・エラー本文・中継するヘッダに
  資格情報が出ることがある、ECS のタスク定義でワークスペースのトークンが見える、モデルの
  ダウンロードで Hugging Face や Civitai のトークンを別のホストへ送りうる、ecs-ec2 のスロットの
  ロールが Control Plane のパラメータを読める、という問題を直しました。
  ([#3501](https://github.com/k-k1/agent-fleet/issues/3501),

### アップグレードの注意

- **`AUTH` の指定が必須です。** native 以外では、`AUTH` が無い（または `oauth`・`proxy`・`dev` 以外の）
  Control Plane は起動しません。`AUTH=dev` には `AF_ALLOW_INSECURE_DEV_AUTH=1` が要り、https の
  背後では拒否されます。compose・Kubernetes・AWS のテンプレートはもともと指定しています。
  手書きの設定を確認してください。([#3485](https://github.com/k-k1/agent-fleet/issues/3485))
- **ECS: 先に `cfn/10-data.yaml` をデプロイし**（パラメータは同じ）、それからいつもどおり
  `update.sh` を実行します。`10-data` が古いと、`update.sh` は何も変えずに止まります。その間は
  Recreate（作り直し）・home の掃除・破棄が失敗し、あとで再試行されます。動いているワークスペースには
  影響しません。`cfn/PARAMETERS.md` の「Home task (volume root)」を見てください。
  ([#3445](https://github.com/k-k1/agent-fleet/issues/3445))
- **弱い `AF_MASTER_KEY` や `AF_COOKIE_SECRET`** には Console にバナーが出ます。止まるものは
  ありません。都合のよいときに値を取り替えてください。
  ([#3499](https://github.com/k-k1/agent-fleet/issues/3499))
- **任意、すべてのレプリカとワークスペースが 0.42.0 になってから:** 用途別の Cookie 鍵をオンにし
  （`AF_COOKIE_PURPOSE_KEYS=1`、ECS では `CookiePurposeKeys=1`）、`af-cp advance-bridge-epochs --yes`
  でこのリリースより前に発行したワークスペースのトークンを失効させ、Console が印を付けた
  ワークスペースを再起動します。どちらも運用ガイドの「セキュリティ運用」と「保存時の鍵」に
  あります。
  ([#3499](https://github.com/k-k1/agent-fleet/issues/3499),
  [#3452](https://github.com/k-k1/agent-fleet/issues/3452))
- **API クライアント:** `/api/` 配下の本文付きリクエストは `application/json` で送ってください
  （アップロードのルートは除く）。([#3448](https://github.com/k-k1/agent-fleet/issues/3448))
