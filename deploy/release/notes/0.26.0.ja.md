各バージョンはワークスペースの rootfs も含めて 1 つの GitHub Release になり、ネイティブパッケージは amd64 に加えて
arm64 の Linux 向けにも出ます。Managed セッションの停止は 2 段になりました。1 回目は実行中のターンだけを止めてキューを残し、
2 回目でキューも捨てます。ミラーは claude が書いている途中の返答を表示します。AWS では「作り直し」と「ホームを掃除」が
成功と報告して何も消していませんでした。ecs-ec2 では動くようになり、ecs では断ります。

### New

- **arm64 の Linux 向けネイティブパッケージ。** `install.sh` と `af update` は動いているマシンに合うパッケージを選びます。
  0.26.0 より前のバージョンには arm64 のパッケージはありません。
  ([#1345](https://github.com/k-k1/agent-fleet/issues/1345))
- **Managed セッションの 2 段停止。** 1 回目の停止は実行中のターンだけを止め、キューに入った自分の追加入力やピアメッセージは
  1 ターンずつ順に実行されます。もう一度停止するか「停止してキューも捨てる」を選ぶと、残っているキューを捨てます。捨てた分は
  通知に並び、「戻す」で自分の入力を入力欄に戻せます。キューの吹き出しには「入力欄へ戻す」と「取り除く」があります。
  ターミナル（CLI）のセッションは CLI 自身の Esc のままです。
  ([#1289](https://github.com/k-k1/agent-fleet/issues/1289),
  [#1292](https://github.com/k-k1/agent-fleet/issues/1292),
  [#1293](https://github.com/k-k1/agent-fleet/issues/1293),
  [#1294](https://github.com/k-k1/agent-fleet/issues/1294),
  [#1244](https://github.com/k-k1/agent-fleet/issues/1244),
  [#1256](https://github.com/k-k1/agent-fleet/issues/1256))
- **ミラーが claude の返答を書いている途中から表示します。** 既定では 1 文字ずつ送って表示します。設定の
  「返答をストリーミング表示」でオフ／行ごと／文字送りを選べます。視差効果を減らす設定では、文字送りは行ごとと同じになります。
  ([#1250](https://github.com/k-k1/agent-fleet/issues/1250),
  [#1274](https://github.com/k-k1/agent-fleet/issues/1274),
  [#1396](https://github.com/k-k1/agent-fleet/issues/1396))
- **Console から Git Flow を初期化できます。** リポジトリの右クリックメニュー（と、`origin` に `develop` があるのに何も宣言が
  ない作業項目からの起動）が git-flow の設定を書き、origin にだけある `main`／`develop` のローカル追跡ブランチを作ります。
  ([#1126](https://github.com/k-k1/agent-fleet/issues/1126),
  [#1329](https://github.com/k-k1/agent-fleet/issues/1329))
- **起動中のまま進まないワークスペースは 30 分で止まり**、どこで止まったかが通知で届きます。テナント管理者はメンバー一覧で
  自動停止とその理由を見られます。上限は `AF_WORKSPACE_START_DEADLINE`（`0` で無効）。
  ([#1240](https://github.com/k-k1/agent-fleet/issues/1240),
  [#1298](https://github.com/k-k1/agent-fleet/issues/1298),
  [#1384](https://github.com/k-k1/agent-fleet/issues/1384))
- **テナント管理者は自前の LLM／画像エンジンを許可したメンバーだけに使わせられます**（テナント設定 › 運用 ›
  推論エンジンの利用者）。既定は「メンバー全員」のままです。
  ([#1215](https://github.com/k-k1/agent-fleet/issues/1215))
- **GitHub で squash／rebase マージされたブランチのワークツリーを作り直すと**、マージされた PR の head を候補に出します。
  使い回したブランチ名は最新のマージを選びます。
  ([#1043](https://github.com/k-k1/agent-fleet/issues/1043),
  [#1397](https://github.com/k-k1/agent-fleet/issues/1397))
- **概要カードがすべてのエージェント種別でコンテキストのゲージ・トークンの推移・回答したモデル・最後の行を表示します。**
  Claude だけではなくなりました。
  ([#1342](https://github.com/k-k1/agent-fleet/issues/1342),
  [#1362](https://github.com/k-k1/agent-fleet/issues/1362))
- **スキルピッカーが他のエージェントの個人スキルも出します**（例: Muse Code や Codex のセッションで claude のスキル）。
  ([#1351](https://github.com/k-k1/agent-fleet/issues/1351))
- **llama.cpp セッションが 設定 › エージェントへの指示 に並び**、次のターンから効きます。
  ([#1202](https://github.com/k-k1/agent-fleet/issues/1202))
- **ECS: `Persistence=retain` では EFS を毎日バックアップします**（既定 7 日保持）。実配備ではまだ走らせていません
  ([#1235](https://github.com/k-k1/agent-fleet/issues/1235))。
  ([#1195](https://github.com/k-k1/agent-fleet/issues/1195))
- **ECS: `standup.sh` と `update.sh` が `--comfy-digest` を受け付け**、コピーする ComfyUI イメージを固定できます。ECR に
  入ったダイジェストは毎回表示します。
  ([#966](https://github.com/k-k1/agent-fleet/issues/966),
  [#1319](https://github.com/k-k1/agent-fleet/issues/1319))

### Upgrade notes

- **リリースの添付ファイル**: 別の `rootfs-<r>` リリースはなくなり、rootfs は `v<version>` に添付されます。各リリースの
  `SHA256SUMS` はそのリリースの添付ファイルをちょうど列挙します。導入済みの環境と `af update` は何もしなくて大丈夫です。
  `rootfs-<r>` リリースから取得するスクリプトやミラーだけが追従を要します。
  ([#1345](https://github.com/k-k1/agent-fleet/issues/1345))
- **`AF_MASTER_KEY` なしで人をサインインさせる配備**は、起動時に警告をログに出し、super admin にバナーを出します。止まりはしません。
  ([#1080](https://github.com/k-k1/agent-fleet/issues/1080))
- **`PUBLIC_BASE_URL` がないと、内部 git のクローン・push・LFS は 503 を返すようになりました。** 内部 git を使うなら設定してください。
  ([#1212](https://github.com/k-k1/agent-fleet/issues/1212))
- **`AF_USAGE_SAMPLE_INTERVAL`・`AF_GIT_GC_INTERVAL`・`AF_SCHEDULER_INTERVAL`・`AF_CLOUD_COST_INTERVAL` は `0` で本当に止まるようになりました。**
  ([#1186](https://github.com/k-k1/agent-fleet/issues/1186))
- **他メンバーのセッションを止める管理者用 MCP ツールは `stop_user_session` になりました。** 旧名では一度も動いていませんでした。
  ([#1188](https://github.com/k-k1/agent-fleet/issues/1188))
- **ECS**: CP のロールが SSM コマンドを送れるのは自分のスロットのインスタンスだけになりました。`AF_ECS_EC2_POOL` を上書きして
  いる場合はクラスター名と同じにしてください。`retain` のデータスタック名は 37 文字までです。稼働中の配備で EFS バックアップを
  有効にする手順は ECS の runbook にあります。
  ([#1182](https://github.com/k-k1/agent-fleet/issues/1182),
  [#1195](https://github.com/k-k1/agent-fleet/issues/1195))
