A session's conversation can be shown to another member of your tenant, a new session
can branch from any past message with the conversation copied as-is, the main area
lays out as a tabbed grid as well as split panes, and sessions can send each other a
one-line message without going through you.

### New

- **Share a conversation with another member.** From a session or repository row's ⋯
  menu, share a single session, a single worktree, or a whole project with someone in
  your tenant, as **view only** or **may propose** — where what they compose reaches
  the agent only after you approve. Shared conversations appear under *Shared sessions*
  with the same rendering as your own mirror and a colour you can set separately.
  **Sharing exposes the whole conversation** — your prompts, the agent's replies and
  tool output. Secrets in it are not detected for you, and unsharing cannot recall a
  copy the recipient already saved.
- **Messages between sessions.** A session can send one short message to another in the
  same workspace, across agent kinds, and a stopped session is resumed to receive it.
  Off by default, in Settings › Agents › Session, applying to sessions started
  afterwards. A message carries plain text only — no history, no files — and the
  receiving agent is told it did not come from you, so it cannot read it as your
  approval for a permission prompt. Shell and SSM sessions cannot take part.
- **Branch from a past message.** Hovering one of your own past messages offers
  **Branch here**, which starts a new session carrying the conversation up to that
  point — either redoing that message, with your original wording back in the composer,
  or continuing after it. The current session is left exactly as it is. Supported on
  claude, codex, opencode and GitHub Copilot.
- **Tabbed grid layout.** Each cell of the main area can switch by tab instead of
  splitting. Tabs reorder by dragging, drop on a cell edge to split it, and carry a
  state badge so you can tell which session is working before selecting it. The choice
  is stored per device, and the two layouts are remembered separately.
- **Your own standing instructions for every agent.** Settings › *Agent instructions*
  adds what you write to every agent started in this workspace from then on. It sits
  between the fleet-wide workspace guide and a repository's committed
  `CLAUDE.md` / `AGENTS.md`, and is never committed anywhere. Cursor is the one kind
  that cannot take it, and says so with the reason.
- **See the MCP servers a repository commits.** *Project settings* lists the definitions
  checked into the repo with per-agent status and warnings — a secret already under
  Git, a name clash, files that disagree with one another — and can copy an entry to
  another agent's file or add a file to Git's ignore list.
- **The browser pane works with touch** — swipe to scroll, press and hold to drag, and
  pinch to re-lay the page out at a narrower width so text stays legible.
- **Switch tabs inside a page an agent handed you** (*Retarget*), and **what you did in
  it reaches the session** instead of updating only the Console.
- **Codex screenshots show in the mirror** instead of a path you cannot see.
- **Sakana AI as an OpenCode provider preset.**
- **Archive a repository's stopped sessions in one action**, from its left-pane row.
- **Markdown code blocks wrap by default** (Settings › Display).

### Improved

- **Reading a shared conversation got much faster** — no whole-inventory re-sync on
  every poll, and compressed responses. Authorisation is still checked on every request.
- **The assistant can be turned off outright** — a hard lock that keeps overriding even
  if an API key or an OAuth sign-in shows up later.
- **Running several control-plane replicas is safe under contention.** Workspace
  lifecycle operations are fenced with an advisory lock and a lease.
- **The built-in Agent Fleet MCP server takes a fresh name each launch**, so a
  repository that commits a server called `af` can no longer take its place and kill
  self-reporting for every session in it.
- **The member guide gained a settings chapter and a much larger troubleshooting
  chapter**, covering every tab of the settings dialog, the editor and git.
- A message between sessions can be 16 KiB, enough for a stack trace; confirmation
  dialogs focus the confirm button; untracked files in the change list open the file
  view.
- Pinned CLI versions: Claude Code 2.1.231, Codex 0.147.0, OpenCode 1.18.18, GitHub
  Copilot 1.0.79, Antigravity 1.1.12, Cursor 2026.08.11, Kiro 2.18.0, rtk 0.45.0.

### Fixed

- **Every click, key and scroll in a handed-over browser page was thrown away.** An
  attachment starts in view-only, and the pane sent input the agent silently rejected —
  a live picture in which nothing you did had any effect and no error said why. In the
  same area: the hand-off link could point nowhere, a fixed debugging port could attach
  you to another session's browser, fit-to-width did nothing, and dragging and
  copy/paste did not work.
- **A terminal from the previously selected tab kept showing** after switching tabs.
- **Codex answered the wrong question in a multi-question prompt**, and sending an
  image with a caption left the composer stuck "waiting to appear".
- **Pressing send twice in quick succession wedged the composer.**
- **A session running a slash command was reported as idle**, so it looked finished
  while it was still working.
- **Only the last handoff proposal survived** when an agent proposed more than one.
- **The share list showed only old archives** — a repository share covered just the
  sessions directly under the base working copy, and archived ones were listed.
- **The assistant fell back to OpenCode's free tier while nothing was connected**,
  which some tenants' policies do not allow.
- **The state badge read "waiting for permission" during a plan approval or a
  multiple-choice question**, and comments on a plan that were never delivered were
  marked sent.
- **The lightweight preview failed to resolve the tenant** on sub-requests, so pages
  that fetched anything came up broken.
- Display fixes: quoted Markdown was too dim in dark mode, pane buttons sat in the tab
  strip instead of the view header, and the Appearance popover wrapped its colour
  swatches onto a second row.
- A popped-out pane leaked its WebGL context; a model ID that was an exact match could
  be judged ambiguous; Codex's per-thread configuration merges rather than replaces;
  front matter that is not valid YAML is read line by line instead of dropped.

### Upgrade notes

Nothing to migrate — the new tables for shared sessions are applied at start. Sharing
does nothing until you create a share, and messages between sessions stay off until you
turn them on; both apply to sessions started afterwards. Markdown code blocks now wrap
by default. Workspaces need a Stop → Start to pick up the newly pinned agent CLIs.
