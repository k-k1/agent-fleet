Agents' skills can now be browsed read-only, the assistant moves past a backend held up by a usage
or rate limit, and work items are marked when they have new activity.

### New

- **See your agents' skills, read-only:** the folders each CLI reads, which copy wins when two share
  a name, and what each file says. Personal skills of Claude Code, Codex, OpenCode and Muse Code are
  under Settings › **Skills**, and a repository's (Cursor's too) under **Skills…** in its row's menu.
  ([#2792](https://github.com/k-k1/agent-fleet/issues/2792),
  [#2795](https://github.com/k-k1/agent-fleet/issues/2795))
- **The assistant steps past a backend held up by a usage or rate limit.** A chat turn that fails on
  one before showing any output is re-run on the next usable backend in your priority list, with a
  notice naming both, and AI-assist one-off generations skip that backend too; a limit about to lift
  is waited out, and compaction and memory review never switch.
  ([#2780](https://github.com/k-k1/agent-fleet/issues/2780))
- **Work items show new activity:** a row updated since you last looked gets a dot and a bold
  title, and GitHub and Bitbucket rows show their comment count.
  ([#2779](https://github.com/k-k1/agent-fleet/issues/2779))
- **Settings › Machine charts the workspace's memory pressure** beside the Agent's response time.
  It only measures; nothing warns or stops a session yet.
  ([#2516](https://github.com/k-k1/agent-fleet/issues/2516),
  [#2837](https://github.com/k-k1/agent-fleet/issues/2837))

### Improved

- **Find works in the PDF pane:** Ctrl/Cmd+F opens the pane's own find bar, which searches every
  page (a word wrapped across lines included) and moves between matches, and the highlight no
  longer hides the word.
  ([#2822](https://github.com/k-k1/agent-fleet/issues/2822))
- **The work item Merge button is offered to GitHub App sign-ins too**, when GitHub reports that
  you can write to the repository. Fine-grained tokens still do not get it.
  ([#2753](https://github.com/k-k1/agent-fleet/issues/2753))
- **"Review again in ‹reviewer›" is offered on every device** for reviews started from this
  version; a link made earlier still shows only in the browser that made it.
  ([#2496](https://github.com/k-k1/agent-fleet/issues/2496))
- **A Claude conversation restored from the Agent's backup says so** in the transcript, since its
  latest part may be missing.
  ([#2740](https://github.com/k-k1/agent-fleet/issues/2740))

### Fixed

- **A mistyped slash command left its chat bubble at Pending forever** on claude sessions. Claude's
  "Unknown command" warning now shows in the chat.
  ([#2830](https://github.com/k-k1/agent-fleet/issues/2830))
- **Jira: Markdown bodies came out wrong and `issue create -P` dropped the parent.** Comments and
  descriptions now keep `code` and **bold** next to Japanese text and a list after a paragraph, and
  the new issue gets its parent.
  ([#2809](https://github.com/k-k1/agent-fleet/issues/2809),
  [#2812](https://github.com/k-k1/agent-fleet/issues/2812))
- **opencode 2: the Agent instructions preview was empty**, and the first turn of a session made
  with `/new` did not update the session's working / waiting status.
  ([#2799](https://github.com/k-k1/agent-fleet/issues/2799),
  [#2827](https://github.com/k-k1/agent-fleet/issues/2827))
- **Assistant chat: claude's own auto-memory stayed on while Agent Fleet memory was on.**
  ([#2488](https://github.com/k-k1/agent-fleet/issues/2488))
- **A slash command sent with an attachment** showed an internal instruction in its chip instead
  of the attachment.
  ([#2823](https://github.com/k-k1/agent-fleet/issues/2823))
- **Smaller fixes:** a Control Plane URL with an IPv6 address was refused by the egress allowlist,
  an MCP connection test that ran out of time was reported as the process exiting, and some
  Settings headings sat flush against the block above.
  ([#2754](https://github.com/k-k1/agent-fleet/issues/2754),
  [#2820](https://github.com/k-k1/agent-fleet/issues/2820),
  [#2813](https://github.com/k-k1/agent-fleet/issues/2813))

### Other changes

  workspace**, as merging already was, and each post is recorded in the audit log.
