A Mac with Apple Silicon is supported for a single user, terminal panes side by side no longer
garble each other's text, and a Cursor session on Default runs Auto, so a Free plan can use it.

### New

- **macOS (Apple Silicon), single user.** The Compose bundle carries
  `docker-compose.macos.yml` for Docker Desktop, OrbStack or colima (single user, on
  `127.0.0.1:8099`), and the `linux-arm64` native package can run inside a Linux VM such as Lima or
  an OrbStack machine. The steps are under "macOS" in the bundle's `README.md`. Checked on an M1
  Mac with colima, OrbStack and Docker Desktop, and natively in Lima and OrbStack VMs; OrbStack
  and Docker Desktop have to be started once from the Mac's screen.
  ([#2960](https://github.com/k-k1/agent-fleet/issues/2960),
  [#2961](https://github.com/k-k1/agent-fleet/issues/2961))

### Improved

- **The installers recognise macOS:** `install.sh` explains those two routes instead of a bare
  "Linux only", `install-compose.sh` runs there and verifies its download with `shasum`, and
  `af update` no longer picks a Linux package on a host that is not Linux.
  ([#2960](https://github.com/k-k1/agent-fleet/issues/2960))
- **Jira: Markdown tables become real tables** in comments and descriptions sent through the
  `jira` command.
  ([#2943](https://github.com/k-k1/agent-fleet/issues/2943))
- **Less file-system load on AWS:** the Agent no longer keeps rereading the files of archived and
  stopped claude sessions in the background, which had raised EFS metadata I/O.
  ([#2850](https://github.com/k-k1/agent-fleet/issues/2850))

### Fixed

- **Terminal panes side by side showed garbled characters** until the pane was clicked.
  ([#2983](https://github.com/k-k1/agent-fleet/issues/2983))
- **Cursor: a session on Default ran whichever model the CLI had last used**, which a Free plan
  refuses. Default now runs Auto; on a paid plan, pick a model to get a different one.
  ([#2928](https://github.com/k-k1/agent-fleet/issues/2928))
- **Synced settings failed to load on a device** when one of the values stored at the Agent was
  empty.
  ([#2904](https://github.com/k-k1/agent-fleet/issues/2904))
- **A remote MCP client signed in to Agent Fleet could lose its connection** when it renewed its
  sign-in twice at once.
  ([#2885](https://github.com/k-k1/agent-fleet/issues/2885))

### Other changes

- **Much of the Control Plane, Agent and Console code was reorganised:** agent kinds, settings, MCP
  tools and Control Plane relays are now each registered in one place
  ([ADR 0124](https://github.com/k-k1/agent-fleet/blob/main/docs/decisions/0124-second-refactor.md)). Nothing is meant to behave differently; if something does,
  please [open an issue](https://github.com/k-k1/agent-fleet/issues).
