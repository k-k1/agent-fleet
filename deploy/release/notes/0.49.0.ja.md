Console を閉じていても、セッションからの知らせが Web Push でスマートフォンやパソコンに届くように
なりました。メモの自動実行では、メモごとにエージェント・モデル・エフォートと開始日時を決められ、
リポジトリにキューの設定ファイルを置けます。セッションが書いたスケジュールは、あなたの承認を待つ
ようになりました。

### 新機能

- **Web Push:** 管理者が有効にしたデプロイでは、⚙ 設定 →「通知」→「この端末へのプッシュ通知」で、
  あなたを待っている質問・計画・許可や、終わった回答を、Console を閉じたスマートフォンやパソコンに
  届けられます。何を届けるかは端末ごとに選べ、画面で見ているセッションは届きません。質問の文面を
  含めるかはテナントの管理者が決めます。([#4750](https://github.com/k-k1/agent-fleet/issues/4750))
- **スケジュールの承認:** セッションが作ったスケジュールや、セッションがプロンプト・時刻・実行先を
  変えたスケジュールは「承認待ち」のバッジ付きで止まり、スケジュールのビューで「確認して承認」を
  選ぶまで実行されません。Console で作ったスケジュールは止まりません。
  ([#4631](https://github.com/k-k1/agent-fleet/issues/4631))
- **メモの自動実行、メモごとの実行設定:** メモの「実行する設定」の行で、カテゴリの代わりにその実行の
  エージェント・モデル・エフォートを選べます。セッションも `add_memo` / `update_memo` で設定できます。
  ([#4845](https://github.com/k-k1/agent-fleet/issues/4845))
- **メモの自動実行、開始日時:** キューのメモの編集で「この日時より前は実行しない」を選ぶと、その日時
  までは始まりません。メモを承認しても日時は残ります。
  ([#4777](https://github.com/k-k1/agent-fleet/issues/4777))
- **メモの自動実行、リポジトリの設定ファイル:** リポジトリにキューの設定を
  `.agent-fleet/autorun.yaml` として置けます。カテゴリの自動実行の設定に、ファイルとあなたの設定との
  違いが出て、項目ごとに承認できます。あなたの設定をこのファイルの形で書き出すこともできます。
  ([#4881](https://github.com/k-k1/agent-fleet/issues/4881))
- **Go のビルドキャッシュの整理:** ホームの空きが少なくなると、1 日使われていない Go のビルド
  キャッシュを古いものから消します。設定 →「マシン」でオフにでき、片付けの一覧に前回の整理で空いた
  量が出ます。([#4560](https://github.com/k-k1/agent-fleet/issues/4560))
- **gitleaks** がワークスペースのイメージに入りました。
  ([#4904](https://github.com/k-k1/agent-fleet/issues/4904))

### 改善

  大きさを変えられ、「メモを送る」では送ったあともメモを残せます。「連鎖を止める」と実行のメモを
  キューに戻す操作はメモのメニューに移り、承認のカードはチェックしたメモだけを承認でき、実行履歴の

### アップグレードの注意

- **セッションが書いたスケジュールは承認を待つようになります。** Fleet Operator のものも同じです。
  いまあるスケジュールはそのまま動きます。
- **プルリクエストのない実行を待つメモ**は、その実行の最後の回答が `Done:` で始まることが必要に
  なりました。そうしたキューの常設の指示には、最後に `Done:` の行を書くよう求めてください。
- **Web Push はオペレーターが有効にするまでオフです。** VAPID の鍵と連絡先（`AF_WEB_PUSH*`、ECS では
  `WebPush=on` とそのパラメータ）を設定し、Console を HTTPS で配信して、Control Plane から
  プッシュサービスへの HTTPS の外向き通信を許可します。運用ガイドの「Web Push をオンにする」を見て
  ください。

エージェント CLI のピン: Antigravity 1.5.15、新たに gitleaks 8.30.1（ほかは 0.48.0 から変わりません）。
