Sessions can use Confluence through a bundled `confluence` CLI on the existing Jira connection, and
session rows now show when a pull request has requested changes or a merge conflict.
Background shells can be stopped one by one, a Start working draft can be set aside as a memo, and
Claude's idle compaction can be switched off.

### New

- **Confluence in every workspace.** The `confluence` CLI is baked into the image and signs in
  through the member's Jira connection, so `confluence search`, `read`, `create` and `update` work
  without a token. It is opt-in per tenant: see Upgrade notes.
  ([#2212](https://github.com/k-k1/agent-fleet/issues/2212),
  [#3266](https://github.com/k-k1/agent-fleet/issues/3266),
  [#3267](https://github.com/k-k1/agent-fleet/issues/3267),
  [#3309](https://github.com/k-k1/agent-fleet/issues/3309))
- **Pull request feedback on the session row.** Next to the CI result, the PR chip marks a PR whose
  reviewer requested changes and one with a merge conflict (GitHub and Bitbucket).
  ([#3129](https://github.com/k-k1/agent-fleet/issues/3129))
- **Background shells you can see and stop.** For Claude, the conversation lists each background
  command above the input box, with how long it has run and a **may be stuck** warning, and
  **Stop** ends that command alone. ([#3279](https://github.com/k-k1/agent-fleet/issues/3279))
- **Save a Start working draft to the memo queue.** **Save to memo** sets the prompt and its
  attachments aside; **Start with this** on the memo brings them back into a new Start working.
  ([#3289](https://github.com/k-k1/agent-fleet/issues/3289))
- **Turn off Claude's idle compaction.** Settings › Agents › Claude has an **Idle compaction**
  switch, for when you would rather come back to an uncompacted long conversation.
  ([#3303](https://github.com/k-k1/agent-fleet/issues/3303))

### Improved

- **Free disk space sooner:** Settings › Machine › Leftover files lists the work folders of archived
  sessions still inside their 7 days, and can delete them now after a confirmation.
  ([#3299](https://github.com/k-k1/agent-fleet/issues/3299))
- **Time zone and region format reach more places:** the Console's remaining dates and charts,
  a schedule's next run, and text the Agent writes itself (with "follow browser", the zone of the
  browser you used last). ([#3217](https://github.com/k-k1/agent-fleet/issues/3217))
- **A Console left open and unattended** pauses its live updates after 10 minutes while no session
  is working, and resumes on the next input. Together with lighter session-list reads in the
  Control Plane and the Agent, this cuts idle load.
  ([#3235](https://github.com/k-k1/agent-fleet/issues/3235),
  [#3236](https://github.com/k-k1/agent-fleet/issues/3236),
  [#3231](https://github.com/k-k1/agent-fleet/issues/3231),
  [#3239](https://github.com/k-k1/agent-fleet/issues/3239),
  [#3255](https://github.com/k-k1/agent-fleet/issues/3255))
- **A working copy's archive shelf includes its child sessions**, which live in worktrees of their
  own. ([#3295](https://github.com/k-k1/agent-fleet/issues/3295))
- **Smaller Console touches:** the work items **Show less** button stays in view, and the last
  browser confirm boxes are now the Console's own dialog.
  ([#3296](https://github.com/k-k1/agent-fleet/issues/3296),
  [#3307](https://github.com/k-k1/agent-fleet/issues/3307))
- **More Agent errors appear in your display language** instead of Japanese only, including the
  OpenCode 1.x refusal. ([#3227](https://github.com/k-k1/agent-fleet/issues/3227),
  [#3241](https://github.com/k-k1/agent-fleet/issues/3241),
  [#3246](https://github.com/k-k1/agent-fleet/issues/3246))

### Fixed

- **Stopping a Terminal (CLI) Claude session before its reply** left the stopped prompt in Claude's
  input box, so the next message was glued onto it and stayed Pending.
  ([#3290](https://github.com/k-k1/agent-fleet/issues/3290))
- **A queued Claude prompt with a pasted image** showed its thumbnail twice.
  ([#3284](https://github.com/k-k1/agent-fleet/issues/3284))
- **The llama.cpp chat pill** stayed in the top bar, as "Not reachable", after llama.cpp was
  switched off. ([#3291](https://github.com/k-k1/agent-fleet/issues/3291))
- **The stalled-tree notice** counted a session launched from a handoff proposal as the proposer's
  child. ([#3243](https://github.com/k-k1/agent-fleet/issues/3243))
- **The Jira card's Site picker** could list the same site twice.
  ([#3265](https://github.com/k-k1/agent-fleet/issues/3265))

### Upgrade notes

- **Confluence needs a tenant admin's opt-in.** Nothing changes for a tenant that does nothing. To
  enable it, add the ten Confluence scopes listed in the admin guide (Access, Jira) to the tenant's
  Atlassian app, tick the Confluence checkbox on the tenant Jira card, and have members reconnect
  Jira. ([#2212](https://github.com/k-k1/agent-fleet/issues/2212),
  [#3309](https://github.com/k-k1/agent-fleet/issues/3309))

### Other changes

- Chromium in the workspace image is updated to the current Debian security build.
