A fix release for 0.32.0: memory suggestions no longer run in the background unless you ask for it,
stopped opencode sessions show their history again, and the bundled Jira CLI creates issues without
`jira init`.

### Fixed

- **Memory suggestions ran automatically as soon as they were turned on.** Automatic review is now a
  separate switch, **Also suggest automatically**, off by default; with only **Have finished sessions
  suggest memories** on, a review runs when you choose **Suggest memories now**. The setting also says
  when no agent that can run the review is available.
  ([#2358](https://github.com/k-k1/agent-fleet/issues/2358),
  [#2356](https://github.com/k-k1/agent-fleet/issues/2356))
- **A stopped opencode session's conversation history was empty** in the Console.
  ([#2379](https://github.com/k-k1/agent-fleet/issues/2379))
- **`jira issue create -p KEY` failed without `jira init`**, and used another project's issue
  types when one was configured.
  ([#2369](https://github.com/k-k1/agent-fleet/issues/2369),
  [#2373](https://github.com/k-k1/agent-fleet/issues/2373))
- **A Jira work item's first prompt pointed the agent at a Jira MCP server**; it now reads the ticket
  with the `jira` CLI.
  ([#2367](https://github.com/k-k1/agent-fleet/issues/2367))
- **The MCP connection test passed for servers that lose their sessions behind a load balancer**; it
  now reports the problem.
  ([#2368](https://github.com/k-k1/agent-fleet/issues/2368))

### Improved

- **Tenant › External memory access** lets a tenant admin block members from using Agent Fleet memory
  from agents outside Agent Fleet. Allowed by default.
  ([#2318](https://github.com/k-k1/agent-fleet/issues/2318))
- **The Settings Jira card says when boards, sprints and epics are unavailable** because the
  connection lacks the Jira Software scopes, and what the tenant administrator has to do.
  ([#2372](https://github.com/k-k1/agent-fleet/issues/2372),
  [#2377](https://github.com/k-k1/agent-fleet/issues/2377))
