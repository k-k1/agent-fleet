0.29.0 の修正版です。0.29.0 に入っている Claude Code の版で Agent Fleet 自身の MCP ツールが再び使えるようになり、
答え終わった claude のセッションが最大 1 分ほど実行中と表示されることもなくなりました。

### Fixed

- **claude のセッションで、いくつかの af MCP ツールがスキーマ検証のエラーで失敗していました。** Claude Code
  2.1.292 が `list_repos`・`list_my_sessions`・`get_session_status`・`get_session_usage`・`get_session_output`
  と画像生成のスタジオのツールの結果を受け付けず、親のセッションが子の出力を読めませんでした。再び使えます。
  ([#1842](https://github.com/k-k1/agent-fleet/issues/1842))
- **claude のセッションが、答えた後も 45〜60 秒ほど「実行中」のままになることがありました。** claude の Stop
  フックが動いている間に Console が状態を見たときに、ミラーとセッションの一覧で起きていました。
  ([#1834](https://github.com/k-k1/agent-fleet/issues/1834),
  [#1836](https://github.com/k-k1/agent-fleet/issues/1836))

### Upgrade notes

どちらの修正もワークスペースのイメージに入っています。動いているワークスペースは、停止して起動し直すまで
0.29.0 のままです。いつ起動し直せばよいかは、WS バーの「更新あり」のバッジで分かります。

エージェント CLI のピンは 0.29.0 から変わりません。
