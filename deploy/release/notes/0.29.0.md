SVN working copies get a Show log and a Local changes view, and claude's existing auto-memory can be
imported into Agent Fleet memory. A Terminal claude or Antigravity session that stops making progress
no longer keeps its workspace awake. Image generation through Antigravity and codex works again, Muse
Code questions can be answered, and the Console's Japanese wording follows one glossary.

### New

- **SVN: Show log and Local changes.** The menu of an SVN working copy opens its revision history
  (including revisions newer than the working copy) and its uncommitted changes, each with a diff.
  Both views are read-only.
  ([#1705](https://github.com/k-k1/agent-fleet/issues/1705))
- **Import claude's auto-memory into Agent Fleet memory.** Settings › Agent memory › **Import from
  Claude Code** previews each working copy's claude memories and imports the ones you confirm; the new
  `af-memory` command does the same from a shell. Memories that look like secrets are skipped, and a
  memory you forgot is not brought back.
  ([#1569](https://github.com/k-k1/agent-fleet/issues/1569))
- **Separate appearance per tenant.** With **Separate appearance per tenant** on (the appearance menu in
  the top bar, or Settings › Display), each tenant keeps its own theme and colours, and switching
  tenants applies them. The switch is shown only when you belong to two or more tenants, is off by
  default, and is stored in this browser.
  ([#1692](https://github.com/k-k1/agent-fleet/issues/1692))

### Improved

- **A stuck session no longer keeps its workspace awake.** A Terminal claude or Antigravity session
  that has shown no sign of progress for an hour stops counting as working, so idle auto-stop can stop
  the workspace. A dead Antigravity turn is also recognised as finished. Settings › Tenant › Members shows
  in the idle-stop outlook how long the holding session has been working.
  ([#1811](https://github.com/k-k1/agent-fleet/issues/1811),
  [#1818](https://github.com/k-k1/agent-fleet/issues/1818),
  [#1819](https://github.com/k-k1/agent-fleet/issues/1819))
- **The Agent Fleet memory switch moved to Settings › Agent memory**, next to the change list and the
  import. It can be turned on there while the workspace is stopped. Your setting is unchanged.
  ([#1735](https://github.com/k-k1/agent-fleet/issues/1735))
- **`memory_index` stays small with many memories.** It lists your feedback and user memories first,
  then the newest, and names the rest instead of cutting them off silently.
  ([#1702](https://github.com/k-k1/agent-fleet/issues/1702))
- **Archived sessions opens quickly and is wider.**
  ([#1701](https://github.com/k-k1/agent-fleet/issues/1701))
- **A merged PR or closed issue linked from the mirror shows its title, state and assignees** in the
  work item detail, even when it is not in the inbox.
  ([#1697](https://github.com/k-k1/agent-fleet/issues/1697))
- **Antigravity image generation can edit a picture** from up to three reference images. An account
  that is not offered image generation gets an error that says so.
  ([#1718](https://github.com/k-k1/agent-fleet/issues/1718))

### Fixed

- **Image generation through Antigravity produced nothing**, and **through codex it failed on ChatGPT
  accounts**. Both work again; `AF_IMAGEGEN_CODEX_MODEL` overrides the model the codex route drives.
  ([#1716](https://github.com/k-k1/agent-fleet/issues/1716),
  [#1711](https://github.com/k-k1/agent-fleet/issues/1711))
- **Muse Code questions could not be answered or cancelled**, the text written before a tool call was
  missing, and a waiting question showed as in progress. Answers now reach the question, the chip shows
  the question, and settled questions stay in the mirror.
  ([#1695](https://github.com/k-k1/agent-fleet/issues/1695))
- **A Muse Code session stopped by its usage limit was not auto-resumed** and showed as idle. It now
  shows the limit and resumes when the limit lifts, as claude and codex do.
  ([#1766](https://github.com/k-k1/agent-fleet/issues/1766))
- **Turning RTK on or off removed your own Claude Code Bash hooks**, and your own question, plan or
  permission hooks kept Agent Fleet's status hooks from being installed. Your hooks are now kept
  alongside Agent Fleet's.
  ([#1779](https://github.com/k-k1/agent-fleet/issues/1779))
- **A claude session in a git worktree stopped at the folder-trust dialog** when the main checkout was
  not trusted and the repository has permission rules. The main checkout is now trusted as well.
  ([#1784](https://github.com/k-k1/agent-fleet/issues/1784))
- **A long prompt with an image in a claude Terminal session** arrived as `[Image #N]` and its echo
  stayed pending.
  ([#1686](https://github.com/k-k1/agent-fleet/issues/1686))
- **After switching tenants, the left pane and top bar kept the previous tenant's data**: repositories,
  files, connection status, AWS and Google Cloud logins, import jobs and assistant chats.
  ([#1680](https://github.com/k-k1/agent-fleet/issues/1680))
- **The tenant's default machine class was ignored** when a schedule woke a workspace or its home was
  resized, and the member list showed the deployment default instead.
  ([#1687](https://github.com/k-k1/agent-fleet/issues/1687))
- **Refreshing GitHub work items failed with a bare 422.** GitHub's reason is now shown, and a query
  without `is:issue` or `is:pull-request` is retried with one.
  ([#1690](https://github.com/k-k1/agent-fleet/issues/1690))
- **Logging out of an AWS profile did not end the AWS session** once the cached SSO token had expired.
  ([#1689](https://github.com/k-k1/agent-fleet/issues/1689))
- **Gallery thumbnails of rotated JPEG photos were drawn sideways.**
  ([#1643](https://github.com/k-k1/agent-fleet/issues/1643))
- **Mirror**: skill picker entries were squeezed and lost their description line, and the tooltip on a
  child session's badge now names the parent session (in English it showed a literal `{name}`).
  ([#1782](https://github.com/k-k1/agent-fleet/issues/1782),
  [#1752](https://github.com/k-k1/agent-fleet/issues/1752))
