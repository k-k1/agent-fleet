The AWS profiles in Settings now work with the AWS CLI, SDKs and build tools in your workspace, and
the Console asks you to log in when one needs it. Deleted worktrees go to the trash and come back
at the same path with their uncommitted changes. Sessions that need you stand out, and **Alt+U**
jumps to the next one. The image studio is usable on a phone, starts from a repository row and runs
several studios at once. The model pickers show API list price, context window and retirement.

From this release, bugs and requests are tracked as GitHub issues at
<https://github.com/k-k1/agent-fleet/issues> — please report there rather than on the distribution
repository. Items below end with the issue they came from.

### New

- **Your Settings › AWS SSM profiles work with the AWS CLI, SDKs and build tools.** They are
  written into `~/.aws/config`, and `af-aws-exec --profile <name> -- <command>` runs a command as
  you instead of as the workspace's own AWS identity. When the login has expired, a toast in the
  Console asks you to log in; the device code starts only when you press it, and the agent waits
  about 1.5 minutes for you.
  ([#998](https://github.com/k-k1/agent-fleet/issues/998),
  [#1026](https://github.com/k-k1/agent-fleet/issues/1026),
  [#1036](https://github.com/k-k1/agent-fleet/issues/1036))
- **Deleting a worktree can be undone.** The delete goes to the trash with the branch and any
  uncommitted changes; restoring it recreates the worktree at the same path, lays the changes back
  unstaged, and brings its sessions back from the archive. For a worktree deleted before this
  release, the archive offers **Recreate working copy** from its branch.
  ([#1040](https://github.com/k-k1/agent-fleet/issues/1040),
  [#1042](https://github.com/k-k1/agent-fleet/issues/1042))
- **Sessions that need you stand out, and Alt+U jumps to the next.** A question, plan approval or
  permission request puts an amber outline on the row and a ring on the pane; unread rows get a
  bold title. **Alt+U** walks the waiting sessions first, then the unread ones. A notification is
  now marked read when what it points to is on screen, so a report stays unread until its
  conversation is shown.
  ([#1057](https://github.com/k-k1/agent-fleet/issues/1057))
- **The model pickers show API list price, context window and retirement**, from models.dev and
  from codex itself; a retiring model is badged with its date and successor. This is the API list
  price, not what a subscription is charged. Not shown for cursor, Muse Code, llama.cpp or claude's
  tier names.
  ([#1021](https://github.com/k-k1/agent-fleet/issues/1021))
- **Desktop notifications that programs raise in a Terminal (CLI) session** (OSC 9, 99 or 777)
  now reach the notification center and the OS notification. claude, codex and opencode already
  report through their own hooks.
  ([#1058](https://github.com/k-k1/agent-fleet/issues/1058))
- **Settings › Machine › Leftover files** removes files nothing reads again: stale headless
  Chromium profiles, orphaned `~/.af-work` folders, superseded Node patch versions and old Kiro
  versions. The Agent also removes them when it starts, together with old Copilot and Cursor
  versions.
  ([#1038](https://github.com/k-k1/agent-fleet/issues/1038),
  [#981](https://github.com/k-k1/agent-fleet/issues/981))
- **Settings › Agents › Session › Archive stopped sessions after** sets your own period (1 to 30
  days, or Off) instead of the deployment's.
  ([#982](https://github.com/k-k1/agent-fleet/issues/982))
- **Clip skip, FLUX guidance and Anima shift can be set** from the studio, a catalogue row and
  `generate_image`. On SDXL, ComfyUI already stops at the second-to-last layer, so only 3 and up
  change the picture.
  ([#1035](https://github.com/k-k1/agent-fleet/issues/1035))

### Improved

- **The image studio works on a phone, starts from a repository or worktree row** (**Start an
  image studio**), and runs **several studios** at once, each with its own results. A narrow pane
  keeps a draft bar above the composer, the sampler settings fold under **Details**, and the
  lightbox walks the results with **Use as reference** and **Back to these settings**. Every pane
  now edits a studio; a draft from an older pane moves into a new studio once.
  ([#1074](https://github.com/k-k1/agent-fleet/issues/1074))
- **Work items show every label in its tracker colour**, priority first, and say when a query
  matched more than was fetched. GitHub queries fetch 100 rows, and **Search the tracker** finds
  items past the cut.
  ([#993](https://github.com/k-k1/agent-fleet/issues/993),
  [#994](https://github.com/k-k1/agent-fleet/issues/994),
  [#1095](https://github.com/k-k1/agent-fleet/issues/1095))
- **The admin and tenant settings reopen where you left them.**
  ([#1100](https://github.com/k-k1/agent-fleet/issues/1100))
- **Settings says when your settings failed to sync**, with a Retry, and a copy another account
  left in the same browser no longer mixes into yours.
  ([#1023](https://github.com/k-k1/agent-fleet/issues/1023))
- **llama.cpp sessions stop a model that keeps calling one tool with changing arguments**: it is
  warned at turn 12 and stopped at turn 20.
  ([#953](https://github.com/k-k1/agent-fleet/issues/953))
- **Smaller messages:** an engine that does not come up in time names the reason ECS gives
  ([#967](https://github.com/k-k1/agent-fleet/issues/967)); a refused assistant setting says what
  was wrong, in your language ([#971](https://github.com/k-k1/agent-fleet/issues/971));
  right-clicking a session in the fleet graph opens its menu.

### Fixed

- **A deletion lock could be undone** by a session action running at the same moment, letting the
  next delete through.
  ([#950](https://github.com/k-k1/agent-fleet/issues/950))
- **Resuming a Terminal (CLI) session went back to its launch model, effort and mode** after you
  had switched them inside the terminal.
  ([#987](https://github.com/k-k1/agent-fleet/issues/987))
- **In Managed sessions, Agent Fleet's own tools** (handoff, image generation, the studio, browser
  handoff) **refused when two sessions shared a folder**, and on cursor every call failed.
  ([#978](https://github.com/k-k1/agent-fleet/issues/978),
  [#951](https://github.com/k-k1/agent-fleet/issues/951),
  [#989](https://github.com/k-k1/agent-fleet/issues/989))
- **A workspace could stop for idleness under a running or queued image generation**, losing the
  queue. Paused jobs still do not keep it running.
  ([#949](https://github.com/k-k1/agent-fleet/issues/949))
- **AI assist with Muse Code chosen ran on claude.**
  ([#1020](https://github.com/k-k1/agent-fleet/issues/1020))
- **Resume on a stopped SSM pane skipped the SSO login dialog**, and on a narrow pane the sign-in
  link was cut short.
  ([#1025](https://github.com/k-k1/agent-fleet/issues/1025))
- **Resuming a codex or opencode Managed session whose folder was deleted** did not refuse;
  opencode started a new, empty conversation in its place.
  ([#1039](https://github.com/k-k1/agent-fleet/issues/1039))
- **flux1 image models could not be completed** from the catalogue.
  ([#1053](https://github.com/k-k1/agent-fleet/issues/1053))
- **The image studio**: a message sent from it stayed "Pending", every tab read "Image
  generation", the tab had no right-click menu, switching back flashed an empty studio, the phone
  swipe did not leave it, finished trials piled up in the queue, and the agent's change outlines
  spread to every field.
  ([#1089](https://github.com/k-k1/agent-fleet/issues/1089))
- **Starting a session from a work item could send the first prompt twice.**
- **A prompt starting with `-`** (a `--flag` or a `- ` bullet) failed with "invalid flag" and
  never reached the session.
- **The composer's history (↑/↓, Ctrl+R) offered text you never typed** — operator, schedule and
  peer messages. It now recalls only your own input.
- **claude's "Could not refresh your login because another Claude Code process is refreshing it"**
  was retried every minute; it now offers signing in again.
- **agy sessions showed "waiting for input" while working**, and the mirror showed no model on
  agy, llama.cpp and Muse Code replies.
- **The CP's MCP `list_models` refused llama.cpp.**
  ([#1075](https://github.com/k-k1/agent-fleet/issues/1075))
