ECS の配備で、推論をフリート自身の GPU で動かせるようになりました。インスタンスは誰かが使って
いる間だけ存在し、opencode の起動メニューに並ぶモデルと、外部のアカウントを要らない画像生成に
なります。
セッションに「終わったら止まって」と指示できるようにもなり、画像生成の経路が 2 本になりました。

### New

- **フリート自身の推論エンジンを動かせるようになりました。** 要求が来たときだけ GPU の
  インスタンスを買い、誰も使わなくなれば自分で止まります。`llm` 役は opencode の起動メニューに `llamacpp/<モデル>`
  として並び、`image` 役は `generate_image` を配備自身で賄います。管理者は設定 > 管理 >
  推論エンジンで「無効 / 常時稼働 / オンデマンド」を選びます。ECS の配備のみ・任意で、
  動いている間は安くはありません（Upgrade notes を参照）。
- **モデルの追加と入れ替えを Console から行えます。** 「Hugging Face などから取り込む」で
  配備自身のバケットへモデルを取り込み（ライセンスの同意と gated リポジトリを含む）、すでに
  バケットにあるファイルを手で登録することもできます。行ごとに有効化・起動時に読むモデルの
  指定・登録の取り消し（ファイルを消すかは選べます）ができ、いずれも CloudFormation の実行は
  要りません。
- **エンジンの画面がインスタンスの現況を出します。** いつ起動したか、いつ自分で止まるか、直近どれだけ
  要求があったか、VRAM に載っているモデル、そして 14 日ぶんの稼働実績です。
- **セッションに「終わったら止まって」と指示できます。** 走っているターンをやり切ってから
  停止するので、会話も作業コピーも残り、あとから再開できます。セッションの ⋯ メニューから
  指示でき、エージェント自身とオペレーターからも予約できます。
- **定時実行が、実行後にセッションを停止できます。** 夜中に起こしたワークスペースが、アイドル
  タイムアウトまで起きっぱなしになることは無くなりました。
- **セッションが、自分の置かれたフリートの状況を見られるようになりました。** 指示を渡した相手が
  まだ動いているか、自分の文脈がどれだけ詰まってきたかを見て、気づいたことをあなたのメモ
  キューに残せます。動かす操作は増えません——他セッションへの指示・質問への回答・プランの
  承認・セッションの起動と停止はこれまでどおりあなたとオペレーターのもので、他セッションが
  待っている質問やプランの本文も渡りません。既定はオフで、設定 > エージェントで有効にします。
- **画像生成の経路が 2 本になりました。** Antigravity の内蔵生成（Gemini・通称 Nano Banana）は
  Codex とは別のプランを消費し、依頼した縦横比を守るため、既定ではこちらを先に試します。
  経路を名指しすることもでき、自動の場合は枠が尽きればもう一方へ送ります。ツールはどの画像
  サービスへ行ったのかを名乗るようになりました。
- **claude 同梱のスキルがミラーのスキルピッカーに出ます。** 利用者定義のスキルが先に並び、CLI
  同梱のものは 1 行に畳まれます。`//`・トリガの 2 連打・↓ からの Enter のいずれかで開きます。
- **共有費のカードが「何のための費用か」を出します。** 推論エンジンと音声エンジンが、EC2 や
  ECS に混ざらず自分の行を持ちます。

### Improved

- **消えたセッションのタブが自分で閉じます。** 掃除の画面・別の端末・オペレーター・エージェント
  自身がアーカイブしたセッションのタブは、「セッション未接続」を出したまま二度と繋がらない
  状態で残っていました。
- **再認証すると表示が「再認証済み」に変わり、セッションが自動で続きから再開します。** これまでは
  「再認証する」が出たままで、自分で「続けて」と打つ必要がありました。
- **大きな submodule を持つリポジトリの worktree 作成が、再ダウンロードをしなくなりました。**
  すでに手元にあるクローンから複製します。
- **カーネルが RDRAND を取り下げたホストでも Antigravity を使えます。** これまでは起動メニュー
  ごと隠れていました。
- Agent Fleet 自身のツールの説明文が、セッションの文脈を消費する量が減りました。

### Fixed

- **長い会話で、作業過程が勝手に開き、読んでいた位置が飛んでいました。** スクロール中にも、
  以前の会話を読み込んだときにも起きていました。
- **質問カードの自由入力の書きかけが消えていました。** セッションが停止・再開してカードが
  もう一方の種類に入れ替わるときです。
- **ファイルビュアーのフォントサイズ設定が Markdown に効いていませんでした。** また、ミニマップを
  ドラッグすると通り過ぎた本文が選択されていました。
- **ミラーで、パスがコミットのリンクに食われて開けなくなることがありました**（特に生成画像のパス）。
- **開く先を持たない通知が「該当セッションがありません」と言っていました。**
- **スロット種別を変えた起動が「このまま待っても進みません」と出していました。** 実際にはその
  30 秒後に起動します。
- **Codex の使用量チップに画像生成の消費が出ていませんでした。**
- **opencode の起動メニューに、どのワークスペースからも使えない `amazon-bedrock/*` が並んで
  いました。**
- **スマートフォンでワークスペースバーのラベルが何も出ていませんでした**（「WS」と出ます）。

### Upgrade notes

自前の推論エンジンを使わないのであれば、やることはありません。任意かつ ECS の配備のみで、
`20-platform` と `30-ingress` を更新してから、新しい `cfn/60-engines.yaml` を配備します。
手順は `deploy/aws/ecs/README.md` にあります。G 系 vCPU のクォータ引き上げも含みます——新しい
アカウントでは 0 で、申請は承認まで数時間から数日かかります。GPU のインスタンスは稼働中
$1.26/時なので、
「オンデマンド」のまま使うことをお勧めします。

費用の画面は Cost Explorer への要求が 1 本増えます（月 $1.2 程度）。費用のタグは遡らないため、
役割ごとの内訳は配備した日から埋まります。
