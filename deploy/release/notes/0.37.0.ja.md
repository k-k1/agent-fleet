Apple Silicon の Mac に単独利用で対応し、並べたターミナルのペインの文字が互いに崩れなくなり、Cursor の
セッションは既定で Auto で動くので Free プランでも使えます。

### 新機能

- **macOS（Apple Silicon）に単独利用で対応しました。** Compose のバンドルに
  Docker Desktop・OrbStack・colima 向けの `docker-compose.macos.yml` が入り（単独利用、
  `127.0.0.1:8099`）、`linux-arm64` の native パッケージは Lima や OrbStack のマシンなどの Linux VM の
  中で動かせます。手順はバンドルの `README.md` の「macOS」にあります。M1 の Mac で colima・OrbStack・
  Docker Desktop、および Lima と OrbStack の VM での native を確認済みです。OrbStack と Docker Desktop は
  一度 Mac の画面から起動する必要があります。
  ([#2960](https://github.com/k-k1/agent-fleet/issues/2960),
  [#2961](https://github.com/k-k1/agent-fleet/issues/2961))

### 改善

- **インストーラが macOS を見分けます:** `install.sh` は「Linux only」だけで止まらずに上の 2 つの
  方法を案内し、`install-compose.sh` は macOS でも動いてダウンロードを `shasum` で検証し、
  `af update` は Linux 以外のホストで Linux 用パッケージを選ばなくなりました。
  ([#2960](https://github.com/k-k1/agent-fleet/issues/2960))
- **Jira: Markdown の表が本物の表になります。** `jira` コマンドで送るコメントと説明が対象です。
  ([#2943](https://github.com/k-k1/agent-fleet/issues/2943))
- **AWS でのファイルシステムの負荷が減りました:** Agent が、アーカイブ済みや停止中の claude セッションの
  ファイルを裏で読み続けなくなりました。これが EFS のメタデータ I/O を押し上げていました。
  ([#2850](https://github.com/k-k1/agent-fleet/issues/2850))

### 修正

- **並べて表示したターミナルのペインで文字が崩れていました。** ペインをクリックするまで直りませんでした。
  ([#2983](https://github.com/k-k1/agent-fleet/issues/2983))
- **Cursor: 既定（Default）のセッションが、CLI が最後に使ったモデルで動いていました。** Free プランでは
  そのモデルが拒否されます。既定は Auto で動くようになりました。有料プランで別のモデルを使うときは
  モデルを選んでください。
  ([#2928](https://github.com/k-k1/agent-fleet/issues/2928))
- **Agent に保存された値のどれかが空だと、同期した設定がその端末で読み込まれませんでした。**
  ([#2904](https://github.com/k-k1/agent-fleet/issues/2904))
- **Agent Fleet にサインインしたリモート MCP クライアントが、サインインの更新を 2 回同時に行うと接続が
  切れることがありました。**
  ([#2885](https://github.com/k-k1/agent-fleet/issues/2885))

### その他の変更
