Apple Silicon の Mac で、Docker Compose 版、または Linux VM の中の native 版を試験的に試せるように
なりました。

### 新機能

- **macOS（Apple Silicon）に試験対応。Mac 実機ではまだ動かしていません。** Compose のバンドルに
  Docker Desktop・OrbStack・colima 向けの `docker-compose.macos.yml` が入り（単独利用、
  `127.0.0.1:8099`）、`linux-arm64` の native パッケージは Lima や OrbStack のマシンなどの Linux VM の
  中で動かせます。手順はバンドルの `README.md` の「macOS」にあります。Mac 実機での確認はこれからです。
  ([#2960](https://github.com/k-k1/agent-fleet/issues/2960),
  [#2961](https://github.com/k-k1/agent-fleet/issues/2961))

### 改善

- **インストーラが macOS を見分けます:** `install.sh` は「Linux only」だけで止まらずに上の 2 つの
  方法を案内し、`install-compose.sh` は macOS でも動いてダウンロードを `shasum` で検証し、
  `af update` は Linux 以外のホストで Linux 用パッケージを選ばなくなりました。
  ([#2960](https://github.com/k-k1/agent-fleet/issues/2960))
