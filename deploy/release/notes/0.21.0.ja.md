モデルの取り込みが 1 押しになりました——検索し、計画を読み、確かめるだけです。カタログの
裏にある S3 Bucket が台帳になったので、どの行も宣言していないバイト列が、黙って課金され続ける
かわりに画面に出ます。画像エンジンは同時に複数持てるようになり、エンジンが起きているかを
管理者だけでなく**すべてのメンバー**が見られるようになりました。

### New

- **モデルの取り込みが 1 押しになりました。** 検索してカードの「追加」を押すと、そのモデルが
  必要とするファイルが 1 行ずつ、費用（ダウンロードなら MiB、すでに S3 Bucket にあるなら
  「取得なし」）・ライセンス・警告つきで並ぶ計画カードが出ます。押すボタンは 1 つです。
  バイト列の置き場所はこちらで決まるので、**複数ファイルに分かれた族も 1 回の操作で入り**、
  部品が欠けている行も同じ押下で揃います。
- **S3 Bucket が台帳になりました。** カタログの 2 枚目の画面が、ストレージに実際にあるものを
  並べます——どのカタログ行も宣言していないオブジェクトも含めてで、行として登録するか、
  消すかを選べます。これまでは行を忘れるとそのファイルが画面から消える一方で課金は続いて
  いました。置き場所が違うファイルも、取り直さず S3 Bucket の中で移して直せます。
- **画像エンジンを同時に複数持てます。** 絵がどのエンジンで作られるかは、provider の種類では
  なく**エンジンの行**で決まるようになりました。自分の LAN にある ComfyUI を優先し、その PC が
  落ちているときは借用エンジンへ落ち、どちらかを名指しすることもできます。設定 › エージェントの
  優先順位も行ベースになりました。
- **外部 ComfyUI のファイルを、その箱から読めます。**「このエンジンのファイルを調べる」で、
  読み込まれている checkpoint・LoRA・VAE が候補として並びます。行にするのは今までどおり
  人の押下で、族を宣言するのも運用者のままです。
- **すべてのメンバーがエンジンを見られます。** トップバーに役（llm / image）ごとのピルが出て、
  行ごとの popover に状態・待ち・箱が止まるまでの残り時間が出ます。
- **テナント単位で `llm` / `image` を止められます。** テナントの limits にあり、書けるのは
  super admin だけです。誰も何も言っていないテナントは両方とも使えるままなので、版を上げても
  何も変わりません。
- **`external` / `remote` の行から、任意の OpenAI 互換画像サーバに当てられます。**
  `provider: "openai-compat"` で行を 1 本宣言するだけです。

  ```json
  {"key":"oai-image","api":"images","provider":"openai-compat",
   "url":"http://<host>:<port>","health":"/v1/models","lifecycle":"external"}
  ```

  サーバが bearer を要求するなら `AF_ENGINE_API_KEY_<KEY>` から読みます。`<KEY>` は行の
  `key` を大文字にしたうえで、**英数字以外の文字を全部 `_` に置き換えたもの**です——上の行が
  読むのは `AF_ENGINE_API_KEY_OAI_IMAGE` であって `AF_ENGINE_API_KEY_OAI-IMAGE` ではありません。
  🔴 **この経路が試験されているのは、このプロジェクト自身の試験用の偽サーバに対してだけです。**
  実在の OpenAI 互換サーバに当てるまでは未実証として扱ってください。
- **`generate_image` が steps・CFG・sampler・scheduler を受け取ります。** 省略した欄は
  モデルの公表値で走り、その族が読まない摘みは黙って落とさずその旨を伝えます。
- **LoRA のトリガー語がチャット経路にも出ます。** 選ぶ前の行にも出ます。これまでチャットから
  LoRA を頼むとトリガー語なしで走り、アダプタは読まれるのに絵は変わらず、失敗として観測できる
  ものが何もありませんでした。
- **SD 1.5・Anima・Krea 2 がカタログの知る族に加わりました。** 既定の寸法も、常に 1024×1024
  ではなく族ごとの値になりました。
- **Civitai のトークンを登録できます。** ログインが要る資産を取り込めるようになります。
  Hugging Face のトークンと並んで管理モーダルの「API トークン」にあり、エンジンをまだ 1 本も
  登録していなくても開けます。
- **ギャラリーのフォルダに表紙と枚数が出ます。** 画像を開いたときに届くのも、原本ではなく
  画面の大きさに合わせた複製になりました。
- **プルリクエストの「始める」がレビューの起動になりました。** head ブランチを新しい作業コピーへ
  checkout し、そのセッションにレビューを頼みます。

### Improved

- **この build が serve できない provider を名乗る行が、黙って消えなくなりました。** 以前は
  `sdcpp` を名乗ったままの行があると `generate_image` がツール一覧から消えるだけで、エラーも
  印も出ませんでした。いまは管理者用の**「推論エンジン」**の画面がその行に印を付け、名乗って
  いる provider 名を表示します。
- **稼働中のセッションが、新しく有効にしたチェックポイントを作り直さずに見られます。**
  カタログが動いたらツール一覧を組み直してエージェントに知らせます。借用元の変更も、最大
  20 分ではなく約 2 分で届きます。
- **モデルカタログがスマホで使えます。** 検索・絞り込み・並び順がカードと一緒に流れて消えず、
  末尾で次のページを読み、例示画像も原寸ではなくサムネイルで届きます。
- **取り込みの検索を族で絞れます。** これまで拾えていなかった ComfyUI 向けの構成のリポジトリも
  見つかります。
- **エンジンの監査ログに、実際に買えたインスタンスの型と価格が残ります。**
- **ギャラリーのフォルダ間の行き来が、一度白くならずに描画されます。** カードのサムネイルも、
  それを映す画面の密度で頼むようになりました。

### Upgrade notes

- **`ImageEngine` は、それが選んでいたエンジンごと無くなりました。** image ロールは ComfyUI を
  動かすだけで選ぶものが無いので、パラメータ自体を `60-engines` から削除しました。退役した
  stable-diffusion.cpp にしか意味の無かった 2 つ——`ImageImageTag`（その ECR タグ）と
  `ImageExtraArgs`（`sd-server` の追加フラグ）——も同様で、`deploy` はこの 3 つのどのキーも
  拒みます。`ImageComfyImageTag` は無関係でそのまま残ります——パラメータファイルを編集する
  ときに取り違えないでください。`EcrSdcpp` の ECR リポジトリと、そこにある 2.31 GB の
  イメージも消えました。
- 🔴 **今回だけ、`60-engines` を `20-platform` より先に更新してください**——`update.sh` の
  通常の順序とは逆です。`60-engines` は `20-platform` がこの版でもう作らなくなった
  export（`EcrSdcppUri`）を import していたためで、`20-platform` を先に更新すると
  CloudFormation がまだ使われている export の削除を拒んでロールバックします。`update.sh`
  自身がこれを検知します——手元の `60-engines` スタックがまだ `EcrSdcppUri` を import
  しているなら、何にも触れる前に止まり、`60-engines` だけを先に更新する
  `aws cloudformation deploy` のコマンドをそのまま印字します。そのコマンドを実行してから、
  改めて `update.sh` をいつもどおり実行してください。
- **`ImageEngine` に何が書いてあっても自動で落とされます。** `standup.sh` は捕捉済みの
  パラメータファイルから値に関わらずこの行を消し、`update.sh` は何も渡しません——稼働中の
  スタックが持っていた値は次の更新で単に失われます。それが「パラメータが消えた」という
  ことです。いつもどおりスクリプトを実行する以外にすることはなく、それは `sdcpp` でも
  `comfy` でも同じです。`deploy` はテンプレートが宣言していないキーを値に関わらず拒むので、
  `ImageEngine` を手で渡している deploy コマンドがあれば、そこからは外してください。
