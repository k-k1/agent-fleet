Settings AWS profiles on one IAM Identity Center portal can share a single login, every
`af-aws-exec` run shows in the session that made it, and your own `~/.aws/config`, `~/.ssh/config`
and gcloud configurations can be imported into Settings.

### New

- **Shared AWS sign-ins.** Settings AWS profiles that use the same IAM Identity Center portal can
  share one sign-in: one login and one logout cover every profile in it. Existing profiles are
  grouped with **Share one sign-in**, and an import proposes the grouping.
  ([#3014](https://github.com/k-k1/agent-fleet/issues/3014),
  [#3077](https://github.com/k-k1/agent-fleet/issues/3077))
- **AWS runs in the session mirror, and confirm before use.** Each `af-aws-exec` run appears in
  the calling session with the account, role and region it ran as, and the SSM pane prints the
  identity it uses. A profile can be set to ask you in the Console before its first use in each
  session; such a profile is usable only through `af-aws-exec`.
  ([#3050](https://github.com/k-k1/agent-fleet/issues/3050),
  [#3064](https://github.com/k-k1/agent-fleet/issues/3064))
- **Import and export your own config files.** Settings can import AWS profiles from
  `~/.aws/config`, SSM hosts from `~/.ssh/config` and Google Cloud profiles from gcloud
  configurations, with a preview of what will be created; the files are read in the browser and
  never sent. Settings AWS profiles can be exported as a `~/.aws/config` fragment.
  ([#3010](https://github.com/k-k1/agent-fleet/issues/3010),
  [#3017](https://github.com/k-k1/agent-fleet/issues/3017))
- **Where your home disk went.** Settings › Machine breaks the whole home volume down by category
  (working copies, build output, tool caches, `~/.af-work`, trash and more).
  ([#3083](https://github.com/k-k1/agent-fleet/issues/3083))
- **Codex re-authentication.** The Codex card has a Re-authenticate button, a turn that failed on
  a revoked login is reported as a login problem and further prompts are refused until you sign in
  again, after which the session resumes by itself. Other kinds than Claude and Codex have no such
  path yet.
  ([#3021](https://github.com/k-k1/agent-fleet/issues/3021))

- **An archived session's `~/.af-work` folder is removed 7 days after it was archived.**
  ([#3105](https://github.com/k-k1/agent-fleet/issues/3105))
- **Agent memory from outside agents:** a save by `repository` can start the project for a
  repository cloned in the workspace, accepts the remote form `memory_projects` lists, and the
  working-copy search no longer times out on a large workspace.
  ([#3032](https://github.com/k-k1/agent-fleet/issues/3032),
