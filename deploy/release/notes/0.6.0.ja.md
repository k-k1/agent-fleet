エージェントが操作しているブラウザのページを利用者に渡し、最後のクリックだけ人が
引き取れるようになりました。Console は日本語へ落ちずに英語のまま通します。
**本リリースで Docker Compose 版の導入方法が変わります。コンテナイメージは tar から
読み込むのではなく GHCR から pull します。**

### Breaking changes（Docker Compose 版のみ）

- **イメージはレジストリから取得します。** リリースに
  `agent-fleet-images-<version>.tar.gz` は入らなくなり、control-plane と workspace の
  イメージは GHCR で公開します。導入は「tar をダウンロード → `load-images.sh`」から
  `docker compose pull` に変わります。パッケージは public なのでログインは不要です。

  既存デプロイの更新: `.env` に `REGISTRY=ghcr.io/k-k1/agent-fleet` と
  `VERSION=0.6.0` を設定し、`WS_IMAGE` を
  `ghcr.io/k-k1/agent-fleet/workspace:0.6.0` に向けて、従来の `load-images.sh` の
  代わりに `docker compose pull` と `docker pull "$WS_IMAGE"` を実行してください。
  データも `AF_MASTER_KEY` もその他の設定もそのままです。

  レジストリに到達できないホストには 2 つの手段があります。2 つのイメージを社内
  レジストリへミラーして `REGISTRY` をそこへ向けるか、`deploy/compose/release.sh
  --save` で自分でビルド・書き出して `load-images.sh` を使い続けるかです。どちらも
  バンドルに残しています。

- **native 版と AWS/ECS 経路は影響を受けません。**

### New

- **ブラウザのページを人に渡す。** エージェントが Workspace 内でヘッドレス Chromium を
  操作しているとき、その生きたページを利用者へ渡せます。Console のペインで開き、
  クリック・スクロール・入力（日本語 IME を含む）ができ、終わったら返せます。切り離し
  で閉じるのは Console 側の表示だけです。最後の公開・送信・同意のクリックをエージェント
  が代行することはありません。それがこの機能の要点です。
- **思考の展開表示をエージェント種別ごとに設定**できます（Settings › Agents ›
  各カード › 挙動）。既定は off です。

### Improved

- **Console が表示言語で話します。** 表示言語を英語にすると、内蔵アシスタントは日本語
  ではなく英語で答えます。返信候補・compact の引き継ぎ・作業計画も表示言語に従います。
  ペルソナは会話ごとに固定されるので、切り替えは新しい会話に効き、開いているスレッドは
  そのままです。
- **完了報告がどちらの言語でも読めます。** カードは事実を表示言語で述べ、モデル向けの
  文言は出さなくなりました。
- CLI の固定版: Claude Code 2.1.220、Codex 0.146.0、OpenCode 1.18.11、GitHub Copilot
  1.0.77、Antigravity 1.1.9、Cursor 2026.07.23、Kiro 2.16.0、rtk 0.44.2。

### Fixed

- **Workspace バーの使用量チップが丸一日固まることがありました。** Claude のステータス
  ラインが、別パスから実行されるたびに包み直され、やがて実行できない大きさになって
  使用量の取得が黙って止まっていました。壊れている設定は次回起動時に自分で直ります。

### Upgrade notes

**Compose のデプロイはレジストリ pull へ切り替える必要があります。** 具体的な `.env`
の変更は上の Breaking changes を参照してください。レジストリに到達できないホストは、
同梱 runbook の「Air-gapped install」節が対象です。native はいつものワンライナーで
更新できます。
