ターンの実行中に送る続きのプロンプトを、セッションごとの送信待ちに溜められるようになりました。フォルダを zip で
ダウンロードでき、Console のターミナルでは Ctrl+C と Ctrl+V でコピーと貼り付けができます。Agent Fleet のメモリは、
オンの間は claude 自身のメモリに代わって使われ、claude へ書き戻すこともできます。期限のある GitHub App と
Google Cloud のトークンは自動で更新され、ecs-ec2 のワークスペースで Chromium が動くようになりました。

### New

- **送信待ち。** ターンの実行中は、送信ボタン横の矢印（または Alt+Enter）から「送信待ちに追加」を選べます。溜めた
  プロンプトは編集、並べ替え、削除、すぐに送信ができ、セッションがアイドルになると 1 件ずつ送られます。ターンを
  止めると送信待ちも一時停止します。送信待ちはこのブラウザのタブにだけあり、再読み込みすると消えます。
  ([#1083](https://github.com/k-k1/agent-fleet/issues/1083))
- **フォルダを zip でダウンロード。** ファイルのツリーと画像ギャラリーのフォルダのメニュー（タッチ画面では長押し）から
  使えます。フォルダ内の `.git` と `node_modules` は含めず、ほかに含めなかったものはトーストで知らせます。
  ([#1829](https://github.com/k-k1/agent-fleet/issues/1829))
- **ターミナルで Ctrl+C / Ctrl+V によるコピーと貼り付け。** Ctrl+C は自分で選択した範囲をコピーし、何も選択して
  いなければ従来どおりプログラムを中断します。設定 › 表示 でオフにできます。
  ([#1708](https://github.com/k-k1/agent-fleet/issues/1708))
- **「別のプロファイルからロールを引き受ける」** を 設定 › AWS プロファイル/SSM の新しい種類として追加しました。
  SSO プロファイルのログインを使って IAM ロールを引き受けるので、長期のキーは要りません。`af-aws-exec` と SSM
  セッションでも使えます。
  ([#1109](https://github.com/k-k1/agent-fleet/issues/1109))
- **Agent Fleet のメモリを Claude Code へ書き戻す。** 設定 › エージェントメモリ の「Claude Code へ書き戻す」で、
  プロジェクトのメモリを確認してから claude 自身のメモリへコピーします。Agent Fleet のメモリをオフにするときに使います。
  ([#1914](https://github.com/k-k1/agent-fleet/issues/1914))
- **ピン留めしたメモリ。** 設定 › エージェントメモリ でメモリをピン留めすると、`memory_index` が常に先頭に並べます。
  ほかのメモリは、セッションが読んだ回数の多い順に並びます。
  ([#1703](https://github.com/k-k1/agent-fleet/issues/1703))
- **子セッションが親の作業コピーを共有できます。** `create_session` に `allow_shared_working_copy` を指定すると、
  断らずに親自身の作業コピーで子を起動します。
  ([#1826](https://github.com/k-k1/agent-fleet/issues/1826))

### Improved

- **Agent Fleet のメモリがオンの間は、claude 自身のメモリに代わって使われます。** 新しく起動した claude のセッションは
  claude のネイティブのメモリを読み書きせず、すべての種類のエージェントにメモリツールの使い方を伝えます。メモリの
  名前、説明、本文には claude のメモリが持つ内容がそのまま入るので、取り込みで短くなることはなくなりました。
  ([#1734](https://github.com/k-k1/agent-fleet/issues/1734),
  [#1733](https://github.com/k-k1/agent-fleet/issues/1733),
  [#1921](https://github.com/k-k1/agent-fleet/issues/1921))
- **左ペインで畳んだリポジトリに、いちばん新しいセッションを表示します。** リポジトリの行にタイトルと状態が出て、
  実行中の数のバッジのツールチップにほかの実行中のセッションが並びます。
  ([#1915](https://github.com/k-k1/agent-fleet/issues/1915))
- **コマンドパレットで、子セッションを親の下にまとめて表示します。** 検索で見つかった子には親の名前が付きます。
  ([#1887](https://github.com/k-k1/agent-fleet/issues/1887))
- **リンクになるチケットの参照が増えました。** ミラーでは Jira の接続にあるどのプロジェクトのキーもリンクになり、
  作業項目の一覧にない Jira の課題や Bitbucket の PR は開いたときにその場で読み込みます。Markdown ファイルのプレビューでは
  `#N` がそのファイルのリポジトリに対してリンクになり、`#573-#598` のような範囲は両端ともリンクになります。
  ([#1899](https://github.com/k-k1/agent-fleet/issues/1899),
  [#1661](https://github.com/k-k1/agent-fleet/issues/1661),
  [#1900](https://github.com/k-k1/agent-fleet/issues/1900),
  [#1909](https://github.com/k-k1/agent-fleet/issues/1909))
- **期限のある GitHub App のトークンを自動で更新します。** GitHub App の「Expire user authorization tokens」は
  オンのままでかまいません。8 時間の期限を過ぎても、接続し直さずにクローンやプッシュを続けられます。
  ([#1676](https://github.com/k-k1/agent-fleet/issues/1676))
- **Google Cloud プロファイル。** 設定 › Google Cloud と WS バーから「ログアウト」できるようになり、`af-gcloud-exec` は
  長いコマンドの実行中にトークンを更新します。Terraform のように起動時に一度だけトークンを読むプログラムには、
  更新はまだ届きません
  ([#1879](https://github.com/k-k1/agent-fleet/issues/1879))。
  ([#1850](https://github.com/k-k1/agent-fleet/issues/1850),
  [#1488](https://github.com/k-k1/agent-fleet/issues/1488))
- **自分のターミナルで実行した `af-aws-exec` と `af-gcloud-exec` も、Console にログインを頼みます。** エージェントが
  実行したときと同じ動きで、最大 10 分待ちます。`--login` を付ければ、これまでどおりターミナルでログインします。
  ([#1512](https://github.com/k-k1/agent-fleet/issues/1512))
- **GitHub の作業項目の既定のクエリに種類を含めました**（`is:issue OR is:pull-request`）。種類が必要なアカウントでも、
  更新のたびにやり直しが起きなくなります。保存済みのクエリは変わりません。
  ([#1715](https://github.com/k-k1/agent-fleet/issues/1715))
- **WS バーの Muse Code の利用量メニューから、Meta の利用量のページを開けます。** Claude と Codex と同じです。
  ([#1892](https://github.com/k-k1/agent-fleet/issues/1892))

### Fixed

- **ecs-ec2 のワークスペースで、ブラウザの機能が使える表示なのに Chromium が動きませんでした。** ecs-ec2 では
  動くようになりました。Chromium を動かせない `ecs`（Fargate）では、Console がブラウザの機能を押せない状態にして
  理由を表示します。
  ([#1927](https://github.com/k-k1/agent-fleet/issues/1927))
- **「リモートコントロール」をオンにしても効きませんでした。** claude のセッションがリモートコントロールにつながり
  ませんでした。オンの間に新しく起動した claude のセッションはつながります。テレメトリ、エラーレポート、自動更新は
  止めたままです。
  ([#1254](https://github.com/k-k1/agent-fleet/issues/1254))
- **git の `index.lock` が残ると、fast-forward での取り込みがずっと失敗していました。** ロックが古いときは、Console が削除するかを
  確かめてからやり直します。エージェント自身の状態確認も、このロックを取らなくなりました。
  ([#1930](https://github.com/k-k1/agent-fleet/issues/1930))
- **`create_session` が知らない引数を黙って無視していました。** `initial_prompt` の代わりに `prompt` を渡すと、
  何もしない子が起動していました。af の MCP ツールは、知らない引数や型の違う引数をエラーで断り、正しい名前を
  示すようになりました。
  ([#1905](https://github.com/k-k1/agent-fleet/issues/1905))
- **Markdown で `<a>` などの書式のタグを閉じ忘れると、** 後に続く段落がすべてリンク（あるいは太字や斜体など）として
  表示されていました。閉じていないタグは文字のまま表示し、`<marquee>` も描画しなくなりました。
  ([#1846](https://github.com/k-k1/agent-fleet/issues/1846),
  [#1853](https://github.com/k-k1/agent-fleet/issues/1853),
  [#1876](https://github.com/k-k1/agent-fleet/issues/1876))
- **Antigravity がバックグラウンドで動かしているコマンドが、ワークスペースを止めない理由になっていませんでした。**
  アイドル自動停止が、実行の途中でワークスペースを止めることがありました。
  ([#1825](https://github.com/k-k1/agent-fleet/issues/1825))
- **コマンドパレット。** 開き直すと、先頭の行ではなく前に選んだセッションが選ばれていました。また「会話」の検索で、
  会話の読み込み済みの範囲より古いヒットを選ぶと、会話の末尾へ移動していました。
  ([#1886](https://github.com/k-k1/agent-fleet/issues/1886),
  [#1663](https://github.com/k-k1/agent-fleet/issues/1663))
- **メンバーの詳細で、ワークスペースが残っているのに「メンバーを完全に削除」が表示され、** 削除は断られていました
  （たとえば ecs-ec2 で「home を掃除」した後）。今は先に「ワークスペースを破棄」を表示します。
  ([#1888](https://github.com/k-k1/agent-fleet/issues/1888))
- **クラウドのログインのコードを送ると、届いていてもエラーになることがありました。**
  ([#1885](https://github.com/k-k1/agent-fleet/issues/1885))
- **スマートフォンで、WS バーが画面より広くなることがありました。** 入りきらないときは、ペインのボタンを ⋯ の
  メニューへ移します。
  ([#1650](https://github.com/k-k1/agent-fleet/issues/1650))

### Upgrade notes

- **Agent Fleet のメモリ。** 「セッションに Agent Fleet のメモリを使わせる」がオンなら、アップグレード後に起動した
  claude のセッションは claude 自身のメモリを読まなくなります。前回の取り込み以降に claude が覚えた内容を残さない
  よう、先に「Claude Code から取り込む」をもう一度実行してください。実行中のセッションは、起動したときの設定のままです。
- **ecs-ec2。** 各ワークスペースは、次に起動したときにブラウザの変更を受け取ります。対応するスロットの強化を効かせる
  には、ECS のランブックの手順どおりにスタックを更新し、それより前に起動したスロットを入れ替えてください。

エージェント CLI のピン: Claude Code 2.1.295、Codex 0.162.0、Copilot 1.0.94、Antigravity 1.3.2、Muse Code
1.4.4-R5419.1。OpenCode、Cursor、Kiro は変わりません。
