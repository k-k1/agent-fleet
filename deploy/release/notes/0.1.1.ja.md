### 新機能

- **設定モーダルに「アシスタント」タブを新設** — フリート・アシスタントの設定を
  セッション設定から切り離して独立タブにしました。アシスタントのモデルとセッションの
  既定値が混ざらなくなります。

### 改善

- **配布物の文言を英語に統一。** 配布物の利用者が目にするもの（`install.sh`、
  リリース／ビルドスクリプト、各デプロイ README、CI ワークフロー）をすべて英語に
  しました（私有リポジトリ内のドキュメントは従来どおりです）。
- **README に製品概要を追加。** ルート README と dist リポジトリの README が、内部の
  開発ステータスではなく「Agent Fleet とは何か」「どのエージェント CLI に対応するか」
  から始まるようにしました。
- README の概要にランタイム対比（Docker/cgroup と Docker 不要の native ランタイム）と、
  Antigravity CLI 対応の記載を追記しました。
