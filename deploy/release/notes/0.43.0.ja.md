新しい `watch` ツールで、セッションがプルリクエスト・レビュー・指定した時刻を待てるようになり、任意で
有効にできるメモリの自動整理が、エージェントのメモリの直しを下書きして承認を待つようになりました。
Workspace はサインイン時に起動したり、新しいイメージへ自分で移ったりできます。設定 › エージェント の
権限確認のスイッチも、表示どおりに動くようになりました。更新の前にアップグレードの注意を読んでください。
弱い `AF_MASTER_KEY` や `AF_COOKIE_SECRET` では Control Plane が起動しなくなりました。

### 新機能

- **`watch` でセッションがプルリクエストを待てます。** バックグラウンドでポーリングする代わりに、
  チェックの完了や失敗・コンフリクト・マージ可能・マージやクローズ・変更要求・（GitHub では）未解決の
  新しいスレッドを、GitHub と Bitbucket Cloud について自分の接続で待ちます。`list_watches` と
  `unwatch` で管理でき、子セッションは通知を親へ送れます。
  ([#3627](https://github.com/k-k1/agent-fleet/issues/3627),
  [#3628](https://github.com/k-k1/agent-fleet/issues/3628))
- **タイマー:** `watch` の `source: time` は、指定の時刻か最長 30 日の待ち時間のあとに発火し、
  そのために停止中の Workspace を起動することもできます。
  ([#3632](https://github.com/k-k1/agent-fleet/issues/3632))
- **自分の MCP サーバーをウォッチのソースにできます。** MCP サーバーで **ウォッチのソース** に印を付け、
  テナント管理者が テナント設定 › **ウォッチのソース** で許可したとき（既定はオフ）に使えます。
  ([#3631](https://github.com/k-k1/agent-fleet/issues/3631))
- **webhook でウォッチの通知が速くなります。** webhook が無ければ、これまでどおりポーリングします。
  公開リポジトリの GitHub webhook は運用者が `AF_GITHUB_WEBHOOK_SECRET` で有効にします（`/webhooks/`
  のパスにはサインイン無しで届く必要があります）。管理者権限を持つ非公開リポジトリには
  `af-watch-hook add github|bitbucket <owner/name>` で hook を入れます。
  ([#3630](https://github.com/k-k1/agent-fleet/issues/3630),
  [#3751](https://github.com/k-k1/agent-fleet/issues/3751))
- **メモリの自動整理（任意）。** Workspace がアイドルの間に、エージェントのフィードバックとリントの
  指摘をもとに、モデルがメモリの部分修正・置き換え・統合を下書きします。下書きは **提案** に
  **承認するとどうなるか** のプレビュー付きで並び、承認するまで何も変わりません。承認した変更は
  元に戻せます。設定 › エージェントメモリ でオンにします。Claude を使い、トークンを消費します。
  ([#3497](https://github.com/k-k1/agent-fleet/issues/3497),
  [#3702](https://github.com/k-k1/agent-fleet/issues/3702),
  [#3720](https://github.com/k-k1/agent-fleet/issues/3720))
- **メモリのリントレポート**（設定 › エージェントメモリ › 取り込み・書き出し、または `af-memory lint`）:
  もう存在しないパス・シンボル・リンクを指すメモリ、大きすぎる本文、廃止した用語を指摘します。
  `af-memory lint-rename` は名前の変わったパスを書き換えます。
  ([#3443](https://github.com/k-k1/agent-fleet/issues/3443),
  [#3571](https://github.com/k-k1/agent-fleet/issues/3571),
  [#3496](https://github.com/k-k1/agent-fleet/issues/3496))
- **新しいメモリのツール `memory_patch` と `memory_feedback`**（外部の `/mcp` のメモリのツールにも
  あります）: メモリの一部分だけを変えたり、古い・誤りだと報告したりできます。
  ([#3441](https://github.com/k-k1/agent-fleet/issues/3441),
  [#3496](https://github.com/k-k1/agent-fleet/issues/3496),
  [#3649](https://github.com/k-k1/agent-fleet/issues/3649),
  [#3636](https://github.com/k-k1/agent-fleet/issues/3636))
- **サインイン時の自動起動:** テナントの設定（既定はオフ）で、メンバーがサインインしたときに停止中の
  Workspace を起動します。メンバーは 設定 › ツールチェーン で個別にやめられます。
  ([#2031](https://github.com/k-k1/agent-fleet/issues/2031))
- **イメージの自動更新:** 古いイメージのままアイドルになった Workspace を、新しいイメージで再起動させ
  られます（設定 › ツールチェーン、既定はオフ）。作り直しはしません。
  ([#3656](https://github.com/k-k1/agent-fleet/issues/3656))
- **月ごとの稼働時間とクラウド費用**を、前月からの増減とともに、使用量・クラウド費用・メンバーの
  パネルに表示します。([#3383](https://github.com/k-k1/agent-fleet/issues/3383),
  [#3609](https://github.com/k-k1/agent-fleet/issues/3609))
- **PAT の最長有効期間**をテナントごとに、テナントの上限で設定できます。
  ([#3465](https://github.com/k-k1/agent-fleet/issues/3465))
- **作業項目の詳細パネルから Bitbucket Cloud のプルリクエストをマージできます。** マージ方式と
  **ソースブランチを閉じる** を選べ、マージ可能かコンフリクトしているかもパネルに出ます。
- **色をランダムに**（外観のポップオーバーと 設定 › 表示）で、面の色を開くたび・1 時間ごと・毎日に
  選び直します。🎲 ボタンですぐに選び直せます。
  ([#3738](https://github.com/k-k1/agent-fleet/issues/3738))
- **ECS:** `20-platform` のパラメータ `MasterKeyKmsKeyArn` で、`/af-cp/master-key` を自分の KMS 鍵で
  暗号化できます。手順の順番は `cfn/PARAMETERS.md` に従ってください。
  ([#3470](https://github.com/k-k1/agent-fleet/issues/3470))

### 改善

- **弱い `AF_MASTER_KEY` や `AF_COOKIE_SECRET` では Control Plane が起動しません**（`AUTH=oauth`・
  `AUTH=proxy`）。メッセージには変数名だけを出し、値は出しません。
  ([#3552](https://github.com/k-k1/agent-fleet/issues/3552))
- **Cookie は既定で用途ごとの鍵で署名されます。** 0.42.0 が発行した Cookie はセッション 1 回分の
  期間は有効なので、誰もサインアウトされません。
  ([#3552](https://github.com/k-k1/agent-fleet/issues/3552))
- **Console は自分自身のスクリプトだけを実行し**、レンダリングした Markdown の外部画像はクリックした
  ときだけ読み込みます。([#3454](https://github.com/k-k1/agent-fleet/issues/3454),
  [#3458](https://github.com/k-k1/agent-fleet/issues/3458))
- **アーカイブしたメモリや置き換えられたメモリ**は、索引・検索・セッションのプロンプト・Claude Code へ
  書き戻すコピーから外れます。([#3495](https://github.com/k-k1/agent-fleet/issues/3495))
- **ファイルペイン:** Markdown の分割表示でエディタとプレビューが一緒にスクロールし、タブを切り替えて
  戻っても表示モードとスクロール位置が保たれます。
  ([#3659](https://github.com/k-k1/agent-fleet/issues/3659),
  [#3662](https://github.com/k-k1/agent-fleet/issues/3662))
- **Jira のチケットからセッションを始めるとき、リポジトリを推測しなくなりました。** 自分で選び、その
  選択を Jira のプロジェクトごとに覚えさせられます。
  ([#3770](https://github.com/k-k1/agent-fleet/issues/3770))
- **PR の通知**は、セッションがすでにウォッチしている内容を繰り返さず、レビューの通知は何が新しいかを
  伝えます。コンフリクトしたままの PR が、ベースが進むたびに再通知されることもなくなりました。
  ([#3629](https://github.com/k-k1/agent-fleet/issues/3629),
  [#3732](https://github.com/k-k1/agent-fleet/issues/3732))
- **細かな改善:** スキルの候補が単語の先頭で一致するようになりました（`/itp` で `issue-to-pr`）。agy の
  使用量のポップオーバーに **失敗した呼び出しで判明した上限** が出ます。作業項目の種別の行にトラッカー
  自身の課題タイプが出ます。`bkt` は拒否されたときに足りない Bitbucket のスコープを示します。
  ([#3614](https://github.com/k-k1/agent-fleet/issues/3614),
  [#3744](https://github.com/k-k1/agent-fleet/issues/3744),
  [#3734](https://github.com/k-k1/agent-fleet/issues/3734),
  [#3570](https://github.com/k-k1/agent-fleet/issues/3570))

### アップグレードの注意

- **更新の前に 2 つの鍵を確認してください。** 鍵として 32 バイト未満（16 進または base64 で 32 バイト未満に
  なるもの、43 文字未満の生の文字列）か、同じパターンの繰り返しだと弱い値です。0.42.0 の警告バナーと
  同じ基準なので、バナーが出ていなければ何もいりません。弱い `AF_COOKIE_SECRET` は
  `head -c 32 /dev/urandom | base64` で作り直してください。全員が一度サインインし直します。
  **弱い `AF_MASTER_KEY` は単純には入れ替えられません。** その値で封じたものが開かなくなります。
  このリリースはその値では起動しないので、先に段取りを決めてください（運用ガイドの「デプロイの鍵」と
  「保存時の鍵」）。`deploy/aws/ecs/standup.sh` は短い保存値を、値を表示せずに知らせます。
  ([#3552](https://github.com/k-k1/agent-fleet/issues/3552))
- **先に 0.42.0 へ更新してください。** 0.42.0 より前のレプリカは新しい Cookie 形式を読めないため、
  それより古いリリースから直接更新すると、古いレプリカにリクエストが届くたびにサインアウトされます。
- **従来の Cookie 形式をもう 1 リリース使いたい場合**は `AF_COOKIE_PURPOSE_KEYS=0`（ECS は
  `CookiePurposeKeys=0`）を設定します。この退避設定と古い形式は、後のリリースで無くなります。
  ([#3552](https://github.com/k-k1/agent-fleet/issues/3552))
- **`AF_PAT_MAX_DAYS` を下げると、既存のトークンも**新しい上限より古ければ失効します。これまでは
  新しいトークンだけが対象でした。([#3465](https://github.com/k-k1/agent-fleet/issues/3465))
- **Console のページに差し込まれたスクリプト**（リバースプロキシが足すものなど）はブロックされます。
  ([#3454](https://github.com/k-k1/agent-fleet/issues/3454))
