The tenant Members page shows each member as a card with live sessions, last activity, home disk,
memory and CPU. A full home disk or a CLI that failed to install is now reported to the member and the
tenant admin instead of surfacing as a broken session. The command palette searches Agent memory, and
loopback URLs in Markdown open the workspace preview.

### New

- **The tenant Members page is one card per member**, with a state badge in words, counts, a filter,
  a sort and a search. Cards show live and total sessions, when the member was last active, home disk
  use, and live memory and CPU for running workspaces in view.
  ([#2385](https://github.com/k-k1/agent-fleet/issues/2385),
  [#2388](https://github.com/k-k1/agent-fleet/issues/2388),
  [#2389](https://github.com/k-k1/agent-fleet/issues/2389))
- **A full home disk and failed CLI installs are visible.** On a dedicated home disk the Console warns
  when space runs low, Settings › Toolchains shows "install failed: <reason>" for a CLI that did not
  install at start, and starting a session of that kind is refused with the reason. The tenant admin
  sees the same members flagged on the Members page. A start no longer begins an install that cannot
  fit, so the CLIs already installed keep working.
  ([#2383](https://github.com/k-k1/agent-fleet/issues/2383),
  [#2398](https://github.com/k-k1/agent-fleet/issues/2398))
- **Search Agent memory from the command palette.** A **Memory** mode, offered while Agent memory is
  on, matches names and descriptions at once and the text after a short pause; Enter opens the memory
  in Settings.
  ([#2407](https://github.com/k-k1/agent-fleet/issues/2407))
- **Loopback URLs in Markdown open the workspace preview** of that port, in the conversation, the
  assistant chat and the document and file viewers; right-click offers the same menu as the port chip.
  A URL in inline code is a link only while a session reports that port.
  ([#2414](https://github.com/k-k1/agent-fleet/issues/2414),
  [#2419](https://github.com/k-k1/agent-fleet/issues/2419),
  [#2426](https://github.com/k-k1/agent-fleet/issues/2426))
- **A parent is nudged once when its whole session tree stalls.** When a parent and all its live
  children have been idle for 15 minutes with no message in flight, the parent receives one notice,
  shown as **Stalled-tree notice** in the conversation. Sessions waiting for you never trigger it;
  `AF_STALLED_TREE_MINUTES` changes the wait (`0` turns it off).
  ([#2397](https://github.com/k-k1/agent-fleet/issues/2397))

### Improved

- **`$AF_WORK_DIR/…` paths in a Terminal session's replies are links**, and file menus offer **Open
  the folder** and **Open folder in gallery** for files in a folder under home.
  ([#2429](https://github.com/k-k1/agent-fleet/issues/2429))
- **The command palette cycles modes backwards** with the palette chord plus Shift (Ctrl/⌘+Shift+P by
  default), PageUp/PageDown move a page, and the mode-switch hint has its own line so it is never cut
  off.
  ([#2412](https://github.com/k-k1/agent-fleet/issues/2412),
  [#2421](https://github.com/k-k1/agent-fleet/issues/2421))
- **kiro can be the target of Move to another agent.** cursor is still not offered.
  ([#2252](https://github.com/k-k1/agent-fleet/issues/2252))
- **The handover file of a moved session** is written in your Console language, lists the inputs the
  stop discarded, and leaves out more old read-only tool calls.
  ([#2233](https://github.com/k-k1/agent-fleet/issues/2233))
- **Muse Code 1.4.11** is supported, and its new record kinds show as one-line summaries.
  ([#2394](https://github.com/k-k1/agent-fleet/issues/2394))
- **ECS: `pause.sh` deletes the NAT gateway** while the deployment sleeps and recreates it on `--up`
  with the same egress IP (`--keep-nat` keeps it), and a paused RDS instance is stopped again when AWS
  starts it after 7 days.
  ([#2386](https://github.com/k-k1/agent-fleet/issues/2386))

### Fixed

- **A CLI install that failed half-way at workspace start was logged as successful**, and the broken
  binary was kept on every later start. rtk, agy and cursor are now installed atomically and
  reinstalled when they do not run.
  ([#2384](https://github.com/k-k1/agent-fleet/issues/2384))

### Upgrade notes

- **ECS deployments:** deploy the `10-data` stack once to get the RDS re-stop rule. From this release
  `pause.sh` deletes the NAT gateway by default; pass `--keep-nat` if something must keep reaching the
  internet while paused.
