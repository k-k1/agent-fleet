Postgres を使うデプロイで、ワークスペースの設定がまったく保存できていませんでした。
ワークスペースの中から利用ガイドが開かない件も直しています。プレビューの設定には
「いまの URL」が出るようになりました。

### Improved

- **プレビューの名前を、専用のホストゾーンに置けるようになりました。**
  `PreviewHostedZoneId` でプレビューの証明書と DNS レコードだけ Console とは別のゾーンへ
  向けられます。Console の名前自体が委任ゾーンのとき、兄弟の名前（`af.example.com` の
  隣の `pv.example.com`）を使うにはこれが要ります。

### Fixed

- **Postgres を使うデプロイで、ワークスペースの設定の保存が必ず失敗していました。**
  読み出しは黙って既定値を返すため画面は正常に見え、保存を押したときだけ分かる状態
  でした。使うエージェント CLI も、プレビューで公開するポートも、公開するかどうかも、
  一度も保存できていませんでした。
- **ワークスペースの中から利用ガイドが開きませんでした。** ボタンの行き先はガイドの
  入口ページで、そこだけがコンテナへ配られていませんでした。
- **プレビューの設定に「いまの URL」が出ます。** 再発行も何をしたかを必ず言うように
  しました。停止中に押すと何も起きないように見えていました。
- **ツールの版一覧で OpenCode と Copilot が「(timeout)」になる**ことがありました
  （初回起動が遅い配備）。同じ実体なのに列で食い違うこともありました。

### Upgrade notes

やることはありません。`PreviewHostedZoneId` の既定は `HostedZoneId` なので、既存の
スタックは変わりません。エージェント CLI のピンは 0.14.0 から変わりません。
