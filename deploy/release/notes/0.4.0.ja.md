機能別のトークン使用量が見えるようになり、Console の File ペインで本文を編集でき、
ロックした対象は消えなくなりました。途中で切れたターンの自動再開も入ります。

### 新機能

- **機能別の使用量** — 設定に使用量タブが付き、トークン消費（CLI が実測 USD を返す
  経路では金額も）をグラフで見られます。セッション本体と、フリート自身の補助呼び出し
  （アシスタントチャット・タイトル・返信サジェスト・要約引き継ぎ・自動ターン・
  ブリッジ応答など）を同じ台帳に載せ、「どの機能が予算を食っているか」が
  ワークスペースバーのサブスク枠チップだけでは分からなかったところまで追えます。
- **File ペインでの Text / コード編集** — ファイルを編集モードで開き、dirty バッファと
  undo を保ったまま、revision 検査付きでワークスペースへ保存します。Markdown は
  編集 / プレビュー / 左右分割（Marp 含む）、それ以外のテキストはコードエディタです。
  画面遷移・再読込・ワークスペース停止などは、保存・破棄・キャンセルを選ぶまで
  未保存の内容を捨てません。
- **削除ロック** — セッション・作業コピー（clone / worktree）・アシスタント会話を
  固定でき、手動削除も自動 prune も越えられません。効きどころは Agent の REST 層
  なので、Console・オペレーターツール・チャットブリッジのどの入口から来ても同じ
  403 で止まります。アーカイブと halt は実体を消さないので従来どおり使えます。
- **中断ターンの自動再開** — 再送すれば直る理由（切断・一時的なレート制限など）で
  ターンが切れたとき、紐付いた会話上でオペレーターが再開できます。連続は 2 回までで、
  それ以上は利用者へエスカレーションします。設定 › アシスタントで切り替え（既定 ON）。
  Console からだけ起動した（会話に紐付かない）セッションは自動再開せず、通知だけ出ます。
- **用途別のモデル選択** — 各 CLI ごとに、アシスタント用と補助生成用（タイトル・
  サジェストなど）のモデルを分けて指定できます。**推奨**はライブのカタログと接続状況
  から解決し（例: OpenCode Go 契約なら Go 向けの組）、設定画面にはいま実際に効いている
  具体モデルが表示されます。

### 改善

- OpenCode のモデル一覧を Go / Zen 向けに整形できるようにしました。
- OpenCode マネージドで失敗したターンが消えず、はっきり分かるようにしました。
- モバイルの設定は長い一枚ではなく、一覧起点で開くようにしました。
- 配布 README の冒頭に短い訴求文を追加しました（英日）。
- README / ドキュメントのスクリーンショットを更新しました（使用量ビューを含む）。

### 修正

- 別のチャットを開くと回答が会話間で混線することがありました。
- 再提示したプランの承認バッジがミラー上で正しく残らないことがありました。
- 削除ロックの状態が Console にすぐ反映されないことがありました。ロックは
  コントロールプレーン経由で中継・保持され、表示が即時更新されます。
- ファイル保存・復旧の競合: クライアントが諦めたあとに PUT が進まないよう
  タイムアウトを検査し、復旧 GET は書き込み mutex の後ろに直列化して偽の 200 を
  成功に見せないようにし、discard は disk 確定まで待ち、競合 snapshot は
  確定境界を守ります。
- 使用量台帳: 折り込みの取りこぼし・ブロック・二重計上を塞ぎ、`(ref, idx)` の
  重複行で合計が膨らまないようにしました。
- guard キャンセル時の中断伝播と I/O タイムアウトを整えました。

### アップグレード時の注意

移行や設定変更は不要です。自動再開は既定 ON です。中断のたびに自分で判断したい
場合は 設定 › アシスタント でオフにしてください。既存ワークスペースに削除ロックは
付いていません。必要な対象だけ明示的にロックしてください。
