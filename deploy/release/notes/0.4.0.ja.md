トークン使用量を機能別に見られるようになり、Console でファイルを編集でき、ロック
したものが消えなくなり、途中で落ちたターンが自分で再開するようになりました。

### New

- **機能別の使用量。** 設定に使用量タブが加わり、トークン消費（CLI が報告する場合は
  実際の USD も）をグラフにします。セッションのターンと、fleet 自身の補助呼び出し
  （アシスタントチャット・タイトル・返信候補・compact・ブリッジの返信など）を 1 つの
  台帳で扱うので、どの機能が予算を食っているかが分かります。
- **File ペインでのテキスト／コード編集。** ファイルを開いて編集し、undo 付きの未保存
  バッファを保ち、リビジョン検査を通して Workspace 経由で保存します。Markdown は
  編集／プレビュー／分割（Marp を含む）のままです。未保存の内容を黙って捨てることは
  ありません。
- **削除ロック。** セッション・作業コピー・アシスタントの会話を固定すると、手動削除も
  自動整理も外せなくなります。強制は REST 層で行うので、Console・オペレーターのツール・
  チャットブリッジのどこから来ても同じ拒否になります。
- **中断したターンの自動再開。** 送り直せば直る理由でターンが落ちた場合、fleet
  オペレーターが再開します。自動再試行は 2 回までで、その後は利用者に上げます。既定で
  on（Settings › Assistant）。会話が紐づいていないセッションは自動再開せず、通知だけ
  出します。
- **アシスタントの用途別モデル指定** — チャット用と補助生成用に別々のモデルを指定
  できます。**おすすめ**を選ぶと、実際のカタログと接続状況から具体的なモデルが決まります。

### Improved

- OpenCode: モデル一覧を Go / Zen のカタログに合わせて絞れるようになり、失敗した
  ターンが消えずに見えるようになりました。
- モバイルの設定を、1 枚の長いシートではなく一覧から開く形にしました。

### Fixed

- **別のチャットを開くと、会話間で回答が混ざることがありました。**
- **削除ロックの状態が、再読み込みするまで Console に反映されませんでした。**
- 再提示されたプランのミラー上の承認バッジが正しくありませんでした。
- ファイル保存・復元の競合: タイムアウトした PUT がクライアント放棄後に進まないように
  し、古い読み取りが保存成功に見えないようにしました。
- 使用量台帳: 取りこぼし・書き込み阻害・二重計上を塞ぎました。

### Upgrade notes

作業はありません。自動再開は既定で on です。中断のたびに自分で判断したい場合は
Settings › Assistant で off にしてください。既存の Workspace には、設定するまで削除
ロックはありません。
