エージェントのスキルを読み取り専用で一覧できるようになり、アシスタントは利用上限やレート制限で
止まったバックエンドを避け、作業項目には新しい動きがあると印が付きます。

### 新機能

- **エージェントのスキルを読み取り専用で見られます:** 各 CLI が読むフォルダ、同じ名前が複数あるときに
  どれが使われるか、各ファイルの中身がわかります。Claude Code・Codex・OpenCode・Muse Code の個人の
  スキルは 設定 › **スキル**、リポジトリのスキル（Cursor のものも）はその行のメニューの **スキル…** にあります。
  ([#2792](https://github.com/k-k1/agent-fleet/issues/2792),
  [#2795](https://github.com/k-k1/agent-fleet/issues/2795))
- **アシスタントは利用上限やレート制限で止まったバックエンドを避けます。** 長引く制限で何も
  表示する前に失敗したチャットのターンは、優先順位で次に使えるバックエンドで実行し直し、切り替え前と
  切り替え先を示すお知らせを出します。AI 補助の単発の生成もそのバックエンドを避けます。解除が近い制限
  では切り替えず（そのターンはエラーで終わります）、制限で失敗した圧縮は別のバックエンドで再試行せず、
  メモリのレビューは別のベンダーに移りません。
  ([#2780](https://github.com/k-k1/agent-fleet/issues/2780))
- **作業項目に新しい動きが表示されます:** 前に見たあとで更新された行には点が付いてタイトルが太字になり、
  GitHub と Bitbucket の行にはコメント数が出ます。
  ([#2779](https://github.com/k-k1/agent-fleet/issues/2779))
- **設定 › マシン にワークスペースのメモリ逼迫のグラフ**が、Agent の応答時間と並んで出ます。
  測るだけで、まだ警告やセッションの停止はしません。
  ([#2516](https://github.com/k-k1/agent-fleet/issues/2516),
  [#2837](https://github.com/k-k1/agent-fleet/issues/2837))

### 改善

- **PDF ペインで検索できます:** Ctrl/Cmd+F でペイン専用の検索バーが開き、全ページ（行をまたいで
  折り返された語も含む）を検索して一致箇所を移動でき、ハイライトで語が隠れなくなりました。
  ([#2822](https://github.com/k-k1/agent-fleet/issues/2822))
- **作業項目の マージ ボタンが GitHub App でのサインインにも出ます。** GitHub がそのリポジトリへの
  書き込み権限があると答えたときです。fine-grained トークンには引き続き出ません。
  ([#2753](https://github.com/k-k1/agent-fleet/issues/2753))
- **「‹reviewer› で再レビュー」がどの端末でも出ます。** この版から始めたレビューが対象で、それより前の
  リンクは作ったブラウザにだけ出ます。
  ([#2496](https://github.com/k-k1/agent-fleet/issues/2496))
- **Agent のバックアップから復元した Claude の会話には、その旨が会話に表示されます。** 最後の部分が
  欠けていることがあるためです。
  ([#2740](https://github.com/k-k1/agent-fleet/issues/2740))

### 修正

- **打ち間違えたスラッシュコマンドのチャットの吹き出しが、claude のセッションでずっと「送信待ち」の
  ままでした。** claude の「Unknown command」の警告がチャットに出るようになりました。
  ([#2830](https://github.com/k-k1/agent-fleet/issues/2830))
- **Jira: Markdown の本文が崩れ、`issue create -P` で親が付きませんでした。** コメントと説明で、
  日本語の隣の `code` や **太字**、段落のあとのリストがそのまま表示され、新しい課題に親が付きます。
  ([#2809](https://github.com/k-k1/agent-fleet/issues/2809),
  [#2812](https://github.com/k-k1/agent-fleet/issues/2812))
- **opencode 2: エージェント指示のプレビューが空でした。** また、`/new` で作ったセッションの最初の
  ターンで、セッションの「進行中」「入力待ち」の状態が更新されませんでした。
  ([#2799](https://github.com/k-k1/agent-fleet/issues/2799),
  [#2827](https://github.com/k-k1/agent-fleet/issues/2827))
- **アシスタントのチャットで、Agent Fleet のメモリが有効でも claude 自身の自動メモリが有効のままでした。**
  ([#2488](https://github.com/k-k1/agent-fleet/issues/2488))
- **添付付きで送ったスラッシュコマンドのチップに、添付ではなく内部向けの指示が表示されていました。**
  ([#2823](https://github.com/k-k1/agent-fleet/issues/2823))
- **細かな修正:** IPv6 アドレスの Control Plane URL が通信の許可リストで拒否される、時間切れになった
  MCP の接続テストがプロセスの終了として報告される、設定の一部の見出しが上のブロックに詰まって表示される。
  ([#2754](https://github.com/k-k1/agent-fleet/issues/2754),
  [#2820](https://github.com/k-k1/agent-fleet/issues/2820),
  [#2813](https://github.com/k-k1/agent-fleet/issues/2813))
