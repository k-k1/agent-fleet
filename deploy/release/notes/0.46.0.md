Memo categories can now run their waiting memos as sessions, by a press or by themselves within
limits you set, once a tenant administrator allows it. Re-authenticating an agent keeps the current
login until the new one completes, and a quarantined ECS EC2 slot can be returned from the Console.
On ECS, read the Upgrade notes before running `update.sh`: `10-data` has to be updated first.

### New

- **Memo auto-run:** give a memo category an instruction, an agent and limits, and its waiting
  memos run as sessions, with "Run now" or by themselves at any time, in a time window or once
  enough are waiting. Memos a session adds wait for your approval, and each category has a run history,
  pause and resume, and notifications. A tenant administrator allows it under Tenant settings →
  Operations → Memo auto-run; it is blocked until then.
  ([#4148](https://github.com/k-k1/agent-fleet/issues/4148),
  [#4149](https://github.com/k-k1/agent-fleet/issues/4149))
- **Return a quarantined ECS EC2 slot from the Console:** the pool view offers the return for a
  slot held out of the pool, instead of removing its tag by hand.
  ([#4019](https://github.com/k-k1/agent-fleet/issues/4019))
- **"Not delivered" chip:** a session whose input never reached the CLI says so in the session list
  and the pane header, so you know to send it again.
  ([#4222](https://github.com/k-k1/agent-fleet/issues/4222))

### Improved

- **Re-authenticate no longer signs you out first:** for Claude, Codex, Antigravity, Cursor, Kiro
  and Muse, the current login stays in use until the new sign-in completes, so an abandoned or
  expired sign-in leaves the agent working. ([#4231](https://github.com/k-k1/agent-fleet/issues/4231))
- **Watches:** the session list and Home cards show "idle · N watches" like the mirror, a `fleet`
  watch links its session, a re-run of a finished Actions run is noticed within about a minute,
  and a Bitbucket Pipelines run waiting on a manual step is read less often while PR-triggered runs
  are labelled with their branch.
  ([#4251](https://github.com/k-k1/agent-fleet/issues/4251),
  [#4310](https://github.com/k-k1/agent-fleet/issues/4310),
  [#4147](https://github.com/k-k1/agent-fleet/issues/4147),
  [#4221](https://github.com/k-k1/agent-fleet/issues/4221))
- **Antigravity is no longer marked experimental** in Settings, the usage chip and the launch hint.
  ([#4238](https://github.com/k-k1/agent-fleet/issues/4238))
- **Copilot:** a failed turn shows its error and ends as failed instead of a normal idle, a Free
  plan account is recognised, and "Model is not available" points at the plan.
  ([#4083](https://github.com/k-k1/agent-fleet/issues/4083),
  [#4082](https://github.com/k-k1/agent-fleet/issues/4082),
  [#4128](https://github.com/k-k1/agent-fleet/issues/4128))
- **Muse:** a failed turn shows its error, with a hint when the context overflowed, and the memory
  import picks up the facts Muse keeps in `MEMORY.md`.
  ([#4102](https://github.com/k-k1/agent-fleet/issues/4102),
  [#4301](https://github.com/k-k1/agent-fleet/issues/4301))
- **Conversation search:** an archived hit opens the archive narrowed to that session, and every
  hit shows its slug and branch. ([#4158](https://github.com/k-k1/agent-fleet/issues/4158))
- **MCP servers with many OAuth scopes** list them folded behind a count.
  ([#4259](https://github.com/k-k1/agent-fleet/issues/4259))
- **Confluence:** `confluence` bolds Markdown next to Japanese and Korean text correctly.
  ([#4206](https://github.com/k-k1/agent-fleet/issues/4206))

### Upgrade notes

- **ECS: the internal Git repositories move to a file system of their own.** Up to 0.45.x they
  were on the Control Plane task's own disk and were lost on every replacement. Before
  `update.sh`, copy out the repositories that are still readable and update `10-data`, as in
  "The Control Plane's data root" in the ECS upgrade guide; `update.sh` stops until `10-data` is
  updated. ([#4089](https://github.com/k-k1/agent-fleet/issues/4089))
- **Memo auto-run stays blocked until a tenant administrator allows it.** Allow it only after every
  Control Plane and the Console run 0.46.0; members restart their workspace to get runs that start
  by themselves.
- **ECS with `EgressRoute=gateway`:** the gateway fix is in `00-network`, which `update.sh` does
  not deploy. Update `00-network` through a change set with its current parameters to get it.
