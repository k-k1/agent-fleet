画像生成のスタジオが入りました。セッションのエージェントが会話に合わせて生成の下書きを書き直し、
生成のボタンは人が押します。あわせて、セッションの削除は必ずごみ箱を通り、worktree を道連れに
しなくなりました。ほかに、削除済みセッションが残したキャッシュの掃除、Agent Fleet が使っている
ディスクの内訳、質問と peer メッセージの翻訳、PDF の文字の選択が入りました。

### New

- **画像生成のスタジオ。** 画像生成ペインの**エージェントを付ける**で、セッションを下書きに
  結びます。資料を読ませて「夕暮れの港に立たせて」、続けて「もっと暗く」と頼むと、エージェントが
  プロンプト・negative・steps・cfg・寸法・LoRA・参照画像を書き直します。生成のボタンは必ず人が
  押します。欄ごとに錠を掛けられ、編集はすべて履歴に残ってその時点へ巻き戻せます。モデル・seed・
  マスクは人だけのもので、**エージェントを替える**で下書きを保ったまま別のセッションに結び直せます。
  claude と copilot・cursor・kiro はターミナル（CLI）でだけ、opencode はマネージド以外で付けられ、
  Muse Code はまだ付けられません。
- **セッションの削除は必ずごみ箱を通り、元に戻せます。** 行・一括整理・作業コピーの削除から消した
  shell / ssm のセッションも、AI のセッションと同じくごみ箱へ入ります。**セッションを消しても
  worktree は消えなくなりました。** worktree を消すと、中の停止中のセッションはアーカイブへ移ります。
  ごみ箱のタブに **30 日より古いものを完全に削除**が付きました。ごみ箱がひとりでに空になることは
  ありません。
- **掃除ダイアログで削除済みセッションのキャッシュを片付けられます。** 貼り付けた画像と codex が
  読んだ画像のうち、もうどこからも参照されないものです。**設定 › マシン**には Agent Fleet が
  使っているディスクの内訳がフォルダのパス付きで出ます。パスを押すと左ペインのファイルで開き、
  画像のフォルダはギャラリーでも開けます。
- **質問・回答済みの質問・他のセッションからのメッセージに翻訳ボタン**が付きました。別の言語で
  届いたときに出ます。訳すのは表示だけで、回答は原文と照合されます。
- **PDF の文字を選択してコピーできます。**
- **利用ガイドに更新履歴が入りました。** 全リリースのノートとこの索引がガイドに載り、組み込みの
  アシスタントが「どの版で何が変わったか」に答えられます（新しい会話から）。

### Improved

- **1 つのセッションが同時に持てる子セッションが 10 本まで**になりました（これまでは 6 本）。
  既定の 3 本は変わりません。
- **設定 › 通知 › 子セッションの入力待ちを通知**をオフにできます。子からの質問と許可の要求は
  オフでも通知します。
- **思考ブロックが場所を取らなくなりました。** 畳むと 1 行のプレビューになり、下の「閉じる」は
  長いときだけ出ます。
- **貼り付けた画像のチップを押すとライトボックスで開きます。** ミラーのコンポーザと起動ダイアログの
  両方です。
- **左ペインの長いファイル名は中央で省略されます。** 拡張子と名前の末尾が残り、ツールチップに
  フルパスが出ます。

### Fixed

- **Antigravity のフリート・オペレーターと SRE アシスタントが「no response from agy」を返していました。**
  モデルがコマンドを試したり参考資料を読んだりしたときです。いまは答えが返り、断られたコマンドは
  文章で断ります。agy が失敗したときは理由が出ます。
- **サムネイルのキャッシュのフォルダをギャラリーで開くと、サムネイルのサムネイルが作られ続けていました。**
