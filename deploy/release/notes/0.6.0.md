**Docker Compose installs change in this release: the container images are pulled from
GHCR instead of being loaded from an image tarball.**

### Breaking changes (Docker Compose edition only)

- **Images now come from a registry.** Releases no longer carry
  `agent-fleet-images-<version>.tar.gz`; the control-plane and workspace images are
  published to GHCR. Installing goes from "download the tar → `load-images.sh`" to
  `docker compose pull`. No registry login is needed — the packages are public.

  Upgrading an existing deployment: set `REGISTRY=ghcr.io/k-k1/agent-fleet` and
  `VERSION=0.6.0` in your `.env`, point `WS_IMAGE` at
  `ghcr.io/k-k1/agent-fleet/workspace:0.6.0`, then `docker compose pull` and
  `docker pull "$WS_IMAGE"` in place of the old `load-images.sh` step. Your data,
  `AF_MASTER_KEY` and every other setting are untouched.

  A host that cannot reach a registry has two supported paths: mirror the two images
  into an internal registry and point `REGISTRY` at it, or build and export them
  yourself with `deploy/compose/release.sh --save` and keep using `load-images.sh`.
  Both stay in the bundle.

- **The native edition and the AWS/ECS path are unaffected.**

### New

- **Hand a browser page to a human.** When an agent is driving a headless Chromium in
  your workspace, it can pass that live page to you: it opens in a Console pane and you
  click, scroll and type in it (Japanese IME included) before handing it back.
  Detaching closes only the Console's view. The agent never performs the final publish,
  send or consent click for you — that hand-off is the point.
- **Show reasoning expanded, per agent kind** — Settings › Agents › (each card) ›
  behaviour. Off by default.

### Improved

- **The Console speaks your display language.** With the display language set to
  English, the built-in assistants answer in English rather than Japanese, and reply
  suggestions, compaction handoffs and work plans follow it too. Personas are
  snapshotted per conversation, so switching applies to new ones and leaves open
  threads alone.
- **Completion reports are readable in either language.** The card states the facts in
  your display language, and no longer shows model-facing text.
- Pinned CLI versions: Claude Code 2.1.220, Codex 0.146.0, OpenCode 1.18.11, GitHub
  Copilot 1.0.77, Antigravity 1.1.9, Cursor 2026.07.23, Kiro 2.16.0, rtk 0.44.2.

### Fixed

- **The usage chip in the workspace bar could freeze for a day.** Claude's status line
  was re-wrapped on every run from a different path until it grew too large to execute
  and usage capture silently stopped. Existing broken configurations repair themselves
  on next start.

### Upgrade notes

**Compose deployments must switch to registry pulls** — see the breaking-changes
section above for the exact `.env` edits; the "Air-gapped install" section of the
bundled runbook covers hosts with no registry access. Native installs update with the
usual one-liner.
