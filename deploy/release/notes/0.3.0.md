Kiro joins the agent CLI lineup, the composer gains reply suggestions, and the
fleet operator can now answer questions and review plans on your behalf.

### New

- **Kiro CLI support (`kind=kiro`)** — Kiro joins the lineup, bringing the total
  to seven agent CLIs. Both execution methods are supported (Terminal/TUI and
  Managed via `kiro-cli acp`), the CLI is installed on demand against a
  sha256-pinned version, live context and credit usage show up in the mirror and
  in session usage, and the connection card offers an opt-in control when a newer
  pinned version is available.
- **Reply suggestions** — the composer now offers tappable reply chips, in both
  the session mirror and assistant chat. Candidates come from two sources:
  learned quick replies re-ranked against the latest agent message, and an
  on-demand ✨ button that generates context-aware candidates with the LLM. They
  are fully keyboard-driven (Tab to focus, ←/→ to pick, Enter to insert,
  Ctrl+Enter to send), Ctrl+click sends immediately, and on narrow screens they
  stay on a single horizontally scrollable row.
- **Fleet operator: answering questions and reviewing plans** — the operator can
  now answer a session's pending question (`answer_session_question`), report
  interim progress without consuming that question, and approve or reject a plan
  (`respond_session_plan`). A new autopilot mode drives a session through the
  plan-review loop unattended; the automatic reply cap is configurable (default
  10, max 50). Plans are linked to their session rather than transcribed into the
  conversation.
- **Scheduled execution: assistant firing and provenance** — a schedule can fire
  into an operator conversation (`session_mode=assistant`) instead of a session,
  user turns carry a badge that distinguishes a scheduled run from a manual one,
  and delivery is now confirmed against evidence that a turn actually started, so
  runs are no longer reported as fired when they were not.
- **Memo queue: category hierarchy** — memos are grouped under collapsible
  category sections, and Ctrl+K M focuses the text area as the modal opens.
- **Host update prompt (native)** — when a newer host build has been staged, the
  top bar surfaces it next to the build indicator instead of leaving it to be
  discovered in settings.

### Improved

- **Agent CLI self-update now actually advances.** Updates are applied to the
  effective `PATH` prefix, and every tool moved to a single shadow model: the
  baked `/usr/local` pin stays immutable, and turning self-update off reverts to
  it immediately. OpenCode's own background auto-updater is stopped.
- Usage: Opus 5 / Sonnet 5 are recognised as 1M-context models — the
  context-window estimate now treats 200k as the exception rather than the rule.
- Lean images show their pinned version in parentheses instead of `—`.
- Mobile: agent selection is a horizontal swipe, and the send-key preference is
  honoured inside modals.
- Agent CLI version pins refreshed to the latest contract-verified combination.
- The assistant's "copy ID" action copies the conversation slug, which is now
  shown in the menu.

### Fixed

- Completion reports could be lost when a background subagent was still running
  and the session stopped early; the report is now held and delivered afterwards.
- Mirror: an entire user turn could disappear when a skill emitted its command
  tags in reverse order. Codex 0.145's changed plan rendering is followed.
- The launch-default normaliser dropped `copilot`.
- Deleting a worktree or session that an active schedule still references is now
  refused instead of silently breaking the schedule.
- Kiro follow-ups from review: session-id fencing, an approval-wait guard,
  crash-safe install, cross-process locking, and more robust resume/switch on the
  managed driver.

### Other changes

- **Licensing and attribution are now stated where you receive the software.** The
  distribution repo carries `LICENSE` and `NOTICE`, the READMEs state that Agent
  Fleet is Apache-2.0, and `NOTICE` names this repo as the primary distribution — so
  anyone who passes a copy on can point recipients back to the original, as
  Apache-2.0 §4(d) asks.
- **Releases have real release notes from now on**, including for every earlier
  version — indexed in [CHANGELOG.md](CHANGELOG.md).

### Upgrade notes

No migration or configuration change is required. If you pin agent CLI versions,
note that the bundled pins moved forward; `AF_VERSION` and the self-update opt-out
behave as before.
