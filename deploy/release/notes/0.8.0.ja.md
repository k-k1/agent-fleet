セッションの会話を同じテナントの他のメンバーへ読み取り専用で見せられるようになり、
過去の発言から会話をそのまま引き継いだ新しいセッションへ分岐できるようになりました。
メイン領域は分割ペインに加えてタブ付きグリッドで並べられ、セッション同士はあなたを
経由せずに一行のメッセージを送り合えます。

### 新機能

- **会話を他のメンバーへ共有する（共有セッション）。** 「この調査がどこへ行くか見て
  おいて」「レビューする前に、ここまでの経緯を見て」— セッションの会話を、同じテナントの
  他のメンバーが**読み取り専用**で開けるようになりました。セッション行かリポジトリ行の
  **⋯** メニューから共有し、対象は3種類から選びます。**セッション**単体、**WT**（1つの
  worktree）、そして**プロジェクト**（基点の作業コピー＋その下の worktree にいる
  セッション。セッションごとに worktree を分けているなら、たいていこれです）。相手は
  メールアドレスの検索で選び、権限は**閲覧のみ**か**提案可**（相手が送る内容を作れますが、
  **あなたが承認するまでエージェントには届きません**）です。共有された会話は相手の左ペインの
  **共有セッション**に、所有者とプロジェクトごとにまとまって並びます。表示は自分のミラーと
  同等で、状態バッジ・Edit/Write のインライン差分・「最新へ」ピルまで揃っており、面の色は
  設定 › 表示で別に選べます（他人の会話を読んでいる面が自分の面と同じ色に見えないように）。
  **共有すると会話は丸ごと見えます** — あなたのプロンプト、エージェントの返答、ツールの
  出力まで。紛れ込んだ秘密情報は検出されませんし、共有を解除しても相手が既に保存した控えは
  取り戻せません。
- **セッション間メッセージ。** 同じワークスペースの別のセッションへ、短いメッセージを
  1本送れます。「いま develop を rebase した。そちらの `api.ts` は先に取り込んで」や、
  相手が待っていた判断の答えを渡す、といった用途です。**設定 › エージェント ›
  セッション**で有効にします。**既定はオフ**で、反映は次に起動するセッションからです。
  Claude Code に内蔵の同種機能（有効化すると Claude 側の利用統計送信も戻る作りのため、
  Agent Fleet では無効のままにしています）と違い、**エージェントの種類をまたいで**
  届きます — claude から codex、opencode から cursor など、claude / codex / opencode /
  cursor / kiro / agy / copilot のどの組み合わせでも通ります。**停止中のセッション**にも
  届き、その場合は相手を再開してから配達します。送りっぱなしではなく、配達できたことを
  確認します。

  できないこと: 渡るのは平文だけで、会話履歴もファイルも渡りません。文脈ごと渡すのは
  従来どおり引き継ぎか分岐です。受け取った側には「あなたからの指示ではない」と明示され、
  権限の確認ダイアログへの承認代わりにはならず、設定を書き換える理由にもなりません。
  本文中のコマンドはただの文字列として届きます。生シェル（shell / ssm）のセッションは、
  送られた文字列がそのまま実行されてしまうため送受信とも対象外です。届いたメッセージには
  送信元のバッジが付くので、あなたが打った入力と混ざりません。
- **過去の発言から分岐する。** 自分の過去の発言にカーソルを合わせると
  **「ここから分岐」**が出て、そこまでの会話を引き継いだ**新しいセッション**が始まります
  （元のセッションはそのまま残ります）。方式は2つ。**この発言をやり直す**はその発言自体を
  含めず、あなたの元の文面を下書きとして入力欄に戻します。**この発言の続きから**は発言と
  その返答まで引き継ぎます。要約して渡す引き継ぎでは落ちてしまう「言い回しそのもの」が
  効いている場面向けです。対応は claude / codex / opencode / GitHub Copilot のセッション
  （codex と opencode は**マネージド**実行のみ。CLI の起動コマンドには分岐点を渡す口が
  ありません）。
- **タブ付きグリッドレイアウト。** メイン領域を分割ではなく**タブ**でセルごとに切り替えられる
  ようになりました（上部バーの**外観**ポップ、または設定 › 表示 ›「メイン領域のレイアウト」から
  選べます）。タブはドラッグで並べ替え、
  セルの端に落とせば分割、あふれたら横スクロール、狭いときは押し出さずに最小幅まで縮みます。
  セッションのタブには**状態バッジ**が付くので、選ぶ前に作業中か入力待ちかが分かります。
  設定は端末ごとに保存され、2つのレイアウトは別々に記憶されるので、行き来してもどちらも
  崩れません。
- **自分用の指示を全エージェントへ。** 設定 › **エージェント指示**に書いた内容が、以後この
  ワークスペースで起動する全エージェントの指示に足されます — 報告の言語や口調、事前に確認して
  ほしい場面、優先してほしいツールなど。フリート全体の方針（オペレーターのもの。衝突したら
  そちらが勝ちます）とリポジトリにコミットされた `CLAUDE.md` / `AGENTS.md` の**中間**の層で、
  どこにもコミットされません。配れるのは claude / codex / opencode / GitHub Copilot / agy /
  Kiro で、**受け取れないのは Cursor だけ**（理由付きで一覧に出ます）。行ごとに、どのファイルへ
  書いたか・実際に効いているかが分かります。
- **リポジトリがコミットしている MCP サーバーを見る。** リポジトリ行のメニューから開く
  **プロジェクト設定**に、リポジトリへコミットされた MCP 定義（`.mcp.json` とエージェント別の
  相当ファイル）がエージェント別の状態と警告付きで並びます — 既に Git に入っている秘密情報、
  名前の衝突、ファイル同士の食い違い。エントリを**別のエージェントのファイルへコピー**でき
  （方言変換・衝突時の扱い・書き込み前のプレビュー付き。値はマスクできます）、コミットすべき
  でなかったファイルは**Git の無視設定へ追加**できます。
- **ブラウザペインがタッチ操作に対応。** タブレットでは、スワイプでスクロール（指を離しても
  滑ります）、タップでクリック、長押しでドラッグ、2本指のピンチでズームできます。ピンチは
  絵を引き伸ばすのではなく**狭い幅でページを組み直す**ので文字は読める大きさのままで、
  **ダブルタップ**で幅に合わせる表示と等倍を行き来します。タップでキーボードは**出ません**
  （リンクやボタンを押すたびに出てしまうため）。入力するときはペイン左下のキーボードボタンを
  使います。
- **渡されたページの中でタブを切り替えられる。** エージェントのスクリプトが複数の Chromium
  タブを操作している場合に、ペインを閉じて再依頼して新しいリンクを開く、を繰り返さなくても、
  同じペインのまま別のタブへ向け直せるようになりました（Retarget）。
- **渡されたページでの操作結果がセッションへ届く。** ブラウザのハンドオフを完了／キャンセル
  しても Console 側が更新されるだけで、依頼したエージェントは何も起きていないかのように
  待ち続けていました。結果は会話へ配達されるようになり（停止していたセッションは再開して
  から配達）、配達直前に Agent が落ちた場合も起動時に拾い直します。
- **Codex のスクリーンショットがミラーに映る。** Codex が `view_image` で撮った画像が、
  見られないパス文字列ではなく会話の中に描画されます。
- **OpenCode のプロバイダに Sakana AI を追加。** 設定 › エージェント › OpenCode で、
  OpenCode Go / Anthropic / OpenAI / OpenRouter / Gemini と並んで選べます
  （`SAKANA_API_KEY`・Fugu / Fugu Ultra）。
- **リポジトリの停止中セッションを一括アーカイブ。** 左ペインのリポジトリ行を右クリックすると、
  AI のセッションはアーカイブ、shell / SSM は削除します（掃除モーダルの①と同じ振り分け）。
  対象はそのフォルダ直下のセッションで、worktree は別フォルダ扱いなので親の一括操作には
  含まれません。
- **Markdown のコードブロックが既定で折り返します。** 長い行を折り返す手段はブロックごとの
  トグルだけで、しかも保存されませんでした。設定（設定 › 表示）になり、既定はオンです。

### 改善

- **共有された会話の読み込みが大幅に速くなりました。** 履歴表示がポーリングのたびに在庫を
  丸ごと同期するのをやめ、応答も圧縮するようにしました（認可は毎回とおします）。
- **アシスタントを明示的にオフにできます。** 設定 › アシスタントの「使う枠」に4つ目の
  **オフ**が入りました。後から API キーや OAuth サインインが増えても override し続ける
  ハードロックで、既定の「未接続なら実質オフ」では約束できなかった無効化です。
- **セッション間メッセージが 16 KiB まで**送れます（従来 4 KiB）。スタックトレースや差分の
  抜粋がそのまま載ります。
- **コントロールプレーンを複数レプリカで動かしても競合しません。** ワークスペースの
  ライフサイクル操作を advisory lock とリースで fence し、リースを失ったレプリカが他の
  レプリカの持つランタイムへ触れないようにしました。ワークスペースの活動はレプリカ間で共有し、
  アイドル停止の reaper も同じ fence に入って待機後にアイドル状態を検証し直します。
  取り残された停止 intent は次の起動で回収します。
- **変更一覧の未追跡ファイル**も、追跡済みと同じようにクリックでファイルビューが開きます。
- **確認ダイアログの初期フォーカスが確認ボタン**になり、停止や削除をキーボードだけで
  確定できます。
- **組み込みの Agent Fleet MCP サーバーが起動ごとに名前を取り直します。** リポジトリが
  `af` と同名のサーバーをコミットしていると、claude 以外の全エージェントでそちらが勝ち、
  そのリポジトリのセッションで自己申告・引き継ぎ提案・Chromium のハンドオフが黙って
  死んでいました。変わるのは設定ファイルのキーだけで、ツール名はそのままです。
- **利用者ガイドに設定の章を新設し、トラブルシューティングを大幅に拡充**しました（設定
  ダイアログの全タブ、バッジとメニューの表、エディタ、git、オペレーター画面）。配布物の
  README も現行の機能に合わせています。
- ピン止め CLI: Claude Code 2.1.231 / Codex 0.147.0 / OpenCode 1.18.18 / GitHub Copilot
  1.0.79 / Antigravity 1.1.12 / Cursor 2026.08.11 / Kiro 2.18.0 / rtk 0.45.0。周辺ツール:
  gh 2.97.0 / Go 1.26.5 / AWS CLI 2.36.22 / mcp-grafana 1.1.0 / CloudWatch MCP 0.1.8、
  および Chromium のセキュリティビルド（従来のピンがアーカイブから消え、ワークスペース
  イメージのビルドが壊れていました）。

### 修正

- **渡されたブラウザページで、クリックもキーもスクロールも全部捨てられていました。**
  接続直後は view-only で、ペインが送る入力をエージェント側が黙って拒否していたためです
  （絵は動いているのに何をしても効かず、エラーも出ない）。ハンドオフしたページは意図どおり
  操作できる状態で渡るようになりました。同じ周辺で: ハンドオフのリンクがどこにも繋がらない、
  固定ポートのせいで別セッションのブラウザへ繋がりうる（空きポートを取り、ブラウザの同一性を
  検証するようにしました）、幅に合わせる表示が効かない、ドラッグとコピー／ペーストができない、
  背面タブはフレームが来ない（前面化してから開始）、screencast の初回フレームがレースで
  失われる、未閲覧リンクの期限が10分（30分へ延長・環境変数で調整可）— も直しました。
- **タブを切り替えても前のセッションの端末が映り続けました。** 1セル1コンポーネントの作りで
  コンテナを使い回すため、前のセッションの端末が新しいタブの上に残っていました。
- **別タブへ切り離したペインが WebGL コンテキストを返さず**、開閉を繰り返すと最終的に描画が
  壊れていました。
- **Codex の複数質問で、他の質問の回答が混入しました**（先頭の質問の自由入力欄へ貼られる）。
- **Codex へキャプション付きで画像を送ると反映待ちが固着しました**（キャプション側の閉じ
  マーカーを剥がしていなかったため）。画像だけを送ったターンが後から transcript から消える
  問題も直しました。
- **送信を続けて2回押すと入力欄が固着しました。** 二重発火がレースになり、ターンが
  「反映待ち」のまま戻らなくなっていました。
- **引き継ぎ提案が最後の1件しか残りませんでした。** 複数回提案すると前のものが上書きされて
  いました。
- **スラッシュコマンド実行中のセッションがアイドルと判定されました。** CLI がスラッシュ
  コマンドで使う表示形をスピナー判定が取りこぼし、作業中なのに終わったように見えていました。
- **プラン承認中や選択肢の質問中に、状態バッジが「許可待ち」に化けました**（一時的な state を
  見ていたため。payload を正とするようにしました）。
- **届かなかったプランへのコメントが「送信済み」になっていました。**
- **何も接続していないのにアシスタントが OpenCode の無料枠へ落ちていました。** チャットの
  バックエンド選定がバイナリの有無しか見ておらず、認証情報を一切設定していない環境でも無断で
  無料モデルを使っていました（テナントによってはポリシー上許容できません）。対話セッションの
  起動ゲートと同じ接続判定に統一しました。
- **共有先の一覧に古いアーカイブしか並びませんでした。** リポジトリの共有が基点の作業コピー
  直下だけを対象にしており、さらにアーカイブ済みも並んでいたため、開いても「今の会話」が
  無い状態でした。リポジトリ共有はプロジェクト全体を指すようにし、アーカイブは非表示、
  worktree はブランチ名で見分けられるようにし、ツリーは折りたためます。
- **完全一致のモデル ID が曖昧と判定されることがありました**（別の ID がそれを接頭辞に持つ
  場合）。角括弧を含む Claude のモデル ID も受け付けます。
- **Codex のスレッド単位の設定は「置換」ではなくマージでした。** そのため Codex セッションで
  プロジェクトスコープの MCP サーバーが誤って報告されていました。
- **軽量プレビューがサブリクエストでテナントを解決できず**、何かを取得するページが壊れて
  表示されていました。
- **YAML として無効な front matter** は捨てずに `key: 値` の行として読みます。
- 表示の修正: ダークモードで Markdown の引用が暗すぎて読めない、別タブ／閉じるボタンがタブ帯に
  あってビューのヘッダー行に無い、タブ付きグリッドでミラー右上のボタンが中央寄りに浮く、
  アシスタントチャットのヘッダで状態チップと作業計画が行の中央に取り残される、外観ポップで
  11 個の色見本が2段に折り返して面ごとの段の切れ目が分からなくなる。

### アップグレード時の注意

移行作業はありません（共有セッション用のテーブルは起動時に適用されます）。共有は実際に
共有を作るまで何も起きず、セッション間メッセージは設定 › エージェント › セッションで有効に
するまでオフのままです（どちらも反映は以後に起動するセッションから）。Markdown のコード
ブロックは既定で折り返すようになったので、横スクロールのほうがよければ設定 › 表示で戻して
ください。エージェント指示は空の状態から始まります。compose 版は従来どおり新しいイメージを
pull し、native 版はワンライナーで更新します。新しくピン止めしたエージェント CLI を取り込むには
ワークスペースの Stop → Start が必要です。
