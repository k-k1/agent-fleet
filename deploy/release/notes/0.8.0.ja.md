セッションの会話を同じテナントの他のメンバーに見せられるようになり、過去の発言
時点から会話ごと分岐した新しいセッションを作れるようになりました。メイン領域は
分割だけでなくタブのグリッドにもでき、セッション同士が人を介さず一言メッセージを
送れるようになりました。

### New

- **会話を他のメンバーに共有。** セッションまたはリポジトリ行の ⋯ メニューから、
  セッション 1 つ・worktree 1 つ・プロジェクト全体のいずれかを、同じテナントの相手に
  共有できます。権限は**閲覧のみ**と**提案可**（相手が書いたものは、あなたが承認する
  までエージェントに届きません）。共有された会話は相手の左ペインの *Shared sessions*
  に出て、描画は自分のミラーと同じ、色は別に設定できます。**共有すると会話全体が
  見えます** — あなたのプロンプト、エージェントの返信、ツールの出力です。含まれる秘匿
  情報は自動検出されませんし、共有を解除しても相手が保存したコピーは取り戻せません。
- **セッション間メッセージ。** 同じ Workspace の別セッションへ短いメッセージを 1 通
  送れます。種別を跨いで届き、停止中のセッションは再開して受け取ります。既定は off で
  Settings › Agents › Session にあり、以後に起動したセッションに効きます。運べるのは
  平文だけで、会話履歴もファイルも運びません。受け取ったエージェントには「利用者からの
  ものではない」と伝わるので、許可要求の承認としては読めません。shell / SSM セッションは
  送受信できません。
- **過去の発言から分岐。** 自分の過去の発言にホバーすると**ここから分岐**が出て、その
  時点までの会話を持った新しいセッションが始まります。その発言をやり直す（元の文面が
  入力欄に戻ります）か、その先を続けるかを選べます。今のセッションはそのまま残ります。
  claude・codex・opencode・GitHub Copilot で使えます。
- **タブのグリッドレイアウト。** メイン領域の各セルを、分割ではなくタブで切り替えられ
  ます。タブはドラッグで並べ替えられ、セルの端に落とせば分割になり、状態バッジが付く
  ので選ぶ前にどれが動いているか分かります。端末ごとに保存され、分割との 2 つの
  レイアウトは別々に記憶されます。
- **全エージェントへの自分の常設指示。** Settings › *エージェント指示* に書いたものが、
  以後この Workspace で起動する全エージェントに足されます。fleet 全体の Workspace
  ガイドと、リポジトリにコミットされた `CLAUDE.md` / `AGENTS.md` の間に位置し、どこにも
  コミットされません。受け取れないのは Cursor だけで、その理由を表示します。
- **リポジトリがコミットしている MCP サーバーを確認。** リポジトリ行の*プロジェクト
  設定*に、リポジトリ内の定義がエージェント別の状態と警告付きで並びます（Git に入って
  いる秘密、名前の衝突、食い違うファイル）。別のエージェントのファイルへ複写したり、
  Git の無視リストへ加えたりできます。
- **ブラウザペインがタッチに対応しました** — スワイプでスクロール、長押しでドラッグ、
  ピンチはページを狭い幅で組み直すので文字が読めるままです。
- **エージェントから渡されたページ内でタブを切り替え**られるようになり（*Retarget*）、
  **そこでの操作結果がセッションに届く**ようになりました（以前は Console だけが
  更新されていました）。
- **Codex のスクリーンショットがミラーに表示されます**（見られないパスの代わりに）。
- **Sakana AI を OpenCode のプロバイダプリセットとして追加。**
- **リポジトリの停止中セッションを一括アーカイブ**できます（左ペインの行から）。
- **Markdown のコードブロックが既定で折り返します**（Settings › Display）。

### Improved

- **共有された会話の表示が大幅に速くなりました** — ポーリングのたびに全体を取り直す
  のをやめ、応答を圧縮しました。認可は毎リクエスト検査したままです。
- **アシスタントを完全に off にできます** — 後から API キーや OAuth サインインが現れて
  も上書きし続ける固定です。
- **Control Plane を複数レプリカで動かしても競合に耐えます。** Workspace のライフ
  サイクル操作をロックとリースで囲いました。
- **内蔵の Agent Fleet MCP サーバーは起動ごとに新しい名前を取ります。** `af` という
  サーバーをコミットしたリポジトリがその座を奪い、そのリポジトリの全セッションで
  自己報告を殺す、ということが起きなくなりました。
- **メンバーガイドに設定の章と、大幅に増補したトラブルシューティングの章が加わりました**
  （設定ダイアログの全タブ・エディタ・git を網羅）。
- セッション間メッセージは 16 KiB まで（スタックトレースが載ります）。確認ダイアログは
  確定ボタンにフォーカスします。変更一覧の未追跡ファイルもクリックでファイル表示が
  開きます。
- CLI の固定版: Claude Code 2.1.231、Codex 0.147.0、OpenCode 1.18.18、GitHub Copilot
  1.0.79、Antigravity 1.1.12、Cursor 2026.08.11、Kiro 2.18.0、rtk 0.45.0。

### Fixed

- **渡されたブラウザページでのクリック・キー・スクロールが、すべて捨てられていました。**
  接続は閲覧のみで始まるのに、ペインは入力を送り、エージェント側が黙って拒否していた
  ため——生きた映像なのに何をしても効かず、エラーも出ませんでした。同じ領域で、渡された
  リンクがどこも指さないことがある・固定ポートのせいで別セッションのブラウザに繋がる・
  幅に合わせるが効かない・ドラッグとコピー／貼り付けができない、も直しました。
- **タブを切り替えても、前に選んでいたタブのターミナルが映り続けていました。**
- **複数質問のプロンプトで Codex が違う質問に答えていました。** 画像にキャプションを
  付けて送ると入力欄が「表示待ち」で固まる問題も直しました。
- **送信を素早く 2 回押すと入力欄が固まりました。**
- **スラッシュコマンド実行中のセッションが idle と判定され**、まだ動いているのに終わって
  見えていました。
- **エージェントが引き継ぎ提案を複数出すと、最後の 1 つしか残りませんでした。**
- **共有一覧に古いアーカイブしか出ませんでした** — リポジトリ共有が基底の作業コピー直下
  のセッションしか含まず、しかもアーカイブ済みが並んでいました。
- **何も接続されていないのに、アシスタントが OpenCode の無料枠へ落ちていました**
  （テナントによっては方針上許されません）。
- **プラン承認や選択式の質問の最中に、状態バッジが「許可待ち」になっていました。**
  配送されなかったプランへのコメントが送信済みと表示される問題も直しました。
- **軽量プレビューが下位リクエストでテナントを解決できず**、何かを取得するページが
  壊れて表示されていました。
- 表示の修正: 暗色で引用 Markdown が暗すぎる、ペインのボタンがビューヘッダではなく
  タブ列に出る、外観ポップオーバーの色見本が 2 行に折り返す。
- 切り離したペインが WebGL コンテキストを漏らす、完全一致のモデル ID が曖昧と判定される、
  Codex の thread 設定が置換ではなくマージされる、YAML として不正な front matter が
  捨てられる、も直しました。

### Upgrade notes

移行作業はありません（共有セッション用のテーブルは起動時に適用されます）。共有は作る
まで何もせず、セッション間メッセージは有効にするまで off です。どちらも以後に起動した
セッションに効きます。Markdown のコードブロックは既定で折り返すようになりました。
新しい CLI の固定版を反映するには Workspace の Stop → Start が必要です。
