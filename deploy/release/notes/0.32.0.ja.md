セッションを、会話と作業の状態ごと別のエージェントへ移せるようになり、利用上限に達したときにはその移動を勧めます。
Google でサインインするアプリがプレビュー用ホストで開発用ログインを使えるようになり、ワークスペースには Jira CLI が
同梱され、opencode は opencode 2 になりました。エージェントメモリには、終わったセッションからメモリを提案する
実験的なレビューが加わり、Agent Fleet の外のエージェントからも使えるようになりました。

### 新機能

- **セッションを別のエージェントへ移す。** セッションメニューの **別のエージェントへ移す…** で、同じ作業コピーに
  別の種類のセッションを作り、会話・未コミットの変更・残っている作業をまとめた引き継ぎファイルを渡します。
  セッションが利用上限に達すると、会話の上に移動を勧める帯が出て、残りのあるエージェントから順に並べます。
  ([#2182](https://github.com/k-k1/agent-fleet/issues/2182),
  [#2254](https://github.com/k-k1/agent-fleet/issues/2254))
- **会話を Markdown で書き出す**: セッションメニューから、会話のみ・ツール名つき・ツールの出力つきを選べます。
  シークレットは伏せられます。
  ([#2183](https://github.com/k-k1/agent-fleet/issues/2183),
  [#2202](https://github.com/k-k1/agent-fleet/issues/2202))
- **プレビュー用ホストのアプリ向けの開発用ログイン。** Google でサインインするアプリが、発行者（issuer）・
  クライアント ID・シークレットを差し替えるだけで Agent Fleet のアカウントでサインインできます。値は
  `AF_DEV_IDP_*` として各ワークスペースに渡ります。設定 › プレビュー用サブドメインで発行者とクライアント ID
  （シークレットはワークスペース内の `AF_DEV_IDP_CLIENT_SECRET` にあり、画面には出ません）と、Spring Boot・Auth.js・
  Go・Better Auth 向けのそのまま使える設定例を確認でき、サインインに使うテスト用ペルソナも定義できます。
  プレビュー用サブドメインが必要です。アップグレードの注意も見てください。
  ([#2218](https://github.com/k-k1/agent-fleet/issues/2218),
  [#2222](https://github.com/k-k1/agent-fleet/issues/2222),
  [#2223](https://github.com/k-k1/agent-fleet/issues/2223),
  [#2228](https://github.com/k-k1/agent-fleet/issues/2228),
  [#2304](https://github.com/k-k1/agent-fleet/issues/2304))
- **Jira CLI `jira` をワークスペースのイメージに同梱しました。** Jira 接続（API トークンでも OAuth でも）で
  サインインし、どのエージェントからも使えます。
  ([#2178](https://github.com/k-k1/agent-fleet/issues/2178))
- **終わったセッションからのメモリの提案（実験的）。** **終わったセッションからメモリを提案させる**
  （設定 › エージェントメモリ › 設定、既定はオフ）をオンにすると、しばらく止まっているセッションをツールを持たない
  補助エージェントが読み、残す価値のありそうなメモリを提案します（セッションメニューの
  **メモリを提案させる（今すぐ）** でその場でも実行できます）。エージェントメモリ › 変更 › **提案** で承認するまで
  何も保存されず、会話の抜粋は AI 補助で選んだプロバイダーに送られてトークンを消費します。初期版のため、
  何をどう提案するかは今後変わることがあります。
  ([#1559](https://github.com/k-k1/agent-fleet/issues/1559),
  [#2320](https://github.com/k-k1/agent-fleet/issues/2320),
  [#2321](https://github.com/k-k1/agent-fleet/issues/2321))
- **Agent Fleet の外からエージェントメモリを使う。** 手元の Claude Code や Claude Desktop から、個人アクセス
  トークンで `/mcp` エンドポイントを通して、ワークスペースの Agent Fleet メモリを読めます（許可すれば書き込みも）。
  既定はオフで、設定 › エージェントメモリでオンにします。
  ([#1988](https://github.com/k-k1/agent-fleet/issues/1988),
  [#2329](https://github.com/k-k1/agent-fleet/issues/2329))

### 改善

- **opencode が opencode 2 になりました。** イメージのピンが opencode 1.19.0 から 2.0.32 に変わります。
  マネージド・ターミナル（CLI）のどちらのセッションも opencode 2 を使い、メンバー向けガイドも opencode 2 の
  動きを前提に書き換わりました。opencode 2 は `AGENTS.md` だけを読み（`CLAUDE.md` には切り替えません）、
  ToDo リストはありません。オプトイン（`opencode-major 2`）を試していたワークスペースは、ピン止めされた版を
  そのまま使います。`install-opencode2` と `opencode-major` はその旨を表示するだけで、何も変更しません。
  ([#2105](https://github.com/k-k1/agent-fleet/issues/2105),
  [#2134](https://github.com/k-k1/agent-fleet/issues/2134),
  [#2133](https://github.com/k-k1/agent-fleet/issues/2133))
- **設定 › エージェントメモリを整理しました。** エージェントメモリとメモリのスナップショットを別の項目に分け、
  メモリは一覧と詳細を並べて表示し、取り込みと書き出しは **取り込み・書き出し** の 1 ページから始めます。
  スナップショットの履歴では、Agent Fleet メモリへの書き込みを既定で隠します。
  ([#2324](https://github.com/k-k1/agent-fleet/issues/2324))
- **修正した計画を、同じレビュー役のセッションで再レビューできます。** 止まった claude セッションに持ち越された
  計画も、別のセッションでレビューできます。
  ([#2219](https://github.com/k-k1/agent-fleet/issues/2219),
  [#2211](https://github.com/k-k1/agent-fleet/issues/2211))
- **Claude のログイン切れ**は、アシスタントのチャットでも生のエラーでなく **再認証** と **再試行** を出し、
  再認証は設定の該当エージェントのカードを開きます。
  ([#2180](https://github.com/k-k1/agent-fleet/issues/2180),
  [#2177](https://github.com/k-k1/agent-fleet/issues/2177))
- **別の claude プロセスがロックを握っていてログインの更新をあきらめたとき**、claude がすぐ再開するようになりました。
  ([#2231](https://github.com/k-k1/agent-fleet/issues/2231))
- **アイドルのワークスペースが確実に止まるようになりました。** アイドルのセッションが始めたバックグラウンド作業
  （開発サーバーなど）がワークスペースを起こしておくのは最長 2 時間（テナントの上限 `background_hold_max`）になり、
  マネージドの cursor・kiro・codex・opencode のターンも、1 時間動きが見えなければワークスペースを起こし続けなくなりました。
  ツールが実行中のときや、Agent が様子を確かめられないときは、これまでどおり起こしておきます。
  ([#2338](https://github.com/k-k1/agent-fleet/issues/2338),
  [#1942](https://github.com/k-k1/agent-fleet/issues/1942))
- **kiro のターミナルセッションが承認待ちをより確実に伝え**、**cursor のターミナルセッションがターンごとのトークン使用量を記録**するようになりました。
  ([#2285](https://github.com/k-k1/agent-fleet/issues/2285),
  [#2286](https://github.com/k-k1/agent-fleet/issues/2286))
- **セッションメニューを区切りごとにまとめました。**
  ([#2189](https://github.com/k-k1/agent-fleet/issues/2189))
- **タイトル提案などの補助呼び出しを claude で動かすとき、あなたの MCP サーバーを起動しなくなりました。**
  ([#2334](https://github.com/k-k1/agent-fleet/issues/2334))

### アップグレードの注意

- **開発用ログインは既定でオンです。** プレビュー用サブドメインと `PUBLIC_BASE_URL` が設定されている環境では
  有効になります。スーパー管理者はAdmin モーダルの **開発用ログイン** でオフにでき、`AF_DEV_IDP=0` で
  オフに固定できます。本番のアプリにこの発行者を信頼させてはいけません。
- **バックグラウンド作業がワークスペースを起こしておくのは 2 時間までになりました。** アイドルのセッションで
  長時間のバックグラウンド作業を走らせる使い方があるなら、テナントの上限 `background_hold_max`（`0` で無制限）を
  上げるか、`AF_BACKGROUND_HOLD_MAX` を設定してください。
- **opencode の会話は引き継がれます。** このリリースでの最初の opencode 2 起動時に、opencode のデータベース
  （`~/.local/share/opencode/opencode.db`）をその場で変換し、既存のセッションを同じセッション ID のまま 1 回だけ
  取り込みます。マネージド・ターミナル（CLI）のセッションはこれまでどおり再開できます。
- **オプトインの専用データは統合されません。** 以前に `opencode-major 2` を使っていた場合、専用データベース
  （`~/.local/share/agent-fleet/opencode2-data`）にしかないセッションは、ピン止めされた opencode 2 からは見えません。
  何も削除されません。不要になったら、このディレクトリと `~/.local/share/agent-fleet/opencode2` を削除してください。
- **opencode 1 に戻すとき。** `--build-arg OPENCODE_VERSION=1.19.0` を付けてイメージを再ビルドし、ワークスペースを
  再起動します。opencode 1 からは、アップグレード前の会話はすべて見えますが、opencode 2 で作った会話や、
  opencode 2 で足したターンは見えません。アップグレードを正確に取り消したいときは、このリリースでの最初の起動の前に
  `~/.local/share/opencode/opencode.db*` をコピーしておき、戻したあとに書き戻してください。
